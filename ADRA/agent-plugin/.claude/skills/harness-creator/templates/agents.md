## Definition of done

A feature in `feature_list.json` may only be marked `"status": "pass"` when:

1. It builds/compiles cleanly.
2. The verification commands in `${STATE_DIR}/init.sh` all pass.
3. `feature_list.json` has been updated with real `"evidence"` — actual command output, not a self-report.
4. No unrelated files were modified.

## Session handoff

At the end of a session, update `${STATE_DIR}/progress.md` and, for multi-session work, write `${STATE_DIR}/session-handoff.md` with what's done, what's next, and any blockers. The next session should be able to resume from those two files alone, without re-reading the whole conversation history.
