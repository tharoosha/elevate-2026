Task Manager Important Terms and Concepts
=========================================

Important Terms and Concepts
----------------------------

Before using Task Manager, it helps to know some basic terms to make learning and setting up Task Manager easier. The following are key terms and definitions used in the guides and training.  
  
**Auto-Recurring**  
The task type assigned to tasks that occur frequently and at regular intervals. This setting is assigned in the **Library**. Auto-recurring tasks cannot be added to a task list.  
  
**Companies**  
Created to mirror the legal entity structure of the organization. Companies may be useful for organizations with locations in multiple countries, for example, as they help to filter and sort tasks.  
Companies are created in **Administration>>Companies and Departments**, and assigned to tasks in the **Library**.  
  
**Co-Prepare**  
If the Co-preparer toggle is turned on for a task template in the Library, any team member with the preparer role can help complete tasks created from that template.  
  
**Departments**  
Created to match the actual departments within the selected team. For example, departments within the Finance Team might include Accounts Payable, Accounts Receivable, etc. Tasks can be sorted and filtered by Departments. Departments are created in **Administration>>Companies and Departments**, and assigned to tasks in the **Library**.  
  
**Extra Fields**  
Allow users to label tasks with additional information that can be used for sorting and filtering. Extra fields can be configured by an administrator to include text, numbers, or dates. Extra fields are created in **Administration>>Extra Fields**, and extra field details are added to tasks in the **Library**.  
  
**Library**  
Stores all the task templates within Task Manager.   
  
**Section**  
Tasks in the **Library** are organized into sections. Each section can include folders and sub-folders to further organize tasks.  
  
**Task**  
An action that must be performed as part of closing out the accounting period. Tasks are assigned to individuals or teams and can be performed in a specific order.  
  
**Task Code**  
A unique sequence of numbers, letters, and/or hyphens that is used to identify a task. Example: AP-228  
  
**Task List**  
A grouping of tasks based on a specific process or processes. For example, all payroll tasks that must be completed at the end of a particular month might be put onto one task list.  
  
**Preparer**  
The Preparer of a task is the person who completes the task and prepares it for review. For example, if the task is to "Schedule Payroll," the person who scheduled the payroll is the one who should prepare that task.   
  
**Approver**  
The Approver is the person who verifies that a **Prepared** task has been done correctly, then **Approves** or **Rejects** the task accordingly. For example, if someone prepares the task "Schedule Payroll" and schedules it for the wrong date, the Approver can reject the task and ask the Preparer to do additional work on it.   
  
**Team Admin**  
Administrators can assign the Team Administrator role to any user. The Team admin can edit tasks that the team is responsible for. For example, if a due date for a report attached to an Accounting team task changes, the **Admin** will amend the task to reflect the change.   
  
**Teams**

In Task Manager, a team is a functional group of users with Preparer, Approver, and/or Team Admin access rights assigned to specific tasks. Teams are essential because tasks must be assigned either to individual team members or to the entire team. Business Administrators are responsible for managing teams.  
Users can have roles in multiple teams, and be assigned all roles for their assigned teams.

**Read Access**

Administrators can assign Read access to users by navigating to **Administrator>>Users**, clicking the specific user, and checking **Read access** in specific teams. This allows the user to view but not handle tasks belonging to the specified Team.  
 

**Section Admin**

Administrators can assign Section Admin privileges to users by navigating to **Administrator>>Users**, clicking the specific user, and checking **Section Admin** in specific teams. This allows the user to manage task templates for assigned **Library** Sections.  
  
  
**Getting to Know Task Manager**

Understanding Task Manager begins by grasping the fundamental concept of tasks. At its core, a task is essentially a to-do item. The Task Manager efficiently organizes these tasks, empowering finance departments to plan and execute processes seamlessly.

What sets Task Manager apart from other to-do list management tools, such as Excel, is its tailored design for finance teams. It stands out as a best-in-class product, offering unique features specifically crafted for finance departments.

To effectively utilize Task Manager, Administrators must comprehend the concept of **Teams**. A task can be assigned to one team at a time, yet a task list can contain tasks assigned to different teams.   
Once task templates are set up in the system, Administrators can organize them into a Task List, a collection of tasks related to a specific process. For instance, Task List processes can be established for activities like "February Month End" or "2019 Audit." A Task List serves as a comprehensive roster of all tasks within a process, allowing users to understand that the process is complete when all tasks in the Task List are prepared and approved.

Tasks within the Task List follow a basic flow for completion:

1.  **Start:** Users indicate which tasks they are actively working on.
2.  **Prepare:** Tasks are marked as completed and prepared for review.
3.  **Review:** Someone reviews the work and approves or rejects the task.

In summary, Task Manager is a potent and adaptable tool designed to streamline the creation and organization of efficient and accurate workflows. Familiarizing users with the key terms and concepts outlined above will enable each organization to swiftly adapt to and leverage the full potential of Task Manager.
