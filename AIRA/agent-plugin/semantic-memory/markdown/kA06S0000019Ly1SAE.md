Adra - Balancer - Delete Comments
=================================

A no longer applicable comment can be deleted by the **original poster** in the **original period** in which the comment was created.

  
  
Navigate to **Balancer>>Accounts and Status** and select the applicable account. Ensure the correct period is selected in the drop-down in the left-hand menu bar.

The option to **Edit** or **Delete** comments will be active, as shown in the image below.  
  
  
![image](https://static.adra.com/adra-assistant/images/10984cc471434dc4724401b7ea7b1c28.jpg)  
  
  
  
If the setting Show comment from previous period is enabled in General settings, the comments from the previous period will dispay on the account in all of the following periods.  
To disable this, administrators can navigate to **Administration>>General Settings>>Other Settings>>Show Comments from previous periods**. Toggle the option to grey to disable it.  
 

![image.png](https://static.adra.com/adra-assistant/images/3215cd98257c037e79c54efc8f463e0c.jpg)
