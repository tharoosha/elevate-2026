Setup Create Access to Adra Success Center for Non-users
========================================================

To grant Success Center access to an individual who is not to have access to applications (a non-user), there are two options:

*   Reach out to Adra support
*   Create a user with no application access in Adra Setup

To create a user  in setup follow these steps:

1.  Navigate to **Setup>>Users>>Create new user**
2.  Add the individual's email, select an employer, and add first and last name
3.  Click **Save**

The non-user receives a verification email, and must click the link and create a new password.   
![image.png](https://static.adra.com/adra-assistant/images/7622d4279bb9f234c20f4b3e39dc68c7.jpg)  
The non-user should log in to Adra and navigate to **Help and feeback>>Success Center.**  
  
A Success Center profile is then automatically created, providing access for the non-user.  
If there are issues with the login, contact support@adra.com.
