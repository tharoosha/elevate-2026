Setup External App Integrations
===============================

The Integrations feature lets administrators set up links to apps and dashboards on the **Adra Setup Apps** page as shown in the figure below. This makes it easy to create shortcuts that are clear and user-friendly. It helps reduce manual work and lowers the risk of errors.

     ![image](https://static.adra.com/adra-assistant/images/45e83248ff81259331a971cba423d1a5.jpg)

 **BEST PRACTICES**: What links to use for each external application.

*   For **Excel**, **Tableau**, and **PowerBI**, link to a dashboard, spreadsheet, or report. The Analytics API sends data from Adra to these applications.
*   For **Workday** and **AAC**, link to the login page. If SSO is set up for both Adra and the external app, users can navigate seamlessly between them.

Add an Application
------------------

To configure the feature, navigate to **Setup>>Engagement>>Integrations**.

1.  Click **Add Application**. A pop-up opens.  
    ![image](https://static.adra.com/adra-assistant/images/8f1e4b620a98a4723121400d8c06741d.jpg)
    1.  **AAC (Adra Application Connector)** Grants AAC permission to communicate with the Integration Hub on behalf of this engagement. This feature is available for organizations that use connectors through AAC. If you are interested in connectors, reach out to your customer representative.  
        ![image](https://static.adra.com/adra-assistant/images/5ca71331bcb946928fc7f51a79eba026.jpg)  
        *   **Integration Hub Download Acess** \- Permits AAC to access downloaded reports.
        *   **Integration Upload Access** - Permits AAC to send balance and transaction data to the Integration Hub, which then uploads it to Balancer or Matcher.
        *   **Adra's authorization resources** - Grant read access to engagement details such as name, customer ID, and licensed applications. This allows AAC to identify which types of files (Balancer files, Matcher files, or both) are available for upload through the Integration Hub. This prevents AAC from configuring unavailable options, reducing the risk of failure. Additionally, this access enables AAC to display the engagement name correctly on their side. While this access can be denied and integrations will still function, AAC may need to perform additional steps to set up the integration correctly.
    2.   **Workday**, **PowerBi**, **Excel**, and **Tableau** have no additional options.
2.  Enter the **Integration Url**. This can be changed at any time. See Best Practices at the top of the page for recommendations.
3.  Enter a **Friendly name**. This can be changed at any time.   
    ![image](https://static.adra.com/adra-assistant/images/6977a497e4e3e0083c6ced52a4d7fe84.jpg)

When the application is configured, it appears on the Apps page.

 **HELPFUL HINT**:

*   To edit the Integration URL and name, navigate to **Setup>>Engagement>>Integrations**, and click the application to open the pop-up. Update the URL and/or the name.
*   To change the application access for connected applications, the application must be removed and reconnected. See below for steps to remove an application integration..

Remove an Application
---------------------

To remove a connected application, navigate to **Setup>>Engagement>>Integrations**.

1.  Click the **Expand** arrow
2.  Click **Remove Integration** or **Revoke Authorization**
