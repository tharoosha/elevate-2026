Task Manager General Settings
=============================

Engagement Settings allow additional engagement configurations for both functional and operational purposes. The figure below shows the available settings that can be enabled or disabled according to the preference of the organization.   
To manage settings, navigate to **Administration>>General Settings**.   
  
 ![image](https://static.adra.com/adra-assistant/images/e161b21ee7ceec7ce7502d925e5d92b0.jpg)

Enforce Segregation of Duties
-----------------------------

When Segregation of Duties is enabled, users cannot perform consecutive actions. For example, if John is assigned the role of Preparer for a specific task, he cannot approve that same task, even if he also has Approver permissions. Another user with Approver permissions must be assigned as an Approver for that task.

 **HELPFUL HINT**: Checklists can be added to tasks so that even if the sequence is allowed to be breached,  the checklist has to be completed to finalize the task.   

Allow Sequences to be Breached
------------------------------

**Allow sequences to be breached** is a feature that allows connected tasks to be completed out of order. If this setting is disabled, users need to wait until the preceding task is completed before the succeeding task can be completed. Connected tasks are the only tasks affected by the **Allow sequences to be breached** setting. Learn more about task sequences: [Task Manager Configure Task Sequences](#article:kA00H000000kJ6ESAU@Success-Center).  
 

Send Notification Email
-----------------------

When **Send notification email** is enabled, users will receive an email when tasks are assigned to them.  
For example; When a task list is started, assigned Preparer(s) immediately receives a notification e-mail about tasks that require action. When a task is prepared, the Approver immediately receives an e-mail about the task that requires action.

 **HELPFUL HINT**: If **Daily To-Do e-mails** are enabled, the tasks are included in the To-Do e-mail the morning after.  

   
The chart below shows which email notifications users receive when **Send notification email** is enabled / disabled.  
![image](https://static.adra.com/adra-assistant/images/c41d3cb8677f8d9d49b33eb6e9e94d9e.jpg)  
  
Regardless of whether this setting is enabled or disabled, preparers will receive Reminder emails.  
   

 **WARNING**: Note that daily to-do emails are not included in the **Send notification email** setting; use the **Enable daily to-do emails** setting to determine whether or not a user receives to-do emails.

          
   

Enable Daily To-Do Emails
-------------------------

Daily to-do emails are enabled by default, and administrators can turn them off by moving the toggle to the left (Off).   
When&nbs**Enable daily to-do emails** is set to the right (On), users will receive **one** daily reminder of to-do list tasks. This daily email regarding assigned Task statuses arrives in a user's inbox every weekday morning. The content is similar to the Task Manager **Home** page and displays overdue or upcoming tasks. To-do emails also include a list of **Upcoming Tasks** assigned to the email recipient and tasks assigned to Teams where the user is a Preparer. The email allows users to stay up to date without logging in to the application.  
 

 **HELPFUL HINT**: If a user is connected to several Engagements, they will receive one email for each Engagement.

Enable Certify Pop-up
---------------------

When enabled, a certification pop-up appears when users click prepare or approve on a task. Tasks with Internal control checked in The **Library** always receive a pop-up notification, regardless of this setting. 

Enable role-based dashboard access
----------------------------------

This option lets administrators restrict user access to the **Dashboard** page if needed.  
  
When enabled

*   Section Admins can only view tasks and task lists within their assigned section.
*   Standard Users cannot access the Dashboard.
*   Business Administrators can still view all tasks and task lists.

Enable Ad-hoc task creation for all users
-----------------------------------------

When enabled, all users, including standard users, can create Ad-hoc tasks in Task Manager.  
When disabled, only task Manager Administrators and Team Administrators can create Ad-hoc tasks.
