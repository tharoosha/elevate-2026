Task Manager Prepare & Approve Tasks
====================================

Preparers and Approvers
-----------------------

A user can prepare and/or approve a task if the following conditions are met:

*   The user is assigned the Preparer role in the team - Learn more [Task Manager Create & Manage Teams](#article:kA00H000000kJ5QSAU@Success-Center)
*   The task is assigned to the user directly, OR the task is assigned to the team - Learn more [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center)
    *   **For preparers** \- Multiple Preparers on the same team can collaborate on a task if the Co-Preparer setting is enabled for the task - Learn more [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center)
    *   **For approvers** - If a task requires multiple approvals, any team member with the Approver role can approve it until the required number of approvals is reached. 

How To Prepare and Approve Tasks
--------------------------------

To prepare, approve and view the details for a task, click the task on one of the following pages in Task Manager:

1.  **Home**
2.  **Tasks**
3.  **Task Lists**

Below is an example of a task page, which varies based on its status and your access level.

![2024-11-19_18-54-54.png](https://static.adra.com/adra-assistant/images/952a8524c00990b7f0d5f1b3568cecd3.jpg)

1.  **Manage Tasks** - These buttons allow users to:
    *   Configure **Preceding Tasks** and **Succeeding Tasks**: See [Task Manager Configure Task Sequences](#article:kA00H000000kJ6ESAU@Success-Center) to learn more.
    *   View **Audit Trail**: Click to view who changed what and when.
    *   **Change status**: Click to alter the task's current status to not started, Prepared, and closed, depending on the current status. See [Task Manager Edit Active Tasks](#article:Task-Manager-Edit-Active-Tasks@Success-Center) to learn more.
    *   **Edit Details**: Change who the task is assigned to, the due date, the company, and the department. See [Task Manager Edit Active Tasks](#article:Task-Manager-Edit-Active-Tasks@Success-Center) to learn more.
2.  **Purpose and Description** - Added and managed in the **Library** by an Administrator. See [Task Manager Library & Manual Task Creation](#article:kA00H000000kJ5kSAE@Success-Center) to learn more.
3.  **Documents** \- Click **Upload files** or drag and drop files to add documentation to the task. 
4.  **Comments** \- Enter a comments regarding the task. Use the @ symbol followed by a name to tag and notify another user. The tagged user receives an email with a direct link.

![image](https://static.adra.com/adra-assistant/images/1fed7c5a2cfd20feac91b7ca030b96a5.jpg)

5.  **Action Button** - This button changes depending on the task's status. The options are to **Start**, **Prepare**, and **Approve**.

 **HELPFUL HINT**: If any of these sections are not available to you and you expect them to be, reach out to an administrator regarding user role assignment (Preparer, Approver, Team Admin)

Task Conditions
---------------

In some instances, a task might need certain conditions met before it can be Prepared:

*   **Task Sequence** - If a task is in a sequence, the preceding task might be required to be completed before the succeeding task can be Prepared. This depends on if the task sequence can be breached. See [Task Manager Configure Task Sequences](#article:kA00H000000kJ6ESAU@Success-Center) to learn more.
