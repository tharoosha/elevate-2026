Setup Manage BPO Organization Engagements
=========================================

View Engagements Connected to the BPO Organization
--------------------------------------------------

To view all engagements connected to the BPO Organization:  
  
1\. Navigate to **Setup>>Organization**.  
2\. Click the **Engagements** tab.  
  
A list of all engagements connected to the BPO organization displays, including those that are managed by another employee of the BPO.  
![image.png](https://static.adra.com/adra-assistant/images/5dee7c3fcdef6545639f76a3ca4a1693.jpg)

  
View Managed Engagements
---------------------------

BPO Admins can view the engagements they manage. To view only the engagements you manage:

  
1\. Navigate to **Setup>>Engagements**.  
![image.png](https://static.adra.com/adra-assistant/images/9df71f4bab105b6d32ce8248e3f9a967.jpg)

Note that the number of engagements you manage may not be the same as the total number of engagements connected to the BPO Organization.
