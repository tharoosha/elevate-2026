Task Manager Create Task Templates
==================================

Task templates can be created manually or be imported in bulk. To learn how to import and update task templates, see [Task Manager Import & Export Task Template](#article:kA00H000000kJ5uSAE@Success-Center).

Before adding task templates, ensure that the correct folders and sections are in place. To learn more, see [Task Manager Manage the Library](#article:kA00H000000kJ5kSAE@Success-Center)

Individual tasks can be added and edited on the **Library** page.

![image](https://static.adra.com/adra-assistant/images/2d2aa71a0006a6b11a9973caa2223169.jpg)

*   **Create new task manually** - Click the **three dots** next to the section or folder where the task will reside, then select Create task template.
*   **Edit existing task** **manually** \- Navigate to the folder or sub-folder where the task is located, then click the **Edit** (pencil) icon.

  
  
**Creating Tasks Workflow**  
![image](https://static.adra.com/adra-assistant/images/c26fd4959cc2d4ca792cd20b00ec26c3.jpg)

### Task Template Details and Assigned Users

### ![image](https://static.adra.com/adra-assistant/images/382c56d3120f9e1cc0938285a136fa7d.jpg)

1.  **Name and code** – Enter name and code.
    *   It is recommended to enter a descriptive task name.
    *   The code can for example include the relevant company code followed by an identification number. For example, if the company code is US001, the task code might be US001-10025.

![image](https://static.adra.com/adra-assistant/images/a09a50a1221019c867e550b0c40e5897.jpg)

2.  **Assigned user(s)** – Select the responsible team and users
    *   **Team** \- Select the team that is responsible for this task.
    *   **Preparer** \- Select a specific user or select **Team**. 
        *   If a specific user is selected, this user is the main user responsible for the preparation of the task.
        *   If **Team** is selected, any user with the preparer role can prepare the task. To learn more about assigned roles, see [Task Manager Create & Manage Teams](#article:kA00H000000kJ5QSAU@Success-Center)
    *   **Allow Co-Preparer** 
        *   *   **ON -** Any team member with the Preparer role can collaborate on and complete the task simultaneously.
            *   **OFF -** Only the person who starts the task can work on and complete it.
    *   **Number of approvers** \- Select one, several or no approvers.
        *   Select **1 approver** to have an additional field appear, which permits selecting a specific user who must approve the task. 
        *   Select multiple approvers to require that number of approvals for the task to be finalized. Make sure the selected team has enough users with the Approver role assigned.
        *   Select **No approvers needed** to have the task be finalized after it has been prepared.
    *   **Approver** \- If 1 approver is selected in the previous field, the Approver field appears. Select a specific user or **Team.**
        *   Select **Team** to allow any team member assigned the approver role to approve the task.
        *   If the **Segregation of duties** is enabled in the **Engagement Settings**, the Preparer and Approver must be different users. 

![image](https://static.adra.com/adra-assistant/images/c3b85aefa0b800a891ef0e376eafa1e3.jpg)

3.  **Description and procedure** – Enter a description and procedure to define the task. Insert a hyperlink or attachments to include external resources such as the how the task needs to be completed. 

 **BEST PRACTICE**: Create a detailed description and procedure to make knowledge transfer more seamless. This is especially helpful when new employees are assigned the task, or if there a user is out of office for a period of time. It is recommended to write or attach a step by step description of how the task needs to be completed in the **Description** field. Additionally, the Description and Procedure content can be used by the AI to create checlists.

4.  **Task due time and duration**
    *   **Task due time** – Enter the time of day the task is ideally expected to be completed. This is a guideline only and does not restrict when the task can actually be performed. 
    *   **Expected completion time** – Enter the average time it takes to complete the task. It is recommended to update this metric regularly to help track actual completion times and identify potential bottlenecks.

![image](https://static.adra.com/adra-assistant/images/bf23a80b856f0316d2082a7a6d8f94e2.jpg)

5.  **Task type**
    *   **Task list** – Select to create a task that can be added to task lists. Go to **a.** below to learn more.
    *   **Auto-recurring** – Select to automatically generate tasks at specified intervals. These tasks cannot be included in a task list but are directly assigned to the designated user(s). Go to **b.** below to learn more

![image](https://static.adra.com/adra-assistant/images/b9c160ca970b5fe3c51b8107b2057fcc.jpg)

1.  1.  **Task Type: Task List**
        *   **Offset zero-day** – Select how many days **Before** or **After** the ZERO-day the task should be due. The ZERO-day is a reference point set when task lists are created, and all tasks are scheduled around it. Offset ZERO-day can be set to 90 days before or after the ZERO-day. To learn more about Zero day, see [Task Manager How to Use ZERO-day](#article:kA00H000000oPNnSAM@Success-Center).
        *   **Include non-work days** - Check to allow the task to calculate the ZERO-day offset regardless of weekends or holidays.

![image](https://static.adra.com/adra-assistant/images/f3d07680417c447531d4face307e1445.jpg)

1.  2.  **Task Type: Auto-Recurring -** Auto-recurring tasks are auto-created at certain intervals and cannot be added to a task list.
        *   **Repetition** – Select task frequency (daily, weekly, monthly, or yearly). For all repetition types, admins can select how many days before the task's due date it should be created.
            *   **Daily** – Select task frequency, such as daily, every second day, etc.
            *   **Weekly** – Select task frequency, such as weekly, every second week, etc. Check one or more weekdays.
            *   **Monthly** – Select task frequency such as every month, every two months, etc. There are two monthly repetition options.
                *   **Repeat on a day** – Select a specific month date.
                *   **Repeat on specific day of the week** – Select the week (first, second, third, fourth, last) and the day of the week.
            *   **Yearly** – Select if the task should repeat every year, every second year, etc. There are two yearly repetition options.
                *   **Repeats on a day of month** – Select month and date.
                *   **Repeats on a specific day in a week of a month** – Select the week, day, and month
        *   **Repetition settings**
            *   **Activate recurrence** – Toggle to **On** to auto-create tasks. Specify the start date if needed.
            *   **End recurrence** – Toggle to **On** and select date to end auto task creation if needed.

 **BEST PRACTICE**: For tasks that repeat frequently, such as more often than every two weeks, it is recommended to use the task type **Auto-Recurring**. These tasks will not show when a task list is created. For less frequent tasks it is recommended to select task type **Task list**.

![image](https://static.adra.com/adra-assistant/images/4063243d2d41a60d0ace6159cdee1b91.jpg)

6.  **Set Reminder and Time Zone**
    *   **Set reminder** – Select if and when the assigned preparer is to receive a notification email. This setting is not impacted by notification settings in **General Settings**.
    *   **Time zone** – Select a different time zone from the engagement's setting if assigned users operate in a different time zone. This ensures that the due time displays accurately for that user.

### Optional Task Details

![image](https://static.adra.com/adra-assistant/images/257f1315ec39afcd123d58610bff62f4.jpg)

7.  **Attachments** – Click **Upload files** to add an attachment. These files can be documentation required to complete the tasks (templates, forms, reference documents), or a step by step guide for the task. This helps with onboarding, efficiency and accuracy, and it provides an audit trail.

![image](https://static.adra.com/adra-assistant/images/2f570e3a23f931e9aec81a5cb5863277.jpg)

8.  **Checklist** – Add or manage checklist items. To learn about the AI-assisted checklist feature, see [AI-Generated Task Checklists](https://success.adra.com/s/share-playlist?vtui__p=hkmgKemdFuqSSIqX3vuU7fx2TvjRb2LpTr0XUc7sRXmlkP%2FctGmy7JOsspi5Qbu560tobpLF2pYorEwu838nRU2bJGlme12XVlCiZkN%2B3j6r6tb1WriVcv9cZcY2elfYoyYP6WQIIanp%2FMXdSnpYGjWDa8pwORTB09U4mRU8LJ6yuq0U9GaGqjPGcdxe4eYi&iospref=web). 
    1.  **Checklist must be completed before the task can be prepared** - Enable if applicable. To learn more, see [Task Manager Checklists](#article:kA0Ua0000001JbhKAE@Success-Center).

![image](https://static.adra.com/adra-assistant/images/d9e9a647c5f6fde077bc1d292aeb0e4b.jpg)

9.  **Additional information** – Select additional labels for the tasks. These labels are used to sort and filter tasks in various Task Manager lists, which is especially helpful during task list creation to for example only view monthly or quarterly tasks.
    *   **Company** - The options available in this dropdown depend on the companies created by administrators under **Administration>>Companies and Departments**.
    *   **Department** \- The options available in this dropdown depend on the companies created by administrators under **Administration>>Companies and Departments**. To learn more, see [Task Manager Create a Company or Department](#article:kA00H000000kJ5VSAU@Success-Center)
    *   **Frequency -** Select whether the tasks frequency is Ad-hoc, Monthly, Bimonthly, Quarterly, Every four months, Half year, yearly or a specific month. This information allows for additional filtering capabilities during task list creation.
    *   Internal Control – Check to trigger a certification pop-up even if the Enable certify pop-up is off. This detail can also be used to filter tasks in the task grids.

![image](https://static.adra.com/adra-assistant/images/69a9571cf0914ce4739403a1fce94979.jpg)

9.  **Extra fields** – Enter applicable details if Extra fields have been configured in Administration. This feature adds additional task filtration capabilities on the **Tasks,** **Task list** and **Dashboard** pages.
    *   Administrators can create extra fields by navigating to **Administration>>Extra field Configuration**. To learn more, see [Task Manager Extra Fields](#article:kA00H000000kJ5fSAE@Success-Center).
    *   The Content for the Extra Fields can be manually populated in library as shown in the image above, or uploaded in bulk through an Excel spreadsheet.

When the all task template details have been completed, click save at the bottom of the page.
