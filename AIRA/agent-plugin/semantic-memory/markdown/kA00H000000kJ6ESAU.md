Task Manager Task Reminders
===========================

 

 **BEST PRACTICE**: This functionality is beneficial for larger teams. If an Administrator needs to alert users they have outstanding tasks, they can send a reminder for multiple tasks.

To send the alert:

1.  Navigate to **Task Manager****\>>T****ask lists>>Opened**

![image.png](https://static.adra.com/adra-assistant/images/7a0cf55766cc61dfae4b0b578f9d9f88.jpg)

2.  Click the desired task list(s) for which a reminder needs to be sent.

![image.png](https://static.adra.com/adra-assistant/images/51795764b8ace54dd88b8ae8cea06d34.jpg)

3.  Check which tasks need a reminder sent.
4.  Click **Edit>>Send reminder.**
5.   A preview box will appear, allowing users to review the selected tasks before sending the reminders. Once satisfied with the chosen tasks, click **Send reminder**.

  
Once sent, the message shown below will appear at the top center of the page, confirming the **Notifications sent successfully**.  
![image.png](https://static.adra.com/adra-assistant/images/2f1f5830100889fa1989caf4ce21fb7c.jpg)  
 

 **HELPFUL HINT**: Tasks can be sorted and filtered to simplify the selection process. For example, click the Due header to sort tasks in ascending or decendig order according to due date. To apply a due date filter, click the filter icon next to the Due header.
