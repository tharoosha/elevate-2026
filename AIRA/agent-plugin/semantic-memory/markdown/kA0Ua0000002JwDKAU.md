Unmatched Items Tab
-------------------

![image](https://static.adra.com/adra-assistant/images/4777b02f7506d4c8c48bf4866dbbf3ed.jpg)

1.  **Reconciliation Group** - Click the dropdown or arrows to select the desired Rec. group.
    *   Click the paper icon to add or edit the reconciliation groups memo. To learn more, refer to [Related Articles](#related-articles).
2.  **Action buttons** \- See relevant sections in this article for more information about these features.
    *   **View selected** \- Toggle to on to only display items currently selected in the grid. 
    *   **New Journal** - Click to add journal entry items. This option is only available if the Journal Entry application is enabled for the organization.
    *   **Find matching suggestions/Suggestions found** - Click to find system-defined matches. This option is only available if the setting is enabled for the group.
    *   **Export** \- Click to export items to Excel.
    *   **Views** \- Click to save or switch the current grid view.
    *   **Grid Settings -** Click the settings icon to manage grid columns, filters, and settings for suggested matching.
3.  **Filter** \- Click the funnel icon in any column header to filter transactions based on column content. 
    *   Double-click any line item to expand and view additional details.
4.  **Match items** \- Select transactions and click to match. Bank items are shown in yellow, and the ledger is shown in blue.
    *   This option is only available if the sum of selected transactions equals 0 or is below the reconciliation group threshold.
5.  **Generate an assisted matching rule** - Click to create a new automatic matching rule. The rule can then be managed and edited on the **Matching rules** page.
    *   To learn more, see [Matcher Assisted Rule Configuration](#article:Matcher-Assisted-Rule-Configuration@Success-Center).
6.  **Additional Options (Ellipsis)** \- Click to send items to Balancer, group transactions, add items manually, view selected items and add text to multiple items.
7.  **Amounts** \- View any remaining variance between the selected items in the **Remaining amount** box, as well as the sum of the selected bank and the ledger items. See [Remaining Amount](#remaining-amount) for more details.

### Remaining Amount

![image](https://static.adra.com/adra-assistant/images/23fd33083a83c0439b422fa21401cd09.jpg)

1.  Select one or more **items** on the exceptions grid.
2.  The sums for bank and ledger items populate automatically, along with the remaining amount.
3.  Click the **Remaining amount**. A pop-up appears, and any possible matches are shown.

![image](https://static.adra.com/adra-assistant/images/371f7c05291372a7c57f352795631b1a.jpg)

4\. Check the box to select a match.

5\. Click **Cancel** or **Match selected** accordingly.

### Save and Manage Grid Views

The Unmatched Items tab permits users to save their preferred column order.  
To save a view, follow the steps below:  
![2024-06-20_11-46-33.png](https://static.adra.com/adra-assistant/images/e6de4c032daa2df525822da75448ea4b.jpg)

1.  Click the settings icon and enable or disable columns.
    *   Click and drag column headers in the grid to reorder them if needed.
2.  Click **Views**. 

![2024-06-20_11-50-09.png](https://static.adra.com/adra-assistant/images/438eef498b966d22c8a6c8726c15627e.jpg)

3.  Click **Save current view**

![2024-06-20_11-53-14.png](https://static.adra.com/adra-assistant/images/052a42e0398605a757f59bc188452678.jpg)

4.  Select a saving option.
    *   **Replace** **last loaded** **view** \- Click to overwrite the current view.
        *   Note that replacing the **Default shared group view** changes it for all users.
    *   **Save as a new view** \- Click to create a new personal view that only you can use.

![2024-06-20_12-12-03.png](https://static.adra.com/adra-assistant/images/97389cd74cea134655ca005832c1f55f.jpg)

5.  Click **Views** again and select the desired view.

### Add Text to Multiple Items

To add text to multiple items at once, follow these steps. 

![image](https://static.adra.com/adra-assistant/images/8d5e20cfa060a06f0293af06e64f5def.jpg)

1.  Select transaction items to add text to.
2.  Click the ellipses at the bottom of the page. 
3.  Click **Add text to selected (max 5000)**.

![2024-03-21_15-08-27.png](https://static.adra.com/adra-assistant/images/7e00b40a978f309e9e9b78138627779f.jpg)

4.  Select which text field to add text to, enter the text to be applied in the text field, and click **Add**. 
5.  The text will appear on the **Unmatched Items** page in the specified column.

### Group Unmatched Items

As partial matches are identified, transactions can be grouped on the **Unmatched Items** screen. This allows users to track progress on partial matches and saves time when investigating exceptions.  
  
To group unmatched items, navigate to **Exceptions>>Unmatched items**.

![image](https://static.adra.com/adra-assistant/images/a2234d242c716f3132348f5bf00b4728.jpg)

1.  Select transactions from one account.
2.  Click the **ellipsis.**
3.  Click **Group Transactions**.

A pop-up window displays. The **Date**, **Reference**, and **Extra Fields** are prepopulated with information from the newest transaction item in the group. These fields can be edited by the user.  
The **Sum transactions** field is prepopulated and cannot be changed.

4.  Edit the prepopulated fields and enter **Comments**, if desired.
5.  Click **Group Transactions**.

![click group transactions](https://static.adra.com/adra-assistant/images/ae6844824c9d44ff65076e870b89bc04.jpg)

The grouped transactions display as one item on the **Unmatched Items** screen, and the Amount shows the sum of all transactions in the group.  
The **grouped items icon** displays next to the **Account Number**, indicating that the item contains multiple transactions.

![image](https://static.adra.com/adra-assistant/images/d95538d5a13f0965a171da125975a7de.jpg)

  
 

#### View Items in a Transaction Group

To view the items included in a transaction group:

Click the **information icon** in the **Details** column of the grouped item.

![2024-03-20_18-48-20.png](https://static.adra.com/adra-assistant/images/ab87521a3e0cddde35f8d8106085bfcf.jpg)  

The individual transactions are included in the group display.

![image](https://static.adra.com/adra-assistant/images/e649d97ecdb9345ff80aac4e53487329.jpg)

#### Undo Grouping of Transaction Items

To undo the grouping of transaction items:

1.  Click the **information icon** in the Details column of the grouped item.
2.  Click **Undo Grouping**.

![image](https://static.adra.com/adra-assistant/images/69260b959ae0a26e58f80f439423dc3f.jpg)  
The items from the transaction group then display as individual items on the Unmatched Items screen.
