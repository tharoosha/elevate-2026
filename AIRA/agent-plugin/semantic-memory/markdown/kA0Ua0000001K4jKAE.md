Task Manager Checklists
=======================

Administrators can add checklists to tasks to ensure processes are followed. Checklists can be created manually or through the use of Adra's AI-Generated Task Checklist feature.  
The Tasks page allows all users to export an Excel file containing all task details displayed in the grid, including checklist details if the columns are activated.  
 

Create Checklist Manually
-------------------------

Administrators must first add checklists to task templates in the **Library**.  
  
To do this, follow the steps below:

1.  Navigate to **Task Manager>>Library**, and locate the task.![2024-06-19_11-32-02.png](https://static.adra.com/adra-assistant/images/f15afd8945ffb5e54629044ddba6bd6a.jpg)
2.  Click the **edit** icon on the task.

![2024-06-19_11-37-18.png](https://static.adra.com/adra-assistant/images/3342b2b4d77fe706080860aee8954602.jpg)

3.  Scroll down to the **Checklist** section. 

  ![2024-06-19_11-40-23.png](https://static.adra.com/adra-assistant/images/489538478c4bde38546ffc0404eaf79c.jpg)

4.  Enter checklist text and click **Add to checklist** until the list is complete.
    1.  Click and drag tasks by the left-side handle to reorder them.
    2.  Click the edit icon to edit the checklist item.
    3.  Click the recycle icon to delete an item.
5.  Toggle **Checklist must be completed before the task can be prepared** if needed.

  
The checklist is now available for the assigned users to complete on the tasks page as shown in the example below.  
![2024-06-19_12-08-34.png](https://static.adra.com/adra-assistant/images/9c7955484e45a327ccf7bfee54e04b7b.jpg)

AI-Generated Task Checklists
----------------------------

The AI-Generated Task Checklist provides a tailored checklist based on a task's description and known procedures. This feature leverages AI to interpret context, recognize patterns, and suggest actionable steps. Users can either accept the checklist as-is or modify it to fit their specific needs.

For more information on AI-Generated Task Checklists, [watch this video](https://success.adra.com/s/share-playlist?vtui__p=hkmgKemdFuqSSIqX3vuU7fx2TvjRb2LpTr0XUc7sRXmlkP%2FctGmy7JOsspi5Qbu560tobpLF2pYorEwu838nRU2bJGlme12XVlCiZkN%2B3j6r6tb1WriVcv9cZcY2elfYoyYP6WQIIanp%2FMXdSnpYGjWDa8pwORTB09U4mRU8LJ6yuq0U9GaGqjPGcdxe4eYi&iospref=web).

To use the AI-Generated Task Checklist feature: 

1.  Click the **edit** icon for the desired task template in the Library.
2.  Under **Checklist**, click **AI Generate checklist**.

![image](https://static.adra.com/adra-assistant/images/a59cef510196910449ce9cee4267ea65.jpg)

3.  Use the **edit** icon to modify the checklist item. Use the **delete** icon to remove a checklist item.
4.  Click **Add**.

![image](https://static.adra.com/adra-assistant/images/026667dc05d8b147acd45b580ffc4526.jpg)

5.  On the task template, click **Save**.

Checklists on the Tasks Page
----------------------------

To enable the checklist column on the **Tasks** page, click the **settings** icon in the upper right corner. Scroll down in the settings menu and toggle **Checklist** and **Completed checklist items** to on.   
![2024-06-19_12-48-30.png](https://static.adra.com/adra-assistant/images/57e94c1d9d0cb38f84f5bd3e73f5d648.jpg)  
In the **Checklist** column, completed items are marked with '**\- 1**', and incomplete items with '**\- 0**'. Each list item is separated with an asterisk **\*.**  
In the Completed checklist items column only completed items are listed, also separated by asterisk \*.
