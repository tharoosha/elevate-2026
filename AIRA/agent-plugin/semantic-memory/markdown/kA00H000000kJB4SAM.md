Matcher Export to Balancer
==========================

Export Unmatched Transactions to Balancer
-----------------------------------------

Exceptions and unmatched transaction data and the account balance can be sent from Matcher into Balancer to help complete reconciliations. It is recommended to send transactions to Balancer when all matching in Matcher has been completed. If the reconciliation group has two sources (for example Ledger and Bank) the accounts balance is sent as a line item to the Balancer account for reconciliation.   
  
There are two ways to send transactions:

1.  Navigate to **Exceptions>>Unmatched items**
2.  Navigate to **Recon. Groups and Details**.
    *   This option allows users to transfer transaction for multiple reconciliation groups at once. Learn more here: [Matcher Recon Groups and Details](#article:kA00H000000482HSAQ@Success-Center)

The Exceptions Page
-------------------

![image.png](https://static.adra.com/adra-assistant/images/a5393619b22be41bab08077755f8511b.jpg)

1.  Navigate to **Exceptions>>Unmatched items**.
2.  Select a reconciliation group in the upper right-hand corner.
3.  Click the **three-dot** icon and click **Send to Balancer**.

![image.png](https://static.adra.com/adra-assistant/images/ef7beb3d583d07ff9348c45d1fdc502d.jpg)

4.  In the pop-up, select which period to send and click **Send to Balancer**. Periods marked with an asterisk \* have already been sent. Resending transactions may lead to duplicate entries in Balancer.
    

Items appear in the Balancer account with the status **Balance Detail**, saving users from manually selecting statuses if **Require status on all transactions** is enabled in Balancer's **General Settings**.

 **WARNING**: Take note of the details below before sending open items and account balance to Balancer.

*   **Resending Items** \- If transactions are sent and changes are made in Matcher, sending them again will create duplicates. It's not possible to select specific transactions to send; every time transactions are exported, all unmatched transactions are sent. 
*   **Which Items are Sent** - Transactions that were open during the period that is being sent are included, even if they have been matched in a later period. For example, if an item has a booking date in January and is matched in March, selecting February when sending items to Balancer will include this transaction since it was open during February.
*   **Number of Items Sent** \- All open transactions from the reconciliation group are sent to Balancer, regardless of how many are shown on the unmatched items tab during the sending process. The maximum number of items that can be sent is 5,000. If the number of open items exceeds 5000 do one of the following:
    *   Group items, like diffs, to reduce the number of items. 
    *   Export the items and attach the file as documentation in Balancer.
*   **Currency** \- It is recommended to upload exchange rates from the ERP system before uploading the balance. This ensures that open items are correctly converted into the legal entity’s currency. If exchange rates are uploaded afterward, each account can be manually updated to reflect the new rate.

In Balancer
-----------

The transfer job, labeled **Import items** by **SYSTEM SYSTEM**, appears on Balancers **Jobs** page. Click the **Log** button to review any errors. If the status of the job is **Waiting for upload**, allow for some processing time.

![image](https://static.adra.com/adra-assistant/images/a9974a6ab49d0b8fcc7d30509f14b0bb.jpg)

In Balancer, the line items appear in the relevant account. If the reconciliation group had two sources, the first line item is the reconciliation groups balance, labeled Balance (External). The source two account number appears automatically in the **Text** field of the balance line item.

![image](https://static.adra.com/adra-assistant/images/7c64ffea2b7998bc77c1ac8b1c61df76.jpg)
