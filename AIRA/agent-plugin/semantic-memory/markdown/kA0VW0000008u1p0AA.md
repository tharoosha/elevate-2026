Journal Entry Posting Accounts
==============================

To enable users to create journal entries in Journal Entry, administrators must first upload a list of approved posting accounts. This feature ensures accuracy and compliance while minimizing the risk of errors. When users create journal entries, the legal entity must first be selected. This determines which accounts are available in the account number drop-down.

 **HELPFUL HINT**: In Matcher, account numbers are entered in the account number field when creating journal entries.

Create Account Lists
--------------------

To create the account lists, follow the steps below:

![image](https://static.adra.com/adra-assistant/images/163a3f0753660d063753ca39d1cf9ba7.jpg)

1.  Navigate to **Administration>>Posting Accounts**
2.  Click **New list**

![image](https://static.adra.com/adra-assistant/images/dd5da7a062e4746aae702e3f5fcc07a2.jpg)

3.  Enter a descriptive name
4.  Click **Save and Continue**

![image](https://static.adra.com/adra-assistant/images/733321bf94693489e454a7f9e1d70cd4.jpg)

5.  To add new accounts
    *   Click **New Account** to create account details manually
        *   Enter **Account Number** and **Account Name**
    *   Click **Import Accounts** to manually upload a list of accounts. For detailed instructions, continue to [Import Account List](#upload-account-lists).

![image](https://static.adra.com/adra-assistant/images/36ceff3e280859b19180ca8cc21944e0.jpg)

6.  Select one of more legal entities the accounts will be linked to. If multiple legal entities share the same chart of accounts, select more than one entity.
    *   Use the funnel icon in the header to filter the legal entities.
    *   Click **View Selected** to only view the legal entities selected in this step.
7.  Click **Save**

The new list can be edited and managed from the **Posting Accounts** page, where multiple lists can be created. When creating a journal entries, users must first select a legal entity, which determines the available accounts in the account number field. To learn more, see [Journal Entry - Journal Entries Page](#article:kA0Ua0000004XOnKAM@Success-Center)

Upload Account Lists
--------------------

After clicking Import Accounts in the previous section, the pop-up below displays.

![image](https://static.adra.com/adra-assistant/images/cdce28f846ebb10d3ac7cf2e87414d13.jpg)

1.  Click the **blue link** to download a template and format discription for the import file. The file can be an Excel file or a tab delimited Text file.  
    The format is:
    *   **Column 1** - Account number. This field is mandatory.
        *   The can contain up to 64 characters, including numbers and letters.
    *   **Column 2** - Account name. This fields is optional, but recomended to provide context.
        *   The fields can contain up to 200 characters, including numbers and letters.
2.  Once your file includes all the necessary accounts and details, drag it into the upload field or click **Select file** to find and upload it.
3.  Click **Import**

The new accounts can be viewed, edited and reimported on the **Posting Accounts** page.

![image](https://static.adra.com/adra-assistant/images/241c375330cf2f1105193ff120f703c9.jpg)
