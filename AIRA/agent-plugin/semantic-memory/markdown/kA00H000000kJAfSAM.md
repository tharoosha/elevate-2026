Matcher Fiscal Years & Periods
==============================

At the start of each fiscal year, a new fiscal year must be created in Setup by the Financial admin. Failure to do so will prevent users from being able to complete work in the new fiscal year. For information on how to create fiscal years and periods, see [Setup Create & Manage Fiscal Years](#article:kA00H000000kJ9cSAE@Success-Center).

 **HELPFUL HINT**: Users who need to create a fiscal year for use in Matcher need Financial admin privileges assigned in Setup.  Learn how to configure users here: [Setup Create New Users In](#article:kA00H000000kJ5LSAU@Success-Center) [Adra](#article:kA00H000000kJ5LSAU@Success-Center)[](#article:kA00H000000kJ5LSAU@Success-Center)

After fiscal years and periods have been created, they can be imported into Matcher.

To import fiscal years and periods:

![Click Import Fiscal Years/Periods](https://static.adra.com/adra-assistant/images/a9944f601094d7feecf4421145a26a08.jpg)

1.  Navigate to **Matcher>>Administration>>Fiscal Years**.
2.  Click **Import Fiscal Years/Periods**.

![MFY2.png](https://static.adra.com/adra-assistant/images/0026adbb1d013496069180c36c1c3227.jpg) 

3.  Check **Import** on any fiscal years that need to be imported.
4.  Click **Complete Import**.
