Task Manager User Page Overview
===============================

The **Users** page allows administrators to manage standard users privileges, includig read access, section admin, team admin, preparer and approver responsibilities.  
  
Navigate to **Administration>>Users** and click a users name.  
![image.png](https://static.adra.com/adra-assistant/images/74dd266b34a19362f9be0091cd307809.jpg)

The users page loads, and the **Grant team roles** tab is selected by default.  
Below is an explanation of each privilidge that can be assigned to users.   
![image.png](https://static.adra.com/adra-assistant/images/8d83d3ccd6ff15a31957aa64b4724548.jpg)

1.  **Read access** - Check the applicable box for specific teams to permit the selected user to view all tasks assigned to those teams. However, they are unable to create, approve, or make any alterations to the tasks. This privilege applies to the **Dashboard**, **Tasks** and **Task Lists** page.
2.  **Preparer and Approver** \- Check the applicable boxes for specific teams to allow a user to act as the preparer or approver for tasks assigned to a specific team. Users without assigned preparer or approver privileges cannot be selected as preparers or approvers for specific task templates in the **Library** or for active tasks.
3.  **Team admin** - Check the applicable boxes for specific teams to allow a user to view and manage all team-assigned tasks in active task lists, including editing details such as due date, Preparer, Approver, etc. Additionally, team admins can send task reminders.

Click **Save changes** when desired changes have been made. 

Section Admin Access 
---------------------

The purpose of the **Section Admin** role is to provide **targeted administrative access** to specific sections of the Task Manager library without granting full system-wide admin privileges. The access level of the user is    
![image.png](https://static.adra.com/adra-assistant/images/8db389db2e90f29d6211ba11f6c7b865.jpg)  
Check the desired **Library** section the user will have access to and click **Save changes**.  
The user can then manage task templates within that section, including updatig all task template details, exporting and importing settings.
