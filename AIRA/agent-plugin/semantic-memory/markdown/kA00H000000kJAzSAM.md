Overview
--------

The **Exceptions** page is where users will spend the majority of their time matching transactions that were not matched during the automatic reconciliation.

Navigate to **Exceptions** in the left-hand menu.

 **HELPFUL HINT**: Double-click any line item to expand and view additional details.

![image](https://static.adra.com/adra-assistant/images/7882376510b7499882cd8b5806989b6b.jpg)

1.  **Exceptions tabs**
    *   **Unmatched Items** - View, manage, and match unmatched items, register items manually, and send items to Balancer. 
        *   To learn more about the unmatched items tab, see [Matcher Exceptions Unmatched Items](#article:kA0Ua0000001K4jKAE@Success-Center).
    *   **Matched Items** - View, manage, export, and unmatch matched items.
    *   **Journal Entry** - Journal entries can be created if the organization uses the Journal Entry application.
        *   To learn more about Journal Entry, see [Matcher Journal Entry](#article:kA06S000000YQcgSAG@Success-Center).
2.  **Memo** \- Click the paper icon to add important notes and information on the specific Reconciliation Group. To learn more, see [Matcher Memo](#article:kA0Ua0000005M37KAE@Success-Center).
3.  **Reconciliation groups** - Select a Rec. group to display on the exceptions page using the dropdown or navigation arrows.
4.  **Action buttons** \- These buttons vary across the **Exception** tabs. Take a look at each section below for more information.

 **HELPFUL HINT**:

There are two helpful ways to locate specific reconciliation groups.

*   Click the Rec group drop-down and check **Only show Reconciliation Groups with unmatched items**.
*   Click the Rec Group drop-down and enter the name of a Rec Group in the search field to locate it.

![2024-03-20_17-25-13.png](https://static.adra.com/adra-assistant/images/d15b34ca0a8215a10c285cc1c2f46e41.jpg)

When the user starts an Automatic Matching job, the reconciliation groups pertaining to that matching job will lock. While a reconciliation group is locked, no actions can be made by the user on the Exception page for that reconciliation group. Once the Automatic Matching job is complete, the reconciliation group will unlock.  
  
Users can view source information for each transaction item on the Unmatched Items and Matched Items screens, including how and when the transaction was imported, who imported it, and the imported file name. To view item details, click the **information icon** in the **Details** column.  
![2024-03-21_11-39-23.png](https://static.adra.com/adra-assistant/images/b5dc3b8052197d8d8921e083ea6829a6.jpg) 

Unmatched Items Tab
-------------------

The unmatched items tab allows users to match items, create new journal entries, send items to Balancer, group unmatched items, and much more.  
To learn more about how to navigate the Unmatched Items tab and utilize the features, see [Matcher Exceptions Unmatched Items](#article:kA0Ua0000001K4jKAE@Success-Center)

Matched Items
-------------

The **Matched Items** tab shows the items that have been matched either automatically or manually. 

![image](https://static.adra.com/adra-assistant/images/c89dc57a10b8d5ab4cdb2a8ff94258e5.jpg)

1.  **Select Matches** - Select an item to view its matches. 
2.  **Undo Items** - Select items and click **Undo items** to revert the match and move the items back to the **Unmatched Items** tab.
3.  **Ellipsis** - Select items and click ellipsis to add text to multiple transactions. Note that text will only be added to the transactions visible in the grid view. The number of visible transactions can be altered in the bottom right corner of the screen. 

![image](https://static.adra.com/adra-assistant/images/7eb30e5078089827fad37e7963efe8af.jpg)

3.  *   Select to add text to **All transactions**, only **Ledger**, or only **Bank**.
    *   Select text field
    *   Enter **Text**
    *   Click **Add**
4.  When matched items are selected, the source, number of items, and sum of the selected items are displayed at the bottom of the page.

### Archived Items

Matched items are automatically moved to the archive after a set amount of days as defined in **General Settings**. 

To view archived items, navigate to **Exceptions>>Matched Item**s and toggle **View archived**. The items are sorted by booking date into periods. Select the period at the top of the screen.

Archived items can be unmatched in the following way.

![image](https://static.adra.com/adra-assistant/images/4fcd628e5cde26bacefe7b4b7b5a9065.jpg)

1.  Toggle **View archived**.
2.  Select the period the transactions you want to unmatch are in.
3.  Click the **magnifying glass**. The **Matched details** pop-up appears

**![2024-03-21_11-07-33.png](https://static.adra.com/adra-assistant/images/71f99d54ab025499a051a29946a7d986.jpg)**

4.  Click **Undo match.**

### Search Items

Users can search for specific transactions using the advanced search on the **Matched Items** tab. 

![image](https://static.adra.com/adra-assistant/images/61c8e726e618407bb23935f88cd639a1.jpg)

1.  On the Matched items tab, toggle **Enable advanced search**.
2.  All filters allow for filtering with different criteria. Filters:
    1.  **Matched Date** - Enabled by default. 
    2.  **Booking Date** 
    3.  **ABS (Amount)** 
    4.  **Reference** 
    5.  **Text** 
3.  **Search** \- filters the view according to current filter settings. 
4.  **Clear** \- clears all filter settings. 

Exporting Items
---------------

Items can be exported from any tabs on the **Exceptions** page;

*   **Unmatched Items**
*   **Matched Items**
*   **Archived Items**
*   **Journals**.

This can be done by selecting the items with a checkmark to export or exporting all items on any of the pages. If the user needs to export all items, they can click the **Export** button without selecting the items.   
  
Click the **Export** button in the top right corner on either the **Unmatched items** or **Matched items** page to create an Export template or just Export the items. 

![export items exceptions.jpg](https://static.adra.com/adra-assistant/images/18e027b81806d00114680fc1604f871e.jpg)

*   Click **Export** to create an Excel file that contains all columns.
*   Click **Create new Export Template** to choose the columns to be exported as shown on the **Create Export Template** image below. 

Exported files are sent to the user's email address.   
 

### Export Templates

Users can create personalized export templates for any of the four exceptions pages.  
To do this, follow the steps below.

1.  Click **Export** on any **Exceptions** page.

![image.png](https://static.adra.com/adra-assistant/images/c25a13075fc2f3fd5a0eaddaedca4d73.jpg)

2.  Click **Create new Export Template**.

![2024-06-20_15-50-28.png](https://static.adra.com/adra-assistant/images/224098a19be168299941ad3acc02c9c3.jpg)

3.  Enter a descriptive name.
4.  **Export Preview**
    *   Click the dropdowns to select what data each column should contain.
    *   Click the recycle icons to remove columns.
    *   Click **+Add column** to add additional columns.
5.  Click **Save Export Template.**

  
To utilize the template, select the template in the **Export Template** dropdown.  
To change or remove templates, click **Edit**.  
![2024-06-20_15-58-06.png](https://static.adra.com/adra-assistant/images/b57c5fd5a5869bc32c996a537ef21d4b.jpg)
