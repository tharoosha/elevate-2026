Adra Success Center : IE Browser settings to View the Adra Success Center
=========================================================================

How to access the Adra Success Center using IE 11 
--------------------------------------------------

The recommended browsers for the Adra Success Center are Edge or Chrome. IE 11 which is a slow and old browser that Microsoft no longer supports is only available if you cannot use EDGE or Chrome.  
  
Please contact your Customer Success Representative to enable IE 11 for your account if EDGE or Chrome are not available at your organization. Once you have been granted access to use IE, you or your IT team may need to configure the browser settings so that IE will work in the Adra Success Center.

Using IE 11
-----------

If you are using IE 11, please check your browser settings are set as below in order to use Success Center.  
        
1\. Step Navigate to internet Explorer settings:  
  
Open General Tab:  
    1.    From the General tab, click Settings under Browsing History.  
    2.    For the Check for newer versions of stored pages option, select Automatically.  
    3.    For the Disk space to use option, enter at least 50 MB.  
  
Security Tab:  
    1.    From the Security tab, click Custom Level under Internet and scroll to the Scripting section.  
     2.    Make sure the Active Scripting option is enabled. JavaScript depends on this setting being enabled.  
  
 Privacy Tab:  
     1.    From the Privacy tab, click Advanced.  
     2.    Select the Override automatic cookie handling option.  
     3.    Select the Always allow session cookies option.  
     4.    For the Third-party Cookies option, select Accept  
  
  Advanced Tab:      
 From the Advanced tab, scroll to the Security section and do the following:        
     1. Leave this option unchecked:  Do not save encrypted pages to disk .  ( see below)   
     2. Select Use TLS 1.0, Use TLS 1.1, and Use TLS 1.2. Make sure to deselect Use SSL 2.0 and Use SSL 3.0.    
  
![image](https://static.adra.com/adra-assistant/images/a38d21a57c2f8dafc22d2230da1d5628.jpg)   P.S: it is very  important that this  option ‘Do not save encrypted pages to disk’   in Advanced Tab is NOT checked. It must be left unchecked
