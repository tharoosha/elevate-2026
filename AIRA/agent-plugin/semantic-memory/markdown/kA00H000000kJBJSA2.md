Matcher Use Cases for Match Rules
=================================

Match rules run from top to bottom. It is recommended to keep your most specific rules toward the top and more generic matching rules last. This will allow Matcher to accurately identify matches. Matching rules are updated/created by going to **Administration > Matching Rules**.   
  
Note, that the use of RegEx in these examples shows ways that rules can be made more specific. This can be beneficial if there are many similar amounts in the files used for matching. The chart below shows use cases that utilize configuration options with example settings for each one.    
  
![Matching Rules Use Cases Chart.jpg](https://static.adra.com/adra-assistant/images/d6433725b99b5f264d30136be86c095a.jpg)

  
1\. **One-One Same Day Equal Text (ACH):** This rule matches one item from ledger vs one item from bank on the same Booking date, but only if the ledger item starts with "ACH" and then the next 3 letters match the first 3 letters in the Text on the bank side.   
 

#### ![match rule sent checks.jpg](https://static.adra.com/adra-assistant/images/c890c5c8a6b64a1a6670ecac36ce47c9.jpg)

  
  
2. **One-One +31 Days Equal Check Number (Sent Checks):** This rule matches on text (33935) to the bank CustRefNo (33935). 33935 is the check number.   
  
![match rule sent checks.jpg](https://static.adra.com/adra-assistant/images/86e5b5a428584cb35f05b69e53ec3bc1.jpg)

  
3\. **Many Ledger - One Bank Same Day (CC REIMBURSEMENTS):** This rule is a many ledger vs one bank rule that groups all ledger payments with the word "Reimbursement" in the DocumentInfo field together and matches them against a lump sum in the bank.

#### ![match rule many ledg to one bank.jpg](https://static.adra.com/adra-assistant/images/18f01b3f3c43368a766227aded29b5da.jpg)

  
4. **Many Ledger - Many Bank Same Day (CC REIMBURSEMENTS):** This rule matches many ledger items to many bank items. For Figure 4.15, it is matching the Field DocumentInfo and RegEx term “Reimbursement” to the Text field Bambora.

![Match RUle many to many.jpg](https://static.adra.com/adra-assistant/images/039ba96cd29c437d84a25b48e1e98216.jpg)  
 

5. **One-One Same Day (Unique):** This is a one to one rule that matches items on the same day if they have the same unique amount only. This rule is beneficial when there is nothing similar to match on but items are close in date and the amount is the same and there are no other items with that amount present.

![Match rules same day unique.jpg](https://static.adra.com/adra-assistant/images/368b9a4bc0a0f2581d92119e5824bb4e.jpg)
