Configure Task List
===================

Folders and Subfolders
----------------------

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/9afab266a2c6e7cf024c4134e9fe999f.jpg) 

Folders and subfolders can be configured to organize task templates within the library, allowing for easier navigation and structured management. To learn more about creating folders and subfolders, see [Task Manager Manage the Library](#article:kA00H000000kJ5kSAE@Success-Center).

![A white rectangular object with a square buttonAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/cf0cbe39856ebb6b60bf72b016a65d12.jpg)

New sections can be created, and section admin access can be granted to users, allowing them to manage only specific sections of the library. This ensures that users can oversee designated areas without accessing other sections that may contain confidential information**.** To learn more about assigning section admin access, see [Task Manager User Page Overview](#article:kA0Ua00000002WTKAY@Success-Center).

Managing Tasks in the Library
-----------------------------

Task templates can be imported in bulk into the library for storage and editing purposes by administrators. Templates can also be manually created or edited if needed.  
  
![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/1b8ce653fc723175e43b46ac53d9ee7d.jpg)  
  
Templates contain multiple fields and sections that determine the workflow of a task and help administrators define the task to be worked on. To learn more about the task template settings, see [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center).

Recommended fields include:  
![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/2a1ebd72ea7400ce89f473fa80b9da50.jpg)

*   **Team** (mandatory)
*   **Preparer** – Who does the task
*   **Approver** – Checks that the task is completed properly.
*   **Description** – Provide a high-level overview  of the task.
*   **Procedure** – Provide a guide or detailed instructions on how to complete the task.

Templates can be edited to configure the due times of the task. User shave two options for a task:

*   **Task list** – Select to create a task template that can be added to task lists.
*   **Auto-recurring** – Auto-recurring tasks are auto-created at certain intervals and cannot be added to a task list.

**Task List**

![A white rectangular object with black linesAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/d53ae79d3f03227d10887b7779ec2869.jpg)

*   This will be for most of your tasks and will allow you to add the task to a task list
*   Tasks will be due in relation to the ZERO-day set when making the task list. To learn more about ZERO day, see [Task Manager How to Use ZERO Day](#article:kA00H000000oPNnSAM@Success-Center).

**Auto-recurring**

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/7e4e3513e786f04b8b94a41691e0b4cc.jpg)

*   For tasks that are repeated frequently, such as more often than every two weeks, it is recommended to use the task type Auto-Recurring.

**Additional Fields**

Other fields help to provide additional information about the task for the sake of those preparing and approving it, including:

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/e2c2ba7fb8a1a3a6a737c8fb86540231.jpg)

*   **Attachments** – Documents or resources needed to complete the task.
*   **Checklist** **items** – Steps that must be done to complete the task.
*   **Extra** **fields** – Additional task details for sorting and additional context

Creating Task Lists
-------------------

To create or copy task lists, navigate to the Task Lists page.  
  
![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/b0519c1e4e2484d8863a5e6f8e381506.jpg)  
  
To copy an exiting list, select the list and click **Copy selected**. This allows you to decide if you want to keep any task sequences and other setting changes from the copied list.

![A white background with black textAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/55aed89ef873d0a9b5cda3ad6107ecda.jpg)

For example, in a previous month, you may have changed the preparer for a number of tasks in a previous month. When copying tasks, you needs to decide if you want to:

*   Use the updated preparer - Select **Task list** to apply the current preparer.
*   Revert to the original preparer defined in the library - Select **Library** to use the preparer originally defined in the library.

If the change is intended to be permanent, the user should make a note to update the preparer setting in the **Library** to keep it current.

You must also enter a new name and a ZERO-day, from which a task’s due date will be configured. To learn more about ZERO day, see [Task Manager How to Use ZERO Day](#article:kA00H000000oPNnSAM@Success-Center).

Task Workflow
=============

Add Tasks and Start Task Lists
------------------------------

Now that the task list has been created, tasks must be added.

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/e4be4ee3bb8ecaf2e8a3f12da6a41010.jpg)

1.  Use search and filter options to find the appropriate tasks to add and then select those tasks.
2.  The library folder names are listed on the bottom and can be used to locate tasks.
3.  Select the tasks you want to add to the list in the middle panel.
4.  Once tasks are selected, they are shown on the right-hand. Click the pencil icon to edit the task details if needed. Most settings are optional, but the task must have a Team in order to be assigned workflows.
5.  Click **Add selected**. You can always add more tasks later if needed.

![A screenshot of a calendarAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/19dfc4471a48823d3093dde2437d5f1a.jpg)  
  

Task can be sequenced off of each other. Click a task to open its detail page, then click **Preceding Tasks** or **Succeeding Tasks**, and select which tasks should be done before or after this one. To learn more, see [Task Manager Configure Task Sequences](#article:kA00H000000kJ6ESAU@Success-Center).  
![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/d8ed9bf30970177a40624fc59e5bc1c0.jpg)  
  

Task details can be edited on the Task Lists page. To learn more, see [Task Manager Edit & Manage Active Tasks](#article:kA00H000000kJ6OSAU@Success-Center).

### Open Task List

New task lists must be started on the Task Lists page.

![image](https://static.adra.com/adra-assistant/images/eb11d18e019c1c6dc5a21510dfd83c82.jpg)

When a task list is opened, all associated users receive an email. Tasks lists can be opened, closed, and archived as needed. Only task lists in **Not Started** can be completely deleted.

Prepare a Task
--------------

Users can find their assigned tasks on their **Home** page. Including not started, tasks to prepare, and tasks to approve.  
  
![image](https://static.adra.com/adra-assistant/images/66d021c097ce1a250abc679d38e2dbad.jpg)  
  
When a user clicks on a task, they’re taken to the task detail page, which includes all the information they need to understand how to complete the task. This is based on the descriptions and procedures set up in the template from the library.

To learn more about preparing and approving tasks, see [Task Manager Prepare & Approve Tasks](#article:kA0Ua0000003Eb7KAE@Success-Center).

When the user clicks Prepare, a pop-up appears showing the procedure. This helps ensure the preparer understands what’s required before confirming that the task has been prepared. Users are also encouraged to report how long the task took to complete. This can be compared with the estimated time to help track time management.

If needed, the **Prepare pop-up** can be turned off in **General Settings**. Depending on email settings, the **approver** will be notified when the task is ready for review. To learn more about settings, see [Task Manager General Settings](#article:kA00H000000kJ5aSAE@Success-Center).  
[](https://trintech.lightning.force.com/lightning/r/Knowledge_Article__kav/ka0Ua0000008Gh7IAE/view#Top)

Approve a Task
--------------

From the **Home page**, under **Tasks to approve**, users will see a list of tasks that have been prepared and where they’ve been assigned as the approver.

When a user selects a task to approve, they’ll be taken to a page similar to what the preparer saw. However, approvers won’t be able to edit the content. They can only **leave comments**, **approve**, or **reject** the task. Rejected tasks are returned to the preparer, so it’s important to include a reason for the rejection to help them understand what needs to be addressed.

Tracking the Close
==================

Using the Home Page
-------------------

On an individual level, the **Home** page provides an overview of upcoming tasks for a user and should be used to manage workload. To learn more, see [Task Manager Home Page Overview](#article:kA00H000000kJ6TSAU@Success-Center).  
![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/737c88cdd29511727be8704378b78d1c.jpg)  
  

Using the Dashboard
-------------------

From the full month-end close level, the **Dashboard** provides team leaders with a view of how the close is progressing. Filtering and grouping capabilities are offered to allow configurable viewing of information.  
![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/60519140783fb98a67a3ff62e2aedf45.jpg)  
  
Each icon shows a number of tasks. When clicked, it takes the user to an auto-filtered Task grid, where they can view the specific tasks that make up the number shown in the icon. To learn more about the **Dashboard**, see [Task Manager Dashboard](#article:kA00H000000kJ6iSAE@Success-Center).
