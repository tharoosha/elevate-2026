Task Manager Searching for Tasks
================================

Searching for Tasks
-------------------

Follow these steps to search for tasks:

1.  Navigate to **Task Manager>>Tasks**. Users will see the tasks grid.

![image.png](https://static.adra.com/adra-assistant/images/1aee52b87ca10fdb52c3e84ca34e8ecf.jpg)

2.  Click the **settings** icon (cogwheel) and toggle the desired columns **On** or **Off**.

  
![image.png](https://static.adra.com/adra-assistant/images/d56485d9dfd009797d15a38fcb3e9d9a.jpg)

3.  The column headers can be used to filter and sort the tasks.

![image.png](https://static.adra.com/adra-assistant/images/2133219926620fb876ffdca96cd7658a.jpg)

*   Select any filter button ![image.png](https://static.adra.com/adra-assistant/images/0f8643238ce3394dac5fed5797ac56a6.jpg), to narrow down the data available for that column, for example name and due date. 
*   Click a header to sort the content in decending or ascending order.
