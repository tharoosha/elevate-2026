Journal Entry General Settings
==============================

 **HELPFUL HINT**: Adra Journal Entry is a new module. If you’d like to adopt this application, please contact your account manager.

The Journal Entry **General Settings** page allows users to configure settings for the application

![image](https://static.adra.com/adra-assistant/images/d5d162378b94060fe965caef004de4cd.jpg)

1.  **Posting Options** - Turn this setting on to prevent journals from being marked as ready to post unless supporting documentation has been added. This reduces the number of incomplete journals and errors. 
    *   Journals that lack documentation can be saved as a draft.
2.  **Dimensions** \- Create additional dimensions that allow users to add extra details to entries when creating or editing them on the Journal Entries page.
    *   The dimensions can be linked to extra fields in Matcher. To learn more, see [Matcher Journal Entry Settings](#article:kA06S000000YQbiSAG@Success-Center)

New Dimensions
--------------

To add dimensions, follow the steps below:

1.  Navigate to **Administration>>General Settings**

![image](https://static.adra.com/adra-assistant/images/073a35ae522c18f0bce8461d9ec74f48.jpg)

2.  Click **New Dimension**

![image](https://static.adra.com/adra-assistant/images/3440264bb043033f53ba05a20420a293.jpg)

3.  Enter the dimension **Name**
4.  Click **Add**

![image](https://static.adra.com/adra-assistant/images/6813be38db4fbdeb1b4feb154c89b4bd.jpg)

The new dimension is added to the list. Click an existing dimension to edit or deactivate it. There is a maximum of 15 dimensions.

The new dimension is automatically available when creating or editing entries, as shown below.

![image](https://static.adra.com/adra-assistant/images/025091f30596e9b5c06b43c86caec11d.jpg)
