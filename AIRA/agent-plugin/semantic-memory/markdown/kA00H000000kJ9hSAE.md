Setup Create & Manage Fiscal Years
==================================

Fiscal years (FY) and periods must be set up before you can:

*   Import balances into **Balancer**
*   Import transactions into **Matcher**
*   Use fiscal years to categorize tasks and task lists in **Task Manager**

A fiscal year is created on an engagement level and is used by all legal entities in the engagement.

 **WARNING**: The fiscal year and periods must be created at the start of an organization's financial year for balances to be imported successfully.

 **HELPFUL HINT**: Watch an instructional video on how to add new fiscal years: [_New Fiscal Year Instructional Video_.](https://success.adra.com/s/by-catalog?vtui__mediaId=a7U6S000000EA2JUAW&vtui__catalogId=a7N0H000000PDASUA4&vtui__launchedFrom=Media&vtui__source=catalog)

  
**Fiscal years:** 

*   Can be longer or shorter than a calendar year. 
*   Can start or end on any day if the end date is greater than or equal to the start date. 
*   Can contain any number of periods.
*   Cannot overlap.

  
**Periods:**

*   An opening balance period is added automatically to all new fiscal years.
*   The start and end of a period can be set to anything within the start and end dates of the FY.
*   Periods cannot overlap.
*   Various period configurations are supported, including 4-4-5, 5-4-4, 4-5-4, 28-day calendar, or an additional end-of-year period.

The end-of-year period is typically added to handle any remaining transactions or adjustments that occur after the 12th period. This additional period allows for a complete and accurate financial closing process before starting a new fiscal year.

**Create a Fiscal Year**
------------------------

Only users with the access level Financial admin can create fiscal years. To learn more, see [Setup User Access Page](#article:kA0Ua0000000UnhKAE@Success-Center).

To create a new fiscal year, do one of the following:

*   In Balancer, navigate to **Administration>>Fiscal Years** and click **New fiscal year**. The fiscal year page in **Setup** loads.
*   In Setup, navigate to **Financial Configuration>>Fiscal year** and click **Create fiscal year**.

![image.png](https://static.adra.com/adra-assistant/images/b87ad2b7a10dcc04993d2f388f883e5c.jpg)

1.  **Name** – Enter FY name. Use a consistent format for naming fiscal years. 
2.  **Code** – Enter FY code. This is only necessary if job automation is used for automatic balance and transaction import.
3.  **Start date** – Select the first day of the fiscal year.
4.  **End date** – Select the last day of the fiscal year.
5.  **Add period** – Click to open the period pop-up, shown in the figure below. Upon creating the first period, an opening balance period is automatically added.
6.  **Save** – Click to retain changes.

### **Add Period**

![image.png](https://static.adra.com/adra-assistant/images/8ea71c3b1d06837c3079838344779d52.jpg)

*   **Name** – Enter a period name.
*   **Code** – Enter a period code. This is only necessary if job automation is used for automatic balance and transaction import.
*   **Period** – Verify the period number, as it determines the frequency of bimonthly and every fourth period tasks in Balancer. Refer to the table below for details. This number is automatically assigned as the next in the sequence and should not be altered unless the fiscal year starts in the middle of the year or there is a need to skip periods.
*   **Type** – Select the period end type. This feature is mainly used in **Balancer processes.**
    *   The task frequency of each account, together with the period end type, determines whether the account’s task requires attention in a given period.
    *   **Example** \- If an account is set to be prepared and approved **quarterly**, it will be automatically finalized in **Month End** periods. Reconciliation will only be required during **Quarter**, **Half Year**, and **Year End** periods.
*   **Start date** – Verify or modify the first day of the period. It is automatically set to be one day after the end date of the previous period. Changing this is only necessary if there are irregular schedules.
*   **End date** – Verify or modify the last day of the period. It is automatically set to be the last day of the month. Changing this is only necessary if there are irregular schedules.
*   **Add period** – Click to approve period details. These can be edited as long as the period has not had balances imported.

Repeat the process to add additional periods. Click Save on the FY page once all periods have been added correctly.   
  
The chart below shows how period type and number impact the reconciliation frequency of accounts.  
![image](https://static.adra.com/adra-assistant/images/64c4c81ec02278e48c02e4b4bfb86d8f.jpg)  
   
   

 **WARNING**: Ensure that the correct period end type is selected during the initial setup of the FY, as an incorrect type will affect the status of account tasks in Balancer.  
**Example**: If March is a **Month End** instead of a **Quarter End** period, accounts with a Quarter End frequency will be incorrectly labeled as finalized on the **Accounts and status** page in March.  
To edit the period end type for a period with uploaded balances, all balances must be deleted for that period, resulting in the loss of work.  
After editing the period end, balances can be reuploaded and the status will display correctly.
