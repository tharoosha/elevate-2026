Balancer Transfer or Remove User Roles
======================================

Administrators can reassign or copy user roles from one user to another permanently or temporarily.  
This feature is useful when new or existing employees take over the responsibilities of another temporarily or permanently. This feature can also be used to transfer **Read access** for auditors.  
  
User roles can be reassigned or copied in several ways:

1.  Updates account settings for future periods.
    *   **Account settings** \- Change individual accounts on the **Account settings** page. To learn more, see [Balancer Account Settings Page Overview](#article:kA00H000000kJALSA2@Success-Center).
    *   **In Bulk On Jobs Page** - Update account roles in bulk through account role Excel files on the **Jobs** page. To learn more, see [Balancer Export & Import Account Roles](#article:kA00H000000kJAGSA2@Success-Center).
    *   Transfer roles for all future periods in **Administration>>Users**.
    *   Copy roles for all future periods in **Administration>>Users**.
2.  Temporarily transfer roles within a single period on the **Accounts and status** page.

 **HELPFUL HINT**: To learn how to remove application access for a user, see [Setup Remove User Access in Adra](#article:kA00H000000oP4lSAE@Success-Center).

Temporarily Transfer Roles Within a Period
------------------------------------------

When roles are transferred from one user to another within a specific period, the original user will temporarily lose permission to carry out the duties associated with the transferred roles during that period. The roles and responsibilities will persist for both past and future periods.  
To transfer roles temporarily within a period, follow the steps below:

1.  Navigate to **Accounts and status**
2.  Select the specific period in the drop-down in the left-hand menu.

![image](https://static.adra.com/adra-assistant/images/bfd0150dd79662d8e7a5c18682a4f115.jpg)

3.  Select the desired accounts in the list.
    *   Add column filters for Main preparer, Main approver, Main reviewer, and Status to simplify the process. Click the cogwheel to manage visible columns if necessary.
4.  Click **Bulk action>>Reassign account roles**

**![image](https://static.adra.com/adra-assistant/images/858f891a1f38845506a098cd9817403c.jpg)**

5.  Select what user will receive the rolles
6.  Select what type of role they will temporarily take on
7.  Unselect any misclicked accounts
8.  Click **Submit job**

Copy or Transfer Roles for Future Periods
-----------------------------------------

The **Users** page permits administrators to copy or transfer user roles between users for all future periods.

 **HELPFUL HINT**: To update user roles for active periods, navigate to **Jobs>>Other jobs>>Update settings and roles**, select the desired period and legal entities, and run the job.

To transfer or copy roles, follow the steps below:  
  

1.  Navigate to **Administration>>Users**, and select the user whose roles will be transferred. The user's page loads.

![image](https://static.adra.com/adra-assistant/images/79ee705cf7d8dc745df4df934f44793f.jpg)

2.  Click the **More actions**:
    1.  Click **Transfer accounts roles** to move the user’s read access and account roles to another user. Legal entity access and account roles are removed for the original user. 
    2.  Click **Copy account roles** the user’s read access and account roles to another user. The original user retains legal entity access and account roles.
3.  The transfer and copy pop-ups are similar. The Transfer Account Roles pop-up is used in this example.

![image.png](https://static.adra.com/adra-assistant/images/2d0e85a31421fb45fb88d875b9b7ade8.jpg)

4.  In the pop-up, select the user to whom the user roles will be assigned.
5.  Check **Select all** or individual legal entities.
6.  Click **Transfer account roles**.
