Adra Platform - SCIM Personal Access Token Expiration and Notifications
=======================================================================

Issue
-----

Administrators configuring SCIM integrations may need information regarding the validity period and expiration notifications for Personal Access Tokens.

Symptoms
--------

Questions commonly include:

*   How long a SCIM Personal Access Token remains valid
*   Where to verify token expiration details
*   When expiration reminders are sent
*   Which user receives the expiration notifications

Resolution
----------

SCIM Personal Access Tokens in Adra Platform are valid for one year from the date they are created.

Expiration details can be viewed within the user profile settings.

Reminder notifications are automatically sent before expiration.

### Steps

1.  Log into Adra Platform.
2.  Navigate to:
    
    Setup → Profile → User Access
    
3.  Locate the Personal Access Token information.
4.  Review the token expiration date.
5.  Monitor expiration reminder notifications sent by the system.
6.  Generate a new token before expiration if continued SCIM integration access is required.

Reminder Notifications
----------------------

*   First reminder: 30 days before expiration
*   Second reminder: 3 days before expiration

The notifications are sent to the user who originally created the Personal Access Token.

 **BEST PRACTICE**: 

*   Maintain documentation of token creation and expiration dates.
*   Renew tokens before expiration to avoid SCIM provisioning interruptions.
*   Use dedicated administrative accounts for SCIM integrations when appropriate.
*   Periodically review active tokens and remove unused credentials.

 **HELPFUL HINT**: Only the creator of the Personal Access Token receives expiration reminder notifications.

 **WARNING**: Expired Personal Access Tokens may interrupt SCIM synchronization and automated user provisioning processes until a new token is generated and configured.
