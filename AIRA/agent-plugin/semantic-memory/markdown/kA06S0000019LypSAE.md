Task Manager Connect Analytics API to Tableau
=============================================

Introduction
------------

Adra Analytics extracts data from Balancer and / or Task Manager to provide full visibility into the month-end close process. While Adra provides Power BI templates for both Balancer and Task Manager reports, users can create their own reports in any data visualization tool that supports OData v4. Analytics reports grant access to tables within the Adra databases that aren’t naturally reported on in the interface, allowing users to analyze their close process in greater detail. This document details how to connect the Task Manager Analytics API to Tableau.  
 

Enable Adra Analytics for a User
--------------------------------

In the Adra Product Suite, settings, engagements, and users are managed in Setup. A user will need to be added to enable Adra Analytics. Read [Setup Create New Users In Adra](#article:kA00H000000kJ5LSAU@Success-Center) to learn more about adding users to the Adra platform. Once the user is added, follow these steps to enable Adra Analytics.  
![image](https://static.adra.com/adra-assistant/images/f1055e1eda18aeec25939c95e87979bd.jpg)

  
1\. Navigate to the user's profile on the Users page. Click on the username. **Users>>Specific User**  
![image](https://static.adra.com/adra-assistant/images/f1a849a599078a8898b31037d6e6f405.jpg)  
2. Click the **Access and roles** tab.  
3\. Under ANALYTICS API, select **Standard User**.  
4\. Click **Save changes**.  
  
 

Generate API Access Keys for Adra Analytics
-------------------------------------------

Once a user has access to the Analytics API, the user will need to retrieve their API access code.  
 

1. Outside of the Adra application, open a Word or Notepad document. This will be used to copy and paste information.

![image](https://static.adra.com/adra-assistant/images/2b19011bc75e2077be6bd307d851eab3.jpg)

5\. A pop-up appears. Under Access token for, ensure that ANALYTICS is selected. Click **Create access token**.  
  
![Tablea A6.png](https://static.adra.com/adra-assistant/images/164f1a8975518a9157b268dbf29cacc0.jpg)  
6\. Click **Copy**. Paste the token into Word or Notepad. Title and save the Word or Notepad document. In Adra, click **Close**.

  
  ![image](https://static.adra.com/adra-assistant/images/9dd650020bf3d7c4d9cea0bff25dbb50.jpg)  
7\. When the pop-up is closed, you will return to the User access page. Click **Copy SID**. Paste the SID into your Word or Notepad document.  
 

Create the Connection between Analytics API and Tableau
-------------------------------------------------------

![Tableau A8.png](https://static.adra.com/adra-assistant/images/71a259be28b3734186923b5c8017c66d.jpg)  
1\. In Tableau, open the workbook or project you wish to connect with the Adra Analytics API data.  
2\. In your Tableau workbook, click **Data**. Select **New Data Source**.

![Tableau A9.png](https://static.adra.com/adra-assistant/images/d4e9d7692c70804bb1df2e7002140b0c.jpg)  
4\. A pop-up appears. Under Server, paste the link of the API that you wish to use.

*   For **Adra Task Manager** data, use: [https://analyticsapi.adra.com/taskmanager/api/](https://analyticsapi.adra.com/taskmanager/api/)
*   For **Adra Balancer** data, use: [https://analyticsapi.adra.com/balancer/api/](https://analyticsapi.adra.com/balancer/api/)

  
![image](https://static.adra.com/adra-assistant/images/592e0e1380ae210f7bc4a72d784ad355.jpg)  
9\. Create the data model in Tableau. TaskFacts is the Adra Task Manager Analytics API's main table. Drag **TaskFacts** onto the canvas to start adding the connections between the different data tables.
