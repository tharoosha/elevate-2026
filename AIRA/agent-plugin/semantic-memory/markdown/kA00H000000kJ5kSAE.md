Task Manager Extra Fields
=========================

Extra Field Configuration
-------------------------

Extra Field Configuration allows administrators to add extra information to tasks, which can be used to label tasks and add filtering and sorting capabilities. There is a maximum of 20 fields, including 10 text fields, 5 numeric fields, and 5 date fields.   
To use the Extra Fields functionality the extra fields must first be created, then details can added to tasks in the **Library**.  
To create Extra Fields, follow the steps below:  
![image.png](https://static.adra.com/adra-assistant/images/0b142111d4616764dade82fef36983d0.jpg)

1.  **Display name** – Enter a name. 
2.  **Data type** – Select whether the field will contain text, numbers, or a date. When adding a numeric field, select Index as the data type.
3.  **Field name** – Select which extra field column in the extra field import file additional task details are collected from.
4.  **Visible and Active** – Toggle Visible to On to allow the specified extra field as a column on the Tasks page. Toggle Active to make the field available for tasks in the Library.
5.  Click **Save**.

Add Extra Field Details
-----------------------

After the Extra Fields have been created in **Administration**, additional details can be added to tasks in the **Library**.   
This can be done in two ways:

1.    **In bulk** – Click the ellipsis for a section, a folder, or a subfolder.   
2.    **Manually** – Navigate to the **Library** and click the edit icon. Refer to Lesson 3 View and Edit Tasks in the Library

### Add Extra Fields Details Manually 

Navigate to **Task Manager>>Library** and locate the task. Click the **edit** icon  
![image.png](https://static.adra.com/adra-assistant/images/8716894a773e633333ce181eafca0a03.jpg)

The additional field details will not be visible in active tasks. However, when a new task list is created or copied, and the task details are retrieved from the Library, the extra fields will now contain the updated information.

### Import Extra Field Details in Bulk

To populate extra fields in bulk, click the ellipsis on the section or folder where the desired tasks reside.    
Click **Export extra fields** to modify existing and add new extra field details to the file. Click **Import extra fields** to import the updated file.  
  
![Picture1.png](https://static.adra.com/adra-assistant/images/3d3234aa5adfab68ee2edd98b8a0e89e.jpg)  
 

#### Export Extra Fields

In the **Library**, click the **ellipsis** of the desired section, folder, or subfolder, and click **Export extra fields**.   
Administrators are notified that the file is Exporting, followed by a notification that advises administrators to navigate to the **Jobs** page.  
  
![image.png](https://static.adra.com/adra-assistant/images/9ca2c0742fb682fb6b32223e0c687545.jpg)  
Navigate to the Jobs page and click **Download**.

#### Import Extra Fields

In the **Library**, click the ellipsis of the desired section, folder, or subfolder, and click Import extra fields. The **Import extra fields** page loads.  
![image.png](https://static.adra.com/adra-assistant/images/16098c37c817d2dc31623100790428ae.jpg)  
Review any error messages to ensure a successful import. The error message displayed in the figure above is not an issue as it is caused by the column headers row in the file.  
Click **Complete import.**
