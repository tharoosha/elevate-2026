Introduction
------------

The exception investigation feature allows all Matcher users (except limited access users) to assign open items to specific users for follow-up. This streamlines the review, tracking, and resolution of unmatched transactions by assigning clear ownership and enabling cross-team collaboration, even with users who don’t typically work in Matcher, such as those in procurement or operations. 

The exception investigations can be assigned to:

*   **Business admins** \- Can view and comment on any investigation.
*   **Standard users** - Requires read access to the relevant Legal Entity/Rec. Group.
*   **Limited access user** - Requires read access to the relevant Legal Entity/Rec. Group.
    *   Users with this role can view and manage assigned exceptions on the **Home** page, but they will not have access to any other pages.

These user roles are assigned in Setup. To learn more, see [Setup Create New Users In Adra](#article:kA00H000000kJ5LSAU@Success-Center).

To learn more about what functions are available to each user role, see [Matcher Understanding User Roles and Access](#article:kA0Ua0000006elxKAA@Success-Center).

Delegate an Exception Investigation
-----------------------------------

To assign an open item for investigation, follow the steps below:

![image](https://static.adra.com/adra-assistant/images/875af04749bd294e89b0e56360b7eddd.jpg)

1.  Select one or more items that need to be investigated.
2.  Click the **Ellipsis** and select **Send for Investigation**. A pop-up appears.

 ![image](https://static.adra.com/adra-assistant/images/b29d79928e014154cda0061919b641a4.jpg) 
----------------------------------------------------------------------------------------------

3.  Select the investigator.
4.  Enter a message with relevant information for the investigator. Click **Send**.

Assigned investigations are marked with a speech bubble icon on the exceptions page and are listed in the investigation grid on Matchers **Home** page.

To edit the assignee and the message, navigate to the Home page and click the pencil icon:

 ![image](https://static.adra.com/adra-assistant/images/50a16dd92074a0291710bab13a57848b.jpg)

Investigation Process
---------------------

To add details to and complete an investigation, navigate to the **Home** page, and view the **Transaction to investigate** grid.  
To learn more about how to use filters, change column order, and sort the items, see [Matcher Home](#article:kA00H000000482CSAQ@Success-Center).

To complete an investigation, follow the steps below:

![image](https://static.adra.com/adra-assistant/images/533a014afb33584804b151ccd3713475.jpg)

1.  Click the relevant investigation or the speech bubble icon. 
    *   Note that business administrators have access to add details to investigations assigned to other users.

![image](https://static.adra.com/adra-assistant/images/e9106349d06c84f5243809e2f7f8760e.jpg)  
The **Investigation Detail**s pop-up opens.

![image](https://static.adra.com/adra-assistant/images/c6df0ae21f5c24d31c2f3f183a368bf5.jpg)

2.  Read the comment from the assigner.
3.  Use the transaction details in the pop-up, as well as in the grid on the home page, to identify and investigate the transaction.
4.  Enter a resolution in the comment field.
5.  Click **Save** to keep the investigation as a draft, leaving the status as Awaiting investigation.
6.  Click **Mark as Investigated** to update the status when the investigation is complete.

Revert Investigation Status
---------------------------

If an investigation is finalized but needs to be reopened, click the **revert status** button.

![image](https://static.adra.com/adra-assistant/images/2712a520b31b853f0f9ef73b4efc6c8d.jpg)

This allows administrators to edit the assignee and message by clicking the pencil icon, while both the assignee and the business administrator can add additional comments.
