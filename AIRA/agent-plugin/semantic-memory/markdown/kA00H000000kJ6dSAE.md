Task Manager Task List Overview
===============================

The **Task Lists** page data can be filtered and sorted, and specific actions can be completed for each of the four tabs:

1.  **Not Started**
2.  **Opened**
3.  **Closed**
4.  **Archived** 

The **Task Lists page** allows administrators to change the task list status and manage tasks within a task list.

 ![2024-06-18_9-02-20.png](https://static.adra.com/adra-assistant/images/f135483d8d5fb57a367ef7d2d9fabe5d.jpg)

1.  **Status tabs** – Select the tab under which the desired task list is located. Only task lists under the Not Started tab can be deleted.
2.  **\+ Create new task list** – Click to create a new task list. See [Related Articles](#related-articles) to learn how to create and copy task lists.
3.  **Manage task list and grid** – These action buttons vary according to the selected tab.  
    *   **Close selected** – Check one or more task lists and click Close selected. This change status action button differs for each status tab. 
    *   **Copy selected** – Check one or more task lists to copy. See [Related Articles](#related-articles) to learn how to create and copy task lists.
    *   **Set FYP for selected** – Click to assign the task list to a period. See [Related Articles](#related-articles) to learn how to create and manage periods.
    *   **Task grid settings** – Click the settings icon to enable or disable columns on the grid, clear all filters, or reset the grid columns.
4.  **Task lists and Actions** – Click a task list to open and manage it. The change status action button differs depending on the task status.

  
The action buttons **\+ Create a new task list** and **Copy Seleced** are available on all tabs on the **Task Lists** page. 

Start a Task Lists
------------------

Once a task list has been created, navigate to **Task Lists>>Not Started** to locate and start it.  
   ![2024-06-18_10-05-11.png](https://static.adra.com/adra-assistant/images/53bb09899f976cac6eb22d8f4c513f53.jpg)

The **Not Started** tab lets administrators start, copy, assign a fiscal year period to, or delete the list. Select a task list and click the desired action button.

Started list are moved to the **Opened** tab. 

 **HELPFUL HINT**: Note that task lists can only be deleted when the task list has the status **Not Started**

Opened Task Lists
-----------------

Open task lists are located on the **Opened** tab on the **Task Lists** page.

![2024-06-18_9-31-47.png](https://static.adra.com/adra-assistant/images/c9c5f81e3c73019fd801c2d16537f7fc.jpg) 

The **Opened** tab allows Administrators to close, copy, and assign fiscal year periods to task lists. Select a task list and click the desired action button.

Tasks in an open task list are accessible to users who have been assigned those tasks.  
Closed task lists move to the **Closed** tab. 

Closed Task Lists
-----------------

Closed Task Lists are located in the **Closed** tab on the **Task Lists** page.  
Tasks on closed task lists remain visible on the **Tasks** and **Task Lists** pages but cannot be changed unless the task list is reopened.  
  
![2024-06-18_10-22-52.png](https://static.adra.com/adra-assistant/images/7fc772302cbda18350718fc369ff8053.jpg) 

The **Closed** tab allows administrators to archive, reopen, copy, and assign fiscal year period to a task list. Select a task list and click the desired action button.

Archived task lists are moved to the **Archived** Tab. 

Archived Task Lists
-------------------

Archived task lists are located in the **Archived** tab on the **Task Lists** page. 

Tasks in archived task lists are not visible on the **Tasks** page.  
 ![2024-06-18_10-35-43.png](https://static.adra.com/adra-assistant/images/5d790cdd5c38a5cd59c4be41435d0211.jpg)

The **Archived** tab allows administrators to set a list as closed, and to copy it. Select a task list and click the desired action button.

Click **Close Selected** to move the list back to the **Closed** tab.
