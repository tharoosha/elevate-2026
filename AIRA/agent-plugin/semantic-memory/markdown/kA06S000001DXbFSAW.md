Setup Create Engagement and Assign Engagement Admins
====================================================

When the BPO Organization's agreement with Adra includes the creation of engagements, BPO Admins have the ability to add engagements based on their customer's needs. In order for a BPO organization to create customer engagements, **Manage engagements** must be toggled on.![Manage Engagements On.png](https://static.adra.com/adra-assistant/images/dc2560fb143e78c3982678f57a0c4dc1.jpg)

  
Create an Engagement
-----------------------

To create a new engagement:  
1\. Navigate to **Setup>>Organization**.  
2\. Click Create engagement.  
![Click Create Engagement.png](https://static.adra.com/adra-assistant/images/3a769e5d0b4829c49e44538a06727480.jpg)  
It is important to note that BPO Admins cannot add additional applications after the engagement has been created, so all necessary application access should be granted in this step. If applications need to be added at a later point, the BPO Admin must log a support ticket with Adra.  
  
 

Select BPO Engagement Admins
----------------------------

5\. Select at least one engagement administrator. Click **Select admin users** to see a list of users that are part of the BPO Organization within the Adra suite. Select one or more **admin users** from the drop-down. If the drop-down does not display any users, see [Setup Create Users for BPO Organization](#article:kA06S000001DXaMSAW@Success-Center) to add users from the BPO.  
  
BPO Admins can choose to be the engagement admin by selecting themselves from the drop-down. The BPO Admin may also wish to delegate the setup of the engagement to another BPO employee. Select another employee or multiple employees of the BPO (not necessarily BPO Organization Admins) to add them as the System Admin(s) for this engagement.  
  
If BPO Admins add themselves as engagement admins, the new engagement will display under the Engagements tab in the left-side menu. When BPO Admins are not the engagement admins, the engagement will display on the Organization page under the Engagements tab. For more information on connected engagements and managed engagements, see [Setup Manage BPO Organization Engagements](#article:kA06S000001DXagSAG@Success-Center).

![Select Admin Users.png](https://static.adra.com/adra-assistant/images/f76be132e040bef9fba844eba0cc9b96.jpg)
-------------------------------------------------------------------------------------------------------------

  
Add Customer Engagement Admin
--------------------------------

An employee of the BPO's customer can also be added as an engagement admin.  
6\. Toggle **Create new engagement admin** to On.  
7\. Enter the employee's **First name**, **Last name**, and **Username (e-mail)**.  
![Create Engagement Admin.png](https://static.adra.com/adra-assistant/images/10112674669a67b3829ab4d100cd98bb.jpg)

Any newly created user (BPO's customer user) will receive an e-mail with a link to verify the account.

.  
  
8\. Click **Save changes**.  
![Click Save Changes.png](https://static.adra.com/adra-assistant/images/c6cda1a6c3339af57a1a71c3d97df8ff.jpg)  
  
After the engagement is created, the Engagement Administrators (BPO user and, optionally, BPO's customer user) can update the Security Settings for the engagement, as described in [Setup Security for Engagements and Organizations](#article:kA0Ua0000000X2PKAU@Success-Center).
