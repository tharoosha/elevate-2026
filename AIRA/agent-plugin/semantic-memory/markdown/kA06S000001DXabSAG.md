Setup Create Users and Administrators for BPO Organization
==========================================================

Existing Users
--------------

Ensure that the BPO employee does not have a user account. Navigate to **Setup>>Users** to view a list of existing users.  
  
The **Access** tab displays a list of existing users in the BPO organization, along with each user's access types. On this tab, a single user may appear multiple times, as users are listed once for each connected engagement.

![Access Tab.png](https://static.adra.com/adra-assistant/images/66da936cdb2013807340fac8e1311fd6.jpg)

Click the **Employees** tab to view a list of BPO employee accounts, as well as other organization employees linked to an engagement under the organization. (These users could be the BPO's customers who have access to their engagements.) In this view, each user is shown once. The view can be customized to show each employee's parent organization. To ensure that the user does not already have an account, enter the user's email in the search box.  
![Employees Tab.png](https://static.adra.com/adra-assistant/images/9b1e6d78d779d3a82f599dd98679fe70.jpg)

  
Create New User or Administrator
-----------------------------------

1\. If the user does not have an account, click **Create user**.  
![Create User BPO.png](https://static.adra.com/adra-assistant/images/b953c829e19d2fa3a821673ab254ec35.jpg)  
  
After clicking **Save**, the user is created and added to the BPO organization. An automatic e-mail notification with a link to activate the account is sent to the employee. All new users, including standard users and organization admins, must access the e-mail to activate their accounts.
