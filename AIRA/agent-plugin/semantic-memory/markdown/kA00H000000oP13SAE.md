Matcher General Settings
========================

  
General settings allow the admin to create User Defined Sources, manage matched transactions archival settings, and manage the Daily Reconciliation Reports feature.
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------

Navigate to **Administration>>General Settings**.

![image.png](https://static.adra.com/adra-assistant/images/5d6a2aaa8e3ef1c639166a58a0910842.jpg)

1.  **User-Defined Sources** \- Click the expand arrow to add additional sources other than the default Bank and Ledger. 
2.  **Archival Settings** - Click the expand arrow to manage how many days after matching transactions will be automatically moved to **Archive**.
3.  **Daily Reconciliation Settings** \- Click the expand arrow to enable and manage system-generated Daily Reconciliation Reports.

User Defined Sources
--------------------

Ledger and Bank are provided as default sources; however, admins can add source names that represent their specific matching scenarios. For example, administrators can create sources based on their ERP and bank names. Additionally, admins can add other types such as Credit Card Processor or Check Payments.

![2024-03-21_15-32-07.png](https://static.adra.com/adra-assistant/images/634742921ba0405c34b882d43c6db691.jpg)

To view or add new sources, admins will navigate to **Administration>>****General Settings**. Expand the **User Defined Sources** section.

Click **Add Source** to open a popup.

![2024-03-21_17-01-42.png](https://static.adra.com/adra-assistant/images/c1391d04b66d900a87606379b7445c10.jpg)

*   Enter the source name in the field.
*   Click **Add Row** to create additional source fields. Multiple sources can be added at once.
*   Click the **recycle bin** for a source to delete it.

Add User Defined Sources during implementation if possible, as reconciliation groups will use them for matching.  
New sources are available in each reconciliation group's setup.  
 

Archival Settings
-----------------

**Archival Settings** allows administrators to configure the number of days reconciled transactions are retained before archiving. This duration acts as the maximum retention period for all legal entities and reconciliation groups, but can also be configured for each legal entity.

Lowering the retention period below 360 (the maximum) will not restore archived transactions if later increased. 

![image.png](https://static.adra.com/adra-assistant/images/f11ac37fdc67064f2d099cf403202635.jpg)  

To alter the reconciled transactions retention time, navigate to **Administration>>General Settings,** and expand the **Archival settings** section.

Toggle the switch to **On** (blue) and enter the number of days transactions are stored in the **Matched Items** tab on the **Exceptions** page before it is automatically moved to Archived.

Daily Reconciliation Settings
-----------------------------

The **Daily Reconciliation** feature supports organizations that have regulatory requirements for reporting. The reports are stored in the application and can be viewed, with options to download the file if needed.  
![image.png](https://static.adra.com/adra-assistant/images/a6d650b2b2638ec549a1c341cb5c0759.jpg)

*   **Enable Daily Reconciliation** - Enable the toggle (blue) to permit daily reconciliation and make the **Daily Reconciliation** page accessible. See Related articles to learn more about the **Daily Reconciliation** page.
*   **Daily Reconciliation Approval**
    *   **Require Approval of Daily Reconciliation** - Check to permit users to approve **Daily Reconciliation** reports.
        *   **Enforce Segregation of Duties** - Check to prevent the user who prepared the report (clicked **Add to daily reconciliation**) from also approving the report.
    *   **Select Roles that can approve a Daily Reconciliation** - Select whether anyone (except auditors) or only BA's and LBS can approve the report.
*   **Daily Reconciliation Reports** - Manage the report format
    *   **Select reports** - Click the drop-down and select **Open transactions**, **Open transactions bank,** or any available custom reports.
    *   **Select format** - Click the drop-down and select whether the report should be a PDF, word file (DOCX), or an Excel file (XLSX)

 **WARNING**: To enable the Daily Reconciliation feature, it needs to be enabled in **General Settings** and for each **Reconciliation Group**.  
Navigate to Administration>>Reconciliation groups and locate the correct reconciliation group. Toggle **Enable Daily Reconciliation**. Refer to **Related Articles** for more information.
