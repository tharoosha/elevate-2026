Trintech Boomi Connector – Adra – Overview and Frequently Asked Questions
=========================================================================

This article provides an overview of the Trintech Boomi Connector, answers common questions about integrations, and outlines steps for setup and support. 

Details
-------

**What is Boomi?**

The Trintech Boomi Connector is low-code, managed by Trintech, and allows organizations to set up rapid connections between their Trintech product and ERPs, CRMs, and more without heavy custom development. Unlike generic cloud integrations, Trintech hosts the Boomi platform in its own secure data centers, setting up dedicated Boomi instances. Integrations run in a controlled environment with Trintech managing infrastructure and InfoSec.  

**What integrations does Trintech offer through Boomi?**

Trintech offers a variety of integrations through Boomi. The list of available integrations changes regularly, as Trintech actively works to expand its integration offerings. Speak with your Account Manager for the current list of available integrations.

**I am interested in an integration with Boomi for one of my Trintech products. What should I do?**

Speak to your Account Manager regarding your interest in an integration with Boomi.

**What does Trintech need to set up an integration with Boomi?**

Trintech integrations normally require that the customer provides credentials to access the ERP platform, ERP endpoints, and field mappings.

**What will I need to do to maintain the integration once it is set up for my organization?**

You will be able to edit the credentials for the ERP platform and view whether your file transfers were successful or not. (File transfers occur through SFTP or Integration Hub depending on your Trintech product.) Ongoing maintenance of the integration (e.g., platform version changes) will be managed by Trintech.  

  
Trintech handles changes to the integration. If you have issues or need changes to your endpoints or field mappings, submit a Support Case.

**I have an existing integration with my Trintech product that doesn't utilize Boomi. How does this impact me?**

There is no impact to existing integrations. 

If you are migrating to a new ERP platform or want to explore the option to move your existing integration to Boomi, contact your Account Manager. Trintech can help assess if a switch to a Boomi integration is recommended for your organization.

**Will the existing SFTP options still be available?**

Yes. Trintech offers SFTP servers to import files. The Adra Integration Hub remains available.

**I am experiencing an issue with my integration through Boomi. What should I do?**

Submit a Support Case.
