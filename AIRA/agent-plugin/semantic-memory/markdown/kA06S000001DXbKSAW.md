Setup Connect External User
===========================

Engagement Admins can connect external users (Support, Auditor, Implementation) to the engagements they manage in three ways.

1.  [**Through e-mail account**](#through-e-mail-account)
2.  [**Through a supplied link**](#through-supplied-link)
3.  [**Through trusted organizations**](#)

**Note:** Ensure that external users activate their account using the activation email before they can be successfully added through any of these methods.

 **HELPFUL HINT**: If the user exists in another engagement, but has not been made globally visible, the following error message appears. To solve this, reach out to the Support team.  
![image.png](https://static.adra.com/adra-assistant/images/531cb4200fd4c9a13404cc83d472ee6b.jpg)

Through E-mail Account
----------------------

![image.png](https://static.adra.com/adra-assistant/images/3f7707ee2298e7a118dd21a28a14253e.jpg)

1.  Navigate to **Setup>>Users>>Connect external user**.

![image.png](https://static.adra.com/adra-assistant/images/7ceb4c18cf95d641208de5048ffcb34f.jpg)

2.  Click **Add user**. The add engagement field appears.

![image.png](https://static.adra.com/adra-assistant/images/f6e92d4179675f0705d3518848162d65.jpg)

3.  Select the name of the **engagement** to which the user will be connected.
4.  Click **Add engagement**.

![image.png](https://static.adra.com/adra-assistant/images/36db9402ecbbf01b74f7621231a05fa2.jpg)

5.  If the user is from an organization that is not listed as trusted, the figure above appears at the top of the page. Check the box to confirm the organization can be trusted.  For additional information on trusted organizations, see [Setup View and Manage Trusted Organizations](#article:kA06S000001DXbKSAW@Success-Center).

**Important:** To complete the addition of a user, ensure that the external user has activated their account as per the instructions provided in the activation email.

![image](https://static.adra.com/adra-assistant/images/f7fd2960823658edb8d1edfd55be954c.jpg)

6.  Click the **expand** arrow for the added engagement. If only one engagement is available, it will expand automatically.
7.  Select the user access level: Administrator, auditor or neither
    *   **Auditor example** \- Toggle **Auditor** to On and assign the **Auditor** role in Balancer
    *   **Service provider example** - Select **Organization and Engagement Admin** if for example a Trintech employee or partner requires access to **Setup** to provide assistance. Select **Business Admin** for the application the service provider requires access to.
8.  Select the user's application access.
    *   **No access** \- The user does not have access to the application
    *   **Standard user** -  The user has limited access to the application to perform everyday tasks. Additional user roles must be granted in each application:
        *   **Balancer** – Navigate to **Balancer>>Administration>>Users**, and click the user. Select **Read access** for the desired legal entities. [Balancer Access for Standard Users & Auditors](#article:kA00H000000kJ9mSAE@Success-Center)
        *   **Task Manager** – Navigate to **Task Manager>>Administration>>Users**, and click the user. Select **Read access** for the desired legal entities. [Task Manager User Page Overview](#article:kA0Ua00000002WTKAY@Success-Center)
        *   **Matcher** – Navigate to **Matcher>>Administration>>Users**, and click the user. Select **User access** for the desired legal entities, or expand a legal entity and select access to specific reconciliation groups.
    *   **Business admin** \- The user is responsible for every day administration and has access to all functionalities within the application.
    *   **Auditor** \- This option is only available if the user was assigned auditor access level.
9.  Click **Save changes**.

Through Supplied Link
---------------------

A link is typically provided by a service provider in order to easily add them to your engagement. Service providers are typically customer success, consultants, or support. Follow the steps below to add an external user through the link.

1.  Click the link(s) shared by a Service Provider to load the **Connect External User** page with the correct email populated.

![image.png](https://static.adra.com/adra-assistant/images/63ba03eca9b636fff946332d6b5edc5d.jpg)

2.  Click **Add user.**

Proceed with step 3 in the [Through E-mail Account](#through-e-mail-account) section as outlined in this article.  
  
 

Trusted Organizations
---------------------

Auditors in trusted organizations can be added as external users by following these steps:

![image.png](https://static.adra.com/adra-assistant/images/1bff653dd85eabede3309db96275855d.jpg)
------------------------------------------------------------------------------------------------

1.  Navigate to **Setup>>Users>>Connect external user**. 

![image.png](https://static.adra.com/adra-assistant/images/284e133291e75bd20083aa7b6889768b.jpg)

2.  The **Connect External User** page loads. Click the empty field.
3.  In the drop-down, search for the name of the desired user. 
    *   Users available in this field are typically auditors.

4.  Select the user and click **Search**. The **Add engagement** field appears.

![image.png](https://static.adra.com/adra-assistant/images/934931a57088e286afbc74f263a34e62.jpg)

5.  Click the add engagement field and select the desired engagement.
6.  Click **Add engagement**. The application access section appears.

![image.png](https://static.adra.com/adra-assistant/images/a7260555ef235391e8c690aa07c7e89a.jpg)

7.  Click the **expand** arrow for the engagement.
8.  Check the desired applications the user will have access to.
9.  Click **Save changes**.

The user now has application access. Note that for Auditors it is necessary to assign access privileges within each application as well.

*   **Balancer** – Navigate to **Balancer>>Administration>>Users**, and click the user. Select **Read access** for the desired legal entities.
*   **Task Manager** – Navigate to **Task Manager>>Administration>>Users**, and click the user. Select **Read access** for the desired legal entities.
*   **Matcher** – Navigate to **Matcher>>Administration>>Users**, and click the user. Select **User access** for the desired legal entities, or expand a legal entity and select access to specific reconciliation groups.

 **WARNING**: If the user is unable to perform tasks in the application after they have been connected to the engagement, do the following:

Check the application access in Setup. Navigate to **Setup>>User**, select the user, and click **Access and roles**. 

1.  Add the engagement if it has not been added already.
2.  Click the engagements expand arrow to view application access. Give access if necessary.

![image](https://static.adra.com/adra-assistant/images/1efa405f480ee2e742b02a5120983181.jpg)
