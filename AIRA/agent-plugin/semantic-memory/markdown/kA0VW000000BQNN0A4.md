Setup Prerequisites for SAML Configuration
==========================================

**This article is currently under approval**, please refer to the previous guides for [OKTA Configuration](#article:old-Setup-Okta-Configuration@Success-Center) and [SCIM Configuration](#article:kA0VW000000BQlZ0AW@Success-Center) until further notice. 

This article outlines the required configuration steps in **Adra Setup** that must be completed before configuring **SAML SSO** with an Identity Provider (e.g., Okta).

Complete these prerequisites to ensure the environment is properly prepared before proceeding with the integration setup.

*   **If you are configuring SAML SSO only:**  
    Complete the sections for [**Environment Domain**](#confirm-environment-domain) and [**Adra Signing Certificate**](#obtain-adra-signing-certificate).
    

Ensure these prerequisites are completed before proceeding to the SAML or SCIM configuration guides.

Confirm Environment Domain 
---------------------------

This value is required when configuring SAML in Adra Setup.

1.  Login in to **Adra Setup**.
2.  Look at the address bar in your browser:
    *   If the URL is [https://setup.adra.com](https://setup.adra.com), then adra.com is the **environment domain.** 

![image](https://static.adra.com/adra-assistant/images/506c32a6b08466e85fb35ae860edf51b.jpg)

Obtain Adra Signing Certificate
-------------------------------

Depending if you are configuring an Organization or an Engagement in Adra you need to navigate to the security settings accordingly for the steps in the Adra Setup Portal:

*   **Organization>>Security**
*   **Engagement>>Security**

1.  Navigate to **Organization/Engagement>>Security**. 
2.  Scroll to **Security Policy>>Use a federated identity provider.** 
3.  Click **Download Adra Certificate for SLO**.

![image](https://static.adra.com/adra-assistant/images/5fef77ad3ebd1397aa8837c2675d5cb8.jpg)
