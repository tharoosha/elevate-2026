Matcher Automatic Import Configurations
=======================================

Automatic Import Configurations
-------------------------------

Automatic Import Configurations create the ability to import data automatically without using the **New Import** button. Users can instead drag and drop files on the Import Screen to quickly import data, and to import files through Integration Hub (See Related Articles). Automatic Import Configurations can be created after an import’s configuration has been established. To add a new automatic import configuration, navigate to **Administration>>Import settings>>Automatic Import Configurations** and click **\+ Add Import Configuration.**

 **HELPFUL HINT**: An automatic import configuration will automatically exclude transactions that have been imported previously. The exception is if there are duplicate transaction within the file, or two of the same file is uploaded at the same time.

  
![automatic import config.jpg](https://static.adra.com/adra-assistant/images/cd5126a243f27e139ac8fb91bd0e1a2e.jpg)

   
Once the administrator clicks to create the new automatic import configuration, the **Add Automatic Import Configuration** page will open.  
  
![import settings Automatic Import configuration.jpg](https://static.adra.com/adra-assistant/images/999edfecad33927c5b3d9c738b250126.jpg)

1.  **Import Configuration Type**
    1.  Transaction Import
    2.  Balance Control Import
2.  **Name** – provide a descriptive name.
3.  **Identify the transaction file from the filename**
    1.  **The transaction filename contains this text** – Ensure that the text entered into this box matches some part of the file name, including if there are any spaces. For Example, the file could be named B of A (Plus date), so in the configuration settings B of A should be typed to match. If written BofA, Matcher will not match the file to the created configuration.
    2.  **The transaction filename should matching this RegEx** – Choose this option if RegEx is needed to specify a more complicated file name.
4.  **Select Import Configuration** – From the dropdown menu, choose the import configuration to associate the automatic configuration with. Matcher will use this selection to determine how to bring in the file. Keep in mind that the column mapping and Look-up Tables configurations will be used here. Additional options include the option of whether to Import the file without approval or to force a manual approval.
5.  Click **Save** to save the configuration and return to the Automatic Import Configuration screen.

 **BEST PRACTICE**: For the Import Configuration to appear in the **Select Import Configuration** drop-down, the following conditions must be met in the Import Configurations settings.  
The **Select how to set periods on transactions** option must be one of the following:

*   Use booking date (BDate) from the transaction file to set period
*   Use fiscal year and fiscal year period codes from transaction file to set period

  
![image.png](https://static.adra.com/adra-assistant/images/2308a6dce654b9e3d90f4bd9fc7d7160.jpg)   
If the option Use period drop-down picker is selected, the Import Configuration will not be shown in the Automatic Import Configuration drop-down list.
