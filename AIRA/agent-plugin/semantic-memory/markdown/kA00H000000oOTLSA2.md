Engagements Page Overview
-------------------------

To view the **Engagement** page, navigate to **SETUP>>Engagement**.

If an administrator has access to multiple engagements, the **Engagements** page contains a list as displayed below. If the administrator only has access to one, click [here](#engagement-details).

![2024-03-22_11-07-26.png](https://static.adra.com/adra-assistant/images/ef60cea95b0cbf950fa8c27a07d2aa44.jpg)

1.  **Search Engagement Name** - Enter the engagement name to locate it.
2.  **Views** \- Click to view saved list view configurations.

![2024-03-22_11-29-50.png](https://static.adra.com/adra-assistant/images/08949537e3cbdadaebd1c5f552f08485.jpg)

*   *   Click **Save current view** to add the current active columns, column order, sort order, filters, and groups.<
    *   The loaded view is marked with a blue line. <
    *   Click the recycle icon to delete the saved view.<

3.  **List settings**

![2024-03-22_11-12-01.png](https://static.adra.com/adra-assistant/images/8614d7d95928214e6f7226af717e1c69.jpg)

*   *   **Clear all filters** - Click to remove any applied filters.
    *   **Reset table** - Click to reset active columns and column order to default, and remove any applied grouping.
    *   **Export to Excel** \- Click to export the current list view to Excel.
    *   **Columns** \- Toggle columns **On** (blue) or **Off** (grey). 

4.  **Sort and Filter**
    *   Drag and drop the column header to the **Drag and drop here to group** field to group the list by the column content.
    *   Click a column header to sort the list in ascending or descending order according to the column's content.
    *   Click a filter icon to apply a filter to reduce the list length.
5.  **Engagements** \- Click an engagement to open the engagement details page.

Engagement Details
------------------

The **Engagement Details** page in **Setup** allows administrators to

*   View engagement details
*   Copy and regenerate the Accounts engagement Key
*   Set engagement time zone and language
*   View what applications are active for the engagement

![image](https://static.adra.com/adra-assistant/images/98286cf5a3a460715578883dd4ae4472.jpg)

1.  **Name** \- Entered by the technician who created the engagement.
2.  **Time zone** - Select the time zone for the engagement. This setting is overridden for Legal entities with a different time zone selected.
3.  **Account engagement key** \- Copy or regenerate the key. This key is used to in the Adra application **Accounts** to transfer items to **Balancer**.
4.  **Language** \- Select the default language for the engagement. New users will be assigned this language by default, but they can change it preferred.
5.  **Organization ID** - This option is only available if the engagement is placed in an Organization.
6.  **Engagement Country** - Assign an engagement country. Note that the engagement country will automatically default the currency to match the country currency. See [**Related Articles**](#article:kA00H000000oOV7SAM@Success-Center) for more information. 
7.  **Engagement Currency** - The main reporting currency set for an Adra environment. All legal entities are tied to this currency for consolidated reporting, but can have local currencies.
8.  **Notes** \- Entered by the technician who created the engagement.
9.  **Personal access token** \- Click the blue link to navigate to the user access tab to manage tokens for use with Analytics and Integration Hub. See [**Related Articles**](#related-articles) for more information.
10.  **Application access** \- View which applications the engagements have active.

Trusted Organizations
---------------------

Trusted organizations can be added to an engagement so that users from said organizations can be added easily through **Connect external users** on the **Users** page. See [**Related Articles**](#related-articles) for more information.

Integrations
------------

The **Integrations** tab lets System and Engagement admins set up links to applications and dashboards, making them accessible from the **Apps** page in **Adra Setup**.

See [Related Articles](#related-articles) for more information.

Available applications are:

*   Workday
*   AAC
*   PowerBi
*   Excel
*   Tableau

![image](https://static.adra.com/adra-assistant/images/2fe8f518ecae829a153bd264e3b9fd8f.jpg)

Audit Trails
------------

The **Audit trails** tab lets administrators see the history of changes made in the engagements **Setup**, such as updates to user profiles, user access, and legal entity settings.  
 ![image](https://static.adra.com/adra-assistant/images/2c0d64ed9b771cf487aa6bce58c2d137.jpg) 

To view older events, scroll to the bottom of the page and click **Get more results**.
