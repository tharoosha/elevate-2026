WS\_FTP Server (CVE-2023-40044, CVE-2023-42657)
===============================================

Problem:  
  
**CVE-2023-4044**  
In WS\_FTP Server versions prior to 8.7.4 and 8.8.2, a pre-authenticated attacker could leverage a .NET deserialization vulnerability in the Ad Hoc Transfer module to execute remote commands on the underlying WS\_FTP Server operating system.  
  
**CVE-2023-42657**  
In WS\_FTP Server versions prior to 8.7.4 and 8.8.2, a directory traversal vulnerability was discovered. An attacker could leverage this vulnerability to perform file operations (delete, rename, rmdir, mkdir) on files and folders outside of their authorized WS\_FTP folder path. Attackers could also escape the context of the WS\_FTP Server file structure and perform the same level of operations (delete, rename, rmdir, mkdir) on file and folder locations on the underlying operating system.  
  
Status:

**Is Trintech operating a version of the Progress Software’s WS\_FTP Server product as defined in vulnerabilities announced on September 27, 2023?**

Yes. Based on our current environment, Trintech WS-FTP Server is susceptible to CVE-2023-42657. Based on validation testing and controls that exist within the Trintech environment, our risk management team have re-classified the severity of this vulnerability as High for Trintech.

CVE-2023-40044 is not applicable.

**If so, have the recommended remediation steps released by the vendor been implemented on all vulnerable systems?**

Trintech will apply remediation to impacted products during the October maintenance window of October 21st, 2023 in accordance with standard contractual obligations of 30 days from identification to remediation.
