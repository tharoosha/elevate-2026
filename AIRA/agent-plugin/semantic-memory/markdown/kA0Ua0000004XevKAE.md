Journal Entry - Journal Entries Page
====================================

The Adra Journal Entry application enhances financial processes by automating journal entries, and centralizing audit documentation to streamline compliance. It eliminates the need for manual work by integrating with ERP systems.

The Journal Entries page lets users add, view, and manage entries.

![image](https://static.adra.com/adra-assistant/images/0e10c2413e395ae24cc3e6ed9bcf79c3.jpg)

1.  **New Journal Entry** - Click to create a new journal entry
2.  **Select period** - Click to select a period to view entries in the grid
3.  **Show deleted** - Click to show deleted entries
4.  **Export** \- Click to export entries with the status **Ready to post.**
    *   Download the file from the **Jobs** page
    *   Entries with the status **Incomplete** or **Posted** can not be exported.
5.  **Grid settings** - Click to do the following
    *   Clear filters applied to the list
    *   Reset column order and visibility
    *   Manage which columns are visible
6.  **Headers** 
    *   Click a header to sort the list in ascending or descending order according to that column's content
    *   Click a funnel to apply a filter on the list
7.  **Journal entry grid** \- View and manage journal entries
    *   **Status -** The status column can display three different statuses
        *   **Incomplete** \- The entry lacks details to balance the difference to zero
        *   **Ready to post** \- The entry is complete and can be exported
        *   **Posted** \- The entry has been exported
8.  **Actions**
    *   **Clone Journal** \- Click to clone the selected journal entry.
    *   **Pencil** \- Click to view and edit details
    *   **Revert** \- Click to revert an entry status from **Posted** to **Ready to post.** The entry can then be edited and exported again.
    *   **Delete** \- Click to delete the entry

New Journal Entry 
------------------

New journal entries can be created in three ways

*   In Matcher on the **Exceptions** page. To learn more, see [Matcher Journal Entry](#article:kA06S000000YQcgSAG@Success-Center).
*   In Balancer on an accounts reconciliation page. To learn more, see [Balancer Journal Entry](#article:kA0Ua0000004XevKAE@Success-Center).
*   In Journal entry on the **Journal Entries** page. To learn more, see [Journal Entry Create Journal Entries](#article:kA0VW0000008u1p0AA@Success-Center).

Edit Journal Entry
------------------

Click on any Journal Entry to view details. Click the **Reverse** button to reverse the journal entry.

![image](https://static.adra.com/adra-assistant/images/20e0d21ada9a0a0df80928d6664d2b20.jpg)

Export Journal Entries
----------------------

Journal entries can be exported to an Excel file that can be downloaded from the **Jobs** page. Additionally, Journals can be exported from the Matcher application in other file formats. To learn more, see [Journal Entry Export Journal Entries](#article:kA0VW0000008tfF0AQ@Success-Center).
