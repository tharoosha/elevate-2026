Task Manager Sequence Breaches
==============================

Task Manager allows users to work their way through a series of tasks to complete the desired action. Sometimes the sequence of that task is essential to follow and other times, breaking the sequence becomes more important than completing tasks in a particular order. When breaking the sequence, or a breach, is necessary, Task Manager settings will need to be adjusted.

Sequence Breach Defined
-----------------------

A sequence breach is when a user tries to prepare a task with an unfinalized preceding task(s). The System Administrator can configure the engagement to allow breaches or not.   
  
To configure the engagement:

*   Navigate to **Task Manager>>****Administration**\>>**General Settings**.

 ![image.png](https://static.adra.com/adra-assistant/images/21e58a7c6a2f8ab93e2cbfffca3a0500.jpg)

*   If the **Allow sequences to be breached** setting is set to the right (On), users will breach a sequence.
    *   While preparing the task, the user will be presented with a pop-up text box where they will be asked to add a **Sequence breach comment** before the **Certify** button is activated. 
*   If the **Allow sequences to be breached** setting is set to the left (Off), users will not be able to prepare the task while it has a preceding task(s) that are not finalized.

  
  
The example below shows what users will see if they try to certify a task with **Allow sequences to be breached** disabled.  
  
![User-added image](https://static.adra.com/adra-assistant/images/21d15fba52844a29e2cb33dd906132e2.png)  
 

Identify Tasks with Breached Sequence
-------------------------------------

### Home Page

Approvers can identify breached task sequences on the **Home** page as long as the task is assigned to them or their team. A breach symbol is displayed on the breached task.

![image.png](https://static.adra.com/adra-assistant/images/301b28ce3db1f90ccb6e7d0edfc8dd32.jpg)  
 

### Tasks Page

Approvers can identify breached task sequences on the **T****asks** page as long as the **Sequence breached** column is visible. A breach symbol is displayed in the column as shown in the figure below. To filter tasks based on Sequences breached, click the column header **filter** icon, and select to view only tasks with breached sequences or those without. Click the column header to sort tasks based on if they are breached, placing them either at the top or bottom of the list.

![image.png](https://static.adra.com/adra-assistant/images/644d302155617206d9e80480b5a3624b.jpg)  
  
Hovering over the breach icon will display the breach comment, as displayed in the figure below.

![User-added image](https://static.adra.com/adra-assistant/images/d8ceff86b4995a7ef5b6ce3505a6d927.png)
