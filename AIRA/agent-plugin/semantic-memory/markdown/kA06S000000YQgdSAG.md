Matcher Journal Entry
=====================

 **HELPFUL HINT**: Adra Journal Entry is a new module that will be generally available to customers in April 2025. If you’d like to be an early adopter, please contact your account manager.

Journal Entry Overview
----------------------

During the reconciliation process, there may be entries that are not already integrated with the general ledger. Examples may include credit card or bank fees, overs, or shorts. Matcher's journal entry feature allows users to filter for these items, assign the appropriate general ledger accounts, and export the entries in a format that will seamlessly upload to the GL.

Journal entries created in Matcher can be viewed and edited in both the Matcher and the Journal Entry applications. To learn more about the Journal entry application, see [Journal Entry - Journal Entries Page](#article:kA0Ua0000004XOnKAM@Success-Center).

View JE Column on Exceptions Grid
---------------------------------

To make the journal entry column visible on the Matcher Exceptions grid:

1.  Navigate to **Matcher>>Exceptions**. Click the **Unmatched Items** tab.
2.  Click the **settings** icon.
3.  Under Columns, toggle **JE** to On.

![settings icon](https://static.adra.com/adra-assistant/images/ecab9df0c4c1e8986deeb395d1b3b77e.jpg)

  
The JE column is visible on the grid. When a journal entry has been created for an item, the JE icon displays.

![je column](https://static.adra.com/adra-assistant/images/fb599cfc1fe3498e4193d56acc128c2a.jpg)  
  
 

Create a Journal
----------------

To create a journal entry:

1.  Navigate to **Matcher>>Exceptions**. Click the **Unmatched Items** tab.
2.  Check one or more **items**.
3.  Click **New Journal**

![click new journal](https://static.adra.com/adra-assistant/images/e453f3222a2484f554f2a598d73efb0d.jpg)

  
The New Journal pop-up displays. 

4.  Enter a **Description** for the journal.
5.  The **Journal Date** and **Period** will populate automatically. Edit these fields as needed.
6.  Information from the selected transaction items populates automatically. Edit the fields or delete the items as needed.
7.  In order to save a journal, the difference between the total of the debit items and the total of the credit items must equal zero. When necessary, click **+Add Row** to add a transaction line.

![click add row](https://static.adra.com/adra-assistant/images/2ae975c3c66963f301d83df3cd213c8b.jpg)

8.  For any added rows, select an **Account No**.
9.  Enter a **Debit** or **Credit** amount to explain the balance. Enter additional information as desired.
10.  Click **Save**.

![click save](https://static.adra.com/adra-assistant/images/029915608b6dd876bbc29cd32c121957.jpg)

To view or hide columns on the journal, click the **settings** icon (gear). A blue toggle indicates that the column is visible.

![click gear](https://static.adra.com/adra-assistant/images/0a38db00c9cad533c47a2c8efb94b128.jpg)

Manage Accounts
---------------

Journal entry items may include references to accounts that are not used in the Adra suite.   
When adding a journal, if an account is not available in the account list:

1.  Click **Manage Accounts**.

![mat 11.png](https://static.adra.com/adra-assistant/images/d98eb08534fc02e596c8522413b0b52d.jpg)

2.  Enter the **Account Number**. If desired, enter the account **Description**.
3.  Click **Create account**.

![mat 12.png](https://static.adra.com/adra-assistant/images/55c1b4484a0028378d4cd202ecf48219.jpg)

4.  To assign the account as the default account, click the **key** icon.
5.  Click **Save changes**.

![mat 13.png](https://static.adra.com/adra-assistant/images/e32ea02f641d48e9c499cbb40de042ec.jpg)

Manage Existing Journals
------------------------

To manage existing journals, navigate to **Matcher>>Exceptions**. Click the **Journals** tab.

*   View or edit a journal: Under the **Actions** column, click the **edit** icon (pencil).
*   Delete a journal: Under the **Actions** column, click the **delete** icon (trash). Note that only journals with a **Ready to Export** status can be deleted.
*   Delete multiple journals simultaneously: Check the desired **journals** in the first column. Click **Delete**.

![edit journals](https://static.adra.com/adra-assistant/images/c8fc7b73ebb3cc507b1fd4ce0fc91692.jpg)

In order to edit or delete an **Exported** journal, the journal must be reverted. **Deleted** journals can also be reverted to the **Ready to Export** status.

*   Change journal status: Check the desired journal(s) in the first column. Click **Revert**.

![click revert](https://static.adra.com/adra-assistant/images/233627e602a3ab8f648c3b183e2dd07d.jpg)

*   Filter journals: Click the **filter** icon on any column headers to filter the journal list.
*   Configure journals grid: To view or hide columns on the journal list, click the **settings** icon (gear). A blue toggle indicates that the column is visible.

![configure grid](https://static.adra.com/adra-assistant/images/73231385e2f1debdc2e23e391eeb1e82.jpg)

Export Journals
---------------

Journals can be exported and downloaded as an Excel file from the **Exceptions** page, and within Journal Entry. To learn more, see [Journal Entry Export Journal Entries](#article:kA0VW0000008tfF0AQ@Success-Center).
