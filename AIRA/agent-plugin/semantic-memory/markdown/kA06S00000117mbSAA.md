Setup Integration Hub / Adra Agent Installation & Troubleshooting
=================================================================

The Integration Hub is an API that enables organizations to automatically import files into the Adra applications, Balancer, and Matcher.  
Trintech offers Integration Hub as a direct API, over SFTP through a hosted cloud solution, and allows organizations to install the Adra agent locally.  
Learn more about the different options: [Integration Hub Guide](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7U6S000000ib5FUAQ).  
To enable the Integration Hub product, [contact your account manager](https://success.adra.com/s/customer-success).

 **WARNING**: The System Administrator who installs the Adra Adent or configures the Integration Hub API is responsible for the yearly update of the Personal Access Token (PAT). If the responsible System Administrator is no longer available, another System Administrator will need to perform this action. An email is sent before the expiry to remind the System Administrator.

Troubleshoot
---------------

If files are placed in the error folder, no job appears for the upload file in Balancer/Matcher, or the import job receives an error message, it may be due to one of the following:

1.  Integration hub is inactive
2.  Incorrect or expired Personal Access Token (PAT)
3.  The file format is incorrect.
    *   Balance: Learn more about Balancer import issues: [Balancer Troubleshoot Balance & Transaction Imports](#article:kA06S000000YRSMSA4@Success-Center)
    *   Matcher: Reach out to Adra Support.

### Integration Hub Is Inactive

Navigate to **Setup>>Engagements** and select the correct engagement.

![image.png](https://static.adra.com/adra-assistant/images/81252e8f9fcc7366a1b4a6e998844af2.jpg)  
In the Engagement details tab, verify that Integration hub is active. If it is listed as not active, reach out to Adra Support. 

### Expired or Incorrect Personal Access Token

The System Admin who originally installed the Adra agent and created the access token must update said token yearly. If there is a new designated System Admin, it is recommended that the Adra agent be reinstalled. In this case, refer to the [Integration Hub Guide](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7U6S000000ib5FUAQ).  
  
If the PAT has expired or is incorrect, follow the steps below:

1.  Navigate to **Setup>>Profile>>User access**
2.  Click **Create token**.

![image.png](https://static.adra.com/adra-assistant/images/778a41917ee03f9912d4892c2d560100.jpg)

3.  In the pop-up, select INTEGRATION HUB and click **Create access token**.
4.  Click **Create token**.

![image.png](https://static.adra.com/adra-assistant/images/89f1fc7042da8b7e4c6ba61441a29f50.jpg)

5.  In the second pop-up, click **Copy** to copy the token. Note that the token will only be displayed once.
6.  To update the token, do one of the following
    1.  If the Adra agent is installed on a server, [follow these steps](#update-the-token-for-adra-agent-installed-on-a-server).
    2.  Click **Download agent** as shown in the figure above, and run the install wizard. [Follow these steps](#update-the-token).

####   
Update the Token

If the Adra agent folder is installed locally (and not on a server), the token can be updated by running the setup wizard for the Adra agent.

1.  Follow the steps above to create a new token and download and run the setup wizard.

![image.png](https://static.adra.com/adra-assistant/images/376f83dc165b87ef7bb6a9a688f83255.jpg)

2.  In the setup wizard, click **Next**, and select **Modify**.
3.  Click **Next** three times and paste in the new token in the **Personal Access Token** field. 
    *   Only change the folder locations if they are incorrect or need to be moved.
4.  Click **Next** and ensure the correct engagement is selected in the drop-down.
5.  Click **Install**.

#### Update the Token for Adra Agent Installed On a Server

To update the PAT for an Adra agent that is installed on a server, follow these steps:

1.  Navigate to **Add or remove the program** on your computer, find the Adra agent, and click **Uninstall**.

 ![image](https://static.adra.com/adra-assistant/images/8a61189a15a3e3878db99fdb8312b328.png)

2.  Confirm that the app is to be uninstalled.

 ![image.png](https://static.adra.com/adra-assistant/images/53eac989522894e2ec28979baa9d14f0.jpg)

3.  In the setup wizard, select **Modify**.
4.  No other setup settings need to be modified unless folder locations need to be updated.
5.  Paste the new token in the Personal Access Token field.
6.  Complete the setup.

Test the Adra Agent
-------------------

It is recommended to run a test import to confirm that the connection works as intended.  
Locate the Adra agent folders as shown in the figure below.  
![image.png](https://static.adra.com/adra-assistant/images/08c8e42e654a7185a73ee2dae5f32f6f.jpg)

Place a file in the desired folder. If the file moves to the corresponding archive folder, verify that the file was imported into the applicable application.

*   **Balancer>>Jobs**
*   **Matcher>>Import**

If the file lands in the **Error** folder, try to uninstall and reinstall the Adra agent, or reach out to support.
