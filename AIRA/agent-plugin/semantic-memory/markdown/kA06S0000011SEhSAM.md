Matcher Suggestive Manual Matching
==================================

Enable Suggestive Matching
--------------------------

  
To enable Suggestive Matching for a reconciliation group:

1.  Navigate to **Matcher>>Administration>>Reconciliation Groups**.
2.  Click the **reconciliation group**.

![Click Rec Group](https://static.adra.com/adra-assistant/images/b1a495cf1d751016efb14e8d0ece24e4.jpg)  
 

3.  Toggle **Suggest manual matches** ON.
4.  Click **Save**.

![Suggest Manual Matches On](https://static.adra.com/adra-assistant/images/04f9a932ad2fc5cc52f326393ed09301.jpg)

  
 

Suggestive Matching Settings
----------------------------

  
On the Reconciliation Group page, users can configure suggestive matching settings. In addition to specifying maximum variances in Amount and Date, users can select the set of rules to be used for suggestions. The system defined rule set is a set of standard rules that can be utilized with no previously configured matching rules for the reconciliation group. The matching rules previously configured for the reconciliation group can also be used for suggestions.  
  
**Allowed Variance**  
  
To specify an allowed variance on amount for suggestions:

1.  Enter an allowed variance in the textbox below **Allowed variance on amount**.

To specify an allowed variance on date for suggestions:

1.  Enter an allowed variance in the textbox below **Allowed variance on date**.

![Enter Allowed Variance](https://static.adra.com/adra-assistant/images/eb2b35ecb5a32dbe0f2bb1ea03a96c84.jpg)  
 

**Matching Rules**  
  
To utilize the system defined rules for suggestions:

1.  Click **System defined matching rules.**
2.  Check **The text must match in the columns for sources 'Ledger' and 'Bank'** to require the text in a field to match.
3.  Click the **Ledger drop-down** and select the **field**.
4.  Click the **Bank drop-down** and select the **field**.

![Click System Defined](https://static.adra.com/adra-assistant/images/8e83bb8c3c46a1a22cf77c54ba6b4d6b.jpg)

  
 

 **HELPFUL HINT**: The following are the system defined rules.

*   **One to one:** A transaction from one source matched to a transaction from the other source with the same date and amount.
*   **One to Many Ref**: Several transactions from one source with the same reference number matched to one transaction with the same date and amount.
*   **Many Ref to Many Ref**: Transactions grouped by reference number from each source, matched by date and amount.
*   **One Debit to One Credit Ledger**: A debit matched with a credit in the ledger with the same date and amount.
*   **One Debit to One Credit Bank**: A debit matched with a credit in the bank with the same date and amount.
*   **Sum Ledger Ref**: A set of transactions in the ledger can be matched if their sum is zero and they share the same reference and date.
*   **Sum Bank Ref**: A set of transactions in the bank can be matched if their sum is zero and they share the same reference and date.
*   **One to Two Random:** Two transactions from one source, grouped by reference, are matched to one transaction from the other source with the same date and amount.

  
  
To utilize the matching rules configured for this specific reconciliation group:

1.  Click **Use matching rules configured for this group**.

![Click Use Matching Rules](https://static.adra.com/adra-assistant/images/fe985edf4044ef2c3918d888c49aca6d.jpg)  
  
 

Run Suggestive Matching
-----------------------

To run Suggestive Matching:

1.  Navigate to **Matcher>>Exceptions**.
2.  Click the **Unmatched Items tab**.
3.  Click the **reconciliation group drop-down** and select the **reconciliation group**.

![Select Rec Group](https://static.adra.com/adra-assistant/images/e8abeb95316925c832a89dce966726f1.jpg)  
 

4.  Click the **gear icon**.

![Click Gear Icon](https://static.adra.com/adra-assistant/images/4e02618fe50eec31209b7baa592057e3.jpg)  
 

5.  Click **Settings for suggestions**.

![Click Settings for Suggestions](https://static.adra.com/adra-assistant/images/4c65d23ec73bec4f2f786951edc7df99.jpg)

6.  Select **System defined matching rules** or **Use matching rules configured for this group**.

![Select Rule Set](https://static.adra.com/adra-assistant/images/c53293e77359968dff10f239c980e1e0.jpg)  
 

7.  If the rule set selected for suggestions differs from the rule set defined on the Reconciliation Group page, click **Save settings** to make the selected rule set the default rule set for suggestions. This will update the selection on the Reconciliation Group page.
8.  Click **Save and find suggestions**. Note that if changes are made to the settings for suggestions on the Reconciliation Group page, Suggestive Matching must be rerun to view new suggestions.

![Click Save](https://static.adra.com/adra-assistant/images/f9a7e8528cf6eb87ab3dbc012d74e58f.jpg)

  
 

View Suggestive Matches
-----------------------

To view suggested matches:

1.  Check the box to select an **unmatched item**.
2.  Click **Suggestions found**.

![Click Suggestions Found](https://static.adra.com/adra-assistant/images/fe9b2704eef89ea42340c5e9d5d9b32b.jpg)

3.  View the amount and date variance, field matches, and the matching rule used for suggestion.

![View Details](https://static.adra.com/adra-assistant/images/510a9b41e7a5747a6ded7dd962d825de.jpg)  
 

4.  Click the **arrow** to view additional suggestions.

![Click Arrow](https://static.adra.com/adra-assistant/images/f0f0087c56598889b09a129ca22e0261.jpg)  
 

5.  If none of the items should match, click **Discard suggestions** to remove the suggestions for the selected item.

![Click Discard Suggestions](https://static.adra.com/adra-assistant/images/fd8ecb3b75c5537768e529f0384f8575.jpg)  
 

6.  If one of the suggestions is a match, click **Match suggestion**. The items will move to the Matched Items tab.

![Click Match Suggestion](https://static.adra.com/adra-assistant/images/acd093078f521a4c53bf06e11c48f743.jpg)

  
Note that Suggestive Matching must be rerun to view new suggestions after new data is imported into the system and after Automatic Matching Rules are run.
