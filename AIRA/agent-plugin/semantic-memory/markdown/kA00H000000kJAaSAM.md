Balancer Account Settings Page Overview
=======================================

The account settings page allows users to add new accounts manually, manage existing accounts, and manage sub classes used for account classification. Navigate to **Administration>>Account settings**.

![image.png](https://static.adra.com/adra-assistant/images/eb88e992a0b8bfb196eea47ee71aef26.jpg)

1.  **Filter accounts**:
    *   **Legal entities** – Select individual legal entities or select All legal entities in the drop-down to view the associated accounts.
    *   **Search Account number** – Enter a partial or entire account number to view corresponding accounts.
2.  Action buttons
    *   **New account** – Create a new account manually.
    *   **Manage sub classes** – Add and edit account sub classes. These are used to categorize and filter accounts on the Accounts and status page.
    *   **Export** – Export a file containing all account settings, account roles, or extra fields.
    *   **Import** – Import a file containing all account settings, account roles, or extra fields.
3.  Accounts grid – Click a column header to sort the list in ascending or descending order. Click the filter icon to apply or clear a filter. 
4.  Manage account list
    *   **Hide sub accounts** – Toggle to hide sub accounts within a group account in the list. In the example image above, account 1010 is a sub account and account 10xx is the main account.
    *   **Show inactive accounts** – Toggle to display any deactivated accounts.
    *   **Settings** – Click to open the menu for enabling user role columns.
