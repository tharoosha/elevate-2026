Use SCIM Read Endpoints Alongside Setup Portal User Provisioning
================================================================

You can query Adra users and groups via SCIM GET (read) endpoints even when Setup Portal User Provisioning is your active provisioning method. Write operations via SCIM are not available in this mode.

**Who this is for:** Adra Organization Admins who manage users through the Setup Portal and need programmatic read access to user or group data via the SCIM API, for example to sync user lists into an external system or audit provisioning state.

What is and is not supported
----------------------------

When Setup Portal User Provisioning is the active provisioning method for your organization:

**SCIM operation**

**Supported**

GET (read users, list users)

Yes

GET (read groups, list groups)

Yes

POST (create users)

No

PUT / PATCH (update users)

No

DELETE (remove users)

No

POST / PATCH (create or update groups)

No

Write operations require SCIM to be set as the provisioning master. If you need full SCIM provisioning, see [Setup SCIM Implementation for Automated User Provisioning Using OKTA](#article:kA0VW000000BQjx0AG@Success-Center).

Prerequisites
-------------

*   Your organization must have the SCIM feature enabled. Navigate to **Organization >> Security >> User management** and confirm that SCIM Integration is active.
*   You must be an **Organization Admin** for the organization you are querying. The Personal Access Token (PAT) used for authentication must be generated by an Org Admin.

Authenticate your SCIM read requests
------------------------------------

SCIM read requests use the same Personal Access Token (PAT) authentication as full SCIM provisioning. If you do not already have a PAT configured for Identity API access, follow the PAT creation steps in [Setup Prerequisites for SCIM Configuration](#article:kA0VW000000BQgj0AG@Success-Center).

Once you have a token, include it in the `Authorization` header of your requests:

    Authorization: Bearer YOUR_TOKEN_HERE
    

For full endpoint reference, including available GET operations for users and groups, see the [SCIM 2 API documentation](https://developer.adra.com/doc/adra-scim/authentication).

Common questions
----------------

**Can I use SCIM GET endpoints without enabling SCIM as my provisioning method?** Yes. SCIM read access does not require switching your provisioning method. Your organization can continue using Setup Portal User Provisioning as the master while read queries are made via the SCIM API.

**Will switching to SCIM read access affect how users are managed in the Setup Portal?** No. Using SCIM GET endpoints is read-only and does not change how users are created, updated, or deactivated. The Setup Portal remains the source of truth for user changes.

**Can I use both SCIM provisioning and Setup Portal provisioning at the same time?** No. Adra requires one provisioning master at any time. You can either use SCIM for full provisioning, or use Setup Portal Provisioning with SCIM read-only access. You cannot push user changes through both simultaneously.
