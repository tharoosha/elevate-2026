Task Manager Create & Manage Teams
==================================

Teams are a way to organize individuals into the tasks they will complete. Because tasks are assigned to a team, the creation of teams is required. When adding teams, give each team a descriptive name so that it can be identified easily. Examples of team names include Accounts Payable, Accounts Receivable, Payroll, General Ledger, Reconciliation, etc.  
  
Each team has the option to have a Team Admin, who is responsible for the oversight of the tasks within that group. A team consists of a collection of users with Preparer, Approver, and/or Team Admin access rights. A user can fill more than one of these roles on a team. Additionally, a user can be on multiple teams, and the user’s role(s) can differ from team to team. For example, a user can be an approver on the Accounts Payable team and a preparer on the Payroll team. 

 **HELPFUL HINT**: Users can have access to a team without being assigned as a Preparer, Approver, or Team Admin. Therefore, it is important to define each team member's role so that users can complete individually assigned tasks or team tasks as needed.

Create New Teams
----------------

To create a new team:

1.  Navigate to **Task Manager**\>>**Administration**\>>**Teams**.
    

![2024-06-18_11-41-30.png](https://static.adra.com/adra-assistant/images/b07dd7d33a5b27897ebac75adda7188b.jpg)

2.  Click **\+ New Team**.   
    

 ![add team details](https://static.adra.com/adra-assistant/images/47d5fe2c2c3a8b16aa104606af781108.jpg)

3.  Enter **Team name**. Create/follow a standardized naming convention. This field is required.
4.  Enter **Team code**. This code is a unique identifier used to link tasks from imported task template files to the team. This field is required.
5.  Enter **Team description**. This is not a required field, but the addition of a team description is recommended. Include details that will aid in the identification of tasks for team member placement.

 ![add team members](https://static.adra.com/adra-assistant/images/e70881491300a9680ae2a05bcf04bc35.jpg)

6.  Click the empty field under **Add team members**. A list of users with access to Task Manager displays.
7.  Select the **users** to add to the team. Begin typing a user's name to filter the drop-down list.
8.  Click **Add**.

![2024-06-18_11-52-58.png](https://static.adra.com/adra-assistant/images/dc89745623ad0ae22becda3681a28503.jpg) 

9.  Assign **Preparer**, **Approver**, and/or **Admin** roles for each user. 
    *   **Preparers** \- In addition to completing tasks directly assigned to them, any users assigned the Preparer role can claim functions that have been assigned to a team (and not to a specific user). Additionaly, they can collaborate on tasks that are not assigned to them if the Co-Preparer setting is enabled. To learn more about the Co-Preparer setting, see [Task Manager Create Task Templates.](#article:kA0Ua00000070phKAA@Success-Center)
    *   **Approvers** \- In addition to reviewing and finalizing tasks assigned directly to them, any user assigned the Approver role can claim tasks assigned to the team. 
    *   **Admin** \- Can view all team tasks, edit active ones (like due dates or assignees), and send reminders for completion. 
10.  Click **Save**.

 **HELPFUL HINT**: Standard users can only view tasks assigned to the team they are a part of. This includes if they have team admin or section admin privileges.

 **BEST PRACTICE**: Create functional teams with multiple users to ensure that all tasks can be completed in the event of a user's absence. 

Manage Teams
------------

To view or edit a team:

1.  Navigate to **Task Manager**\>>**Administration**\>>**Teams**.
2.  Click the **arrow** to view a list of team members and their assigned roles.
3.  Click **Edit** to make changes or additions to the team.

![2024-06-18_12-15-07.png](https://static.adra.com/adra-assistant/images/06dde51a41a0131e0ab1f33195454c35.jpg)

  
The Teams page allows administrators to deactivate the team, add team members, edit details, or change user roles as needed.  
![2024-06-18_11-48-51.png](https://static.adra.com/adra-assistant/images/c71f14a56ed2ba4f073208ab99ad0116.jpg)  

1.  **Active** \- Toggle to off to deactivate the team.
2.  **Roles** \- Add additional team members, and assign or remove user roles.
3.  **Remove** \- Click the recycle icon to remove a user from the team.

 

 **HELPFUL HINT**: When a users role is removed while ongoing tasks are assigned, a pop-up appears as shown below. Click OK to automatically assign the task to the Team.

![image](https://static.adra.com/adra-assistant/images/18c740566037c1ed3e4abd09b08ea393.jpg)

### Reactivate a Team

To reactivate a team, navigate to the **Teams** page, toggle **Show inactive teams** in the top right corner of the page.

![2024-06-18_12-19-38.png](https://static.adra.com/adra-assistant/images/2f660a5446a0c87426042a1847225abc.jpg)

Inactive Teams display an **Inactive** badge.

Click **Edit** for the team, and toggle the **Deactivated** switch to on.
