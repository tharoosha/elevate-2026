Setup SCIM Provisioning Users Using OKTA (replaced soon)
========================================================

SCIM (**S**ystem for **C**ross-Domain **I**dentity **M**anagement) is designed to centrally manage identities used in applications. Adra supports the SCIM specification through the APIs implemented as part of the SETUP API.

This is the second phase in a series of steps for configuring OKTA for Adra.

Prerequisites
-------------

*   An application in OKTA is created manually to be used with Adra or the [Adra by Trintech](https://www.okta.com/integrations/adra-by-trintech/) application is installed from the Okta Integrations Network gallery. See [Setup Okta Configuration](https://trintech.lightning.force.com/articles/Knowledge_Article/Setup-Okta-Configuration) for information on how to add the Adra by Trintech application.
*   SAML SSO is correctly configured and tested between the Adra organization and OKTA.
*   The user creating the Personal Access Token (PAT) for SCIM Provisioning is an Organization Admin or an Engagement Admin for the relevant organization or engagement   
     

Configure Adra
--------------

Depending if you are configuring an Organization or an Engagement in Adra you need to navigate to the security settings accordingly for the steps in the Adra Setup Portal:

*   **Organization>>Security**
*   **Engagement>>Security**

 **![image](https://static.adra.com/adra-assistant/images/35f23758635cf8501ed54439f4dea639.jpg)**

1.  Navigate to **Organization/Engagement**\>>**Security**
2.  Ensure **Use SCIM** is selected under **User Management** and copy the SCIM service provider endpoint URL and save in a document for later
3.  Click **Save changes** 

![image](https://static.adra.com/adra-assistant/images/3b9192f19f927e12dd2273a59949cdde.jpg)

4.  The administrator responsible for the federation must navigate to **Profile>>User access**
5.  Click **Create token**

 **![image](https://static.adra.com/adra-assistant/images/09b5b55f7c6bf8b130d6706d1c444081.jpg)**

6.  Select **Identity API**
7.  Click **Create access token**

  **![image](https://static.adra.com/adra-assistant/images/426a53090b9df3d5cf6d954107dcf762.jpg)**

8.  Click **Copy** and save it in a document

**WARNING**: Once the Personal Access Token is created, it is shown only one time. Copy and save this token to be used later when configuring OKTA for SCIM provisioning.

Configure OKTA User Provisioning
--------------------------------

9.  Navigate to the **Okta Application** configured previously

![image](https://static.adra.com/adra-assistant/images/f85a1d58f486e4bdcfbf04a35199c1e5.jpg)

10.  Select the **Provisioning tab**
11.  Click **Configure API Integration**

 **![image](https://static.adra.com/adra-assistant/images/eff15725b1f21a7e683b8ee832015614.jpg)**

12.  Retrieve and paste the unique **URL for the API endpoint** that was copied in step 2. This is used for SCIM provisioning for the organization.
13.  Retrieve and paste the **Personal access token** copied in step 8.
14.  Click **Test API Credentials**
15.  Click **Save**

 **![image](https://static.adra.com/adra-assistant/images/b7bdba74821e685f89a1873dd912cf5d.jpg)**

16.  Click **Edit** to select the functionality for SCIM Users

![image](https://static.adra.com/adra-assistant/images/69c3f9d090b2927deca6f5929ad84dd8.jpg)

17.  Configure the options as shown in the image above and click **Save**
     *   **Create Users** \- Enable
     *   **Update User Attributes** \- Enable
     *   **Deactivate Users** \- Enable
     *   **Sync Password** - Disable

![image](https://static.adra.com/adra-assistant/images/03486162602ebcd138101d71acccf4ce.jpg)

18.  Scroll down and click **x** to remove any setting **not** displayed in the image above.

![image](https://static.adra.com/adra-assistant/images/698dd5af31c177fa0d8f3e3ae2230ae2.jpg)

19.  Click **Provision User**

 **![image](https://static.adra.com/adra-assistant/images/b2e8868c32147316a32fb93a7c35e1ee.jpg)**

*   *   Click OK if the pop-up above appears

User provisioning is completed. Users can now be provisioned with SCIM.
