Balancer Custom Import XML
==========================

Custom imports can be created when a balance and/or transaction file can not be created in accordance with the default import template. This permits the file to have a custom column order, custom delimiters (Not only Tab or Excel files), and concatenate columns. 

 **HELPFUL HINT**: In cases where a standard balance or transaction file must be imported, disable the **Use custom import definition for balance/transaction import** setting. **Save** the settings and navigate to Jobs>>Import Balances and import the file. Remember to enable **Custom import definition** after.

 

 **BEST PRACTICE**: Custom imports are typically created by consultants, as XML is utilized to configure the import specifications.

 

Enable Custom Import
--------------------

1.  Navigate to **Administration>>General Settings>>Other settings.**

![image.png](https://static.adra.com/adra-assistant/images/c8c5d2c9d2958b31d50eddaaa1b93d90.jpg)

1.  Enable **Use custom import definition for balances/transaction import**.
2.  Click **Add XML import definition**. 
3.  Paste the XML code provided by a consultant.  
4.  Click **Save.**
