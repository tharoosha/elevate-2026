Balancer Export Reconciliations - Auditor and Business Admin
============================================================

Business admins and auditors can export account reconciliations. This produces a zip folder that holds all data for accounts, transactions, balances, and attachments. The data is neatly organized in Excel sheets and folders. These files are widely used to create reports, perform audits, and simplify the process of sharing documentation with auditors during company sales.

 **HELPFUL HINT**: All users can export individual account reconciliations. Navigate to **Accounts and status** and click an account. Click **Export reconciliation** or **Print page** at the top of the account reconciliation page to create a file that contains the specific accounts reconciliation details.

Business Admins
---------------

1.  Navigate to **Jobs>>Other jobs>>Export period**.

![image.png](https://static.adra.com/adra-assistant/images/5a8d13fefdc6d5d433bf1a4e2ea2e8ce.jpg)

2.  **Period** \- Select period. 
3.  **Export only finalized accounts** - Check if applicable to exclude accounts that have not been finalized.
4.  **Legal entity** - Check desired legal entities. 
5.  **Export period -** Click to create a zip file containing all account details, including attachments, for the selected period.
6.  **Download -** The Jobs page loads. Click **Download** in the **Action required** column to download the [zip folder](#the-zip-folder).

![image.png](https://static.adra.com/adra-assistant/images/c47bc2df79a2d44f0e16343f2e293d6b.jpg)  
 

Auditors
--------

Users with auditor access in **Setup** are limited to viewing and exporting account details only.  
The auditors’ view can be limited further by enabling the setting **Show only finalized accounts to auditors**.

Auditors can export accounts in the following way:

1.  Navigate to **Accounts and status**

  
![image](https://static.adra.com/adra-assistant/images/1f1473f475201c220acb15f64772d5a2.jpg)

2.  Select desired accounts in the list
    *   Use the column headers to sort and filter accounts.
3.  Click **Bulk actions>>Export selected**
4.  The auditor receives an email with a  [containing all exported accounts and attached documentation.](#the-zip-folder)

[](#the-zip-folder)

[](#the-zip-folder)

[](#the-zip-folder)The Zip Folder
---------------------------------

The zip folder contains Excel files with account balances and transactions for the exported accounts, neatly organized in folders.

The Zip folder downloaded with the bulk action option on the **Accounts and status** page also contains attached documentation.

1.  Navigate to the location where the zip folder was downloaded.
2.  Right click the zip folder and click **Extract all**.
3.  Open the first two folders. 
4.  Open the file named **Exported\_accounts.xlsx** in the second folder. Open the file and click **Enable editing**.

![image.png](https://static.adra.com/adra-assistant/images/49c06cf54605bc802e83552ab0bd787c.jpg)

The file contains an overview of all exported accounts. 

5.  Click **View** in the **Link to reconciliation** column or a blue number in the **# of docs** column to open the corresponding file.

![image.png](https://static.adra.com/adra-assistant/images/3096b8980dc77bf18218585719dabf3a.jpg)
