Edit Individual Tasks
---------------------

Task details, encompassing team, preparer, approver, due date, company, and department, can be edited for unopened or open tasks, either individually or in bulk.  
To edit individual tasks details, locate the task on the **Home**, **Tasks**, or **Task Lists** page.

### Change Task Status

If a task is prepared or approved, it can be reverted if it needs to be added to or reworked. To change the task status, please follow the below steps. Navigate to a task by clicking on **Tasks** on the left side menu, and then locate and click on a task that needs a status change.  
![image.png](https://static.adra.com/adra-assistant/images/b403a0d57a98b108bc3a3b59d7d2e339.jpg)  
  
Once inside the task, do the following:

1.  Click **Change task status**.
2.  Select **In Progress** to revert a prepared task in the **Task Status** popup. Close will be the only option available if the task has already been approved. Once an approved task's status is saved, click **Change status** to change the status. 
3.  Click **Save** once done.

  
Bulk Edit Task Details
-------------------------

### Edit Details for Tasks in Bulk via Task List

To update tasks in bulk, administrators can navigate to the task list and do one of the following:

*   Edit tasks by clicking the **Edit** button
*   Edit tasks directly in the **Task list** grid

To update details in bulk with the **Edit** button, follow the steps below:

1.  Navigate to **Task Lists** and click on a list.

![image](https://static.adra.com/adra-assistant/images/4835ee4a8015a81ecc969d70f386488a.jpg)

2.  Check the desired tasks on the right-hand side.
3.  Click **Edit**.
4.  Select one of the update options. A pop-up with a drop-down appears. Select the new task details and click **Save**.

Alternatively, the same fields can be updated directly in the list grid.

![image](https://static.adra.com/adra-assistant/images/4591543652044885d57d41974d75d23e.jpg)

Click the desired field and select the new task detail.

### Edit Details for Tasks in Bulk via Library Task Template Export/Import

1.  On the Library page, click the three dots for the relevant section and select **Export task templates**.

![image](https://static.adra.com/adra-assistant/images/93824d6adcedeab4c8bb8e4ebca36571.jpg)

2.  Go to the Jobs page and download the exported task template file.

![image](https://static.adra.com/adra-assistant/images/e6d8c99445d5b8ed3dafebfacba6911f.jpg)

3.  Open the file in Excel, make the necessary changes (tip: use Excel’s built-in replace function for bulk changes), and save the file.
4.  Return to the Library, click the three dots for the section, and select **Import task template** to upload the updated file.

![image](https://static.adra.com/adra-assistant/images/abec2fb0a21ba4f78d37fb26c7a5876f.jpg)
