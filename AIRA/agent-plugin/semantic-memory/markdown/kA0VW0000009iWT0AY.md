Journal Entry Create Journal Entries
====================================

New journal entries can be created in three ways

*   In Matcher on the **Exceptions** page. To learn more, see [Matcher Journal Entry](#article:kA06S000000YQcgSAG@Success-Center).
*   In Balancer on an accounts reconciliation page. To learn more, see Balancer Journal Entry
*   In Journal entry on the **Journal Entries** page

To create an entry in the **Journal Entry** application, do the following

1.  Navigate to the **Journal Entries** page and click **New Journal Entry**
2.  Select legal entity, currency, fiscal year period, booking date, and description.
    *   Administrators can restrict what periods and dates are available on the Posting Periods page. To learn more, see [Journal Entry Posting Periods](#article:kA0Ua00000079hhKAA@Success-Center).
3.  Add documentation if applicable.
4.  Click **Save draft** or **Save.**

![image](https://static.adra.com/adra-assistant/images/081bbb168d25d3f85a801f3b3ff48775.jpg)

5.  To edit a journal entry, choose a journal entry on the **Journal entries page** and click the **pen**. 

![image](https://static.adra.com/adra-assistant/images/f68e012848baeca847d362fa3c878b76.jpg)

6.  Change **currency**, **fiscal year period**, **booking date** and **description** if needed.
7.  Add **documentation** if applicable.
8.  Change journal entry details. All fields are entered manually.
    *   Account numbers must be created on the Posting Accounts page first. To learn more, see [Journal Entry Posting Accounts](#article:kA0VW0000008tyb0AA@Success-Center).
    *   Click **Delete** to remove an entry
9.  Click **\+ New Row** to add journal entry details.

![image](https://static.adra.com/adra-assistant/images/2b757187f4a76c3f059ee625bc22efff.jpg)

10.  Click **Save as draft** or **Save changes**.

 **HELPFUL HINT**: If the setting **Enforce Supporting Documents** is enabled in **Administration>>General settings**, journals that lack documentation can only be saved as a draft. To learn more, see [Journal Entry General Settings](#article:kA0Ua0000004dHJKAY@Success-Center).

 **HELPFUL HINT**: Find the activity log to track journal entry steps on each journal entry at the upper right corner on the active journal entry.

 ![image](https://static.adra.com/adra-assistant/images/75b5a0f9993dafe4fed5527072be38fd.jpg)

Click the icon to open a pop-up showcasing the audit trail the journal entry. This ensures regulatory compliance and guards against audit risk.
