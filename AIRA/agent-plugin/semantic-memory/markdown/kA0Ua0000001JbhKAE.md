Create and assign fiscal years and periods to task lists to ensure that tasks are aligned with the organization's financial planning and reporting cycles, aiding in better organization, tracking, and accountability.

Create Fiscal Years and Periods
-------------------------------

To add new fiscal years and periods in Task Manager, they must first be added in Setup.

![image](https://static.adra.com/adra-assistant/images/3862fbd89ae6ab2642c2ac4140e0345a.jpg)

Administrators with access to Setup can click the Task Manager logo and select Setup.  
Learn how to create periods here: [Setup Create & Manage Fiscal Years](#article:kA00H000000kJ9cSAE@Success-Center). 

Import Fiscal Years and Periods
-------------------------------

To import fiscal years and periods to Task Manager, follow the steps below.

1.  Navigate to **Task Manager>>Administration>>Fiscal Years**.

![image](https://static.adra.com/adra-assistant/images/4816f6830a41f56a9c6cf84562593e6e.jpg)

2.  Click **Import fiscal years/periods**.
    *   Existing Task Manager periods will be updated if changes have been made in Setup.
    *   New fiscal years and periods will be imported from Setup to Task Manager.

Deactivate Fiscal Years and Periods
-----------------------------------

To deactivate fiscal years and periods in Task Manager, follow the steps below:

1.  Navigate to **Administration>>Fiscal Year.**

![image](https://static.adra.com/adra-assistant/images/d873a5c53d4a10aead1156e1da98f5c5.jpg)

2.  Locate the fiscal year or expand it to locate a specific period.
3.  Click the **power** icon to deactivate the period.
4.  Click Deactivate in the pop-up.

Reactivate Fiscal Years and Periods
-----------------------------------

To view and reactivate inactive periods, follow the steps below.

1.  Navigate to **Task Manager>>Administration>>Fiscal Years**.

![image](https://static.adra.com/adra-assistant/images/fb267a7ec50d30a91945fe3c47660c43.jpg)

2.  Toggle **Show inactive fiscal years**.
3.  Locate the fiscal year or period.
    *   Inactive periods will have an inactive badge as displayed in the figure above.
4.  Click the **power** icon to reactivate the period.

Assign Periods to Task Lists
----------------------------

Periods can be assigned to task lists in two ways:

*   **New task lists** - Select a period for a new task list, use the **Active fiscal year** dropdown on the **New Task Lists** page.

![2024-06-18_9-23-55.png](https://static.adra.com/adra-assistant/images/cb95dacad7f7a693cc4cc284300784f2.jpg)

*   **Existing task lists** - Navigate to the **Task Lists** page, and select the task list. Click Set FYP for selected.

![image](https://static.adra.com/adra-assistant/images/50ebc83ef6d890a07e7ba1ccd2a80e3b.jpg)
