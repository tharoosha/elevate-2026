Task Manager Create & Copy Task Lists
=====================================

Create a New Task List
----------------------

To create a new task list, navigate to **Task Lists** and click **\+ Create new task lists**. 

![image](https://static.adra.com/adra-assistant/images/db624bd2efd5a1479042e60902628597.jpg)

The **New task list** page loads.

![image](https://static.adra.com/adra-assistant/images/f2836832ba8d54f1e4941d44cb45d3f1.jpg)   
 

1.  **Task list name** – Enter a task list name.
2.  **ZERO-day** – Select a ZERO-day and ZERO-day options. The ZERO-day is a reference date Task Manager uses to set task due dates. Select ZERO-day options to push the ZERO-day to a working day if it falls on a non-working day. Select Push forward or Pull backwards to move the ZERO-day to the prior or subsequent workday. Learn more about Zero day: [Task Manager Using ZERO-day](#article:kA00H000000oPNnSAM@Success-Center).
3.  **Active fiscal year period** – Select which period the task list belongs to if this is part of your organization's procedures.
4.  **Calendar** – Click a day in the calendar to disable or enable it as a working day. 
    *   Company-wide non-working days are displayed in gray on the calendar. This includes weekends and country-specific holidays, based on the Working Day Calendar created in Setup. See [Setup Working Day Calendar](#article:kA0VW000000BSYr0AO@Success-Center). If a non-working day is selected as a due date, a warning indicates **You have selected a non-working day**. You can still use non-working days as due dates.
5.  **Library section** – Select a **Library** section to select tasks from. Task lists can only be created with tasks from one section of the **Library**.
6.  **Save** – Click to save the task list settings.

  
The **Add tasks** page loads. This page allows the administrator to filter, select, edit and add tasks to a task list. Follow the steps below.  
![image](https://static.adra.com/adra-assistant/images/30e1753db570c52987932d7786a587f8.jpg)

1.  **Filter** – Enter a partial or entire task ID or name in the search field to locate tasks. Click **Frequency**, **Company**, and **Team** to select additional filters. Expand and check an individual folder or subfolder to filter tasks according to the **Library** structure.
2.  **Tasks found** – Click Select all or check individual tasks.
3.  **Selected** – Click Deselect all or the delete icon to remove tasks from the task list. Click the **edit** icon to change the task due date and time.
4.  **Add selected tasks** – Click to add selected tasks to the task list.

New task lists appear on the **Not Started** tab on the **Task Lists** page.  
 

 **HELPFUL HINT**: Tasks can be added to Not started and Opened task lists. Navigate to **Task lists**, select the Not started or Opened tab and select a task list. Click **\+ Add tasks.**

Copy Task List
--------------

Once an Administrator has created a task list that fits the organization's needs, it can be copied and adjusted to save time and help create greater consistency. 

1.  To copy a task list, navigate to **Task Manager>>****Task Lists**.

![image](https://static.adra.com/adra-assistant/images/5852c2bc34418d70b884afea3b71335e.jpg)

2.  On any of the tabs, check the desired task list and click **Copy Selected**. The **Copy task list** page loads.
3.  Complete the required information, as shown in the figure.

![image](https://static.adra.com/adra-assistant/images/2d9d1a9e74c8ecf3e183cbd90e6bdb43.jpg)

1.  **Task list name:** this can be renamed on the Task List detail page. 
    
2.  **Task Settings:**
    
    1.  Selecting **Task list** allows an Administrator to copy lists and keep any overridden settings for the Team, Preparer, Approver, Company,  and Department. This enables users to reuse created task lists and avoid resetting values.
        
    2.  Selecting **Library** copies the unaltered task template from the Library using those settings for Team, Preparer, Approver, Company, and Department.
        
3.  **Sequences:** preserves any sequences set up in the new task list. Learn more about task sequences: [Task Manager Configuring Sequences](#article:kA00H000000kJ6ESAU@Success-Center).
    

![image](https://static.adra.com/adra-assistant/images/5d80677353a892a07b31bbfff8445a97.jpg)

4.  Select ZERO-day. Non-working days, which includes public holidays and custom holidays, are displayed as grey. Choosing a non-working day as ZERO-day will prompt an error message, that you can override. Learn more about ZERO-day: [Task Manager Using ZERO-day](#article:kA00H000000oPNnSAM@Success-Center)
    
5.  Click **Save**

The copied list appears on the **Not Started** tab on the **Task Lists** page.  
Learn how to add additional tasks to the copied task list: [Task Manager Add Tasks To Active Task List](#article:kA0Ua00000002TFKAY@Success-Center)

 **BEST PRACTICE**: If changes are made to tasks in an active Task List, copy a Task List and select **Library,** which will allow those changes to be reflected in the current period.
