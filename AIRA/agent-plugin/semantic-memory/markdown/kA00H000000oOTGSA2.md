Matcher Import History
======================

Import History
--------------

Import History shows a list of imports that have already been added to matcher, with the option to undo those imports if needed. This is useful during the implementation process when testing matching rules, or if a duplicate import file has been loaded.   
To view the Import History navigate to **Administration > Import History**.   
  
To under an import, the matched transactions must be unmatched by clicking **Undo matched transactions**.   
  
![Graphical user interface, application, Word  Description automatically generated](https://static.adra.com/adra-assistant/images/2736979dc056837d9fcd359ca14170c6.jpg)

Next, a pop up will open confirming the change. Click **OK**. Once the transactions are unmatched, you are able to click **Undo Import.**

![undo matched transactions.jpg](https://static.adra.com/adra-assistant/images/f661b71d38ff37583bfd2599380e7dd8.jpg)  
  
Last, click **Undo Import** 

![Graphical user interface, application  Description automatically generated](https://static.adra.com/adra-assistant/images/a6695f854c9b4891e8bc367dc625e688.jpg)
