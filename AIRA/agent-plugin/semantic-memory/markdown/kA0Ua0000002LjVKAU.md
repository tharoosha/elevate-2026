Setup Import Legal Entities on the Jobs Page
============================================

The **Legal entities** page in **Setup** allows administrators to add, import and update legal entities.

Navigate to **Setup>>Financial Configuration>>Legal entities** and click **Import legal entities**.  
  
![image](https://static.adra.com/adra-assistant/images/acfc6dd5ec982f72c5d6bfae15222711.jpg) 

  
  
In the import pop-up, do the following:  
![image.png](https://static.adra.com/adra-assistant/images/a6b9176cc9964fdf1d9f60e4b53d9dee.jpg)

1.  **File format description** - Click the link to download an import template that includes a description of formatting and content. Use the information to create a legal entity file.
    *   Note that engagement codes cannot be updated this way, as new codes will be registered as new legal entities.
2.  **Engagement Name** - Select the engagement the legal entities will be imported to.
3.  **Upload file** - Drag and drop the file, or click **Upload file** and locate the file.
4.  **Import** \- Click to import the file.

  
The import jobs appear in the **Jobs** page grid, where they can be viewed and filtered.

![image](https://static.adra.com/adra-assistant/images/1e76690a60d1130d448b125c4c67ba34.jpg)

5.  The Job Status field can have the following statuses:
    *   **Processing** \- To file is currently processing. 
    *   **Failed** \- No lines were successfully imported.
    *   **Partially Succeeded** - Some lines were skipped, likely due to incorrect formatting.
    *   **Succeeded** \- All lines were successfully imported.  
         
6.  Click the **Log** button to view job details and potential error messages as shown below.

![image.png](https://static.adra.com/adra-assistant/images/5def3f3a4afff5a132b288bf7342547c.jpg)

Review any error messages and use the description in the template to determine incorrect values. Reimport the file if neccessary.
