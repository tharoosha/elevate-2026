Balancer FAQs
=============

**When is an account or reconciliation finalized?**

Once the account has completed the assigned workflow, a reconciliation is finalized.

*   For example:
*   If a Preparer and Approver are assigned to a reconciliation, the account is finalized when it is prepared and then approved.
*   If a reconciliation is set to be prepared at quarter-end, at the month-end, the reconciliation is finalized without any action needed.
*   Read  for insight into the status of reconciliations in the workflow.

**What role or roles should I have within Balancer?**

An assigned role will depend on your visibility and access needs. [Balancer Understanding User Roles](#article:kA00H000000kJ8tSAE@Success-Center) explains the different roles within Balancer. Read [Adra User Profiles](https://success.adra.com/s/by-catalog?vtui__mediaId=a7U0H000000PH1JUAW&vtui__catalogId=a7N0H000000PDASUA4&vtui__source=catalog), a spreadsheet that breaks down activities each user role has access to in the product.

Can I have more than one role on an account?

While you can be assigned more than one role, you should not hold two roles on the same account.

*   For example, the Preparer and approver should be different people on an account. This Segregation of Duty can is configured in the Setup application.
*   [Balancer General Settings](#article:kA00H000000kJ8USAU@Success-Center) explains how to turn on Segregation of Duties for Balancer.

**Within Balancer, can I have more than one Preparer/Approver/Reviewer on an account?**

Balancer allows you to assign Collaborative Roles or Co-Roles.

*   For example, admins can assign Co-Preparer(s), Co-Approver(s), and Co-Reviewer(s) as alternatives if the main Preparer/Approver/Reviewer is unable to complete the assignment (i.e., out of the office).
*   Admins need to import Account Roles within the spreadsheet or individually assign roles to an account under Account Settings in Balancer to add Co-Roles. Read [Balancer Understanding User Roles](#article:kA00H000000kJ8tSAE@Success-Center) to learn more about user roles.
*   Users can search their accounts to determine if they’ve been assigned a Co-Role by selecting **Include active accounts not directly assigned to me** within the Balancer home page. Read [Balancer Home Page Overview](#article:kA00H000000kJ9SSAU@Success-Center) to learn more about home page functionality.
*   Admins can add, remove or transfer roles for users. Read [Balancer Users Page Overview](#article:kA00H000000oOcwSAE@Success-Center) and [Balancer Update Accounts Setting & Roles In Open Periods](#article:kA06S000000kK6sSAE@Success-Center) to learn more.

**How do I import Account User Roles into Balancer?**

An Administrator can import user roles in conjunction with accounts using the Account Roles spreadsheet found in Balancer. Read [Balancer Export & Import Account Roles](#article:kA00H000000kJAGSA2@Success-Center) to learn more.

  
 

**What happens when balances update during a period?**

Any previously certified accounts become uncertified, and the workflow must be completed as a result of adding new balances. When a new balance is uploaded, the account is automatically set to “Not prepared,” and the Preparer is alerted.

  
 

**How can I update User Roles during a period?**

Settings and Roles can be updated in the Balancer product. Read [Balancer Update Accounts Setting & Roles In Open Periods](#article:kA06S000000kK6sSAE@Success-Center) to learn more.

  
 

**What does Carry Forward mean?**

Carry forward allows for documents and items from a reference period, to be carried forward to the current period. Note: Once you carry forward to a specific period, you cannot carry forward to the same period again. Read [Balancer Carry Forward](#article:kA06S000000YQgdSAG@Success-Center) to learn more.

**What does System Certify mean?**

Allowing Adra Balancer to System Certify means that certain accounts can automatically be Prepared and Approved by Balancer as long as they meet preset criteria selected by the Business Administrator. Read [Balancer System Certify](#article:kA00H000000oOVRSA2@Success-Center) to learn more.

**How do I give an Auditor access in Adra?**

To give access to an Auditors will depend on whether your Auditors are already in Adra as users or not.

*   To create a new Auditor, read [Setup Create New Users In Adra](#article:kA00H000000kJ5LSAU@Success-Center)
*   If you receive a warning that the user already exist, read [Setup Connect External User](#article:kA06S000001DXbFSAW@Success-Center). 

**I want the users only to view their assigned accounts. What setting allows this to happen?**

You will need to enable the setting titled **Show only Accounts for which the User has an Account Role**. Read [Balancer General Settings](#article:kA00H000000kJ8USAU@Success-Center) to learn more.

  
 

**I have a user who has left my company. How do I delete or deactivate their profile?**

Users cannot be deleted from Adra, which ensures information is retained for audit purposes, but their users can be deactivated. To learn more, see [Setup Remove User Access in Adra](#article:kA00H000000oP4lSAE@Success-Center). 

**How can I see which users are active or inactive?**

Navigate to **Setup > Users** to see your listing of all users. Filtering by the **Status** column will allow you to see whether they are active or not.

  
 

**What do I do if balances are imported into the wrong Period?**

There are two ways to solve this problem:  
1\. You can go to Jobs and import a new file (make sure the accounts are the same as the previous file) - the new file will then overwrite the previously imported file. Note, however, that the new file import does not undo the accidental import.   
2\. You can go to **Administration > Delete** and select **Accounts in period** or **Periods**. You can import the closing balances in the correct periods after deleting the incorrect accounts in periods or the wrong periods.  
Read [Balancer Delete Accounts and Periods](#article:kA00H000000kJ9hSAE@Success-Center) for more details on how to delete an account. 

  
 

**How do I prevent the application from automatically logging me out?**

If you want to extend the session time for a whole engagement, a System admin can go to:  
**SETUP  > Engagement > Security > Use custom idle timeout.** Fill in a value between 20 and 720 (minutes) and select Update.  
The article [Setup Engagement Settings](#article:kA00H000000oOTGSA2@Success-Center) can provide additional information about engagement level settings.

  
 

**Can an Auditor export from Balancer?**

Once an administrator has assigned a user the auditor role, the user will be able to export from Balancer. To learn more, see [Balancer Export Reconciliations - Auditor and Business Admin](#article:kA06S000000wmlBSAQ@Success-Center)
