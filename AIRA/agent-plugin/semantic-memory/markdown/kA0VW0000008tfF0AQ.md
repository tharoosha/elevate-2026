The balance control feature in Matcher ensures the accuracy of financial data by verifying that the total amount in a transaction file matches a control total from a separate balance file.

To use the balance control feature, an import configuration must first be created.

How To Create a Balance Control Import
--------------------------------------

There are two ways to create a balance control import:

1.  **Individual balance control** \- Used when an automatic import setup is desired, and in scenarios where the balance file must be uploaded at a different time than the transaction file. 
2.  **Transaction and balance control combined** - Used when files are uploaded manually on the **Imports** page. Allows the balance and transaction file to be uploaded simultaneously.

### Import Configuration - Balance Control

![image](https://static.adra.com/adra-assistant/images/6b14c39975df47c75dd72556cf1eb09c.jpg)

1.  Navigate to **Administration>>Import Settings>>Import Configuration**
2.  Click **Add Import Configuration**

**![image](https://static.adra.com/adra-assistant/images/1f7af1a480353666632a526f3b21cb2f.jpg)**

3.  Select the correct legal entity. Selecting Across All Legal Entities allows the creation of an automatic import. Learn more: [Automatic Balance Control Import](#automatic-balance-control-import).
4.  Select Balance Control Import
5.  Select the desired import template
    *   The Standard balance import can be used to import standard balance files. To see a standard balance file example and column descriptions. Click **Standard balance import format**.
    *   Custom import templates for balance control can be created in **Administration>>Import Settings>>Import Templates**. For more information, see Custom Import Templates below.
6.  Click Save.

To learn how to run a balance control with this setup, see [Balance Control Import](#balance-control-import).

### Import Configuration - Transaction and Balance Control Combined

1.  Navigate to **Administration>>Import Settings>>Import Configuration**
2.  Click **Add Import Configuration**

![image](https://static.adra.com/adra-assistant/images/f3d40a57b94b22fcc9aac451a9ef0c17.jpg)

3.  Select the correct legal entity. Note that a combined transaction and balance control import does not permit an automatic import configuration.
4.  Select **Transaction Import** 
5.  Select how the period is selected for the transactions
6.  Select the transaction import template.
7.  Toggle **Activate Balance Control** to on, and select the balance control import template.
8.  Click **Save**

To learn how to run a balance control and transaction import with this setup, see [Balance Control and Transaction Import](#balance-control-and-transaction-import).

### Custom Import Templates

Custom balance import XMLs in Adra Matcher define how balance data files are interpreted and processed during import. They act as a blueprint that tells Matcher:

*   **What the data looks like** - Column structure, delimiters, date formats.
*   **How to identify and map the data** - Which column is the account, which is the amount.
*   **How to handle special cases** - Skipping headers, combining columns, filtering rows.

This flexibility is essential when working with **non-standard file formats** or when integrating data from **multiple ERP systems**.

 **BEST PRACTICE**: It is recommended that you contact your Trintech customer contact to arrange consultant help if custom imports are needed.

If only minor changes are required, the Standard Import Template XML shown below can be modified. 

If, for example, the columns in the import file are arranged differently, modify this template by updating the `columnNumber` values to match the correct order.

`<?xml version="1.0" encoding="iso-8859-1" ?>`  
`<ImpMatchODFile xmlns="[http://schemas.adramatch.com/Import/OdFile](http://schemas.adramatch.com/Import/OdFile)" delimited="true" delimiter="\t">`  
`<collection name="File">`  
   `<row name="Settings" read="false">`  
     `<column name="NumberDecimalSeparator" type="Output" output="','"/>`  
   `</row>`  
   `<end/>`  
`</collection>`  
   `<collection name='BalanceImport'>`  
       `<row name='BalanceItem'>`  
           `<column type='String' name='AccountNo' columnNumber='1' />`  
           `<column type='String' name='BalanceAmount' columnNumber='2' />`  
           `<column type='String' name='Client' columnNumber='3' />`  
       `</row>`  
   `</collection>`  
`</ImpMatchODFile>`

Copy the code above and follow the steps in this article to create an import template: [Matcher Import Templates](#article:kA00H000000kJBOSA2@Success-Center).

### Automatic Balance Control Import

 **HELPFUL HINT**: Automatic imports not only reduce the number of clicks needed to import a file, but also enable **email** notifications when a balance control fails.

Balance control files, like transaction files, can be imported automatically in two ways:

*   Through the Integration Hub
    *   How the integration hub is set up depends on what systems your organization uses. Reach out to your customer representative to learn more.
    *   If transaction files are already imported manually to Matcher, configure the systems to create the Balance file, and ensure it lands in the same or similar location to the transaction files for Integration hub to pick it up.
*   By dragging and dropping the file on the import field on the **Imports** page.

To enable automatic import of balance control files, follow the steps below.

![image](https://static.adra.com/adra-assistant/images/599f16bb7788dccb16d7a6415de919cf.jpg)

1.  Navigate to **Administration>>Import Settings>>Automatic Import Configuration**
2.  Click **Add Automatic Import Configuration**

**![image](https://static.adra.com/adra-assistant/images/32708e59fdfbc5dfc490099b323dd0ca.jpg)**

3.  **Select Balance Control**
4.  Enter a descriptive name
5.  Configure how the file will be identified.
    1.  **The balance control filename contains this text** - Enter a part of the file name that is unique to all balance import files. It is not necessary to include the entire file name.
    2.  **The balance control filename must match this RegEx** - Use a code to identify certain parts of the filename. This is used if certain parts of the filename change regularly while others remain constant, and extra security is needed to identify the right file.
        *   To learn more about RegEx, see [Matcher Regular Expressions](#article:kA00H000000kJBYSA2@Success-Center) and [Matcher Basic RegEx Handout](https://success.adra.com/s/share-playlist?vtui__p=63op1%2FfCTjgNDgTL3ud94NABtgMGriVH6wWSTq%2BPaGxSBXwfubLM3FtZDVI65%2BnZK%2BlWlJmMXGYhTkkwhHh%2BjPR8oziJh%2FzwIsNQCdMCqc8J50I7oDpD7g6akrc7DQjXfCHwZyD%2BhSMTF0FyD0TpcN2kKRiqtt1G2alqSiVp08kqL055Ifneux9cMJFkCbGs&iospref=web).
6.  Select the balance import configuration. If non exist, create one as described in [Import Configuration](#import-configuration---balance-control). Note that only Import Configurations with **Across All legal Entities** selected when the configuration is created are available for automatic imports. 
7.  Select users who will receive a notification email if the balance control fails.

How To Perform a Balance Control
--------------------------------

### Balance Control Import

To use the Balance control feature, the transaction file must be imported first, followed by the balance file. Matcher performs the comparison only after both files are present.

If the totals don’t match, the system does not block the import but flags discrepancies for review. Matcher can also be configured to send email notifications when an out-of-balance condition is detected, enabling prompt administrative response.

This setup safeguards data integrity while supporting automated monitoring and maintaining a smooth reconciliation workflow.

When the balance import has been configured, the balance file can be imported manually or automatically. Follow the steps below to import the balance file:

![image](https://static.adra.com/adra-assistant/images/be505aa7836d6dca86ea577e2ef13f63.jpg)

1.  To import the file (if it is not imported through Integration hub), navigate to the **Import** page and import the file
    1.  If automatic import configuration is enabled, drag and drop the file on the Upload files field
    2.  Click New Import if the automatic import is NOT configured and the file must be imported manually.

![image](https://static.adra.com/adra-assistant/images/f14c86386e8bff06bb6bd81d19a1cdd5.jpg) 

1.  1.  1.  Select Legal Entity
        2.  Select Balance Control
        3.  Select import template
        4.  Upload the file
        5.  Click Start Import

If the balance file does not match the transaction file, an orange issue icon appears on the import job on the import page. The file is automatically imported regardles and does not require verification.

![image](https://static.adra.com/adra-assistant/images/a25d5c603223fdce0efa7e08c096df31.jpg)

Click the job to view the details, including the transaction balance (Balance), expected balance (balance control file balance) and the difference. To recheck the balance, simply re-import the balance control file.

![image](https://static.adra.com/adra-assistant/images/ae12466ea03a48aa1254651f56b95a66.jpg)

If the balance control was automatically imported and it fails, users selected to receive the notification receive the email below, where they can click the link to view the balance control details:

![image](https://static.adra.com/adra-assistant/images/6eadaa824500afc4e1ea18469d31462b.jpg)

### Balance Control and Transaction Import

1.  Navigate to **Import**
2.  Click **New Import**

![image](https://static.adra.com/adra-assistant/images/76c25c12e9609699c9681a23cc12500f.jpg)

3.  Select the correct legal entity
4.  Select **Transaction Import**
5.  Select the transaction and balance import
6.  Upload the transaction file
7.  Upload the balance file, and click **Start Import**.

Click the import job to view the details.
