Setup User Profile
==================

The **User profile** page allows users to view their user details, such as email, name, time zone, date time format and language.

![image](https://static.adra.com/adra-assistant/images/41ad0d98fe4f4c29defc4729d8e82450.jpg)

1.  **Username(e-mail)** - The e-mail used to log in and for receiving application e-mails. The field can only be edited by System Admin on the **Users** page.
2.  **Name** - Appears in various application pages. Serves to identify the user.
3.  **Title -** The Title is visible on all application **User** pages and in **Setup>>Users** to aid administrators in identifying users.
4.  **Employee number** - The employee number is a unique identifier used for administrative purposes within your organization. 
5.  **Time zone** - The time zone you operate in.
6.  **Date time format** \- Specifies how date and time appear in applications based on the chosen region's standards.
7.  **Language** \- Specifies which language the applications appear in.
8.  **Change password** \- Click to update your users password.
9.  **Personal access token** - Click the link to navigate to the User access tab, where personal access tokens can be generated. Personal access tokens are used for automated user provisioning and integration hub.
