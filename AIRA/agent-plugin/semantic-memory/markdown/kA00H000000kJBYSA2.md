Matcher Automatic Matching Overview
===================================

Automatic Matching
==================

Automatic matching is the process by which transactions are reconciled together using the matching rules previously created. Refer to [Matcher Automatic Matching Rules](#article:kA00H000000kJBJSA2@Success-Center).

Automatic running of matching rules can be configured for each reconciliation group by navigating to **Matcher>>Reconciliation Groups**. For additional information on running automatic matching rules, see [Matcher Reconciliation Groups](#article:kA00H000000kJB4SAM@Success-Center).

The **Automatic Matching** page can be found on the left side menu. From here, the Admin can choose to Run Matching Rules or review a completed run.

![image.png](https://static.adra.com/adra-assistant/images/49fa0a31821e57fafef47f77ea50cd15.jpg)

1.  **Run matching rules** - Click to run matching rules.
2.  **Job details** - Review legal entity, date and time, responsible user for the job.
    *   Click a job to view % matching
3.  **Document icon** - Click to view job log.

 

Run Matching Rules
------------------

When Matching Rules are run, a popup will open to select which entity or rules should be run.![image.png](https://static.adra.com/adra-assistant/images/bed27f90a68ba2b783bead55b8be8862.jpg)

1.  **Drop down** - Select a specific legal entity or **Across All Legal Entities**.
2.  **Reconciliation groups/Legal entity** - Select which rules to run.
    *   To drill down, expand the desired reconciliation group and choose to run only specific matching rules. This allows the admin to monitor the success of a specific rule or set of rules.
3.  **Run Selected Matching Rules** - Click to run the selected rules.

 **HELPFUL HINT**: When an automatic matching rule is run across all legal entities, administrators can only select the reconciliation group to run the rules for. The finalized job will show percentage matches and other details at the reconciliation group level. When rules are run for specific legal entities, administrators can select which rules to run. The percentage matches and other details will then be displayed at the rule level.

After the selected rules are run, the main Automatic Matching screen will appear showing the completed job. If for some reason the job needs to be stopped, click on the X shown in the image below. While in progress, the job will spin orange. Once completed, it will show green with a checkmark.  
  
![stop automatic matching.jpg](https://static.adra.com/adra-assistant/images/01b6616699b5e3ba402588c8f8161af3.jpg)

  
Match Success
----------------

Once the job has a green check mark, click the job to view the matching percentage. This percentage reflects the reconciliation group and/or rule based on the automatic matching rules that were run. This data helps ensure the matching rules are working as intended.

Matching rules can be viewed and updated by navigating to **Administration >> Matching Rules**. If the matching rules aren't producing the necessary percentages, adjustments can be made by copying and modifying, or reordering as needed.

![image.png](https://static.adra.com/adra-assistant/images/e22f7769806a5f3e1917fd2aa97fa544.jpg)
------------------------------------------------------------------------------------------------

Additionally, administrators can click the paper icon to view the job log for each individual reconciliation group or rule.

![image.png](https://static.adra.com/adra-assistant/images/cc3fba2bb1ff1c8eeb9f6f30f0b8c4f7.jpg)  
 

Job Logs
--------

To view the log for an entire automatic matching rule job, click the paper icon for the job on the **Automatic matching** page.  
This log displays job ID number, job process, and any error messages.  
![image.png](https://static.adra.com/adra-assistant/images/c5ff2ee0181f1e0ddf0c611d4995e84e.jpg)
