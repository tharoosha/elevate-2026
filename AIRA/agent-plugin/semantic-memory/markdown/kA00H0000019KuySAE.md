Matcher Copy and Clone Matching Rules
=====================================

Copying Matching Rules
----------------------

In certain situations, it's more efficient to copy or clone an existing rule instead of creating a new one from scratch.

*   **Copy rules** - Use when the rule needs to be added to a different legal entity.
*   **Clone rules** - Use when a rule needs to remain the same but with an added date or amount variance.

To view or modify matching rules, navigate to **Administration>>Matching Rules**.  
 

### Copy Rules

![image](https://static.adra.com/adra-assistant/images/2072d2244586141883960491e2c7112b.jpg)

1.  Select the correct legal entity in the drop-down
2.  Click **+ Copy Rules**. The **Copy Rules** pop-up appears.

### ![image.png](https://static.adra.com/adra-assistant/images/5eecffa98903aedf9f80e9279bb4785d.jpg)

3.  In the drop-down, select which legal entity the rules will be copied from.
4.  Select all matching rules that need to be copied.
5.  Click **Copy**.

The rules will appear at the bottom of the original matching rules screen.  
  
  

Cloning Matching Rules
----------------------

To clone a matching rule, click the paper icon for the specific rule. Once the rule is cloned, it will appear at the bottom of the rules list and say "- Clone" at the end of the name. After cloning, double-click on the rule to open and make any necessary modifications. Rules can also be reordered after being copied or cloned.
