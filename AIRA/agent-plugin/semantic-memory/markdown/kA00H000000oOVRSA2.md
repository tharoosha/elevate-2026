Setup Closing Rates for Currency Conversion
===========================================

The Closing rates functionality enables the use of exchange rates to convert currencies between the engagement and the legal entities, and among different transaction currencies.

*   Engagement currencies and closing rates are defined in **Setup>>Financial Configuration>>Closing Rates.**
*   Each legal entity's operating currency is also defined in **Setup**.  This currency is used as the base currency for currency calculations and facilitates easy comparison between legal entities on the **Balancer Dashboards** and the **Balancer Home** page.

Closing Rates
-------------

To manage closing rates, navigate to **Setup>>Financial Configuration>>Closing Rates.**

![image](https://static.adra.com/adra-assistant/images/42e90510e7726a9508ccb04071c3b563.jpg)

1.  **Rate actions**:

*   *   **Copy rates** – Click to copy rates and/or currencies from a previous period.
    *   **Add rate** – Click to add rates and currencies manually in the Add rate pop-up.
    *   **Import closing rates** –  Click to import multiple rates and currencies via file upload.

2.  **Engagement and Periods**– If applicable, select the engagement from the drop-down menu. Select Fiscal Year and Period from the drop-down to view corresponding rates.
3.  **Actions** – Click the three dots to edit or delete rates.
4.  **Currency logic** – Closing rates are required to have rates for converting a currency to itself and for converting between different currencies in both directions.

 **HELPFUL HINT**: To view the rates for transactions on an account’s detail page in Balancer, click the settings icon and enable the currency columns: Transaction amount, Engagement amount, Currency, and Rate.

![image](https://static.adra.com/adra-assistant/images/1548aebf67c0a6a80f487025c469a3d6.jpg)

Import Closing Rates
--------------------

Navigate to **Setup>>Financial Configuration>>Closing rates.**

Click **Import Closing Rates.** A pop-up window displays.  
![image](https://static.adra.com/adra-assistant/images/9051a7eb4ae79a06cfa78e2bad6c8b8f.jpg)  

1.  **A file format description can be found here** – Click to download a template for closing rate import. Use the template to create a file with desired currencies.
2.  **Engagement Name** and **Period -** If applicable, select the engagement. Select the period to import the rates to.
3.  **Select file** – Drag and drop or click to select the closing rates file.
4.  **Import** – Click to import the file.

On the **Jobs** page in Setup, click the job **Log** to view the imported rows and any errors.

![image](https://static.adra.com/adra-assistant/images/235354e18aa812c285f6e82210fe2233.jpg)

### Copy Rates

This functionality allows users to copy rates from an earlier period.  
Navigate to **Setup>>Financial Configuration>>Closing Rates>>Copy Rates**.  
![image](https://static.adra.com/adra-assistant/images/c1d4df0156809b3362b830fa9240b2e2.jpg) 

1.  **Period** – Select a period to copy from. 
2.  **Copy only currencies and not closing rates** – Check to copy only currencies. 
3.  **Copy closing rates** – Click to copy currencies and/or closing rates to the current period.

### Add Rates

Navigate to **Setup>>Financial Configuration>>Closing Rates>>Add Rate**.

![image](https://static.adra.com/adra-assistant/images/c36ee57642da785db357955544b8916d.jpg)

1.  **From currency** – Select the currency the rate converts from.
2.  **To currency** – Select the currency the rate converts to. 
3.  **Closing rate** – Enter the exchange rate.
4.  **Add rate** – Click to save the rate.
