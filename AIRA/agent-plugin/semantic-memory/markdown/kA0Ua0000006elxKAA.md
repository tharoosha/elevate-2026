Adra Out of Office Readiness Checklist
======================================

To prepare for vacation periods, it is recommended that administrators(s) follow these steps below.

1\. Assign a System Administrator
---------------------------------

Assign a new/temporary system administrator to support and manage users during the vacation period, especially those among the temporary staff.

2\. Add Users 
--------------

Add users for new and temporary staff in Setup.

3\. Assign Application Privileges
---------------------------------

Assign responsibilities in the desired applications

### Balancer 

1.  Assign reading privileges to legal entities for standard users and auditors - [Balancer Users Page Overview](#article:kA00H000000oOcwSAE@Success-Center)
2.  Assign Local Business Admin rights to a legal entity if necessary (can manage settings for that legal entity) - [Balancer Users Page Overview](#article:kA00H000000oOcwSAE@Success-Center)
3.  Assign Preparer, approver, and/or reviewer roles - [Balancer Understanding User Roles](#article:kA00H000000kJ8tSAE@Success-Center)  
    1.  Permanent staff - [Balancer Export & Import Account Roles](#article:kA00H000000kJAGSA2@Success-Center)
        1.  Apply account role changes for an open period - [Balancer Update Accounts Setting & Roles](#article:kA06S000000kK6sSAE@Success-Center)
    2.  Temporary staff - [Balancer Transfer or Remove User Roles](#article:kA00H000000oP13SAE@Success-Center)

### Matcher

1.  Assign access to legal entities and reconciliation groups for standard users.
2.  Assign Local Business Admin rights if necessary (can manage settings for that legal entity) 

To learn more about granting legal entity access and Local Business Admin rights, see [Matcher User Page](#article:kA0Ua0000006enZKAQ@Success-Center).

To learn more about access level privileges, see [Matcher Understanding User Roles and Access](#article:kA0Ua0000006elxKAA@Success-Center).

### Task Manager 

1.  Assign read access - [Task Manager User Page Overview](#article:kA0Ua00000002WTKAY@Success-Center)
2.  Assign a team, and preparer, and/or approver privileges - [Task Manager Create & Manage Teams](#article:kA00H000000kJ5QSAU@Success-Center)
3.  Assign team admin rights if necessary - [Task Manager Understanding User Roles and Access](#article:kA06S000000kK7vSAE@Success-Center)
4.  Assign section admin access if necessary (can edit tasks in the **Library**) - [Task Manager Understanding User Roles and Access](#article:kA06S000000kK7vSAE@Success-Center)
5.  Temporarily reassign tasks in active task lists for the periods that will be impacted by vacation time - [Task Manager Edit & Manage Active Tasks](#article:kA00H000000kJ6OSAU@Success-Center)
