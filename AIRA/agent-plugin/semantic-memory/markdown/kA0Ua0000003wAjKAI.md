F5 Big-IP Remote Code Execution (CVE-2022-1388)
===============================================

Problem:   
[(CVE-2022-1388)](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2022-1388)  
On F5 BIG-IP 16.1.x versions prior to 16.1.2.2, 15.1.x versions prior to 15.1.5.1, 14.1.x versions prior to 14.1.4.6, 13.1.x versions prior to 13.1.5, and all 12.1.x and 11.6.x versions, undisclosed requests may bypass iControl REST authentication. Note: Software versions which have reached End of Technical Support (EoTS) are not evaluated.  
  
Status:  
  
F5 Big-IP Remote Code Execution (CVE-2022-1388) Response FAQ  
 

*   Is Trintech operating a vulnerable version of F5 products as defined in CVE-2022-1388?
    *   Yes.  Trintech operates F5 load balancers which could potentially be impacted by this vulnerability.
*   If so, have the recommended remediation steps released by F5 been implemented on all vulnerable systems?
    *   Trintech has made configuration changes recommended by F5 to mitigate potential impact.  As a second mitigation, Trintech has completed software upgrades on all F5 load balancers during our monthly scheduled maintenance window which took place on May 21.
*   If not, what is the anticipated completion date to implement recommended patching on all affected devices?
    *   Following configuration changes made, patching described above was completed on May 21.
