Balancer Exclude or Include Zero Balance Accounts
=================================================

When a balance file is imported into Balancer, accounts with a zero in the balance field will display with a zero balance on the **Accounts and status** page. If the balance field is empty, the account will not be displayed on the **Accounts and status** page.

If there are accounts imported with a balance of zero and the intention is to exclude them, it is recommended to remove these entries from the import file. 

Configure the Bank or ERP Settings
----------------------------------

The most sustainable way is to configure the export location of the file, such as bank or ERP, to leave the fields empty.

Delete Incorrectly Imported Accounts
------------------------------------

If accounts have already been imported, they can be deleted by removing the account for the period, either by deleting specific accounts or the entire period, which will only remove the instance of the account in that period while retaining details in all other periods and in the account settings. To learn how to do this, see [Balancer Delete Accounts and Periods](#article:kA00H000000kJ9hSAE@Success-Center).

 **WARNING**:

*   Deleting accounts for a period will remove all associated balances and content for that period.
*   Carefully review which accounts need to be excluded to avoid unintended data loss.

Edit the Import File Manually
-----------------------------

If it is necessary to edit the file manually for import, either to remove or add zeros in the Balance column, do the following:

1.  Open the file.
2.  Select the Balance column.
3.  Click Ctrl+F on the keyboard.
4.  Select the **Replace** tab.
5.  Enter 0 in the Find what field. Leave the Replace with field empty. (Reverse this to ensure zero balance accounts are included).
6.  Check **Match case**.
7.  Click **Replace All**.
