Balancer Period Documents
=========================

Users can upload documents and links to a period, rather than to a specific account. This is useful if there are contextual items which pertain to the period or year, rather than to one reconciliation.  
 

Access / Preview Period Documents
---------------------------------

To access period documents:

1.  Navigate to **Balancer>>Accounts and status**.
2.  Click **Period documents**. 

![image](https://static.adra.com/adra-assistant/images/66d94c4453e615da67afce9e7f765736.jpg)

3.  Click the **name** of an existing document to preview it, or check multiple documents to perform actions in bulk. 
4.  Click **Bulk actions**. Click **View selected**, **Delete selected**, or **Download selected**.

![image](https://static.adra.com/adra-assistant/images/dc1dc9a66c061c935027cd2cb395c803.jpg)  

*   *   **View selected** opens the documents in a new browser tab. The documents are read-only.

![image](https://static.adra.com/adra-assistant/images/11217ab37b349fe9abca3ea2903d47db.jpg)

Add Files
---------

To add files:

1.  Drag and drop up to five **files** or click **Upload document(s)**.

![Drag and Drop Files](https://static.adra.com/adra-assistant/images/8a88a5f3cf2d58e70c01bb8499487b18.jpg)

 

2.  Click the **legal entity drop-down**.
3.  Select the **legal entity**.

![Select Legal Entity](https://static.adra.com/adra-assistant/images/6b9058d9e5894f982d201699bf24195e.jpg)  
 

4.  Click the **down arrow** to expand.

![Click Down Arrow](https://static.adra.com/adra-assistant/images/a494548a9f0e010a75dedb31aa193000.jpg)  
 

5.  Enter a **Description**.
6.  Select access. Click **Everyone with access to the legal entity** or **Specific users**. If granting access to specific users only, select the **users**.

![Grant Access](https://static.adra.com/adra-assistant/images/67b894e06e5a0d32e078e376811fa329.jpg)  
 

7.  Click **Upload document(s)**.

![Click Upload Documents](https://static.adra.com/adra-assistant/images/94f9bdeb54e124ab753f6e37d0d962d4.jpg)

Add a Link
----------

To add a link:

1.  Click **Add link**.

![Click Add Link](https://static.adra.com/adra-assistant/images/ff88101c3b411450f9bdd5789ced350c.jpg)  
 

2.  Click the **legal entity drop-down**.
3.  Select the **legal entity**.
4.  Enter the **Link/URL**.
5.  Enter a **Description**.

![Enter URL](https://static.adra.com/adra-assistant/images/91a674dfc601716dcff7dc7e5e950ed6.jpg)  
 

6.  Select access. Click **Everyone with access to the legal entity** or **Specific users**. If granting access to specific users only, select the **users**.
7.  Click **Add link**.

![Click Add Link](https://static.adra.com/adra-assistant/images/e88c5c3c98324248217038144a1ba9bf.jpg)

Note that multiple documents can be added simultaneously, but links can only be added one at a time.  
 

Managing Period Documents
-------------------------

Users will be shown only the items which are assigned to legal entities to which they have read access. If an item is restricted to specific users, a user with read access to that entity but not access to the specific item will see a row for the item but will not be shown the name, description, or have the ability to delete, edit, or open/download the item.  
 

Users can open/download all items to which they have access, but will only be able to delete and edit items which they uploaded.  
  
Click the **Action icons** to manage files and links:

*   **Delete** (trash can) - Delete a link or file
*   **Edit** (pencil) - Edit a link or file
*   **Open** (link) - Open a link
*   **Download** (down arrow) - Download a file
