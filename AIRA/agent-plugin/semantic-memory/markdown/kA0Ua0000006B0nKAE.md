Matcher Transaction Definition and FAQ
======================================

What Is a Transaction?
----------------------

A transaction in Matcher is defined as any line item that is imported into Matcher. This includes transactions that are manually created through the Exceptions screen as well as the internal transfer of items from one Reconciliation Group to another.

All transactions will be included in the customer’s transaction usage total. If transactions are unimported or deleted through the Reconciliation Group, these are still included in the transaction usage total.

How Do I See My Used Transactions?
----------------------------------

The transaction count can be seen for each individual legal entity and for imports done across all legal entities.

To see the transaction count, follow the steps below:

![image](https://static.adra.com/adra-assistant/images/f91f677381bee5203072706389c52131.jpg)

1\.    Navigate to **Matcher>>Administration>>Import History**  
2\.    Click **View and calculate used transactions**.

![image](https://static.adra.com/adra-assistant/images/a01e8ca310d323a40548c229aded2c5c.jpg)

3.  Select the **Type** filter.
4.  Check **Import** and **ManualRegistrartion**, and click **Add filter**.

 **HELPFUL HINT**: To see the total used transactions for a specific date range, use the Date and Time filter on the Used Transactions grid

FAQ
---

**Are transactions created by variance matching counted in the total transaction usage?**

*   No, transactions that are created due to variance matching do not count in the calculation of total used transactions.

**Are transactions imported through the Reconciliation Group configuration to substantiate a starting balance count in the total transaction usage?**

*   No, transactions imported to substantiate a starting balance through the Reconciliation Group open item import do not count in the total transaction usage calculation.

**Do canceled import transactions count in the total usage?**

*   No, only transactions that are successfully imported into Matcher count in the total transaction usage.

**What if customized XML is excluding rows from a file on import?**

*   If XML is configured to exclude rows from a file when importing into Matcher, only the items imported into the application (appear as a line item in the Exception screen) count in the total transactions used calculation.

**What if the transactions do not match manually or automatically?**

*   All transactions imported into Matcher are counted in the total transaction usage regardless of whether they will ultimately match manually or automatically.
