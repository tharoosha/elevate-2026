Balancer Home Page Overview
===========================

The **Home** page provides an overview of outstanding accounts related to the user’s assigned roles.

Navigate to ****Balancer>>Home****.

![image](https://static.adra.com/adra-assistant/images/299d488ae40888a8579720db36a16714.jpg)

1.  **Role** - Select a user role to display associated accounts.
2.  **Include active accounts not directly assigned to me** - Check to display accounts where the active user has a secondary role.
3.  **Account gird settings** - Manage which columns are visible in the grid.
4.  **Column headers** \- Click to sort accounts in ascending or descending order. Click a funnel to apply a filter.
5.  **Account list** - View not finalized accounts assigned to the user. Click an account to open the account’s detail page.
6.  **Statistical overview** \- View a statistical overview of assigned accounts.
    1.  Percentage of finalized accounts.
    2.  Bar chart of the balance for finalized accounts.
    3.  Percentage of accounts in each account status category.
