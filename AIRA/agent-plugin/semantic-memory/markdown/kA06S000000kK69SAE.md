Logging Into Adra
--------------------

Follow these steps to access the Adra Product Suite from within Microsoft Dynamics 365 Finance & Operations:

1.  Click on the **Adra Product Suite** tile.

![2.png](https://static.adra.com/adra-assistant/images/2778bd2dc4d097fac81d407adc02a45d.jpg)

![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/60a06309-a186-40a3-9b01-c17cfca555f2/whcheckmarkv1.png)  **Tips:  This is a Microsoft Dynamics 365 administrator view. Non-administrative users will see different tiles. Microsoft Dynamics 365 Finance & Operations user roles are discussed below.**

2.  Only administrators will have access to the **administration tile** which is used to navigate to System administration from within Microsoft Dynamics 365 for the management of users, security & system settings, data management, and lifecycle services.

![3.png](https://static.adra.com/adra-assistant/images/d5cac904acc3aab9a28df2b621c1dd2a.jpg)  
All users can also access the Success Center and the Innovation portal from this page.

3.  Select a product to log into and type in the **username**, click **Login**.

![4.png](https://static.adra.com/adra-assistant/images/9d1fd13064af89dcf55d95715221afe3.jpg)

![loggedin.png](https://static.adra.com/adra-assistant/images/8588f92ec421077fd5294887e82fb9f6.jpg)  
  
User Roles In Microsoft Dynamics 365 Finance & Operation
-----------------------------------------------------------------------------------------------------------------------------------------------------------------

There are two types of roles in Microsoft Dynamics 365 Finance & Operations for Adra product users, Adra administrator and Adra user. Administrators will see more tiles for access to other content from within the Finance and Operations page.   
 

![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/6e9ba989-6960-4118-8d91-bf4dff3019be/whlightbulbv1.png) **Recommendations: Adra product roles like System, Business, and Local Business Administrators are not connected to security roles in Microsoft Dynamics 365 Finance & Operations. We recommend a System or Local Business Administrator utilize the administrator role within Microsoft Dynamics 365 Finance & Operations, typically an IT person who is responsible for setting up products and/or defining security settings.**

Assigning Roles
---------------

In order for users to see the Adra Product Suite a role has to be assigned to their user. Roles are assigned by the Administrator role type from within Microsoft Dynamics 365 Finance & Operations.

1.  From **Administration** click on **Manage Users**.

![7.png](https://static.adra.com/adra-assistant/images/e579f97c971d54124b82c542d3f43658.jpg)

2.  Select a **user** by double clicking.

![8.png](https://static.adra.com/adra-assistant/images/9cfca94f33e1417fd58cd0c04456842f.jpg)

3.  Expand the roles section and double-click on **Adra user**.

![9.png](https://static.adra.com/adra-assistant/images/cb890a7a5286170f43eec2aea17b07a4.jpg)

4.  Select the **checkbox** next to the role required for this user, **Adra administrator** or **Adra user**.

![15.png](https://static.adra.com/adra-assistant/images/587f1ec0f5977f1f67d56eab61c5228b.jpg)

Adra Configuration within Microsoft Dynamics 365 Finance & Operations
---------------------------------------------------------------------

To ensure all products are visible to users an Administrator will need to configure application URL’s from within Microsoft Dynamics 365 Finance & Operations.

1.  As an Adra administrator, from the Adra Product Suite page click on **Administration**.

![11.png](https://static.adra.com/adra-assistant/images/307309b2fb868c53eebe03ebd38935c3.jpg)

2.  **Copy** and **paste** the URL’s for each product in the space provided.
