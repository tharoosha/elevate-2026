Task Manager Configure Task Sequences
=====================================

Create Sequences with Preceding and Succeeding Tasks
----------------------------------------------------

Task Manager offers the ability to set a preceding and/or a succeeding task. Administrators can use this feature when tasks need to be completed sequentially or are connected.  
Note, sequences can only be created with tasks within the same task list.

  
Follow the steps below to set a preceding or succeeding task:

1.  Navigate to **Task Manager>>Tasks** or access the task from the applicable task list.

![image.png](https://static.adra.com/adra-assistant/images/14602f9e9521fb2dd2e2a56ddd427b52.jpg)

2.  Click on the specific task.

![image.png](https://static.adra.com/adra-assistant/images/da02cc72c744dfbee20d79e43ac18fd6.jpg)

3.  To add succeeding or preceding tasks, click on either the **Preceding Tasks** or **Succeeding Tasks** button. The Connect tasks pop-up appears.

![image.png](https://static.adra.com/adra-assistant/images/821d7bb5009b91f2245e0cdeacb4a720.jpg)

1.  All existing connected tasks are listed. Note that both preceding and succeeding tasks are added in the same pop-up. Click X to remove a connected task.
2.  To connect a task, place the cursor in the Connected Preceding Tasks or Connected Succeeding Tasks field. Enter a task name or code to search for a task.
3.  Check the desired task(s) in the drop-down.
4.  Click **Add**. If the incorrect task is added.
5.  Click **Save tasks**.

 **BEST PRACTICE**: Start with the first task in a sequence and build on that to create the Task process.

Import Task Sequences to a Task List
------------------------------------

Users can use a template to import task sequences to a task list instead of manually creating the sequences.

1.  Navigate to **Task Manager>>Task Lists**. Click the name of a task list on the Not Started tab.

![image](https://static.adra.com/adra-assistant/images/b42b705fed22ef5c61c57f03da56358f.jpg)

2.  Click **Import sequences.**

**![image](https://static.adra.com/adra-assistant/images/68cbef8122b121a1dd7333861e1f2292.jpg)**

3.  The Import task sequences page displays.

![image](https://static.adra.com/adra-assistant/images/803670ce6ba397da9870d9fc388375c3.jpg)

1.  1.  Click **download the template**.
    2.  Complete the template using **task codes**.
    3.  Click **Select file.**
    4.  Click **Import and back** to go begin the import and navigate back to the **Task List** page. Click **Import and continue** to begin the import and navigate to the **Jobs** page.

4.  Navigate to the Jobs page to **Review** the import or view the import **Log**.

![image](https://static.adra.com/adra-assistant/images/8b3bf869a4dc479f23953af3fc5a13dd.jpg)

5.  Review the imported rows and any errors. Click **Cancel import** to update the template or **Complete import** to import the rows.

![image](https://static.adra.com/adra-assistant/images/3f97975051655243b5bf1dbd7754f381.jpg)

 **HELPFUL HINT**: To manage whether tasks can be completed out of sequence (in or out of order), navigate to **Administration>>General Settings**, and toggle **Allow sequences to be breached** to on or off.

Export Task Sequences from a Task List
--------------------------------------

Users can use a template to export task sequences from a task list.

1.  Navigate to **Task Manager>>Task Lists**. Click the name of a task list from any of the tabs.

![image](https://static.adra.com/adra-assistant/images/50a5f3e7659cbe2727ace8352120b178.jpg)

2.  Click **Sequences**. 
3.  Select **Export sequences**.

![image](https://static.adra.com/adra-assistant/images/121d8c154ceb56ccf0c9e47968ed01b1.jpg)

4.  An Excel file will immediately start downloading.
5.  If necessary, enter additional sequences on the template and import it. Note that changes cannot be made to existing sequences through the import, but additional sequences can be added.
