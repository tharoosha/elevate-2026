Balancer Opening Balance
========================

When a new fiscal year is created in Balancer, an **Opening balance** period is created automatically. Learn more: [Balancer Creating Fiscal Years and Periods](#article:kA00H000000kJ9cSAE@Success-Center).  
Balances must be uploaded to the opening balance, as it does not populate automatically from the previous **Year end** balance.  
  
When the opening balance has been imported, the Opening balance period automatically closes.  
Learn how to open the period again and reupload the opening balance: [Reupload Opening Balance](#reupload-opening-balance).

Import Opening Balance
----------------------

To import an opening balance, follow the steps below:  
![image.png](https://static.adra.com/adra-assistant/images/e2a662b1d4ca2bb1d3bdff38e3d55765.jpg)

1.  Navigate to **Jobs>>Import balances** 

![image.png](https://static.adra.com/adra-assistant/images/a5c428eba41c479d3f56d56dc079e47a.jpg)

2.  Select the correct opening balance, labeled '(**Opening Balance \[FY....\])'**
3.  Click **Upload files** and select the opening balance file.
    *   Click the **A file format description can be found here** link to download the file template if needed. This does not apply to engagements where a custom import template is used. Learn more: [Balancer Custom Import XML](#article:kA00H00000048OmSAI@Success-Center). 
4.  Click **Import**. The **Jobs** page loads.

![image.png](https://static.adra.com/adra-assistant/images/03bfa47bb1d22c9b60916d48ef797b13.jpg)

5.  Reload the page until the **Review and approve** button displays. Click it and verify the import. The opening balance period for legal entities included in the file will automatically be closed. Opening balance periods for legal entities not included in the file will remain unaffected, enabling the option to upload opening balances for these entities at a later time.

Reupload Opening Balance
------------------------

Once an opening balance is uploaded to the opening period, the period automatically closes. To update the opening balance, follow the steps below:  
![image.png](https://static.adra.com/adra-assistant/images/22b35a86fff511a2c67edaca0e809d29.jpg)

1.  Navigate to **Periods>>Closed periods**
2.  Select **\- All Periods -** in the **CURRENT VIEW** drop-down. Optional to specify a legal entity in the legal entity drop-down.
    *   Click on a column header to sort the list in ascending or descending order.
3.  Check the correct opening balance period(s)
4.  Click Reopen Selected.
5.  Navigate to Jobs>>Import balance and upload the opening balance as described [above](#import-opening-balance).
