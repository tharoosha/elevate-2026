Setup Create New Users In Adra
==============================

This Article Contains: 
-----------------------

*   [Create New User](#create-new-user)
*   [Application Access](#application-access)

  
To add a new user directly in **Setup**, navigate to **Setup>>Users>>Create user**. The **Create New User** page loads.   
The same page can also be accessed through any of the applications. In Balancer, Matcher, or Task Manager, click **Administration>>Users>>Create new user**.

![image.png](https://static.adra.com/adra-assistant/images/d49dd24a93e6c0fdb661aa9cb9f612aa.jpg)

Create New User
---------------

 **WARNING**: If the user's email already exists in the Adra platform, the following message appears. To learn how to add existing/external users, such as auditors, please read the following article: _[Setup Connect External User](#article:kA06S000001DXbFSAW@Success-Center)_  
![image.png](https://static.adra.com/adra-assistant/images/3489bcac6745afd15f002fd13dbf9924.jpg)

  
To create a new user, follow the steps below:  
![image.png](https://static.adra.com/adra-assistant/images/2d095e7ad05e7557946cad532cc104d5.jpg)

1.  **Username** - Enter an active e-mail address and click **Continue** to unlock the other fields. The username becomes locked and the button changes to **Update username**. 
2.  **Employer** \- Select the engagement the new user will have access to.
3.  **First name and Last name** - Enter the names that will appear in job logs and settings.
4.  **Email address** \- This field is only unlocked if the engagement uses SAML login for their users. 
    *   Using SAML login allows users in a project or engagement to have various Adra profiles connected to the same email address, indicated in this field. These profiles can represent different roles or aspects of the user's involvement in the engagement, and the user can use different usernames when logging in through SSO for each of these profiles.
5.  **Additional user information** - Include additional user details, such as titles, to track the positions assigned to specific roles. Complete any other important information relevant to your organization.
6.  **Region and language** \- Choose the appropriate time zone, date and time format, and language. The latter determines the decimal point formats in the applications.
7.  **Activation e-mail** 
    *   Toggle to Off to prevent sending the user activation e-mail. This feature is useful when users need to be added but are not ready to activate their profile. When the profile is saved, a **User status** section appears on the bottom of the users profile. Click **Send activation e-mail** when the user is ready to activate the profile. The activation link expires after 24 hours.

![image.png](https://static.adra.com/adra-assistant/images/fbc803433f7fc47a6492b99b8b6e1841.jpg)

*   When the Toggle is On, an e-mail with an activation link is sent to the user. The activation link expires after 24 hours.

8.  **Save** \- Click to save the user profile.

 **HELPFUL HINT**: If the activation link has expired, navigate to the user's profile in Setup, scroll to the bottom, and click **Resend activation e-mail**   
![image.png](https://static.adra.com/adra-assistant/images/304cd900764e0f6fe88c1ff87dfacb69.jpg)  
 

Application Access
------------------

When the user profile has been created, application access levels must be assigned. Follow the steps below: 

1.  Navigate to **Setup>>Users**, click the user, and select the **Access and roles tab**.

![image.png](https://static.adra.com/adra-assistant/images/1728ff55eb92e957319625faf8e44b29.jpg)

2.  **Select engagement** - Click the empty field and select the relevant engagement(s) the user will have access to.
3.  **Add engagement** - Click to add engagement access.

![image.png](https://static.adra.com/adra-assistant/images/a07e935f115383d6cd5bf9e5090c37bf.jpg)

4.  **Expand or Delete** - Click the **expand** arrow to view application access for the engagement. Click **delete** to remove engagement access.

![image](https://static.adra.com/adra-assistant/images/423969fbdc6a77aa3df55ff6860ed24f.jpg)

5.  **Organization and Engagement Admin**  - Select to enable the user to manage all **Setup** configurations, such as managing users and security. To learn more, see [Setup User Access and Roles Definitions](#article:kA0Ua00000003CPKAY@Success-Center).
6.  **Financial admin** - Select to enable the user to manage financial configurations and legal entity settings across the platform. To learn more, see [Setup User Access and Roles Definitions](#article:kA0Ua00000003CPKAY@Success-Center).
7.  **Auditor**  \- Toggle to On to assign the user the responsibilities and restricted view of an auditor. 
8.  **Application access**  - Select which application(s) the user will have access to.
    *   **No access**  - When selected, the user can not access the specified application.
    *   **Standard user & Limited access user (Matcher)**  - When selected, the user has limited access to the selected application. Standard users and limited access users must be granted privileges within each application in order to perform their tasks. Learn more in the applicable article:
        *   **Balancer**
            *   User role definitions - [Balancer Understanding User Roles](#article:kA00H000000kJ8tSAE@Success-Center)
            *   How to assign access - [Balancer Users Page Overview](#article:kA00H000000oOcwSAE@Success-Center)
        *   **Task Manager**   
            *   User role definitions - [Task Manager Understanding User Roles and Access](#article:kA06S000000kK7vSAE@Success-Center)
            *   How to assign access - [Task Manager Create & Manage Teams](#article:kA00H000000kJ5QSAU@Success-Center) & [Task Manager User Page Overview](#article:kA0Ua00000002WTKAY@Success-Center).
        *   **Matcher** 
            *   User role definitions - [Matcher Understanding User Roles and Access](#article:kA0Ua0000006elxKAA@Success-Center)
            *   How to assign access - [Matcher User Page](#article:kA0Ua0000006enZKAQ@Success-Center)
        *   **Journal Entry**
            *   User role definitions - [Journal Entry Understanding User Roles and Access](#article:kA0Ua000000794zKAA@Success-Center)
    *   **Business admin**  - When selected, the user has day-to-day management responsibilities of the application, such as managing user tasks, settings, and fiscal years.
    *   **Auditor** \- This option is only available if the user was assigned **Auditor** access.
9.  **Save changes** - Click to apply any changes.

To learn more about the user roles, read the following article: [Setup User Access and Roles Definitions](#article:kA0Ua00000003CPKAY@Success-Center).
