Task Manager Import & Export Task Template
==========================================

The Admin can import a template from the **Library** to make multiple changes using an Excel spreadsheet. Find the template in the Task Manager Workbook on the Adra Success Center. Use codes instead of names in the template.

 **HELPFUL HINT**: To learn in depth about the different task settings options, see [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center).

    
Follow these steps to upload the template,

1.  Click the **ellipsis** for the folder you would like the tasks to reside in and select **Import Task Templates.** The Import task template screen loads.
    *   Alternatively, click **Export task template**. Navigate to the **Jobs** page and click **Download**. Add new tasks or modify existing tasks in the exported file. Continue to step 2.

![image.png](https://static.adra.com/adra-assistant/images/a0bf4a253ac97aaa22014b0ab6504073.jpg)

2.  Click **download the template** or **description** and use them to create an import template.
3.  Check **Update existing ‘Description’** and **Update existing ‘Procedure’** as applicable
4.  Click **Select a file** to upload the template.

 **BEST PRACTICE**: The import file must be in Excel (.xls or .xlsx), tab-delimited format. All data must be entered on the first sheet. If the Task ID exists from before, the import will overwrite the old values, but not until you review and approve the import. Ensure you do not have any tabbed spaces as they will prevent files from importing.

 **BEST PRACTICE**: To learn more, complete this **[interactive video](https://success.adra.com/s/by-catalog?vtui__mediaId=a7U0H000000PFjPUAW&vtui__catalogId=a7N0H000000PDANUA4&vtui__source=catalog)** for Importing Tasks. This video walks through using the Task Manager Workbook to set up tasks in the library.

For more information on the requirements for fields in an import, review this Info pdf. Click the preview image to view the pdf.

After initiating a task template import, a notification displays and the user is automatically directed to the **Jobs** page to complete the import.  
  
To approve a task template import, click **Review**.
