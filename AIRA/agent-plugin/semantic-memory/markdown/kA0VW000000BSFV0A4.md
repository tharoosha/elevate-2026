OKTA SCIM Groups Troubleshooting
================================

OKTA - SCIM Groups Troubleshooting
----------------------------------

### Group Push Error

This is an example of a **Group Push Error**. If you believe the problem is not in the OKTA configuration, you can report the error information to Adra support for investigation. Provide the information in the highlighted box when submitting your report.

![image](https://static.adra.com/adra-assistant/images/d35f8d87f1c0d6234e88a18874e703c7.jpg)

### Missing Groups

If you are missing groups from Adra, click the **Refresh App Groups**. This will re-sync all Adra groups to OKTA.

![image](https://static.adra.com/adra-assistant/images/5469a8eeb60cbe93aecf6a727f5760a5.jpg)

### Check Logs

Logs can be helpful in investigating potential problems.

![image](https://static.adra.com/adra-assistant/images/fffb0580a458f00e89e345a823f7e77b.jpg)

### Groups

It may be helpful to inspect that the groups coming from Adra are those expected.

![image](https://static.adra.com/adra-assistant/images/9fc4627d645e62ff1fffc1c792b53f4c.jpg)

Clicking any of the groups should show "managed automatically by OKTA".

![image](https://static.adra.com/adra-assistant/images/a16596fa9867d35340c7baf698061529.jpg)
