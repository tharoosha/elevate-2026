Balancer Jobs Page Basics
=========================

The Jobs feature in Balancer automates repetitive tasks and allows for the import of balances and transactions.   
BAs and LBAs can run jobs to:

*   Export, import, and update account settings and roles.
*   Import balances and transactions.
*   Synchronize changes to account settings and roles across multiple legal entities for open periods.
*   Automatically certify accounts that meet selected criteria.
*   Update variance analysis.
*   Export data from a period as a zip file.
*   Export and import additional fields.

To access the variance analysis option, it must be enabled:  
**Administration>>General settings>>Certification settings>>Enable variance analysis.**  
  
To start a job, navigate to the **Jobs** page.  
  
 ![bal delete.png](https://static.adra.com/adra-assistant/images/f3cd3ad0a2ca9ddd1f214a175773e909.jpg)

  
  
The Jobs page loads.  
![image.png](https://static.adra.com/adra-assistant/images/98bf5265f786fda561a98bfaa38464f3.jpg)

1.  **Log** – Click to view the import Summary and Logs to review details about the job and any error messages.
2.  **Headers** – Click to sort the jobs in ascending or descending order. Click a filter icon on any header to filter the jobs list. See Job Period filter example below.

![image.png](https://static.adra.com/adra-assistant/images/f83b8fe83d2e3d761479bfeea972a2ec.jpg)

3.  **Jobs**:
    *   **Import balances** – Click to import balances to a period.
    *   **Import items** – Click to import transactions.
    *   **Other jobs** – Click to open a menu with additional jobs.
4.  **Actions** – Some jobs require actions. Click **Review and approve** to cancel or confirm import jobs. Click **Download** to create and download an excel file for the export jobs.

Import Balances and Transactions
--------------------------------

These jobs are listed separately, as they are both frequently run jobs. Click **Import balances** or **Import items**, then upload a file of balances/transactions and select the period to which they should be imported.  
Learn how to import balances and transactions here: [Balancer Import Balances & Transactions](#article:kA0Ua0000000SU9KAM@Success-Center)

Other Jobs
----------

![image.png](https://static.adra.com/adra-assistant/images/33b41fed9d9dc69a38c717ee49b0a1f1.jpg)

1.  **Update current period** – These jobs are used to manage the open periods’ balances, transactions, settings, and certifications, as well as export reconciliations and scheduled items.
2.  **Account roles, settings, and extra fields** – These jobs are used to manage and bulk update account roles, settings, and extra fields.

Job Log
-------

The job log can be used to track the status of jobs. For example, administrators can view a list of deleted accounts on the job log.

Job Status Definitions
----------------------

Each job on the **Jobs** page has a status. View the list below to learn what each status indicates.

![image.png](https://static.adra.com/adra-assistant/images/a3cf3821ddd29f0c6bc97ff6291e6c51.jpg)

*   **Not started** - Job is waiting in the queue
*   **Waiting for period selection** - User needs to manually select the target period for data import
*   **Waiting for upload** - Data is ready for upload and waiting in the queue
*   **Uploading** \- Data is being uploaded
*   **Paused** \- Job is paused as its waiting for a user action
*   **Waiting for review** \- Data is read from the import file and is waiting for a manual review before upload
*   **Reviewing** \- Data is being reviewed
*   **In progress** - Job is still executing
*   **Completed** \- Jos is completed successfully
*   **Aborted** \- Job is cancelled manually (for example during the review stage)
*   **Error** \- Job failed due to some error (see logs)
*   **Cleaned up** - All import jobs still requiring a user action have been cleared out after a certain time period (not possible to take any action on them after that)<
*   **Waiting to generate** - An export job is waiting in the queue<
*   **Generating** \- An export file is in the making
*   **Generated** \- An export file is generated and ready for download
