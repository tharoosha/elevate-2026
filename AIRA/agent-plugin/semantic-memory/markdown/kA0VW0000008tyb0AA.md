Journal Entry Export Journal Entries
====================================

Journal entries can be exported in the following ways:

*   On the **Journal entries** page in Journal Entry
*   On the **Exceptions** page and on the **Reports** page in Matcher

Export Journals from Journal Entry
----------------------------------

To export the journal entries, do the following:

![image](https://static.adra.com/adra-assistant/images/c47a6c07f550fc886ea38bd1cc4a1232.jpg)

1.  Navigate to the **Journal entries** page
2.  Select entries and click export, or click **Export** without selecting any entries.

![image](https://static.adra.com/adra-assistant/images/0c10f3461042113abc11c9b40650b72a.jpg)

3.  Select the **Export Template**, or create a new template. To learn more, see [Create new Export Template](#create-new-export-template).
4.  Export options
    *   **Export only selected with status 'Ready to post'** \- Select to export only the selected entries. This option is only available if entries have been selected.
    *   **Export all with status 'Ready to post'** - Select to export all entries with the status ready to post
5.  Click **Export**

**![image](https://static.adra.com/adra-assistant/images/9dd2c5bc34765e4da34eef2f90dc881b.jpg)**

6.  Navigate to the **Jobs** page
7.  Click **Download**. The file can be found in the download location.

Export Journals in Matcher
--------------------------

Journals can be exported from Matcher in two ways:

*   From the **Exceptions** page as an excel file.
*   From the **Reports** page - To learn more, see [Matcher Reports](#article:kA06S0000019Ly1SAE@Success-Center)
    *   This permits the file to be a PDF or a DOCX, in addition to Excel. 
    *   Reports may be configured to run automatically at defined intervals if needed.

### From the Exceptions Page

To export a journal from the **Exceptions** page:

![mat 14.png](https://static.adra.com/adra-assistant/images/0155e2480d49548933980be6a19fb746.jpg)

1.  Navigate to **Matcher**\>>**Exceptions**\>>**Journals**.
2.  Check one or more **journals** in the first column.
    *   **Note** \- When multiple journals are selected, all journal items will be compiled onto one Excel sheet.
3.  Click **Export**.

![mat 15.png](https://static.adra.com/adra-assistant/images/b4607ed86cb6cef0fc247dc498a2772c.jpg)

4.  Select the **Export Template**, or create a new template. To learn more, see [Create new Export Template](#create-new-export-template).
5.  Select journals to export:
    *   **Export selected journals** - The number in parentheses indicates the number of journals that were checked on the journal list.
    *   **Export all not exported journals** - The number in parentheses indicates the number of journals with a Ready to Export status.
6.  Click **Export**.

![mat 16.png](https://static.adra.com/adra-assistant/images/e1b684770f2a3f12f0a8462feafcda1f.jpg)  
A notification alerts the user that a link to the export file will be delivered via the user's e-mail.

![mat 17.png](https://static.adra.com/adra-assistant/images/32a75388d9ca2fdc6e967576b32b9950.jpg)

7.  In the Adra e-mail, click the blue **Click here to download** button. 

 ![mat 18.png](https://static.adra.com/adra-assistant/images/a6012a603440969987340307fd0d99a6.jpg)

8.  Open / save the file.

Create New Export Template
--------------------------

Users can create custom Excel formats for journal exports in both Journal Entry and Matcher.

*   In Journal Entry, navigate to the **Journal Entries** page and click **Export**
*   In Matcher, navigate to **Exceptions page>>Journals** and click **Export**

After this point, the export process is identical in both Journal Entry and Matcher.

![image](https://static.adra.com/adra-assistant/images/bf42761f40ac373c007b16da2fa192a2.jpg)

1.  Click **Create New Export Template**

**![image](https://static.adra.com/adra-assistant/images/b69a6b4da154f48c411120cf9078dae1.jpg)**

2.  Enter a descriptive name, for example; 
    *   **NetSuite – JE Export (USD, IFRS)**
    *   **Consolidated Entries – CSV Upload Template**
    *   **Adra-to-Workday Journal Export – Trial Balance**
3.  Select what each column will contain. The order of the column is reflected in the exported excel file.
    *   Leave empty columns as they are if required for import purposes in other software/applications.
4.  Add additional columns if needed
5.  Remove unused columns
6.  Click **Save Export Template**

Custom templates can then be edited and deleted as well. 

![image](https://static.adra.com/adra-assistant/images/2baba6609abc867d205c6d150bcd05f5.jpg)

1.  Select the custom template in the drop-down, and click **Edit**.

****![image](https://static.adra.com/adra-assistant/images/50221497ee23db224559ab03a13f6205.jpg)****

*   *   **To make changes** - Make any changes needed and **Save**
    *   **To delete** - Click **Delete**

 **HELPFUL HINT**: In Matcher, the columns available in the custom export drop-downs include extra fields. In Journal Entry, the columns avaliable in the custom export dorop-down include dimensions.  
To learn how to create these additional fields in each application, see the following resources:

*   [Journal Entry General Settings](#article:kA0Ua0000004dHJKAY@Success-Center)
