Setup Add Internal BPO Company Code
===================================

BPO Admins can identify customers by engagement names or by adding company codes or customer IDs that are used in other systems.  
  
To add an internal company code to an existing engagement:  
1\. Navigate to **Setup>>Organization**.  
2\. Click the **Engagements** tab.  
 

![Click Engagements](https://static.adra.com/adra-assistant/images/15c13121b8def75ce5f13e286ca71bb3.jpg)

  
All engagements under the organization display.  
  
3\. Under **Company code**, use the free text fields to enter company codes or IDs for each engagement.  
 

![Enter Company Code](https://static.adra.com/adra-assistant/images/d92b3178561e32a43e898c80c36934a1.jpg)

  
4\. To save the company codes, click anywhere on the page outside of the free text fields.  
  
A success message indicating that the changes have been saved displays.  
 

![Success Message Displays](https://static.adra.com/adra-assistant/images/436f6c0f99644127690eeb2164347b76.jpg)

  
  
To add an internal company code when creating a new engagement:  
1\. Navigate to **Setup>>Organization>>Engagements**.  
2\. Click **Create engagement**.  
3. Enter the code or ID in the **Company code** field. 

  
![Enter Company Code](https://static.adra.com/adra-assistant/images/b066b4466a757935eac49c0a6f6c721c.jpg)
