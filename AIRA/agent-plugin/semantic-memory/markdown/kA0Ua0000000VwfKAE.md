Setup User Access Page
======================

The **User access** tab located in **Setup>>Profile** allows users to view their engagement and application access, copy SID, and view and manage personal access tokens. 

It is recommended that Administrators handle the creation and management of Tokens. Standard users will need access to Analytics and Integration Hub, which must be assigned by an Administrator.

![image](https://static.adra.com/adra-assistant/images/c22782a5222cbf89825f1641a83a847d.jpg)

1.  **Engagement access** - View which access engagements your user has access to. The shortcodes indicate the application and access level.
    *   **Application access shortcodes** \- BAL BA = Balancer Business Administrator. IH = Integration Hub.
    *   **Copy SID** - Click to copy a code to use for direct integration. Learn more here: [Setup Direct Integration IH API](#article:kA06S0000011SEhSAM@Success-Center)
2.  **Create token** - Click to create a personal access token. Personal access tokens are used to authenticate and authorize access for a specific user or application to interact with the Adras APIs or services.   
    ![image](https://static.adra.com/adra-assistant/images/513919aa251a393da592da1bef48b6a4.jpg)
    1.  **Analytics -** This token is used to connect Analytics API to the statistical tools: Power BI, Excel, and Tablau. Learn more here: [Analytics Resources](#article:kA00H0000019KuySAE@Success-Center)
    2.  **Integration hub** \- This token is used to automatically import files to the Adra applications using Integration Hub. Learn more here: [Integration Hub / Adra Agent Installation & Troubleshooting](#article:kA06S00000117ijSAA@Success-Center)
    3.  **Identity API** \- This token is needed for setting up SCIM. Learn more here: [Setup SCIM Implementation for Automated User Provisioning Using OKTA](#article:kA06S000001DXbPSAW@Success-Center) and [Setup SCIM Implementation for Automated User Provisioning Using Microsoft Entra ID.](#article:kA06S000001DXbUSAW@Success-Center)
3.  **Personal access tokens** - Click the expand arrow to
    *   View existing token details
    *   Download the Adra agent (only for the Integration hub token)
    *   Delete access token
    *   Extend token expiration
