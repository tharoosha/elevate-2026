Task Manager Jobs Page
======================

Jobs Page Overview
------------------

In Task Manager, the **Jobs** page shows a log of jobs run by the user. A job is automatically logged each time the user:

*   Initiates an export from the **Tasks** page.
*   Initiates an import or export in the **Library**.
*   Copies or deletes a section, folder, or subfolder in the **Library**.

  
Library Organization Jobs
----------------------------

When a user copies or deletes a section, folder, or subfolder in the **Library**, a notification displays. Navigate to the **Jobs** page to view the results.  
![Navigate to Jobs Page](https://static.adra.com/adra-assistant/images/c93bbdf754fab131dbad2b41915251de.jpg)

  
  
Export Jobs
-----------------

When a user initiates an export from the **Tasks** page or **Library**, Task Manager prompts the user to navigate to the Jobs page to view the results and download the file. For this reason, the **Jobs** page is available to all users but shows only jobs that are relevant to the user.  
![Check Job Results](https://static.adra.com/adra-assistant/images/c49c8cf53d07fd79daa526c61b544b76.jpg)  
  
To view results and download files, navigate to the **Jobs** page and click **Download**.

![image.png](https://static.adra.com/adra-assistant/images/9ef451af818a4da663dab1861480022f.jpg)
------------------------------------------------------------------------------------------------

Import Jobs
-----------

After initiating an import in the **Library**, a notification displays and the user is automatically directed to the Jobs page to complete the import.  
  
To complete a task template or extra fields import, click **Review**.  
![jobs 12.png](https://static.adra.com/adra-assistant/images/f1438bb62a8539e533463b0b29adac6d.jpg)  
  
 

Job Log
-------

Click the **job log** icon to view additional information about a job.  
![image.png](https://static.adra.com/adra-assistant/images/ab8a56731897741daca78b976eea714b.jpg)  
  
The log provides the user with the same basic information included in the job history table, as well as the number of rows imported/exported and a Job Tracking ID, which can be used when contacting Support.

![View Job Log](https://static.adra.com/adra-assistant/images/09601cd650f3802d7a256fd1029dad9c.jpg)

  
  
Job History
-----------------

The Jobs page provides a history of jobs, which are cleaned up every three days. To view cleaned up jobs, toggle **Include cleaned up jobs** to on.  
![Toggle On Include Cleaned Up Jobs](https://static.adra.com/adra-assistant/images/bdbc74e7ebcbaae6a688b12857f33baf.jpg)

 **WARNING**: If a previous import job remains unresolved on the **Jobs** page, an error will occur if a new file is imported. Locate the active import job on the **Jobs** page and click **Review**. On the Review page, click **Cancel** or **Complete**.   
  
If the issue remains, please reach out to the support team.
