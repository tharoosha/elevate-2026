Balancer Connect Analytics API to Tableau
=========================================

Introduction
------------

Adra Analytics extracts data from Balancer and / or Task Manager to provide full visibility into the month-end close process. While Adra provides Power BI templates for both Balancer and Task Manager reports, users can create their own reports in any data visualization tool that supports OData v4. Analytics reports grant access to tables within the Adra databases that aren’t naturally reported on in the interface, allowing users to analyze their close process in greater detail. This document details how to connect the Adra Balancer Analytics API to Tableau.  
 

Enable Adra Analytics for a User
--------------------------------

In the Adra Product Suite, settings, engagements, and users are managed in Setup. A user will need to be added to enable Adra Analytics. Read [Setup Create New Users In Adra](#article:kA00H000000kJ5LSAU@Success-Center) to learn more about adding users to the Adra platform. Once the user is added, follow these steps to enable Adra Analytics.

![image](https://static.adra.com/adra-assistant/images/93dc34be243ae2ba3f88037d55a9bf64.jpg)

1.  Navigate to the user's profile on the Users page. Click on the username. **Users>>Specific User**

![image](https://static.adra.com/adra-assistant/images/b61069d611c186e6c86ea96dea0ce33e.jpg)

1.  Click the **Access and roles** tab.
2.  Under ANALYTICS API, select **Standard User**.
3.  Click **Save changes**.

Generate API Access Keys for Adra Analytics
-------------------------------------------

Once a user has access to the Analytics API, the user will need to retrieve their API access code.  
 

1.  Outside of the Adra application, open a Word or Notepad document. This will be used to copy and paste information.

![image](https://static.adra.com/adra-assistant/images/6e21365912c42410a2c663fdf1b09d83.jpg)

2.  Navigate to the Profile page. **Setup>>Profile**
3.  Click **User access**.
4.  Click **Create token**.

![image](https://static.adra.com/adra-assistant/images/155f2edeac46324d4afccb93752cb02a.jpg)

5.  A pop-up appears. Under Access token for, ensure that ANALYTICS is selected. Click **Create access token**.

  
![Tablea A6.png](https://static.adra.com/adra-assistant/images/4326d123577bbdd5e4031a492d75d820.jpg)

6.  Click **Copy**. Paste the token into Word or Notepad. Title and save the Word or Notepad document. In Adra, click **Close**.

![image](https://static.adra.com/adra-assistant/images/2bf8b33dae1fbb214fb5a34164a2b3cf.jpg)

7.  When the pop-up is closed, you will return to the User access page. Click **Copy SID**. Paste the SID into your Word or Notepad document.

Create the Connection between Analytics API and Tableau
-------------------------------------------------------

![Tableau A8.png](https://static.adra.com/adra-assistant/images/1d8171fb9b60bc2e244f48659fb86c94.jpg)

1.  In Tableau, open the workbook or project you wish to connect with the Adra Analytics API data.
2.  In your Tableau workbook, click **Data**. Select **New Data Source**.  
     

![Tableau A9.png](https://static.adra.com/adra-assistant/images/457a048ef83bfeec7c1a5ab6bc4e995b.jpg)

3.  A pop-up appears. Click the **Connectors** tab, then click **oData**.

![Tableau A10.png](https://static.adra.com/adra-assistant/images/af4a0e3f0d79188630b6af0522229481.jpg)

4.  A pop-up appears. Under Server, paste the link of the API that you wish to use.
    *   For **Adra Balancer** data, use: [https://analyticsapi.adra.com/balancer/api/](https://analyticsapi.adra.com/balancer/api/)
    *   For **Adra Task Manager** data, use: [https://analyticsapi.adra.com/taskmanager/api/](https://analyticsapi.adra.com/taskmanager/api/)

 ![image](https://static.adra.com/adra-assistant/images/133f01f16cee1f51c12c931f042a25db.jpg)

5.  In the Authentication drop-down, select **Username and Password**.
6.  From the Word or Notepad document, copy the **access token** that was created in step 7 of Generate Access Keys for Adra Analytics. Paste the **access token** under Username.
7.  From the Word or Notepad document, copy the **SID** that was created in step 8 of Generate Access Keys for Adra Analytics. Paste the **SID** under Password.
8.  Click **Sign In**.

![image](https://static.adra.com/adra-assistant/images/2e61001b46749809366b8411f939ae3a.jpg)

9.  Create the data model in Tableau. AccountFacts is the Adra Balancer Analytics API's main table. Drag **AccountFacts** onto the canvas to start adding the connections between the different data tables.
10.  Set up the other tables in relation to the AccountFacts table as shown in the figures below.

### AccountDimensions Table  
 

![TabB2.png](https://static.adra.com/adra-assistant/images/7e9096bef8808f07de6f012847ac5ad6.jpg)

1.  Connect the other tables to the AccountFacts table. Drag the tables to the canvas as shown in the figure below.

  
![TabB3.png](https://static.adra.com/adra-assistant/images/4046812d5e0aa0508926b3fe4a438477.jpg)

2.  For each of the tables, you can define the relationship between the **AccountFacts** table and the other tables using the **EngagementKey** variable.

  
  
![TabB4.png](https://static.adra.com/adra-assistant/images/1c703a262587827a660d723af5e9662f.jpg)

3.  The **TransactionExtraFieldsFacts** table's relationship needs to be with the **TransactionFacts** table. Use the **TransactionKey** variable to connect them.

  
  
![TabB5.png](https://static.adra.com/adra-assistant/images/d1c16a8b5eaaf67ed3fcb468beff9bdf.jpg)

1.  Once the Adra Analytics API and relevant data relationships between the various tables are created in Tableau, you can start building your dashboards.

NOTE: The established oData feed and data connection was made using the Balancer data API connection. The same steps can be taken to connect the Task Manager data API.
