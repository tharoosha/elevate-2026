Analytics Resources

Analytics Resources 
--------------------

The attached resources guide users in configuring Analytics using Power BI or Excel.  
Learn how to connect to external applications to Adra Setup see [Setup External App Integrations.](#article:kA0Ua0000003GGLKA2@Success-Center)

Analytics Resources - Power BI
------------------------------

*   The [Adra Analytics Configuration Guide - Power BI](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7U0H000000LGl9UAG) walks users through the process for configuring Analytics using Power BI.
*   The [Adra Analytics Configuration Video](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7U0H000000LGioUAG) accompanies this Configuration Guide. 
*   The [Analytics Templates](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7U0H00000001zMUAQ) document includes Zip files of pre-configured Power BI report templates that can be used with Balancer or Task Manager.
