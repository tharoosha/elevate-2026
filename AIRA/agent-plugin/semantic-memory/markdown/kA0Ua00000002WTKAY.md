Task Manager Add Tasks To Active Task List
==========================================

New tasks can be created in two ways:

*   **Ad-hoc** - A one-off task that falls outside the organization's normal process. When creating an ad-hoc task, simply select the desired task list. Note that ad-hoc tasks can only be added to **Opened** task lists. Learn more here: [Task Manager Ad-hoc Task.](#article:kA0Ua0000005GovKAE@Success-Center)
*   **Existing tasks to open task list** \- Task templates from the library can be added to task lists with the status **Unopened** and **Opened** task lists.
    *   This feature is especially useful when a task list has been copied from an existing one.

To add an existing task to a task list:  
![image](https://static.adra.com/adra-assistant/images/cb3d687fa100539a44f80ea2c036a53f.jpg)

1.  Navigate to **Task Lists** and select the **Unopened** or **Opened** tab.
2.  Click the name of the desired task list.

![image.png](https://static.adra.com/adra-assistant/images/db6eb66371e58f797d3daeaa1209e1e4.jpg)

3.  Click **\+ Add Task**. The **Add tasks** page loads.

![image.png](https://static.adra.com/adra-assistant/images/2442ac7f1c47a136797cb108d6f20d66.jpg)

4.  Filter and locate the desired task. Learn more about the Add tasks page: [Task Manager Create & Copy Task Lists](#article:kA00H000000kJ5zSAE@Success-Center)
5.  Check the desired task and click **Add selected task.**
