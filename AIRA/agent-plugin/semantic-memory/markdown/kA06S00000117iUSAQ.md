Notification: Public IP Change Across Trintech Integration Points
=================================================================

Trintech currently leverages a global Content Delivery Network (CDN) and dynamic Web Application Firewall (WAF) infrastructure to support delivery of web based online services accessed via HTTPS. On July 16, 2022, Trintech will extend CDN and WAF functionality to all Trintech file and web-based integration points supporting our online services accessed via SFTP and/or HTTPS.

_**Please note**: If your organization does not currently restrict outgoing Internet access via “allowed lists” defined on corporate proxies and/or firewalls, you may safely disregard this message._

Key Points:
-----------

*   **Summary:** All attempts to connect to Trintech file and web-based integration points via SFTP and/or HTTPS using old public IP addresses will no longer work after this change. All connections must use new public IP addresses after this change.
*   **Timing:** On July 16, 2022, aligned to Trintech’s regularly scheduled maintenance window cadence (third Saturday of each calendar month).
*   **Action:** Update “allowed lists” on corporate proxies and/or firewalls to reflect new public IP addresses/ranges for Trintech file and web integration points.
*   **Trintech Products Affected:** Adra SFTP

How this affects your organization:
-----------------------------------

Once this change takes effect, all connections to Trintech file and web-based integration points via existing URLs will be made to new Trintech public IP addresses/ranges published and maintained at https://www.cloudflare.com/ips.  
Please note: Access to core products via HTTPS will be unchanged since CDN and WAF protections were in place prior to July 16, 2022. Access to file and web-based integration points via HTTPS and SFTP is the focus of this change.  
What you should do to prepare:

If your organization does not currently limit outgoing Internet access to Trintech file and web-based integration points via explicitly defined lists of Trintech public IP address/ranges configured on corporate proxies and/or firewalls, no action is required to accommodate this change.  All integrations will continue to work after using currently configured URLs and authentication methods.  
  
If your organization actively limits outgoing Internet access to Trintech file and web-based integration points by explicitly adding Trintech public IP addresses/ranges to “allowed lists” configured on corporate proxies and/or firewalls, it will be necessary to add all CloudFlare public IPs published and maintained at https://www.cloudflare.com/ips to “allowed lists” prior to July 16, 2022. This will ensure that all integrations can continue to connect to Trintech file and web-based integration points after July 16, 2022.  
  
If you are unsure whether your organization limits outbound Internet access on your integration endpoints, we encourage you to share this communication with your Information Technology and Information Security teams. It is likely these teams will be able to help confirm that no action is needed.  
  
Trintech can help your Information Technology and Information Security teams plan for this change. If you require assistance, please log a support case and reference this article. In it, you can request a current list of the public IP addresses/ranges currently available at [https://www.cloudflare.com/ips](https://www.cloudflare.com/ips) . While this list changes infrequently, please note that this list is dynamic, and may be updated periodically by the CDN and WAF provider. Customers who wish to programmatically accommodate any future changes to this list may do so by leveraging published APIs (e.g., [https://api.cloudflare.com/#cloudflare-ips-cloudflare-ip-details](https://api.cloudflare.com/#cloudflare-ips-cloudflare-ip-details) ) to ensure that “allowed lists” on corporate proxies and/or firewalls remain up to date.
