Matcher Test Run Matching Rules
===============================

After creating a matching rule, users can test it against transactions currently open on the transactions page.

To test a matching rule, follow these steps:

1.  Navigate to **Administration>>Matching Rules.**
2.  Select the matching rule you want to test

![image](https://static.adra.com/adra-assistant/images/c49927bb1c97a1cc13f731fd64427ac8.jpg)

3.  Click **Test rule**.

![image](https://static.adra.com/adra-assistant/images/15283c5cb615e475933ffe3bd128ad22.jpg)

The completed test will display the possible number of matches based on the current unmatched items on the **Exception** page for the applicable **Reconciliation Group**.

5.  Click the grid icon on the right side of the completed test to view a subset of potential matches.

![image](https://static.adra.com/adra-assistant/images/871a0ba55723a030ee8f5ff13ea0941d.jpg)

6.  A pop-up containing all potential matches displays.

![image](https://static.adra.com/adra-assistant/images/5a03871d1c7e4dda115abddb09583bd4.jpg)
