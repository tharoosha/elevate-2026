Setup Select Language for a BPO Engagement
==========================================

Rather than setting the language for individual users, BPO Admins can set the default language value for an engagement. The selected language will automatically populate for all users created and added to the engagement.  
  
To set the language for an engagement:  
1\. Navigate to **Setup>>Engagements**.  
2\. Select the **engagement** for which to set the language.  
3\. Click the **Engagement details** tab.  
4\. From the Language drop-down, select the **language** for the engagement.

  
![image.png](https://static.adra.com/adra-assistant/images/0efe3c35e261ccce17b944471f6b2737.jpg)  
 

When creating a new user, the language defaults to the global language of Adra (English) until an employer is selected.  
 

![image.png](https://static.adra.com/adra-assistant/images/bf1a14ebf7eb5e7f15c012ed57e2e7e7.jpg)  
After selecting the employer, the language automatically changes to the default engagement language.

Individual users may choose to conduct their work on Adra in a language other than the one selected for the engagement. In these instances, the language can be changed to another supported language at the user-level.
