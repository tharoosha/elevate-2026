Balancer Account Reconciliation Workflow
========================================

In Balancer, the accounts reconciliation workflow operates as explained below. Note that the account's selected preparation, approval, and review frequencies determine when it is finalized. If for example an account only requires monthly preparation, it is finalized once it has been prepared. 

![image](https://static.adra.com/adra-assistant/images/115cd1dbd62ed58ea51b9c05420f01f9.jpg)

1.  **Prepare** \- For more details on the features of an accounts reconciliation page, see [Balancer Account Reconciliation Page Overview](#article:kA00H000000oOVWSA2@Success-Center) 
    1.  Transactions are added in one of three ways:
        *   By an administrator or automatic import on the **Jobs** page. To learn more, see [Balancer Import Balances & Transactions](#article:kA0Ua0000000SU9KAM@Success-Center).
        *   Manually, directly in the account. To learn more, see [Balancer Add & Manage Transactions](#article:kA06S000000YR4GSAW@Success-Center)
        *   By uploading a spreadsheet directly to the account. To learn more, see [Balancer Spreadsheet Based Reconciliations](#article:kA0Ua0000007A4HKAU@Success-Center)
    2.  Add documentation
    3.  Add a variance analysis explanation if necessary.
    4.  When all details have been added, the preparer can prepare the account.
        *   Click **Set as prepare** at the bottom of the account page

 ![image](https://static.adra.com/adra-assistant/images/e6c4e48347447efb7b8b774f5f3f314b.jpg)

1.  1.  *   Preparers can use the **Revert Preparation** button if additional details are needed. This option is not available when the account has been approved.

![image](https://static.adra.com/adra-assistant/images/445e8347f01f7687557fb91b8bc6d93f.jpg)

2.  **Approve** \- When an account has been set as prepared, the approver can verify that all details and documentation are correct.

![image](https://static.adra.com/adra-assistant/images/6c3bd48b5320ffbf8cde58ebd8390f82.jpg)

3.  *   Click **Reject** to move the account back to the preparer. In the Reject pop-up, provide a comment explaining the reason for the rejection. 
    *   Click **Approve** to either send the account to the reviewer or finalize it, based on the account settings.

3.  **Review** \- When the account has been approved, the reviewer can do a final check that all account details and documentation are correct.

![image](https://static.adra.com/adra-assistant/images/124a3fa1dbe6e341a6a55e76a23cedb4.jpg) 

*   *   Click **Reject** to send the account back to the preparer. In the Reject pop-up, provide a comment explaining the reason for the rejection.
    *   Click **Review**, select a reviewed code, and add a comment if applicable to finalize the account.
        *   Either review status option still finalizes the account.

![image](https://static.adra.com/adra-assistant/images/2230511610a2428a32c422ab2bc61488.jpg)

 **HELPFUL HINT**: The following issues can hinder the reconciliation process:

*   The preparer lacks access to add transactions or documentation.
*   The account has been approved but cannot be finalized.
*   The account is finalized without any required action being taken. 

Follow the steps below to identify and solve the issue.

1.  Click the **three dots** in the upper right corner of the accounts page and select **Account Information**. The settings displayed here are the settings applied to the account for the current period.

![image](https://static.adra.com/adra-assistant/images/7dd55b3d35d646bc053e326871dcca25.jpg)

2.  Compare this to the account settings under **Administration>>Account settings**. 
3.  If they are different, ensure that the settings in administration are correct and continue to step 4. If they are the same, move to the next section.
4.  Run an **Update Roles and Settings** job from either the **Jobs** page or the upper right corner of the **Account and Status** page.

If the **Account settings** and **Account information** display the same details do the following

1.  Review the task frequency in the accounts settings as shown below. Ensure that these are correct.

![image](https://static.adra.com/adra-assistant/images/16d0072a3239c06de6cd15a863d68825.jpg)

2.  Navigate to **Administration>>Fiscal year** settings, and ensure that the **period type** is correct and that it matches the preferred task frequency.
    *   To learn more about what period type is and how to configure it, see [Balancer Fiscal Years and Periods](#article:kA00H000000kJ9cSAE@Success-Center).
