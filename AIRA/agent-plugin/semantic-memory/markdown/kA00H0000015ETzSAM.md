Balancer Account Settings Explanations
======================================

Learn how to create new accounts manually or in bulk: [Balancer Add & Manage Accounts](#article:kA00H000000kJ8oSAE@Success-Center) & [Balancer Export & Import Account Settings](#article:kA0Ua0000000TgLKAU@Success-Center)  
Learn how to create group accounts and cross-entity group accounts: [Balancer Group Accounts and Cross Entity Group Accounts](#article:kA00H0000015EUOSA2@Success-Center)  
Learn how to manage user roles: [Balancer Export & Import Account Roles](#article:kA00H000000kJAGSA2@Success-Center)  
  
  
Account settings and roles can be added and updated in two ways; through the **Jobs** feature, and in **Account Settings**.

*   **Jobs** \- Navigate to **Jobs>>Other Jobs>>Export/Import account settings**.
*   **Account settings** - Navigate to **Administration>>Account settings.** Click an existing account to update settings, or click **New account** to create an account manually.

![2024-03-20_13-08-42.png](https://static.adra.com/adra-assistant/images/785798619b41595ba9ba9bfa2e35bc40.jpg) 

1.  **Logs** \- Click to view the account's activity log for auditorial purposes.
2.  **Account name** – Enter the account name, for example from the ERP system.
3.  **Active/Deactivated –** Click to activate (blue) or deactivate (grey) the account. Inactive accounts keep previous period data and settings but can't receive new balances. 
4.  **Group account –** Learn more [here](#group-accounts-and-sub-accounts).
    *   **Use the account as a group** – Make the account the primary account for a group, enabling the addition of sub accounts.
    *   **Use account as a sub account to an existing group** – Add the account as a sub account to an existing group account.
5.  **Frequency and roles** – Select the reconciliation frequency and designate the responsible users. Learn more [here](#frequency-and-roles).
6.  **Purpose and procedure** – Enter account management details. Learn more [here](#purpose-and-procedure).
7.  **Classification and extra fields** – Select account classifications. This feature aids in risk mitigation, sorting, and generating statistics. Learn more [here](#classification-and-extra-fields).
8.  **Job settings** – Select job automation settings for the account, specifically for automating certification and transferring transactions and documentation between periods. Learn more [here](#job-settings).

Group Accounts and Sub Accounts
-------------------------------

Group accounts are recommended if a set of GL accounts are reconciled together. The trial balance is imported to each GL account, but the cumulative total will be the balance of the group account. The group account must be created before balances can be uploaded.  
     
Learn about **Cross entity group** accounts: [Balancer Group Accounts and Cross Entity Group Accounts.](#article:kA00H0000015EUOSA2@Success-Center)

   
To designate an account as the main account in a group, navigate to **Administrations>>Account settings** and click an account.  
![image.png](https://static.adra.com/adra-assistant/images/6f3ac98b2967099d7971386f8b085475.jpg)

1.  **Use the account as a group** – Toggle to On to make the account the main account in a group.
2.   **Add sub accounts** – Click to open a pop-up.

![image.png](https://static.adra.com/adra-assistant/images/dceee6c06118891de44701b47677761f.jpg)

3.  **Search field** – Enter the full or partial account number or name in the search field. 
4.  **Accounts** – Check a box to include the account as a sub account.
5.  **Add sub accounts** – Click to save group account changes.

Administrators can return to the account’s settings page to modify the group at any time.  
Toggle **Use account as a sub account to an existing group** to **On** to add the account as a sub account in an existing group, then select the group account in the drop-down.

![image.png](https://static.adra.com/adra-assistant/images/21552215a19078e4db2e0754fbf53b40.jpg)  
 

Frequency and Roles
-------------------

Prepare, approve, and review frequencies determine the interval at which tasks need to be completed for the account. Configuring this is essential for granting appropriate certification access to users.  
![image.png](https://static.adra.com/adra-assistant/images/9b108de62aa405300396f7fc70e8eaf1.jpg)

1.  **Frequency** – Each role can have a separate task frequency.
    *   10 - Month end
    *   15 - Bimonthly - Even periods
    *   16 - Bimonthly - Odd periods
    *   20 - Quarter end
    *   21 - Every fourth period
    *   25 - Half-year end
    *   30 - Year end
    *   50 - Never

The numbers correspond to the export/import file code for bulk updating account settings.

2.  **Account roles** – Click the empty field to select users for the preparer, approver, and/or reviewer roles. Click Add to assign each role to the selected user(s).
3.  **Selected users** – Lists users assigned each role. 
    *   Main Users –  Drag a user to the top of the list to make them the main Preparer/Approver/Reviewer. Only the main user in each role receives notification e-mails for accounts that require action.
    *   Remove role – Click X for a user to remove the user role.
    *   Inactive users – Users set as inactive in **Setup** are displayed in red. 

 **WARNING**: Correctly specifying the period end type in **Fiscal year** is crucial when the task frequency is set to **Quarter end**, **Half year** end, and **Year end**.  
For accounts with **Bimonthly** and **Every fourth** **period** frequency, the period number (as set in the Fiscal year settings) determines when the account needs action. Learn more about Fiscal years and period numbers: [Balancer Creating Fiscal Years and Periods](#article:kA00H000000kJ9cSAE@Success-Center).

Extra account details can be entered in each of the optional fields:

Classification and Extra Fields
-------------------------------

This optional section can be used to provide additional account categorization. Use of this feature is recommended to help with risk mitigation, account sorting on the **Accounts and status** page, and statistics on the **Dashboards** pages. Learn more about the Dashboard pages: [Balancer Using Dashboards](#article:kA00H000000kJ9DSAU@Success-Center).  
![image.png](https://static.adra.com/adra-assistant/images/aef2d202a34d8010e1412745cfd0c5b4.jpg)

*   **Account class** – Select the applicable class for the account. 
*   **Sub class** – Select the applicable sub class for the account. Learn more about sub classes [Balancer Account Settings Page Overview](#article:kA00H000000kJALSA2@Success-Center).
*   **Reconciliation type** – Select the appropriate reconciliation type.
*   **Key account** – Select if an account is a key account or not. 
*   **Risk rating** – Select a risk rating for the account.
*   **Extra field** – Enter additional account details in the accounts extra field(s). The field is named Company in the example image. Learn more about extra fields: [Balancer Extra Fields Overview](#article:Balancer-Extra-Fields-Overview@Success-Center).

The number associated with the classifications relates to the number in the account settings file allowing settings to be updated in bulk.    

 **HELPFUL HINT**: The classifications can provide additional grouping, sorting, and filtering capabilities on the **Dashboard** and the **Accounts and Status** page.

To utilize the classification feature to sort accounts navigate to the **Accounts and status** page click **List Options>>Columns**, and enable the desired columns. Learn more: [](#article:kA00H000000kJ8eSAE@Success-Center)

Job Settings
------------

**System certify** and **Carry forward** are automated processes started in **Jobs>>Other jobs**. The selections made in the account’s settings determine whether the account can be certified automatically and/or if documentation and transactions can be transferred from one period to another.  
![image.png](https://static.adra.com/adra-assistant/images/93c88246336df0bd4fd5bbe32c4c4dd6.jpg)

*   **System Certify** – Allows the system to automatically certify the account if it meets certain criteria.
    *   **0 - No** – Accounts cannot be automatically certified.
    *   **10 - System prepare** – The system can prepare the account.
    *   **20 - System approve** – The system can approve the account.
    *   **30 - Allow prepare and approve** – The account can be automatically prepared and approved.
*   **Carry Forward** – Allows the transfer of attachments and transactions from one period to another.
    *   **0 - Not allowed** – No information can be transferred between periods.
    *   **10 - If carry forward rules are met** – Attachments and items can be transferred when the criteria selected for the job are met.
    *   **20 - Always allow carry forward** – Attachments and items are transferred if the account is set to always carry forward when the job is run.
