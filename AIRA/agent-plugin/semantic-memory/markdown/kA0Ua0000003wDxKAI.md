In Progress MOVEit Transfer Vulnerability CVE-2023-34362
========================================================

Problem:  
[(CVE 2023-34362)](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2023-34362)  
A SQL injection vulnerability has been found in the MOVEit Transfer web application that could allow an unauthenticated attacker to gain access to MOVEit Transfer's database in versions before 2021.0.6 (13.0.6), 2021.1.4 (13.1.4), 2022.0.4 (14.0.4), 2022.1.5 (14.1.5), and 2023.0.1 (15.0.1).   
  
Status:  
Trintech does NOT use In Progress MOVEit Transfer in any capacity.  
  
Products Impacted:

*   None
