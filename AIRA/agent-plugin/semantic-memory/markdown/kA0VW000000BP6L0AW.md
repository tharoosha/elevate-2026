Setup OKTA Configuration
========================

**WARNING: The contents of this guide are currently being updated and will be replaced with new guidelines in the near future.**

Okta is an application used for signing in to different applications. Administrators can configure SAML 2.0 Single Sign-On (SSO) for Adra.

Configuration in OKTA
---------------------

1.  Log in to your **Okta Organization.**

**![image](https://static.adra.com/adra-assistant/images/593927e051f471a069178ee5b871948f.jpg)**

2.  Navigate to **Applications**
3.  Click **Browse App Catalog**

![image](https://static.adra.com/adra-assistant/images/762ccf960175192269bc5fdb2a31c6f2.jpg)

4.  Enter **Adra by Trintech** in the **Search box**.
5.  Click on the filtered search result that contains **Adra by Trintech** and navigate to the **Adra by Trintech integration page**.

![image](https://static.adra.com/adra-assistant/images/3fabb30b48cabe3dd4ea18bae35ea7ff.jpg)

7.  Click **Add Integration**.

![image](https://static.adra.com/adra-assistant/images/011c98f7786d06e78dcdd3c923d4866b.jpg)

8.  If needed, change the **Application label.**
9.  Under **Application Visibility**, check the box to turn off application icon display, if desired.
10.  Click **Next** to finish adding the application.

![image](https://static.adra.com/adra-assistant/images/9eae48a9362e9dddc948be4bac8ca600.jpg)

11.  Add links
     1.  **Single sign-on URL** \- [https://login.adra.com/Saml/AssertionConsumerService](https://login.adra.com/Saml/AssertionConsumerService)
     2.  **Audience URI** - [https://login.adra.com](https://login.adra.com/)
     3.  **Default Relay State -** [https://setup.adra.com](https://setup.adra.com/) 
12.  Scroll to the bottom of the page and click **Next**.
13.  Click **Finish**.

![image](https://static.adra.com/adra-assistant/images/1f87214916f5d4432868ef84115fe51b.jpg)

14.  Copy the Metadata URL and save to your local machine in a notepad file or similar.

Configuration at Adra Setup Portal
----------------------------------

The remaining configuration is completed at the Adra Setup Portal. To continue with the configuration:  
  

1.  Log in to the Adra Setup Portal as a **System Administrator**.
2.  Open the **Engagement** and navigate to the **Security** tab.
3.  Select **Use a Federated Identity Provider** from the **SECURITY POLICY** section.
4.  Click **Add new Federated Identity Provider**.

![image](https://static.adra.com/adra-assistant/images/f77698796ef4df5551add8e6ea3828ed.jpg)

A pop-up window appears to create the new Federated Identity Provider policy. In the **Provider details** pop-up window:

5.  Add the **Name** and **Description**. These values are required.
6.  Under **Federation Metadata**, select **Use Metadata URL**.
7.  In the **Metadata URL** field, paste the Metadata URL that was copied from the Okta Setup Instructions.
8.  Click **Test URL**.

![image](https://static.adra.com/adra-assistant/images/20f0bd961a9ac23f2268dca01afbbfb5.jpg)

Under **SAML Configuration**, the required input fields will automatically be populated with values.

9.  Click **Save** to save the configuration.

![image](https://static.adra.com/adra-assistant/images/1c0188f329b3bd6187c6d0c40928ef54.jpg)

10.  On the **Security** tab, select the newly created **Federation Identity Provider policy**.
11.  Click **Save changes** to complete the configuration.

![image](https://static.adra.com/adra-assistant/images/a7413466a98cb93824235f4ecd9f0018.jpg)

Frequently Asked Questions
--------------------------

**What are the supported login flows?**  
The Okta Gallery App supports Service Provider (SP) initiated login where the user needs to start at the Adra application (e.g. Adra Balancer, Adra Task Manager) in order to log in. Using an Identity Provider (IdP) initiated login (starting from Okta and clicking on the Adra by Trintech application) takes the user to Adra Setup. From there, users can navigate to other appliations to which they have access.  
  
**How can Multi-Factor Authentication (MFA) be configured on Okta?**  
Okta provides the capability to configure different methods of performing Multi-Factor Authentication. Okta also provides very detailed guidelines on how to configure MFA. Read [Multi-Factor Authentication](https://help.okta.com/en/prod/Content/Topics/Security/MFA.htm?cshid=ext_MFA) and/or [Setting up MFA](https://support.okta.com/help/s/setting-up-mfa-for-end-users?language=en_US) from the Okta documentation site to learn more.
