Adra AI Features
================

The March 2026 release of the Adra Suite introduces a new set of AI-powered capabilities designed to simplify configuration, reduce manual effort, and accelerate the financial close. Built on Trintech’s vision of intelligent automation for the Office of the CFO, these features leverage AI to guide users, standardize processes, and deliver faster time-to-value while maintaining control and transparency. This article serves as an overview for these features. View the [Trintech Adra Security FAQs](https://success.adra.com/s/share-playlist?vtui__p=Lc3QaLxd74t0sXsGn6n%2B4pvKgqTy9URWAHUv%2FTL8ZIiulyf2Q%2FUnCMdm2ZXCnwkc0bVwHkAv8WLdb9eebjFcVv%2Bf3E%2Fh9HOdTA4kIw8YmSzg6%2FfP5zN81faKpdDVLjs7AJyHUiQ8NRrvzBzsNhsUQHiLBFU%2FuT4ToP%2FbNhXl%2B20mzNv9iMd90tQOeDkr6Zmg&iospref=web) for more information.

In order to use Adra’s AI features, the capability must be enabled by an organization administrator at the **engagement level in Setup on the AI tab**.

AI-Assisted Matching Rules
--------------------------

### Matcher

AI-Assisted Matching Rules provides AI-suggested rules that automatically detect patterns across unmatched transactions, eliminating the need for technical rule creation using Regex. By analyzing user-provided matched transactions, the AI recommends appropriate matching rules and guides users through a streamlined, AI-driven rule creation process directly within the interface. For more information, [see this video](https://success.adra.com/s/share-playlist?vtui__p=BptFxTw5hVfqvazHQ0Z%2F2vWQjIj%2BEvMsG8GFk%2F59aiWZmKSyunpD0mDQpCkNe55A67BiQcXlG8MyAze4He%2FiUqKB2ZyPXsGNKNEMfbmGpsYaWAF2swLuRl3Wc5nSEenZYGopjSm9k8z%2FWMm8fPIH4%2BVcLlxg4NdmfUgWiEVr%2F3DtxdtEJvcpZtXCugaSam6y&iospref=web).

AI-Generated Task Checklists
----------------------------

### Task Manager

The AI-Generated Task Checklist provides a tailored checklist based on a task's description and known procedures. This feature leverages AI to interpret context, recognize patterns, and suggest actionable steps. Users can either accept the checklist as-is or modify it to fit their specific needs, supporting flexibility without losing the benefit of automation. For more information, [see this video](https://success.adra.com/s/share-playlist?vtui__p=hkmgKemdFuqSSIqX3vuU7fx2TvjRb2LpTr0XUc7sRXmlkP%2FctGmy7JOsspi5Qbu560tobpLF2pYorEwu838nRU2bJGlme12XVlCiZkN%2B3j6r6tb1WriVcv9cZcY2elfYoyYP6WQIIanp%2FMXdSnpYGjWDa8pwORTB09U4mRU8LJ6yuq0U9GaGqjPGcdxe4eYi&iospref=web).

AI-Assisted Import Wizard
-------------------------

### Matcher

AI-Assisted Import Wizard provides a guided experience for ingesting and preparing match data in Adra Matcher by intelligently recognizing source formats, inferring column roles, and flagging potential import issues. It automatically identifies column headers such as amount, date, and reference ID, detects structural anomalies, and suggests appropriate field mappings while validating data integrity before the final import. Embedded directly within the Matcher import flow, it incorporates human-in-the-loop approvals to ensure accuracy and control. For more information, [see this video](https://success.adra.com/s/share-playlist?vtui__p=6AO2NVAqH6AjyT0Z9gJebYAfDa7cu232LlGhJwyOzFVoE%2BTAs2RYZb%2BV9ci9N314MfIU%2FxqXCIUJGVJjpOfEbsxtGH05RIJsXzvUw%2BDmgJ7zHlaOpCIrrkSQeNt3un%2FNkTbyA5WJSIRDF7C2Y9NctOW3Fa7qwcM4PZxAsbiLvaw%2FQSV83OwiV6ijaZUri9gq&iospref=web).

AI-Assisted Variance Analysis
-----------------------------

### Balancer

AI-Assisted Variance Analysis provides explanations using historical and contextual data, highlighting key drivers while allowing users to review and approve the results. Designed to be user-friendly, it makes variance analysis accessible to all users, including those in smaller organizations. By focusing attention on true anomalies, it enables teams to deliver higher-quality insights and more consistent, audit-ready documentation. For more information, [see this video](https://success.adra.com/s/share-playlist?vtui__p=EjGJoxoxlkVXwZbApRTuMVD7g%2Fus%2FTV0qIDFe4pqFMvJLt6taegEGRKX1TghhqHy%2FDWXSvsx0pQoDPyAtWs1in90ZpMJXM04bA1yTvLNry36BnEIp9pIk9rVKXQdjc%2BnPN620PdcOU6tSerz%2FvLietcV%2FxtZ1g9TS0DqEP9gA5%2BIMCFeMpIRzplc9jkR8IcB&iospref=web).
