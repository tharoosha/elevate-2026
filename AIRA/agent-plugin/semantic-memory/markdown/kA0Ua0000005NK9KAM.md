Matcher Reconciliation Group Memo
=================================

The **Memo** feature on the Exceptions page allows users to add procedures for reconciling specific accounts or leave messages. 

To use the **Memo** feature, navigate to the **Exceptions** page.

![image](https://static.adra.com/adra-assistant/images/cbe6ec649e85aa3c6b487d059b772aad.jpg)

1.  Select the correct reconciliation group
2.  Click the **Memo** icon. The **Note** pop-up opens.

![image](https://static.adra.com/adra-assistant/images/7323c3023082d548bac864f306879706.jpg)

3.  Enter and format the message or procedure in the text field. Note that links can bee added.
4.  Click the dropdown and select the desired version to view a previous versions of the memo. Old versions can not be deleted. Auditors can view all versions of the Memo.
5.  Click **Save** or **Save Changes**.
