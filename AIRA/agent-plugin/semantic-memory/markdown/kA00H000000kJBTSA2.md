Matcher Import Templates
========================

Review of the Import Template
-----------------------------

To review an **Import Template**: 

1.  Navigate to the Matcher home page.
2.  Click the drop-down menu under **Administration**.
3.  Click **Import Settings**, and click **Import Templates**.
4.  Click on the name of the template to be reviewed. 
5.  The system will provide the XML code used to populate the template. 

![import settings import template.jpg](https://static.adra.com/adra-assistant/images/af9e66f8a926e05997f61c96febc672b.jpg)  
 

 **HELPFUL HINT**: In most cases, a new template will be created through the Import Wizard. Accessing Import Templates should only be when customization is needed. Contact your CSM if help is needed to create custom templates.

If a user is proficient in XML and would like to customize the template themselves, double click on the template name and the Edit Template screen will open as shown below. Administrators can then copy and paste the code into Notepad ++ to customize and create a custom template. Administrators will then need to return back to the Import Templates tab and click **\+ New Template** to add the customized version. It is not recommended to customize the original template, to create the additional template.
