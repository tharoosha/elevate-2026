Matcher Matching Rule Date Ranges
=================================

When configuring matching rules in Matcher, administrators have the option to select a **date range** for the **transaction matching** and for **grouping multiple transactions and matching them**. 

When a rule that matches many transactions to one transaction, or many to many, is run, Matcher starts its analysis by identifying which transactions can be grouped.

Example
-------

In this example, we’re only focusing on how dates are used for grouping, not other fields like Text.   
Four transactions in source 1 need to be matched to two transactions in source 2

*   Source 1 - 5 day date range
*   Source 2 - 30 day date range 

![image](https://static.adra.com/adra-assistant/images/24f82f160182326c6cece7133f526913.jpg)

We create the matching rule. In the **Match Multiple Items** section, we enter the date range for each source.

*   Source 1 - from 0 to 5 days
*   Source 2 - 0 to 30 days.

![image](https://static.adra.com/adra-assistant/images/0f8628905020e0abb1e3cb8ba8e907ae.jpg)

 **HELPFUL HINT**: When the Match Multiple Items functionality is used in a rule, Matcher checks each individual transaction in the data set one by one, and uses the given date range to compare transactions before and/or after that transaction to see if they fit the matching criteria. For example, if the date range is set to **From**: -2 and **To**: 2, each transaction is compared with transactions occurring two days before, two days after, and on the same day as that transaction. See [Additional Date Range Examples](#additional-date-range-examples) for a closer look. 

The transactions in Source 1 and Source 2 are grouped separately, and each group is now treated as a single transaction. Each group takes the date of its oldest transaction.

![image](https://static.adra.com/adra-assistant/images/01c4cedbe74538961d96f349fc761d2a.jpg)

Next, the details in the **Date and Amount Matching** section of the rule determine if the two groupings can be matched.

In this example, the range between the groups is 10 days. Since Source 1 has a newer date than Source 2, the **From** field must use a negative value so Matcher looks for dates before January 10. The To field can stay at 0, as Matcher doesn't need to search for transactions newer than the Source 1 date.

![image](https://static.adra.com/adra-assistant/images/6654c99993f2a8bd552e862cbe7d0cc9.jpg)
