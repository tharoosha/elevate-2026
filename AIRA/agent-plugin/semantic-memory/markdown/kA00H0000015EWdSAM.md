Setup Connecting Adra to Communication Platforms
================================================

Connecting to Microsoft Teams
-----------------------------

 

![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/6e9ba989-6960-4118-8d91-bf4dff3019be/whlightbulbv1.png) Recommendations: 

*   For this example we will use Task Manager. This process will work for any products that have email communication functionality.

In Teams
--------

### Creating/Selecting Team. 

1.  Select **Teams**.
2.  Select the **Gear** icon.
3.  Create a **Team** that **Task Manager** will update.

![image](https://static.adra.com/adra-assistant/images/1972e601ec009288175eae096946ff59.jpg)

### Retrieving a Team's Email

1.  Under the newly created **Team** click on **General**.
2.  Click the menu button near the top right corner.
3.  Select **Get email address** from the menu, and copy the email address from the pop-up window that will be displayed.

![image](https://static.adra.com/adra-assistant/images/66c235bea7d422b591d43b9df03c003e.jpg)

*   The email address is blurred in the below image, but a user can click the copy button and the text from the email address line will be copied to your clipboard.

![image](https://static.adra.com/adra-assistant/images/15dc8f6758c07d3b2e3656abf7b7acc6.jpg)

In Adra:
--------

1.  Login to the **Adra** suite and go to **Setup**.
2.  Navigate to **Users** and select a user that will be used for **Task Manager** communications, or create a new user for this purpose.
3.  If you choose to create a new user for this **Task Manager** connection you will need to use a real, and active email to get the user activated, but then the **username** will be changed to the **Teams** email after the user is active.
4.  Enter the email for the **Team** you created for the Username of the **Teams** chat user. The **copy** function in the pop-up will capture the entire string of text, so please remove all additional text when entering the email address.
5.  **Save** when done.
6.  To test, send a reminder to the new user to ensure that **Teams** is receiving the updates correctly. 

![image](https://static.adra.com/adra-assistant/images/1e4ad0b2eaa28741b62f4ed0f12be28b.jpg)

*   The email from Task Manager will look like the below image. For this example, I started a Task List that the user is associated with.

  
![image](https://static.adra.com/adra-assistant/images/bdfb7f47c05cd1cc04cdb58973261976.jpg)

  
Connecting to Slack  
  
In Slack
------------------------------------

### Creating/Selecting Channel

   ![User-added image](https://static.adra.com/adra-assistant/images/014101a5e7bd2d094a726f41d3968c34.png)   **Important: You must have a paid version of Slack to have the email functionality available.**

*   Create a new **Slack** channel, or use an existing one.
*   To create a new channel click the **\+** symbol next to **Channels**.

![image](https://static.adra.com/adra-assistant/images/85fdaa1ba4be4dd06483a3e4e18a164a.jpg)  
 

*   Once you have created or selected a channel to use, then follow the directions on the **Slack** website here [https://slack.com/slack-tips/send-email-to-slack](https://slack.com/slack-tips/send-email-to-slack) , to get an email generated for your **Slack** Channel.
*   Copy the email address from **Slack**, and open the **Adra** suite.

In Adra:
--------

*   Follow the above steps for adding the **Teams** email to an **Adra** suite user. These steps are the same.
*   Your **Slack** channel should look like the below image when receiving emails from **Task Manager**.

  
![image](https://static.adra.com/adra-assistant/images/c860d2ca99a83285b883b3dc22bddfb2.jpg)
