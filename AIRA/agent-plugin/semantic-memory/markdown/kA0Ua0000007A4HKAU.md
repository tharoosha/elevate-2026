Journal Entry Posting Periods
=============================

The Journal Entry **Posting Periods** page in Adra lets administrators control which accounting periods users can post journal entries to. This helps prevent entries from being made in closed or unauthorized periods, improving accuracy and compliance. It also supports audit readiness by making sure posting follows the company’s closing schedule and approval process.

 **WARNING**: The restrictions must be updated regularly, such as when new periods start.

To create journal entry posting restrictions, follow the steps below:

![image](https://static.adra.com/adra-assistant/images/0f716bfc2ca69be0b11da021720ab486.jpg)

1.  Navigate to **Administration>>Posting Periods**.
2.  Click **Enable Posting Periods** toggle to turn on the restriction functionality.
3.  Select the period and date range when **ALL** users are allowed to post journal entries. Users will only be able to create journals within the selected time frame, as shown in the example image below. 
4.  Configure custom exceptions to let specific users post journal entries in certain periods, even if those periods were restricted in the previous step.
    *   **Add new** \- Click to create a new user-specific restriction/exception.
    *   **Recycle icon** - Click to delete a custom restriction.
    *   **Existing restriction** - Click a restriction to edit it.

When a user creates a new journal, the Period and Booking date fields in the New Journal page are restricted by the **Posting Periods** settings.
