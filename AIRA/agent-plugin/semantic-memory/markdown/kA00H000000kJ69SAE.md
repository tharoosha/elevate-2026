Task Manager Automatic Reminders
================================

Task reminders allow a notification email to be sent to the assigned user based on when the task is due. Reminders can be set in two ways:

1.  Manually per task in the library
2.  In bulk through an import task template

  
Set Reminder Manually in the Library
---------------------------------------

The Reminder Setting in the Task Template allows users to submit a single reminder for a task. Follow the steps below to set up automatic reminders.

![image.png](https://static.adra.com/adra-assistant/images/3a1f568e782e4d4e899128b548f12377.jpg)

1.  Click on the **Library**. 
2.  Expand the desired section and folders.
3.  Then click the **Edit** icon. The Edit task pop-up appears.

![image.png](https://static.adra.com/adra-assistant/images/856fe21fcebab968880c47112e59563b.jpg)

4.  Scroll down to **Task due time**. From the **Set reminder** drop-down, select a single reminder for a task. The reminder can be set up to 7 days before or after the task is due. Alternatively, the option **Do not send reminder** is also available. 
5.  Click **Save Changes.**
6.  The Preparer will receive an email similar to the one shown below on the reminder date.

![image.png](https://static.adra.com/adra-assistant/images/84ea99a2f46f5d875fd5d3e763ce4022.jpg)  
 

Set Reminders in Bulk Using the Task Template
---------------------------------------------

Learn more about how to use task template export and import: [Task Manager Task Import Template](#article:kA00H000000kJ5uSAE@Success-Center).

In the Task Templates, the reminders can be added and altered in column N; a blank cell indicates that automatic reminders are turned off.
