Task Manager Create a Company or Department
===========================================

Companies and departments can be created in Task Manager to add additional task filtering and sorting capabilities. Learn how to add Companies and departments to tasks: [Task Manager Library & Manual Task Creation](#article:kA00H000000kJ5kSAE@Success-Center)  
 

 **BEST PRACTICES**: 

*   Set up Companies to match the legal entity structure of the selected organization.  
*   Set up Departments to match the actual departments within the selected finance team.

  
Companies should mirror the legal entity structure of the organization. A legal entity is, by definition, an individual, company, or organization which has legal rights and obligations. Companies may be useful for organizations with locations in multiple countries.  
Departments should mirror the actual departments within the selected team. For example, departments within a finance team might include Accounts Payable, Accounts Receivable, Payroll, etc.  
To create a Company or Department, navigate to **Administration>>Companies and Departments**.   
![image.png](https://static.adra.com/adra-assistant/images/5c84bef0a12d3049d6c1aa322fdd2151.jpg)

1.  Click **Add company**, then add a name and code. Note the code must be ten characters or less and made up of numeric, alphanumeric, and dashes (-). Additionally, it must be unique to the entire engagement.
2.  Click **Add department** and repeat the same process.

Companies and departments must be defined in Administration before updating or importing task templates using the Import Template in the Library. While not required, they enable additional filtering and sorting capabilities when managing tasks and when creating task lists.  
 

 **HELPFUL HINT**:

**•**   Companies and Departments must first be defined in Administration before they can be added or imported into the Library. While not required, using them is recommended.  
•   The code to identify Companies and Departments can be numeric, alphanumeric, and dashes (-) of 10 characters or less.  
•   The code created must be unique to the entire engagement.  
•   Companies and Departments can be edited but not deleted.
