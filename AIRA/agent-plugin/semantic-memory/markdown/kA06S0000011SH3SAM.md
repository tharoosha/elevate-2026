Setup Direct Integration IH API
===============================

Integration Hub API – Getting Started
=====================================

To directly integrate balances and transactions, navigate to the [Adra Developer Portal](https://developer.adra.com/).

Initial Setup
-------------

1.  Navigate to the [Adra Developer Portal](https://developer.adra.com/) to access the full API documentation and reference.
2.  Create a Personal Access Token — make sure to select **Integration Hub** as the token type. To learn more, see .
3.  In Adra, navigate to [**Setup >> Profile >> User Access**](https://setup.adra.com/profile/access) and click **Copy SID** to copy the short identifier (SID) for the engagement. This is required to run the integration.

![Copy SID](https://static.adra.com/adra-assistant/images/ab615ac58ea7c17214ad83fc25a7eccd.jpg)

Endpoint Structure
------------------

The Integration Hub API uses the following URL pattern:

    POST https://integrationhub.adra.com/api/v3.0/{engagementSid}/files/{inboundFileCategory}/{suggestedFileName}

**URL path parameters:**

*   **engagementSid** — The SID copied from Setup >> Profile >> User Access
*   **inboundFileCategory** — The file import category (e.g. `BalancerBalanceUpload`, `BalancerTransactionsUpload`, `MatcherTransactionUpload`, `LegalEntityUpload`)
*   **suggestedFileName** — The name of the file with extension. Must not exceed 380 characters.

**Required headers:**

Header

Value

`Authorization`

`Bearer <YOUR_PAT>`

`User-Agent`

A string identifying your client, e.g. `my-integration-agent`

`Content-Length`

Size of the file in bytes (visible in File Explorer). Files must not exceed 100MB.

`Content-Type`

`*/*`

**Body:** Raw binary file content.

> **Note:** The [Integration Hub API Explorer](https://developer.adra.com/doc/integration-hub/explorer/operation/operation-uploadinboundfile) on the Adra Developer Portal currently shows file upload as unsupported. To test with a file upload, use one of the options below. Alternatively, you can test the data download endpoint instead through the Explorer.

Swagger
-------

1.  Navigate to [editor.swagger.io](https://editor.swagger.io)
2.  Click **File > Import URL**
3.  Paste `https://integrationhub.adra.com/openapi/v3.0.json`

This loads the full API spec and allows you to execute requests directly from the browser.

curl
----

    curl --http1.1 -X POST \
      "https://integrationhub.adra.com/api/v3.0/{engagementSid}/files/{inboundFileCategory}/yourfile.xlsx" \
      -H "Authorization: Bearer YOUR_PAT" \
      -H "User-Agent: my-integration-agent" \
      -H "Content-Type: */*" \
      -H "Content-Length: <file_size_in_bytes>" \
      --data-binary "@C:\path\to\yourfile.xlsx"

PowerShell
----------

    $pat           = "YOUR_PAT"
    $engagementSid = "your-sid"
    $category      = "BalancerBalanceUpload"
    $filePath      = "C:\path\to\yourfile.xlsx"
    $fileName      = "yourfile.xlsx"
    $fileBytes     = [System.IO.File]::ReadAllBytes($filePath)
    
    $uri = "https://integrationhub.adra.com/api/v3.0/$engagementSid/files/$category/$fileName"
    
    $headers = @{
        "Authorization"  = "Bearer $pat"
        "User-Agent"     = "my-integration-agent"
        "Content-Type"   = "*/*"
        "Content-Length" = "$($fileBytes.Length)"
    }
    
    Invoke-RestMethod -Uri $uri -Method POST -Headers $headers -Body $fileBytes

Postman
-------

1.  Click **Import > Link** and paste the following URL to load the API specification: `https://integrationhub.adra.com/openapi/v3.0.json`
2.  Select the POST request and update the URL with your `engagementSid`, `inboundFileCategory`, and `suggestedFileName` as path parameters.
3.  On the **Authorization** tab, set the type to **Bearer Token** and paste your PAT.
4.  On the **Headers** tab, add `User-Agent` and `Content-Length`.
5.  On the **Body** tab, select **binary**, choose your file, and click **Send**.

**Helpful hint:** To download the OpenAPI spec manually, navigate to the [Adra Developer Portal](https://developer.adra.com/) and click **Download Source >> JSON Open API specification**.
