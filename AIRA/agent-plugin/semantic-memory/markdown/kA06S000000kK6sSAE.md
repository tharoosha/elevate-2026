Easily Importing GL Data
========================

Manually Importing Balances
---------------------------

You have the ability to import balances manually through the **Jobs** Page in Balancer.  
For a detailed walkthrough of the feature, see [Balancer Import Balances & Transactions](#article:kA0Ua0000000SU9KAM@Success-Center).  
Here is a brief walkthrough:

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/99be0dea99546b3fd34dc958b5734eeb.jpg)

1.  Navigate to the **Jobs** and click Import Balances.
2.  Select the **Period**.
3.  Select the file
4.  Click **Import**
5.  Users will be taken to the **Jobs** page.
    1.  If **Job Automation** is on, and the file is within the thresholds, the file is imported automatically.
        *   For more information, see [Balancer Job Automation Overview](#article:kA00H000000oOcrSAE@Success-Center).
    2.  If **Job Automation** is off, refresh the page and click **Review and approve**.

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/9c86106b41487f8203c32b51d8462356.jpg)

1.  1.  *   Review the import details
        *   Check the **Open** box to open the period. If this is not done the period must be opened from the **Periods** page. To learn more, see [Balancer Periods Page Overview](#article:kA00H000000kJ9XSAU@Success-Center)[](#article:kA00H000000kJ9XSAU@Success-Center).
        *   Check **Review all changes**
        *   Click **Complete Import**

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/1d65aee75392284c0cc2a22df46064fe.jpg)

  
**Configuration for New Accounts**  
When new accounts are imported through a balancer import job, the accounts can be configured in the **Review and approve** step above.

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/5b3671b6fb3f44a9814b4f28e4ffd86a.jpg)  
Click **View** in the **New accounts** column, click the pencil icon and configure the details.

Save the changes.

If there are a lot of new account it is recommended to use the account settings file feature to make the changes instead. To learn more, see [Balancer Create, Import & Manage Accounts](#article:kA00H000000kJ8oSAE@Success-Center)[](#article:kA00H000000kJ8oSAE@Success-Center).

Manually Importing Transactions
-------------------------------

There are several ways to add line items/transactions to open accounts.

*   You can import them manually on the **Jobs** page
*   You can set up automatic import through **Integration Hub** or through an integration. See sections **Utilize the Integration Hub** and **Utilize an Integration** to learn more.
*   You also have the option to add them directly on the account page. See **Add Line Items** section in this section for more information.

To import line items manually:

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/2e1fd9e6e42054cecfcaf7a93ac8de57.jpg)

1.  Navigate to the **Jobs** page. 
2.  Click **Import Items**. 

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/b46d6dae9fb3ca942e9d677600ae3189.jpg)

1.  *   Select **Period**
    *   Check **Exclude already imported items** to prevent duplications
    *   Check **Replace items on accounts affected** by this import to delete existing items and replace them with the transaction in the file.
    *   Upload the file and click **Import**.

3.  The **Jobs** page loads. If Job automation is not enabled, refresh the page and click **Review and Approve**.
4.  Select the legal entity and click **Complete job**. 

Utilize the Integration Hub
---------------------------

The Integration Hub helps users import balances and transactions into Balancer more efficiently. It can either be set up in the cloud by Trintech technicians, allowing for easier support if needed, or downloaded locally from the Setup menu, which installs the Adra Agent folders on the user’s PC. Once installed, files can simply be dropped into these folders for automatic import into Balancer.

Users can also set up Job Automation in Balancer to cut down on time spent approving and reviewing data.

To learn more about the benefits of using the Integration Hub and how to get started, see [Integration Hub Agent User Guide](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7U0H0000004apQUAQ).

Utilize an Integration
----------------------

Adra has multiple connectors that integrate with ERP systems. To learn more about the partner integrations or the Adra Application Connector that can be utilized, see [Adra Product Suite Integrations](#article:kA06S000000kK69SAE@Success-Center)[](#article:kA06S000000kK69SAE@Success-Center).  
Once the connection is established, it will be configured to run automatically, and the import will appear as a job on the Jobs page.   
  
Jobs Page  
Verification of the balances/transactions imported. 

*   After balances/transactions are imported, an administrator can **Review and Approve** the job.
*   Once the job has been approved, the appropriate balances/transactions will show up inside of Balancer.

Preparing a Reconciliation
==========================

Account Reconciliation Page
---------------------------

Next, the accounts need to be prepared. The accounts reconciliation page allows users to manage and prepare the account for the selected period. To learn more, see [Balancer Account Reconciliation Page Overview](#article:kA00H000000oOVWSA2@Success-Center).

Here is a short overview of the usual to-dos.

*   Review account details such as previous period's balance and current balance.
*   Add and/or manage line items
*   Add attachments and documentation
*   Add comments
*   Export the reconciliation information after it's entered

 **HELPFUL HINT**: If a user is unable to work on an account or the account status appears incorrect, it’s often due to missing or outdated settings. For example, if changes were made to the account settings, such as assigning a new preparer, but the changes aren’t reflected in the current period, try running the following job: [Balancer Update Accounts Setting & Roles In Open Periods](#article:kA06S000000kK6sSAE@Success-Center).

If the issue is related to a mismatch between the account’s reconciliation frequency and the period end type, follow the instructions provided at the end of the previous article.

Preparing a Reconciliation
--------------------------

Now that your balances and items have been loaded, you are ready to reconcile your accounts.

1.  After you’ve imported and/or manually created your items, added documentation, and your balance is reconciled, click **Set as prepared.**

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/969477c34837a4905f3934d4ca81a34b.jpg)

2.  The following pop-up will load.

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/0340e1ef8ed4ff912332708a1a7df3a6.jpg)

3.  You can review the **Reconciliation Procedure** to ensure that you completed all the steps necessary to reconciling the account.
4.  Select the checkbox **Go to next account** if you want to prepare the next ready account assigned to you once this account has been certified.
5.  Use the **Send e-mail to approvers** checkbox if you want to send an email alert to the Approvers of the account that they have an account ready to review.
6.  Once you are satisfied with the state of the account, click **Certify**.
7.  The status on the **Accounts and Status** page will change to Prepared. Hover over the icon to see who prepared the account and the date it was prepared.

*   You can upload a reconciliation spreadsheet. To learn more, see  [Balancer Spreadsheet Based Reconciliations](#article:kA0Ua0000007A4HKAU@Success-Center).

For more details, see [Balancer Add & Manage Transactions](#article:kA06S000000YR4GSAW@Success-Center)[](#article:kA06S000000YR4GSAW@Success-Center).

To add lines individually, follow the steps below:

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/755f9be31dbdbe9970b2267a09e94b5f.jpg)

1.  Click **\+ New row**. The new row will auto populate the **Amount**, **Date** and **Type**, attributes that can be edited as needed.

Transaction Status

*   The Status field is used to classify transactions. When Preparers assign statuses, Business Administrators can more effectively analyze supporting and reconciling items, reducing risk across accounts and legal entities.
*   From the Transaction Item Status Dashboard, Business Administrators can filter and export transactions by Type, Status, and/or Age.

Easy Roll Forward Reconciliations
---------------------------------

Carry forward allows you to roll forward items from a previous period rather than having to manually copy the files over to the new period. You can do this for each individual account or for multiple accounts at the same time on the **Jobs** page. To learn more, see [Balancer Carry Forward](#article:kA06S000000YQgdSAG@Success-Center)

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/df8f3022cbf5833485e59fdc10e7d034.jpg)

1.  On the account’s reconciliation page, click **Import items>>From prior period**.
2.  Select the period you would like to copy from and click **Import**. The transaction items, including their documentation, are now copied to the new period.

 **HELPFUL HINT**: Documentation attached to the account can be carried forward as well.

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/79b1258d93eef91c3fd8f30b0a67c02f.jpg)

Review the Close Process
========================

Tracking My Work
----------------

The home screen allows you to view the accounts that are relevant to you specifically. This is the view that shows you your assigned accounts to be worked on. To learn more, see [Balancer Home Page Overview](#article:kA00H000000kJ9SSAU@Success-Center).

*   You can sort the accounts by role type and apply filters in the account list to locate specific accounts.

*   Click on the **Settings** button on the top right of the grid to hide or enable columns of data in the grid configuration.
*   Click an account in the list to navigate to the accounts reconciliation page.
*   The diagrams provide an overview of how the reconciliation process is progressing.

Reconciliation Analysis
-----------------------

The **Accounts and status** page gives you an overview of all the accounts and current status. To learn more, see [Balancer Accounts and Status Page](#article:kA00H000000kJ8eSAE@Success-Center)[](#article:kA00H000000kJ8eSAE@Success-Center).  
  
On the Accounts and status page, you can:

**Customize the Grid View**

*   Resize or reorder columns to display the most relevant information.
*   Group data by dragging a column header to the grouping area above the grid.
*   Click the **Settings** icon (top-right of the grid) to enable or hide columns.
*   Save your customized grid layout as a reusable view for future sessions.

**Work with Account Data**

*   Click the **funnel** icon (next to each column name) to filter data within that column.
*   Hover over the icons in the **Status** column to view the reconciliation status for each account.
*   Add period documentation by clicking Period Documents in the top-right corner.
*   Export the account list to Excel by clicking the Settings icon, then selecting Export to Excel.

  
 

Review the Quality of My Reconciliations
----------------------------------------

The **Transaction Item Status Dashboard** helps you monitor and manage the _aging of all transactions_. It provides a clear view into reconciliations, outstanding items, and adjustments so you can quickly spot risks and take corrective action. To learn more about the Dashboards, see [Balancer Using Dashboards](#article:kA00H000000kJ9DSAU@Success-Center).

The dashboard helps you monitor reconciliation quality by highlighting transactions without a status, unresolved items such as large balances or those outstanding beyond 30 days, and required adjustments that must be made before the next close.

**Hint:** Items over 60 days should be investigated before they reach 90 days to prevent reconciliation issues.

**How to Use the Transaction Item Status Dashboard**

![A screenshot of a computerAI-generated content may be incorrect.](https://static.adra.com/adra-assistant/images/a3d3e3720802ce856b33584cf1593cf3.jpg)

*   **Flexible Filtering** – Analyze transactions across one or all legal entities, and by transaction type, currency, or status.
*   **Export** – Click a transaction count or sum to generate an Excel export for detailed analysis.

*   **Select Legal Entities** – Choose a single legal entity, or view all entities at once.
*   **Choose Currency** – Display the total value of transactions in your preferred currency.
*   **Filters** – Select filters to view specific groups of accounts.
*   **Toggle Views** – Switch between **Number of Items** and **Absolute Sum of Items** in the Aging section.
*   **Understand Aging** – The system calculates aging in days, based on the transaction date vs. the selected period end date.
*   **The Role of Status** \- The **Status** field classifies each transaction.

*   **Preparers** assign statuses to indicate the reconciliation stage.
*   **Business Administrators** then use these statuses to analyze supporting and reconciling items.

This process improves visibility, reduces risk, and strengthens control across accounts and legal entities.

 **BEST PRACTICE**: Use filters by type, status, and age together to pinpoint the riskiest items in seconds.
