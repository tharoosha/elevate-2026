Balancer System Certify
=======================

System Certify Requirements
---------------------------

**System certify** permits BA and LBA to automatically prepare and/or approve accounts that have one of the following **System certify** settings in **Account settings**:

*   **10 - System prepare**
*   **20 - System approve**
*   **30 - Allow prepare and approve**

![image.png](https://static.adra.com/adra-assistant/images/88a743cd3114990be5fa41a705d53bdd.jpg)

  
 

The System Certify Job
----------------------

To system certify accounts, navigate to **Jobs>>Other jobs>>System certify**.  
![image.png](https://static.adra.com/adra-assistant/images/c41cca20ad78cbfd7fc779e99f152988.jpg)

1.  **Target period** - Select the period in which the accounts to be certified are located.
2.  **Reference period** \- Select what period to compare the target period to. Only displayed when **Balance is unchanged in target and reference period** is checked.
3.  **Legal entities** \- Check **Select all** or individual legal entities.
4.  **System prepare** \- Toggle **On** to activate system prepare. Select one of the criteria in the drop-down and check the box if applicable. See **System Certify Job Settings** below for more details.
5.  **System approve** \-Toggle **On** to activate system approve.
6.  **Submit job** \- Click to start the **System certify** job.

 **HELPFUL HINT**: System certifications can be reverted for open periods. Navigate to **Periods>>Open periods**. Select the period and click **Revert system certified accounts**.

System Certify Job Settings.
----------------------------

The system certify job settings are mostly the same for **System prepare** and **System approve**, with two exceptions:

*   **System prepare criteria** - The account’s current period status must be **Not prepared**. Certification will not occur for accounts where the status is **Rejected**.
*   **System approve criteria** - The account’s period status must be **Prepared** or **System** **prepared**.

Navigate to **Jobs>>Other jobs>>System certify**. To enable **System prepare** and/or **System approve**, ensure that the corresponding toggle is set to **On**.  
**System prepare** and **approve** have the same settings. **System prepare** is used to illustrate below.

![image.png](https://static.adra.com/adra-assistant/images/703b681f1a793de082a1f808dcc5c7a1.jpg)

*   **Unidentified amount is 0 and balance is 0­** - In the target period, the account must have both a balance equal to zero and an unidentified amount equal to zero.

![image](https://static.adra.com/adra-assistant/images/eb1445d6dd789c9f60efdfd64a18aa11.jpg)

*   **Unidentified amount is 0** - The account can have any balance as long as the unidentified amount is zero.

![image](https://static.adra.com/adra-assistant/images/b5f07600bb58644171f2113bdc088841.jpg)

*   **Unidentified amount is 0 or within the configured amount threshold** - This alternative appears if a certification threshold is set in **General settings**. 
*   **Example** - The threshold is $50. The current balance is $200, and the previous period's balance was $300. The account has exceeded the threshold and will not be certified

*   **Balance in the target period is unchanged compared to the reference period** \- Check to enforce that the account in the reference period must be finalized and have the same balance as the target period. If unchecked, the reference account can have any balance.

Revert System Certify
---------------------

System certified accounts can be reverted if neccessary.

Follow the steps below:

![image](https://static.adra.com/adra-assistant/images/ae3f58fd8264a3b78260efdb2f949399.jpg)

1.  Navigate to the **Periods** page. Stay on the Open tab.
2.  Locate the period. Use legal entity end period filters if necessary. 
3.  Click the name of the period.

![image](https://static.adra.com/adra-assistant/images/1cfc12f512a1fa7bee4ad5abf450dce1.jpg)

4.  Click Revert system certified accounts.
