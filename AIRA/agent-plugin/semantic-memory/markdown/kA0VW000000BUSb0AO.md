Setup Working Day Calendar
==========================

Administrators can add country holidays and/or create custom dates to be assigned as "non-working" days based on situational needs. 

Overview
--------

Navigate to **Setup>>Financial Configuration>>Working day calendar**.

![image](https://static.adra.com/adra-assistant/images/fe5ef3a06054b96fc1642e0149858ce4.jpg)

1.  **Select the pen** to customize organization work week.
2.  **Import country holidays** - automatically import public holidays.
3.  **Add custom non-working day** - create custom non-working days for the chosen year.
4.  **Year** \- choose which year to view and/or change.
5.  List of all non-working days for the chosen year for the organization.
6.  **Action** - edit or delete customized non-working days.

Work Week
---------

1.  Click the pen to **edit** work week.

![image](https://static.adra.com/adra-assistant/images/0b8399a4388fce6ea4b6a4659d85fd1e.jpg)

2.  Select the working days for your organization.

![image](https://static.adra.com/adra-assistant/images/51a80d91eaac28c96e86f5d339535e77.jpg)

3.  **Save** workweek.

Import Country Holidays
-----------------------

Administrators can automatically import public holidays. 

**Helpful hint**: If a new country is selected or an existing one removed, the existing public holidays will be replaced. Custom non-working days will not be affected. 

1.  Click **Import country holidays**.
2.  A pop-up appears. Select country in the dropdown menu.

![image](https://static.adra.com/adra-assistant/images/e8b4148db9387bafcc8d5ea5b60c4816.jpg)

3.  Click **Import country holidays**.

Custom Non-Working Day
----------------------

Add custom non-working days to your organization.

1.  Click **Add custom non-working day**.
2.  In the pop-up fill in:
    1.  Name
    2.  Description (optional)
    3.  Date

![image](https://static.adra.com/adra-assistant/images/b32195ce6bdf602eec1f798e1d7290b6.jpg)

4.  Click **Save**.

Change Non-Working Days
-----------------------

All non-working days are shown in the list on the Working day calendar page. 

![image](https://static.adra.com/adra-assistant/images/0e3f603e33ab060642d1f55c2c8e8cf5.jpg)

Click the three dots under **Actions** to **Edit** or **Delete**. Note that only custom non-working days can be edited, public non-working days can only be deleted.
