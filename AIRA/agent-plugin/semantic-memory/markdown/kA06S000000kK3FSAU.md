Balancer - Troubleshoot Common Issues with Balance & Transaction Imports
========================================================================

Balances and Transactions can be uploaded in two ways:

*   Manually
*   Automatically (for example through Integration hub)

To investigate the cause of the issue, users can click **View import message** on the **Review and improve** page (_see Figure 3_). If the file has been canceled or imported, click the **Log** icon on the left-hand side of the job to review the **Summary** and **Logs**. Common Issues For Both Manual and Automatic Imports 
-------------------------------------------------------

### Some or All Lines Fail to Import

#### Steps Taken

1.  The file has been uploaded
    *   Manually by navigating to **Jobs>>Import Balances/Transactions**
    *   Automatically
2.  The user has clicked **Review and Approve** for the job on the **Jobs** page.

 

#### Issue

Only some or no lines have been imported.

Click **View import message**  
Example: The error message reads Legal entity specified in the following line(s) is inactive or not available.  
_Figure 3_  
![image.png](https://static.adra.com/adra-assistant/images/ebea9f8bc601b4f385ff7dc50e356fe7.jpg)

#### Possible Cause and Solution

*   The wrong file format:
    *   Ensure that the file is tab-separated (such as .xlsx, .xls, or .txt) and not comma separated (.csv).
    *   Review the import file and compare it to the standard import template. The standard import template can be found here:
        *   For balance imports: **Balancer>>Jobs>>Import balances>>A file format description can be found here.**
        *   For transaction imports: **Balancer>>Jobs>>Import items>>A file format description can be found here.**

![image.png](https://static.adra.com/adra-assistant/images/b6db1c100ff1696d8ca0d8cd0ccfd1fe.jpg)

*   If custom imports are used, verify that the file configuration matches with the import settings in **Administration>>General settings>>Use custom import definition for balance/transaction import**. Learn more here: [Balancer General Settings](#article:kA00H000000kJ8USAU@Success-Center)
*   Deactivated legal entities:
    1.  To reactivate legal entities, navigate to **Administration>>Legal entities**

_Figure 4_  
![image.png](https://static.adra.com/adra-assistant/images/c83cbd061385397857a0aaaab705f9bd.jpg)

2.  Toggle **Show inactive legal entities** to on
3.  Click a legal entity
4.  Click **Edit legal entity**
5.  Toggle **Active** to on

*   Incorrect legal entity number
    *   Correct the file manually and/or review file generation procedures to avoid future issues

 **HELPFUL HINT**: If the file contains a header, this may cause a **Legal entity not specified in line 1** error message. This does not affect the success of the import.

Common Issues for Automatic Import
----------------------------------

If the file appears on the **Jobs** page to be **Reviewed and approved**, but should automatically be imported without the need for approval, verify the **Job automation** settings.

*   Ensure that the applicable settings are enabled and selected.
*   If RegEX is used to select the right period, ensure that the file name and RegEx code match.
*   Verify that the selected **Thresholds** are not breached. If the imported file exceeds a threshold, the file must be **Reviewed and approved.**

Learn more about **Job automation** here: [Balancer Job Automation Overview](#article:kA00H000000oOcrSAE@Success-Center)  
 

### Local Integration Hub/Adra Agent

If the import file does not appear on the **Jobs** page at all, verify that the balance or transaction file was created and placed in the correct import folder for upload. 

If the file can be found in the import folder and has not been moved to the archive, verify that the **Personal Access Token (PAT)** for the adra agent is up to date. Learn more about PAT here: [Integration Hub / Adra Agent Install & Troubleshoot](#article:kA06S00000117ijSAA@Success-Center).
