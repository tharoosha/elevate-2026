Overview
--------

Reconciliation groups are a collection of accounts with transactions that will match against each other. Reconciliation groups are created per legal entity, meaning they cannot cross legal entities. Accounts are defined within reconciliation groups and must remain unique within that legal entity. However, accounts can be added to other legal entities as matching does not occur across legal entities.  
  
The figure below shows two of the ways that rec groups can be configured. In the top group, Matcher is comparing the ledger to the bank for matches. In general terms, this represents the view of two sources matching against each other. In the bottom reconciliation group, Exp. Payable, Matcher is completing one side matching on the ledger. This example matches debit and credit on one side. Keep in mind that different organizations can have their own User-Defined Sources.  
![rec group example](https://static.adra.com/adra-assistant/images/f46b1a5d0355bfcab2a732a524f745a1.jpg)  
 

Create and Edit Reconciliation Groups
-------------------------------------

To create or edit a reconciliation group follow the steps below:

![image](https://static.adra.com/adra-assistant/images/d48df2fbb0c1f4486a05d44138f093fb.jpg)

1.  Navigate to **Matcher>>Administration>>Reconciliation Groups**.
2.  Select the legal entity.
3.  Click New Reconciliation Group. To edit an existing group, click the reconciliation group.

  
The **Edit Reconciliation Group** page is identical to the **New Reconciliation Group** page except for the addition of Advanced Options. The **Reconciliation group name, Accounts, and Reconciliation settings** portions operate the same regardless of whether they are created as new or edited.

Below is a walkthrough of the Edit Reconciliation Group page with the information filled in as an example.   
  
![Enter Group Name and Add Accounts](https://static.adra.com/adra-assistant/images/68132b8a9272cb3d2175f6279e33c222.jpg)

1.  **Reconciliation group name** \- Enter the name of the reconciliation group.
2.  **S****ource 1** - Designate Source 1 only for one sone-sidehing. To match across two sources, designate both Source 1 and Source 2. Once Source 1 is designated, an account or accounts will need to be added. While these default to Ledger and Bank, admins can select from their previously created User-Defined Sources from each drop-down.
3.  **Add Account** - Click **+Add Account** to generate a popup to input the account number and the starting balance if needed. Additionally, if the account is unique the admin should check the box for **This account number is unique across all legal entities.** Note - setting a starting balance can only be manually entered when adding a new reconciliation group and is not a requirement. If balances are present within your import, the system will pull that balance information from the import.
    *   There is no limit to the number of accounts that can be added to a source if applicable to the match scenario.

![image.png](https://static.adra.com/adra-assistant/images/04b6c6d10b300b1906a78e6c8a823571.jpg)

*   *   **Import Open Items** - Click to import the open items via an Excel file. The template can be downloaded from the blue link in the pop-up.
    *   **Add Row** - Click to add rows manually.

  
**Reconciliation Settings**  
The second half of the Edit Reconciliation Group page allows the admin to set matching guidelines for the reconciliation group.  
  
![image.png](https://static.adra.com/adra-assistant/images/7e8d0a68ce4bcee6df88e6e35252df97.jpg)

4.  **This is a** **Balancer Reconciliation Group** - Toggle On and enter **Balancer Account No.** to send balances to Balancer. Note, the **Balancer Account No**. is editable and should correspond to the number defined in Balancer. However, it does not need to match any of the account names that are defined in Matcher.
5.  **This is a foreign Reconciliation Group** - Toggle On if the currency differs from the legal entity's currency. Select a currency from the drop-down.
6.  **Use a shared set of matching rules**  - Toggle On to allow the rec group to use a set of matching rules that are shared with other rec groups. See [Matcher Shared Matching Rulesets](#article:kA06S00000117mbSAA@Success-Center) for more information.
7.  **Allow match with variance** – Allows the Administrator to set a variance amount for manual matches within the rec group. Toggle On to enter an Allowed Variance and select an account on which to insert the variance. 

![Select Variance](https://static.adra.com/adra-assistant/images/6816d1bd4727b3d4343718a29f49a691.jpg)

8.  **Suggest manual matches** - Toggle On to configure the settings for suggestive matching. See [Matcher Suggestive Manual Matching](#article:kA06S0000011RzvSAE@Success-Center) for more information.

![Allow Suggestive Matching](https://static.adra.com/adra-assistant/images/848a37272bea03b40b1b43463bde30d5.jpg)

9.  **Allow manual registration** **of transactions** - Toggle On to allow accounts within the legal entity to have transactions manually registered to them. Learn how to manually register items on the Exceptions page here.
10.  **Run automatic matching rules** \- Toggle On to trigger matching rules to run after an import of new data into Matcher, then select one of the following options:
     

*   **When data has been imported for all sources** – Matching Rules are triggered when data is imported into accounts for Source 1 AND Source 2.
    
*   **When data for one or more accounts has been imported for Source 1** – Matching Rules are triggered any time data is imported into accounts for Source 1.
    
*   **When data for one or more accounts has been imported for Source 2** – Matching Rules are triggered any time data is imported into accounts for Source 2.
    
*   **When data for one or more accounts for any source has been imported** – Matching Rules are triggered with all data imports.

![Trigger Automatic Matching Run](https://static.adra.com/adra-assistant/images/e7df943961198d138704a4b5631d86fe.jpg)

11.  **Transfer transactions to another reconciliation group** – Transfers matched or unmatched transactions to another account. These transfers can be started automatically or manually. Utilizing this feature is helpful for three-way matching**.** Toggle On, then click +Add Account Link to select the target account.

![Add Account Link](https://static.adra.com/adra-assistant/images/86420b54cca7d511f6ed1c6ce4856250.jpg)

12.  **Enable Journal Entry**  – Toggle On to enable Journal entry for the rec. group. Learn more here: [Matcher Journal Entry Settings](#article:kA06S000000YQbiSAG@Success-Center).

**Advanced Options**

These options are only available for Rec. groups where transactions have been imported.  
![image.png](https://static.adra.com/adra-assistant/images/c6853a71c7469d5683a92243f2c3551c.jpg)

13.  **Delete all transactions and reset balances to zero –** Used during implementation to clear transactions when there are a large number of imports already completed but the administrator needs to make changes to the settings. Once Matcher implementation has been completed, it is not recommended to use this feature.
14.  **Delete matched transactions with matched date equal to and earlier than** – Select a date and click **Delete matched** to remove old and obsolete historic data on and before the selected date.

**Archival Settings**

![image.png](https://static.adra.com/adra-assistant/images/f0f35453c97af57476483ae06b77709f.jpg)

15.  **Choose a custom storage period** \- Toggle **On** (blue) to configure the duration for storing reconciled items in the Matched Items tab on the **Exceptions** page. After the set number of days the, items are automatically moved to archived. This setting overrides the **Archival setting** configured in **General Settings**. 

Once all settings have been configured, click **Save**.
