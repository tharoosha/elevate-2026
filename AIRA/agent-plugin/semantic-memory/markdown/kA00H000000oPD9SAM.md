Task Manager FAQs
=================

**I would like users to be able to complete a task out of the prescribed order. How do I make that available?**

In order to allow users to complete tasks out of order use the [Task Manager Sequence Breaches](#article:kA00H000000kJ72SAE@Success-Center) functionality. 

**What does it mean if a Team is assigned to a task?**

Teams functionality with Task Manager means that any person assigned to that Team can claim a Task within the list as long as he/she holds the appropriate role permissions. For example, if I am a Preparer on the Team assigned to Month End tasks, I can claim any Task that has been assigned to a Preparer. [Task Manager Create & Manage Teams](#article:kA00H000000kJ5QSAU@Success-Center) and [Task Manager Important Terms and Concepts](#article:kA00H000000kJ5GSAU@Success-Center) are great articles to read to learn more.

**What is the difference between copying a task list from the task list page or from the library page?**

The Library is the organizational structure of Task Manager, where all tasks are created and procedures are defined. Task lists use the tasks set up in the library to execute Task Management but can be customized depending on monthly needs. Copying from the library will configure the tasks to their original settings as set in the library. Copying from the task list will retain any changes made for the unique task list from which you are copying. Read more about [Task Manager Manage the Library](#article:kA00H000000kJ5kSAE@Success-Center), [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center) or [Task Manager Create & Copy Task Lists](#article:kA00H000000kJ5zSAE@Success-Center).

**Why would I archive a task list?**

Processes change over time, a task list may no longer be relevant to a process, and archiving it helps keep the most relevant tasks available for viewing in the task grid from the Tasks page. [Task Manager Task List Overview](#article:kA00H000000kJ6YSAU@Success-Center) can teach more about how to use batch actions like archiving.

**What is the difference between sections and folders in the library?**

Folders are contained within sections. Review [Task Manager Manage the Library](#article:kA00H000000kJ5kSAE@Success-Center) for more information. 

**What is an auto-recurring task?**

A task that is repeated at a specific frequency and is not available in a Task List. This is set up when a task is created in the Library, read [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center) to learn more.

**What are sub-tasks?**

Sub-tasks are tasks linked to and completed in support of a parent task. This feature is used to group associated tasks but does not enforce an order of operations for task completion. The parent task can be completed before or after a sub-task. To learn more about parent/sub-task relationships review this article [Task Manager Create Parent and Sub-Tasks](#article:kA00H000000kJ5pSAE@Success-Center)

**Is there any way I can receive fewer emails?**

[Task Manager Automatic Reminders](#article:kA00H000000kJ64SAE@Success-Center) can teach users how to set up the frequency for reminders from Task Manager.  [Task Manager General Settings](#article:kA00H000000kJ5aSAE@Success-Center) will show how to turn off notification emails and daily to-do emails for the entire engagement.

**What is the difference between business admin, section admin, and the two System admin roles?**

Business Admins are the managers for all business tasks and have access to all parts of Task Manager. Section Admins have the same capabilities as the Business Admin, but only for their specific sections. The System Admins are responsible for Setup; creating and managing users, legal entities, security settings, fiscal years etc. To learn more, see [Task Manager Understanding User Roles and Access](#article:kA06S000000kK7vSAE@Success-Center).

**How can I make changes to multiple templates in the library at one time?**

[Task Manager Import & Export Task Template](#article:kA00H000000kJ5uSAE@Success-Center) can teach more about how to upload multiple task templates at one time.

**How do I set up the sequencing of tasks?**

Configuring sequences for tasks is done on the Task Detail page by System or Business Administrators. Users also have the ability to include already configured sequences when copying a task list. [Task Manager Configure Task Sequences](#article:kA00H000000kJ6ESAU@Success-Center) can provide more information.

**How do I create a task that is due on a specific date, not just +/- y days from zero-day?**

Users can create tasks that are due on a specific day by utilizing the auto-recurring tasks feature in the library and setting the recurrence to end after one occurrence, see Task Types in the [Task Manager Create Task Templates](#article:kA0Ua00000070phKAA@Success-Center) article. The repetition of the task can be set to end after the first occurrence, ensuring the user assigned to the task will only be requested to complete the task once.

How can I send reminders to all overdue tasks in a task list?

Users can filter an open task list on the Task lists page to find all overdue tasks and send reminders. Reminder emails can be set up from the engagement settings. [Task Manager General Settings](#article:kA00H000000kJ5aSAE@Success-Center) and [Task Manager Daily To Do Email](#article:kA00H000000kJ6sSAE@Success-Center) can teach more.

**Can I remove a user from a Team?**

It is possible to remove a user from a Team, even if the Team still has open tasks. Any tasks in open task lists assigned to the user will need to be reassigned to other users in the task list. To learn more, see [Task Manager Edit & Manage Active Tasks](#article:kA00H000000kJ6OSAU@Success-Center).

**Is it possible to copy folders between sections?**

It is possible to export task templates from one section, import it into another section, and then delete sub-folders and task templates you no longer need. Note that you still need to create folders and sub-folders in the new section.

**What is the difference between Closed and Archived?**

If you have a task list that is not to be completed for the current period, you can choose to close the task list for the current period. Note that you will not reach 100% on Completed, as they do not go through the various stages/statuses (prepared, approved, completed). Archived is the next step after Closed and you mark these task lists as Archived if they are no longer to be used. 

**How can I remove tasks from an already started task list?**

Unfortunately, it is not possible to delete a task after the task list has started. You can go to the task list and close the task, but note that you will not get 100% completed.
