Setup Currency Handling and Language Settings
=============================================

  
There are two ways to change the currency.   
  
Note that the settings in this article example are in Japanese.

   ![User-added image](https://static.adra.com/adra-assistant/images/20dfd8ab358237819e17fbe998304400.png)   **Important: In the May 2020 release Japanese currency will be handled appropriately by rounding to the nearest JPY-Yen due to no decimals in this currency. This conversion will happen when both Date/Time/Number formats on a user's details is set to** **Japanese and Operating Currency is set to JPY-Yen in Legal Entities.**  
 

Setting Currency and Language on a User Profile
-----------------------------------------------

![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/6e9ba989-6960-4118-8d91-bf4dff3019be/whlightbulbv1.png) R**ecommendations:** 

*   **Setting currency and language on a user profile will apply that setting across the entire product.** 
*   **The date/time/number format controls the currency setting. Users can set the language to a different format if desired. For example: language set to English and currency (date/time/number format) is set to Japanese Yen.**

  
1\. From **Setup**, navigate to the user's **Profile** page.

![image](https://static.adra.com/adra-assistant/images/2dc55a34ac6ab83e39731f5d994be1ee.jpg)

2\. Select **Date/Time/Number format** and **Language**.

![image](https://static.adra.com/adra-assistant/images/67692331f6a9cc7981355a5e016fad7e.jpg)

Setting Currency for Legal Entities
-----------------------------------

![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/6e9ba989-6960-4118-8d91-bf4dff3019be/whlightbulbv1.png) R**ecommendations:** 

*   **Setting currency at the legal entity level will apply those settings only to that legal entity. For example, the primary currency is English but the user has a branch that uses Japanese Yen.**
*   **Language settings have to be set on a user profile.** 

 

1\. From **Setup**, navigate to **Engagements** page.  
2\. Select engagement.  
![image](https://static.adra.com/adra-assistant/images/39f250a8b63aa9aa7517f05841b785b0.jpg)

  4. Select **Operating Currency**. 5. Click **OK**. ![image](https://static.adra.com/adra-assistant/images/dc29b9ba1369caf6d4ac1c0a3654d3cc.jpg)

Japanese Yen - Browser Key Addition
-----------------------------------------

 

   ![User-added image](https://static.adra.com/adra-assistant/images/dcc4d1f7c45fbaf27483e487b8f8a80d.png)   **Important: Once the application is setup correctly, a user must make the below browser adjustment to get Yen values to display correctly without decimals.**

### Before the key is added:

![image](https://static.adra.com/adra-assistant/images/ea80b0ad66823b1ea075fd256639b718.jpg)

### Directions to make browser adjustment:

1.   Log into **Adra**, and once in click F12. This will open the browser console. Select the **Application** tab.
2.   Under **Local Storage** select the application URL.
3.  Under the **Key** column double-click on the blank space at the end of the list. This will allow the user to edit the **Key** value. Enter **currency\_fractions\_enabled** in the field.
4.  In the associated **Value** field enter **true**.

  
![image](https://static.adra.com/adra-assistant/images/bcdcc11d981992cd6719e1c1206b6170.jpg)  
  
After the user has created this **Key**, they will need to logout of the application, and then log back in. The JPY currency values will no longer display decimal values.
