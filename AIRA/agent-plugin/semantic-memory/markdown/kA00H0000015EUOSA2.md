Overview
--------

Extra fields are used to add additional details to and assist in sorting and filtering accounts and transactions. 

*   **Account extra fields** – Adds extra columns for accounts on the **Accounts and status** page and the **Home** page.
    *   Navigate to **Accounts and status** and/or **Home** page, click **List options>>Columns>>Extra fields** on either page and enable desired field.
*   **Transaction extra fields** – and for transactions on the transaction grid on the account’s reconciliation page.
    *   Navigate to an accounts reconciliation page, click the settings icon and check the desired extra field.

Active fields are applied to all legal entities in an engagement. If an extra field is renamed or deactivated, it will affect all current and future periods.  
Extra fields can be added in two ways; individually or in bulk.  
  
 

**Add Extra Fields Individually**
---------------------------------

Navigate to **Administration>>Extra Fields**.  
![image.png](https://static.adra.com/adra-assistant/images/21717b80e31e3aa87c9b84623a94e4c5.jpg)

1.  **Enable account extra fields** – Toggle the switch to the blue position to enable extra fields for accounts.
2.  **Accounts: New extra field** – Click to create a new extra field for accounts. 
3.  **Transactions: New extra field** – Click to create a new extra field for transactions.

 

### **New Account Extra Fields**

Up to 10 extra fields can be added for accounts.  
![image.png](https://static.adra.com/adra-assistant/images/3175ef73b8f6dbad34b64c45723ef67c.jpg)  
1.    **Extra field name** – Enter the desired name for the extra field.  
2.    **Extra fields code** – Adra automatically assigns extra fields a code from CF1 to CF10. This code refers to columns in the extra fields import file.  
3.    **Active** – Toggle to deactivate or activate extra fields.  
4.    **New extra field** – Click to add the new extra field.  
  
Account details can be added in the new field in an account’s settings or in the account setting import file. Learn more about extra fields in account settings: [Balancer Account Edit Settings Page](#article:kA00H0000015ETuSAM@Success-Center).   
  

### **New Transaction Extra Fields**

This functionality enables administrators to include additional columns with information in the transaction import file.

![image.png](https://static.adra.com/adra-assistant/images/3ee0e301855e59199238ffb912f18eb0.jpg)

1.  **Name** – Enter the desired name for the extra field.
2.  **Import sequence** – Select the column location for the field in the transaction import file.The selected number in the drop-down corresponds to a column in the transaction import file. 
    *   **Example** – Sequence 1 corresponds to column K, sequence 2 corresponds to column L, and so on.  
3.  **Description** – Enter a description if needed.
4.  **Active** – Toggle to deactivate or activate extra fields.
5.  **New extra field** – Click to save the new extra field.

   

 **WARNING**: Any number of extra fields can be configured for transactions. However, more than 15 active extra fields are not recommended.

          
  

Import and Export Account Extra Fields
--------------------------------------

Note that to bulk import information into extra fields for the accounts, the extra fields must first be created [as described above](#new-account-extra-fields).

### Export

Export the extra fields file to have a complete overview of all existing accounts and corresponding extra field details, including accounts with empty extra fields.  
Navigate to **Jobs>>Other jobs**

1.  Click **Export extra fields**. The **Export extra fields** page loads.

![image.png](https://static.adra.com/adra-assistant/images/45e5ddcdf4193f9392a59dfbdfc099d7.jpg)

2.  Check the desired legal entities.
3.  Click **Export extra fields**. The **Jobs** page loads.

![image.png](https://static.adra.com/adra-assistant/images/40fb55bbd01cf7bbb0fea2dc8005a90b.jpg)

2.  Click **Download** to extract the extra fields file. Refresh the page if necessary.
3.  Update or add extra field details from column C. The first two columns show the **Legal entity code** and **Account number.**
    *   Column names (CF01, CF02, etc.) represent corresponding extra fields.

![image.png](https://static.adra.com/adra-assistant/images/5456dad7556ede949b9f6f21f5d5fb0e.jpg)

 

### Import

To update existing extra fields in bulk, navigate to **Jobs>>New jobs**.

1.  Click **Import extra fields**. The **Import extra fields** page loads.

![image.png](https://static.adra.com/adra-assistant/images/a013f6c032b6e78d01c489a62bd6a3d8.jpg)

2.  Click **A file format description can be found here** to download an extra fields template.
3.  Click **Upload file**, Locate the extra fields file and upload it.
4.  Click **Import**. The **Jobs** page loads.

![image.png](https://static.adra.com/adra-assistant/images/eca01f29c803db48638d1bf94e6a4a53.jpg)

5.  Click **Review and approve**. Refresh the page if necessary.

![image.png](https://static.adra.com/adra-assistant/images/fb9beeff6685208a02d857a0c434022d.jpg)

6.  Click **View import messages** to to review any issues with the import.
7.  Check the desired legal entities.
8.  Click **View details** to review the imported extra fields.
9.  Click **Complete Import** to import the file.

 

**Populating Accounts Extra Field**
-----------------------------------

Account details can be added in the new field in two ways:

1.  Individually on the account edit settings page.
2.  In bulk on the **Jobs** page (Learn more: [Import](#import)).

 

### **Add Extra Field Details to Individual Accounts**

1.  Navigate to **Account settings** and click an account.

![image.png](https://static.adra.com/adra-assistant/images/690f2ffdaed3e0d28849c1fd579d565e.jpg)

2.  Expand **Classification and extra fields**.
3.  Enter details in the extra fields.

 

Display Extra Fields
--------------------

  
To display a new account extra field on the **Accounts and status** and/or **Home page**, click **List options>>Columns>>Extra fields** on either page and enable desired field. Learn more about list options: [Balancer Accounts and Status Page Overview](#article:kA00H000000kJ8eSAE@Success-Center).  
  
Active transaction extra fields are available on the accounts' detail pages. Navigate to **Accounts and status**, click the **settings** icon, and check the desired extra field to display it in the transaction grid. The column names for the extra fields are accompanied by a number that indicates their location in the transaction import file (see example image below).  
![image.png](https://static.adra.com/adra-assistant/images/275d79553fae81bcbcdc474c3af48759.jpg)
