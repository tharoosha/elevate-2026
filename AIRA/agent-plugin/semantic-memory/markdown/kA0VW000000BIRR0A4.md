Adra - Onboarding & Training Recommendations for New Users and New Administrators
=================================================================================

**Overview**

The Trintech Training Team recommends its New User Learning Paths and New Admin Learning Paths for individuals getting started with Trintech products. The learning path is a curated sequence of training content designed as an entry point to get you up to speed. It combines training guides, videos, and webinar recordings to get you started.

Learning Paths are available in the [**Adra Success Center**](https://success.adra.com/s/). 

If you need assistance at any time related to the training available, contact **[training@trintech.com.](mailto:training@trintech.com)**

* * *

**Adra Balancer User**

In the [**Adra Balancer New User Learning Path**](https://success.adra.com/s/learning-plan-detail-standard?ltui__urlRecordId=a9gUa000000HE3NIAW&ltui__urlRedirect=learning-plan-detail-standard), you will learn how to:

*   complete the day-to-day operational tasks in Balancer
*   navigate the Balancer module
*   prepare, approve, and review an account

**Adra Balancer Admin**

In the **[Adra Balancer New Admin Learning Path](https://success.adra.com/s/learning-plan-detail-standard?ltui__urlRecordId=a9gUa000000HE4zIAG&ltui__urlRedirect=learning-plan-detail-standard)**, you will learn how to:

*   create, edit, and maintain the features of Balancer
*   update Account Settings and troubleshoot common issues
*   automate balance and transaction imports
*   configure Carry Forward (transfer items) and System Certify (bulk certify accounts)
*   maintain account details
*   add a new fiscal year and periods
*   add new users, add external users, and manage user access
