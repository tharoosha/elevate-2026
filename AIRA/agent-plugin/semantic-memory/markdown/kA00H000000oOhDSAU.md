Balancer Users Page Overview
============================

The Users page displays an overview of users and their roles. Click a username to manage read access or to remove, transfer, and/or copy account roles for standard users. 

To create an individual user, click **Create new user**. The **Setup>>Users>>Create new user** page loads. See [related articles](#related-articles) for more info.  
![image.png](https://static.adra.com/adra-assistant/images/294d4364b2d67a5ddc9bfddcc7abe9be.jpg)  
  
Click a users’ name to open the Balancer user page. This page allows administrators to manage legal entity access and local business admin privileges. Additionally, the user’s roles (preparer, approver and reviewer) can be removed, transferred or copied.  
  

![image](https://static.adra.com/adra-assistant/images/a1881e49a1835380e857832bc0ca18c1.jpg)

1.  **Logs** \- Click to view the user's history for auditorial purposes.
2.  **Edit user profile** - Click to view the user profile in **Setup**.
3.  **More actions** - These are also available on business admin user pages.  
    ![image](https://static.adra.com/adra-assistant/images/f4d3d5904c61ef62a1272752163edfd7.jpg) 
    *   **Remove all account roles** - Remove all account roles and remove access to all legal entities for a user.
    *   **Transfer account roles** - Move the user’s read access and account roles to another user. Legal entity access and account roles are removed for the original user.
    *   **Copy account roles** - Copy the user’s read access and account roles to another user. The original user retains legal entity access and account roles.
4.  **Complete access** \- This feature is only available for Standard users.
    *   Grant access to all existing and future legal entities - Check to automatically assign read access to all legal entities, including new ones. 
    *   Grant local business admin privileges to all existing and future legal entities - Check to automatically assign Local BA access to all legal entities, including new ones. 
    *   **Grant access to cross entity group accounts** \- Check to automatically assign read access to all cross entity group accounts, including new ones. This option is only available if cross entities have been enabled in **Settings**.
5.  **Grid settings** \- Click to manage list column visibility.
6.  **Legal entity access**
    *   **Read access** - Check the boxes in the **Read access** column to enable standard users to be granted account user roles in specified legal entities. Alternatively, check **Grant access to all** **existing and future legal entities**.
    *   **Local Business Admin** - Check the boxes in the Local BA column to provide BA privileges for specified legal entities. Alternatively, check **Grant local business admin privileges to all existing and future legal entities**. See [related articles](#related-articles) for more info.
7.  **Legal entity grid** - Click a header to sort the list in ascending or descending order.

Click **Save** to retain any updates or changes made to the user profile.  
In addition to read access, users must be assigned account roles to perform reconciliation tasks.

 **BEST PRACTICE**: User roles can be updated in bulk on the **Jobs** page. Learn more about assigning user roles: [Balancer Export & Import Account Roles](#article:kA00H000000kJAGSA2@Success-Center) and [Balancer Account Edit Settings Page](#article:kA00H0000015ETuSAM@Success-Center) .
