Task Manager Tasks Page & Locating Tasks
========================================

The **Tasks** page allows Standard users and Team admins to view tasks assigned to their team, while Administrators can view all tasks. All users can filter and sort tasks by various details.

![image](https://static.adra.com/adra-assistant/images/fae53970dd14e6f8cadf82baa835f28b.jpg)

1.  **Column headers**
    *   Click a header to sort the content in ascending or descending order.
    *   Click any **funnel** icon ![2024-06-18_14-41-51.png](https://static.adra.com/adra-assistant/images/3d2eda40b960bfba114355781e714dc8.jpg) to add filters, such as code, ZERO-day, team, and fiscal year period.
    *   Click and drag a column header to group sort tasks. 
2.  **Toggles**
    *   **Overdue** \- Toggle to on to view only overdue tasks.
    *   **Include sub-tasks** - Toggle to off to hide sub tasks.
    *   **Include archived task lists** \- Toggle to on to display archived tasks in addition to all other tasks.
3.  **Views** \- The current column setup can be saved as a personal view. Adjust the column order and toggle columns on or off as needed, then click **Views**.

![image.png](https://static.adra.com/adra-assistant/images/b3a42f783d19cf7165936061be430662.jpg)

*   **Save current view** - Click to save the current column setup.
*   **Views** \- Select a saved view to apply to the task grid.

4.  **Task grid options** \- Reset and export the grid view. Enable and disable columns.

![image.png](https://static.adra.com/adra-assistant/images/e8040548ac0d248572f54ec56655105d.jpg)

*   **Clear all filters** - Click to remove any filters applied to the list.
*   **Export to Excel** - Click to create an Excel file containing the tasks currently displayed in the task grid. The file must be downloaded from the **Jobs** page.
*   **Reset configurations** - Click to restore default column order and visibility.
*   **Columns** \- Toggle columns on or off to view more or fewer details. 
    *   Some useful columns are **Task list zero-day**, **Completed checklist items**, and **Fiscal year period**.

Cascading Filters
-----------------

Cascading filters are ones where the selection on the first filter causes the second to be limited to only those values that are now relevant. The task grid uses this cascading filtering to prevent the filters from cluttering with irrelevant data.  
  
Click the **edit** (cog-wheel) icon and toggle the desired columns On or Off. The column configurations will be retained.

![image.png](https://static.adra.com/adra-assistant/images/593f8781a11fc779750bb0cf05b949ac.jpg)  
  
Click **Add filter** or **Update filter** to display only tasks with the selected filter criteria rather than the complete list of tasks.  
Multiple filters can be applied simultaneously.  
 

Groupe Tasks in Task Grids
--------------------------

Drag a column header within the grouping field to group tasks by that column's category. Select ascending or descending sorting. For example, a user could view the task grid by **Due Date** by dragging the **Due Date** column up into the header labeled **Drag and drop here to group**. The task grid will automatically update the data to show selected as the grouping criteria.   
  
  
![image.png](https://static.adra.com/adra-assistant/images/2d92d21daa2dec84a174dd22b4d8b518.jpg)

  
Task Manager also maintains those grouping choices until the user makes a change, which is known as "persistent group and collapse when grouping tasks."  If a user decides to collapse multiple items under a specific due date, the task grid will keep those items collapsed until the user expands them again.   
  
In the example below, information on the task grid is grouped by **Task status**.  
  
![image.png](https://static.adra.com/adra-assistant/images/064153b5032b01f16e19c6961b2dc0a2.jpg)

  
The tasks grouped within a specific **Task status** can be collapsed using the arrow at the top left of each group.   
  
If the user leaves the grid at this point, this view will remain the same the next time they open the task grid. Task Manager maintains the last view set by the user even after the application has been closed. 

 **WARNING**: Users looking too quickly at the task grid may mistake a collapsed row of data (arrow pointing to the right) for no data. Be sure to expand all options.
