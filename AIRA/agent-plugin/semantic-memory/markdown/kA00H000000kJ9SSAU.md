Balancer Using Dashboards
=========================

The Dashboards provide users with a summary of the reconciliation process statuses, and aid in the month-end close process while meeting governance, risk, and compliance standards.   
They are accessible to BAs and LBAs. Administrators can enable Dashboards for standard users in **General settings**. Learn more: [Balancer General Settings](#article:kA00H000000kJ8USAU@Success-Center).  
Navigate to **Balancer>>Dashboards** and select the applicable dashboard tab.   
![image](https://static.adra.com/adra-assistant/images/aeff3b6cbe7af8f75ce6f2a00ce39a73.jpg)  
 

Account Status
--------------

The **Account status** dashboard provides a summary of the accounts’ reconciliation statuses for the selected period. It duplicates the information displayed in the **All accounts** table on the **Home** page. Learn more: [Balancer Home Page Overview](#article:kA00H000000kJ9SSAU@Success-Center) .  
![image](https://static.adra.com/adra-assistant/images/368ef751ec52e9d7126bc46ac0075b13.jpg)  
 

1.  **Legal entities and currency** – Select the legal entity and currency from the drop-downs to view data accordingly.
2.  **Status grid** – View the number of accounts in each status, grouped by the finalization stage. The total balances and absolute sum balances for each status are also displayed. Click a blue number to view the relevant accounts on the **Accounts and status** page.
3.  **Balance vs. unidentified (ABS)** – The balance sum of finalized and not finalized accounts is displayed in a bar graph. This provides close process health insight.
4.  **Status key accounts** – The distribution of key accounts across different statuses is represented using percentages.

Transaction Item Status
-----------------------

The **Transaction item status** dashboard shows a summary of transactions per status as registered by the Preparer. This allows administrators to analyze supporting and reconciling items to reduce risk across accounts and legal entities.  
![image](https://static.adra.com/adra-assistant/images/67d0e7f2074be2aaab47e4b3ff2e4b17.jpg)   
 

1.  **Legal entities and currency** – Select the legal entity and currency from the drop-downs to view data accordingly.
2.  **Sum of items** – Toggle this to display the Absolute sum of items in the aging section.
3.  **Reconciling items** – View transactions and absolute sums grouped by the selected item Status. Learn more about transaction statuses: [Balancer Working Within An Account](#article:kA00H000000oOVWSA2@Success-Center) . 
4.  **Aging** – View the number of days between the selected period end date and the transaction date, indicating the age of the transaction. 

Click any blue number to download an Excel file containing relevant transactions.   
 

User Status
-----------

The **User status** dashboard provides an overview of users' workload and reconciliation progress for their assigned accounts during the selected period. Based on this information, appropriate actions can be taken to ensure that close deadlines are met effectively.   
![image](https://static.adra.com/adra-assistant/images/0514aa553a120e55bf2b3130033676b7.jpg)   
 

1.  **Legal entities and currency** – Select the legal entity and currency from the drop-downs to view data accordingly.
2.  **User status table** – View the distribution of accounts per user based on the remaining tasks per account role. The absolute sums of unidentified and identified balances are displayed per user, and reconciliation status. Click a blue number to view the relevant accounts on the Accounts and status page.
3.  **No. of accounts and type per user** – The number of open accounts per workflow step grouped by user is represented in a bar graph.
4.  **Sum balance (ABS) vs. Sum unidentified (ABS) per user** – The absolute identified and unidentified sum for open accounts per user is represented in a bar graph. 

Finalized Status
----------------

The Finalized status dashboard provides an overview of the finalization progress for a specific period. Accounts are categorized based on their Key account and Risk rating, providing higher visibility into critical accounts. Learn more about extra fields: [Balancer Extra Fields](#article:kA00H0000015ETzSAM@Success-Center).   
The balance and unidentified absolute sum for each account are also displayed, aiding in the prioritization of remaining tasks.   
![image](https://static.adra.com/adra-assistant/images/be3fb40ef0a678ab0ed4f79df7506f66.jpg)   
 

1.  **Legal entities and currency** – Select the legal entity and currency from the drop-downs to view data accordingly.
2.  **Finalized status table** – View the distribution of accounts based on their finalized and not finalized status. Accounts are categorized by key account type and risk level rating, and corresponding sums are displayed. Click any blue number to view relevant accounts on the Accounts and status page.
3.  **Finalized status for key accounts/non key accounts** – The Key accounts and Non-key account columns in the Finalized status table are represented in a bar graph. In a healthy close process, the Key account column should reach finalized status early.
4.  **Sum balance (ABS) for not finalized and finalized accounts** – The Sum balance (ABS) column in the Finalized status table is represented in a bar graph. Towards the end of the close process, the Finalized column should increase, while the Not finalized column should decrease. 
5.  **Finalized status for low/medium/high risk accounts** – The four risk level columns in the Finalized status table are represented in a bar graph. In a healthy close process, higher risk level accounts should reach finalized status faster.
