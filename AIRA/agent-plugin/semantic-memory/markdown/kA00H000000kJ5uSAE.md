Task Manager Create Parent and Sub-Tasks
========================================

Create Parent and Sub-tasks
---------------------------

Learn how to create tasks and manage the task library: [Task Manager Library & Manual Task Creation](#article:kA00H000000kJ5kSAE@Success-Center)  
Subtasks can be added to a task to allow multiple users/teams to collaborate on the parent task.  
  
There are two options when a sub-task must be created:

1.  Create the sub-task directly on the parent task.
2.  Drag and drop an existing task on the parent task.

### Create Sub-Task Manually

![image.png](https://static.adra.com/adra-assistant/images/7b56ab32fe9324770c0c2cae0fa04c66.jpg)

1.  Navigate to **Task Manager>>Library**.
2.  Expand the applicable sections and folders.
3.  Click the **ellipsis** for the parent task. 
4.  Click **Create sub-task template**.
5.  Create the task as normal. Learn more here: [Task Manager Library & Manual Task Creation](#article:kA00H000000kJ5kSAE@Success-Center).

 

### Drag and Drop Existing Task

To make an existing task the sub-task of another existing task, grab the handle on the sub-task and drag it on top of the parent task. To move sub-task out of a parent task, grab the handle and drop it in the correct folder or section.

![image.png](https://static.adra.com/adra-assistant/images/a28aabf5953e2496197928c6bc5b19c7.jpg)  
 

### Create Sub-Tasks Using the Task Import Template

To add sub-tasks to parent tasks in bulk, use the task import template functionality. Learn more about the task import template here: [Task Manager Task Import Template](#article:kA00H000000kJ5uSAE@Success-Center).  
In the template, add the parent task ID in column Q. When necessary changes are made, import the template to the correct folder/section.  
![image.png](https://static.adra.com/adra-assistant/images/510fa60135042bedc957e68f5839b05c.jpg)  
 

Hierarchy Icons
---------------

When the new sub-task(s) have been added to the parent task, they are labeled with **hierarchy** icons as shown in the figure below.  
![image.png](https://static.adra.com/adra-assistant/images/9a354ba81b6be42da404b075ad4baaf8.jpg)  
 

Enable system-prepare
---------------------

When a task has sub-tasks, the setting **Enable system-prepare** becomes available. Enable this setting to auto-prepare the parent task when the sub-task(s) are finalized. 

![image.png](https://static.adra.com/adra-assistant/images/ad84c646b2825b285f3c201eca2a0cd3.jpg)
