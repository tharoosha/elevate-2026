Task Manager Daily To Do Email
==============================

When enabled, users receive a daily to-do email every weekday morning at 6am. This email mirrors the **Home** page, and contains assigned Task statuses, displaying overdue or upcoming tasks, and a listing of Upcoming tasks assigned to the email recipient. It also includes tasks assigned to Teams where the user is given a role as Preparer. The email allows users to stay up to date without logging into the application.

![image](https://static.adra.com/adra-assistant/images/e4c54c433d7efb17ad229124fdc1914d.jpg)  
Daily to-do emails are enabled by default.  
To disable them, navigate to **Task Manager>>Administration>>General settings** and toggle **Enable daily to-do emails** to on.
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

![image.png](https://static.adra.com/adra-assistant/images/7d901968e24f3ff36f90b59dec19f750.jpg)

 **HELPFUL HINT**: If a user is connected to multiple engagements with enabled daily to-do emails, they will receive a to-do email for each engagement.
