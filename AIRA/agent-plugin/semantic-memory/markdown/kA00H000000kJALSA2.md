Balancer Export & Import Account Roles
======================================

Export Using Jobs
-----------------

  
The Jobs function allows users to edit account settings and roles in bulk, streamlining the update process.

 **HELPFUL HINT**: Roles can be temporarily reassigned for a specific period using the **Bulk actions** feature on the **Accounts and status** page. This does not affect future periods as it does not alter the actual account settings and is therefore particularly useful for temporary and seasonal staff. 

Additionally, roles can be easily transferred from one user to another by navigating to **Administrator>>Users** and selecting the desired user. This impacts the settings and therefore future periods, and is useful for permanent or long-term changes in responsibility.

To learn more, see [Balancer Transfer or Remove User Roles](#article:kA00H000000oP13SAE@Success-Center)

Navigate to **Jobs>>Other jobs>>******E**xport account roles.**

![image.png](https://static.adra.com/adra-assistant/images/15775e01637f9be55c532ec91550b2f0.jpg)

The Export account roles window loads.

  
![image.png](https://static.adra.com/adra-assistant/images/f5929550966085a1778a3210f3a5c361.jpg)

1.  **Exclude sub accounts –** Check to create a file without sub accounts. This reduces file clutter.
2.  **Legal entities** **–** Check **Select all** or individual legal entities.
3.  **Export account roles** **–** Click to create account role file. The Jobs page loads.

![image.png](https://static.adra.com/adra-assistant/images/55af6393754be5c7abd3ddbd65e73b08.jpg)

Refresh the page if necessary. Click **Download**.  
Users will also receive an email with a link to the Jobs page when the job is completed.

 

The Account Role File
---------------------

![image.png](https://static.adra.com/adra-assistant/images/66b0a12f0474381bcea227f00887de4f.jpg)  

To edit user roles, replace or exchange user e-mails manually or by using the search and replace functionality in Excel.  
The **Main preparer/approver/reviewer** columns can only contain a single user e-mail.  
The **Co-preparer/approver/reviewer** columns can accommodate multiple user e-mails, separated by a semi-colon (;).  
Please note that the maximum number of account roles per account is 20.  
After making edits, it is recommended to save the file as a new document to preserve a backup of the previous version in case it is needed to revert the update.

  
 

Import Account Roles
--------------------

Navigate to **Jobs>>Other jobs>>Import account roles**.

#### ![image.png](https://static.adra.com/adra-assistant/images/ac0593f8e31d4471c0f7ba5bcc529f87.jpg)

*   **Template** – Click **A file format description can be found here** to download an import template.
*   **Delete roles** – Check **Delete existing account roles in accounts that are affected by the import** to remove roles for existing users that are not included in the import file. If not checked, co-user roles will be added to the existing list of roles. Main users will be replaced, as there can only be one.
*   **Upload file** – Click and locate the correct account role file.
*   **Import** – Click to complete the import.

The **Jobs** page will automatically load. Refresh the page until **Review and approve** is displayed in the **Action required** field.  
To ensure the successful import of account roles, all users must have active accounts and standard users must have read access to the relevant legal entities.  
 

  
Export and Import on the Account Settings Page
-------------------------------------------------

Optionally account roles can be exported and imported on the Account settings page.  
To export and account role file, navigate to **Administration>>Account settings>>Export>>Account roles**.  
![image.png](https://static.adra.com/adra-assistant/images/bf659164a6598526d8e9b399a9ff0741.jpg)  
 

The **Export account roles** page loads as displayed above. Follow the corresponding instructions. The file can be downloaded from the Jobs page when the job has been completed.  
  
To import an account role file, navigate to **Administration>>Account settings>>Import>>Account roles**.

![image.png](https://static.adra.com/adra-assistant/images/9496f3e3d87ffc523e1539751e403599.jpg)  
The **Import account roles** page loads as displayed above. Follow the corresponding instructions.

 **WARNING**: To apply account settings and roles changes to an already open period, run an **Update settigs and roles job** on the **Jobs** page. To learn more, see [Balancer Update Accounts Setting & Roles](#article:kA06S000000kK6sSAE@Success-Center).
