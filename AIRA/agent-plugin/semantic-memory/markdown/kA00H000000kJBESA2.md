Matcher Extra Fields
====================

Extra Fields
------------

Extra fields show additional information and allow more fields for matching.  
To access and create Extra Fields, go to **Administration>>****Extra Fields on Transactions>>+ Add New Extra Field**.  
Extra fields should be added prior to importing files as these fields will be part of the template created by the Import Wizard. 

![image.png](https://static.adra.com/adra-assistant/images/527fe323a8b3d29a2404a3e12c00d531.jpg)

After clicking **Add New Extra Field**, a new screen will appear to create the field.

![image.png](https://static.adra.com/adra-assistant/images/7e05636f380d0235699f3c2ee7c0927b.jpg)

 **BEST PRACTICE**: Select the bottom box when exporting because the Text-field is commonly used when matching.
