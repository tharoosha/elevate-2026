Balancer Troubleshooting Adra Agent Setup for Synced Folders
============================================================

Issue 
------

The following problem is encountered while using the Adra Agent wizard to create a synced folder between the company's server and Adra Balancer balance import.

1.  The access token was created successfully.
2.  The wizard does not show the engagement as an option in the dropdown.

Details
-------

1.  Access token has been created and copied.

![image](https://static.adra.com/adra-assistant/images/420990b1d1bfe3f95b2683a29cdacec1.jpg)

2.  The Adra Agent Setup Wizard is run. To learn more about the Adra agent, see [Integration Hub / Adra Agent Installation & Troubleshooting](#article:kA06S00000117ijSAA@Success-Center).
3.  The Engagement drop down does not display the Engagement.

![image](https://static.adra.com/adra-assistant/images/125f69eb9d16a9e524cf296a1ec4253b.jpg)

4.  The setup cannot be completed due to the lack of the engagement.

Resolution 
-----------

To resolve the issue, follow the steps below:

1.  **Verify Access Token Creation** \- Ensure that the access token has been correctly generated and is active. This is a crucial step for establishing a connection between the server and Adra Balance.
2.  **Check Engagement Visibility** \- If the engagement is not visible in the dropdown, verify that the user's access permissions are correctly set up in the Integration Hub. The engagement must be linked to the user's account for it to appear in the wizard.
3.  **Update Access Permissions** - If necessary, update the user's access permissions to the Integration Hub to ensure that the engagement is correctly associated with their account. This may involve coordinating with the IT department or system administrator.

![image](https://static.adra.com/adra-assistant/images/e00502b86064bb4b055297dff114561f.jpg)

4.  **Re-attempt Setup** \- After updating the permissions, re-open the Adra Agent wizard and attempt to create the synced folder again. The engagement should now appear in the dropdown menu.
5.  **Confirm Resolution** \- Once the engagement is visible and the synced folder is successfully created, confirm with the user that the issue is resolved.
