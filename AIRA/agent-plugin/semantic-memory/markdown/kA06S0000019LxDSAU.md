Balancer How to Use Variance Analysis
=====================================

The purpose of the variance analysis is to explain the variance of balances between two periods. The explanation is recorded for a balance in that point in time.

This functionality allows additional control and visibility. When accounts are prepared, an explanation of the variance is required if the threshold is exceeded. 

 **BEST PRACTICES**: The following the is the recommended way to reconcile an account that includes Variance analysis.

1.  Balances are imported manually or automatically.
2.  Perform any applicable **Carry Forward** and **System Certify** jobs.
3.  Verify that the correct accounts have been certified.
4.  Add variance explanations on the **Variance Analysis** page or on the accounts reconciliation page.
5.  Close previous period.
6.  Prepare the account.

**WARNING**: If the previous period's balance gets updated after variance explanations have been added for the current period and the account has been Prepared, the account status will revert and the variance explanation will be incorrect.  
  
Do the following: 

1.  **Remove Explanation** - Manually delete the variance explanation from the current period.
2.  **Update Variance** \- Navigate to **Jobs>>Other jobs** and run the Update variance job. 
3.  **Enter New Explanation** - Add the new variance explanation for the current period.

Enable Variance Analysis
------------------------

To enable variance analysis, navigate to **Administration>>General settings>>Certification Settings>>Enable variance analysis**

![image.png](https://static.adra.com/adra-assistant/images/64346d3b7534b80ed7d010e84702236a.jpg)

1.  **Enable variance analysis -** Toggle to On (blue).
2.  **Set threshold** \- Click to set variance analysis rules.

![image.png](https://static.adra.com/adra-assistant/images/87d06bd72e1deea2ff669320635ad2b9.jpg)

3.  **Type of comparison** - Select the type of comparison in the drop-down.

*   Period compared to prior period
*   Period compared to prior quarter
*   Period compared to this year’s opening balance
*   Period compared to same period prior year

4.  **Threshold amount** \- Enter the balance threshold.
5.  **Threshold percentag**e - Enter the percentage threshold. 

If either threshold is exceeded, an explanation is required to prepare the account.

  
 

Update Variance Analysis for Open Periods
-----------------------------------------

When the variance analysis threshold is modified in **General settings** or new balances have been updated to previous periods, the current periods' variance analysis must be updated.  
Unopened periods automatically apply the new threshold.  
Navigate to **Jobs>>New job>>Update variance analysis for accounts**.  
  
![image.png](https://static.adra.com/adra-assistant/images/a5409c42a7c6a13b571ec3f8b408cb2a.jpg)

*   **Target period** \- Select what period the threshold must be updated for.
*   **Legal entities** \- Check **Select all** or the applicable legal entities.
*   **Update** \- Click to apply the new threshold to the selected period.

Add An Explanation
------------------

If variance analysis is enabled in settings and the variance between periods within an account exceeds the threshold, the Preparer must add an explanation.  
Variance explanations can be added on the account details page or the **Variance analysis page**. If necessary, the explanations can be edited and deleted in the same locations.  
 

 **BEST PRACTICES**: Variance analysis should be added only after the very last balance update has been imported for the period. 

### Account Details Page

Navigate to **Accounts and status** and click an account that requires variance explanation.

  
![image](https://static.adra.com/adra-assistant/images/9f89169ece54fd2623da99bb7df04c7e.jpg)   
 

Click **Add variance explanation** at the bottom of the page to open the explanation pop-up.  
  
![image](https://static.adra.com/adra-assistant/images/a68763d4a7b91f8057a632c4ba9bb96b.jpg)  
Enter an explanation in the text field and click **Save**.

The account can now be prepared.

### Variance Analysis Page

The **Variance analysis** page provides an overview of all accounts and their variances from the previous period. Ensure that the correct period is selected from the drop-down in the left-side menu.  
  
![image.png](https://static.adra.com/adra-assistant/images/0bfbacfc7ac259df6a105612e137891f.jpg)

1.  **Reorder and filter columns** – Drag the headers horizontally to reorder them. Click the column header to sort the list in ascending or descending order. Click the filter icon next to the column name to select or clear a filter.
2.  **Export** – Click to download an Excel sheet containing an overview of variance analysis for all accounts. Modify the export output by sorting and filtering account lines in the grid on the Variance analysis page.
3.  **Grid view settings** – To enable or disable variance page columns, toggle the corresponding switches. Click Reset table to revert columns to their default settings. Toggle Only accounts exceeding the threshold to display accounts that require an explanation only.
4.  **Add Explanation** – Click to enter a variance explanation. Only Preparers for a given account can add an explanation. If the threshold is exceeded, the account row is shaded red and the Add Explanation displays in blue. In the pop-up, enter the explanation and click Save.

![image.png](https://static.adra.com/adra-assistant/images/cfe5faf1a88ff4546f7c8368fc6e17dd.jpg)

5.  **Go to account** – Click to go to the accounts page.
