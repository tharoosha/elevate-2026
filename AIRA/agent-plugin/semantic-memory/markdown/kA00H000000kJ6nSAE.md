Task Manager Dashboard
======================

The **Dashboard** allows users to view a summary of the tasks in Task Manager. All users can see the same information; however, their permission level determines what information they can access. Access levels are determined on the **Users** page and by enabling role limitations on the **General Settings** page. See [Related Articles](#related-articles) to learn more.

Click a numbered button on the Dashboard page to view the specified tasks on the **Tasks** page.  
  
 ![image](https://static.adra.com/adra-assistant/images/3823849e25e06d853febfeda402a6f49.jpg)  

1.  **Filters** \- Filter tasks based on Task list, Company, Department, Team, Task type, Fiscal year period. 
    *   **Include sub-tasks** - Check to include sub-tasks.
2.  **Overview panel** \- View the percentage of completed tasks along with overall task metrics. Click a task grouping to view the specific tasks on the **Tasks** page.
3.  **Task Due** - View the number of tasks per day in a color-coded bar graph. Each colour indicates the task's status. Click any bar to open the **Exceptions** page, which shows only tasks for that specific day. 
4.  **Grouping** \- Select how to group tasks. The default setting is User, which shows task statuses grouped by user. Other options include Team, Company, Department, Task Lists, and Extra Fields.
5.  **Task** **Metrics by Item/Individual** \- View tasks grouped by completion status and selected group. Click a task grouping to view the specific tasks on the **Tasks** page.

Overview Panel
--------------

The Overview panel is a comprehensive tool for Administrators, offering a consolidated view of the number of tasks within each status category. It facilitates easy access to all tasks, including those that are overdue, ensuring a smooth and organized closing process. Click a status group to view the tasks on the **Tasks** page. This feature helps to prevent oversight by allowing administrators to monitor task progress. Administrators can use the overview panel to gain insights into the different task statuses:

*   Not completed
*   Not Started
*   In Progress
*   Rejected
*   Not approved
*   Partly approved
*   Overdue
*   Completed
*   Approval not needed
*   System prepared
*   Approved
*   Closed

Task Metrics by Item/Individual
-------------------------------

This functionality enables task sorting based on predefined categories shown in the figure below. These categories, including Team, User, Company, and Department, are assigned to tasks within the **Library** and can be edited from the **Task Lists** page for started tasks. The Task list metric categorizes tasks based on their respective task lists. The final two metrics in the figure below represent extra fields, which are customized by administrators and added to the tasks in the **Library**. Learn more about extra fields: [Task Manager Extra Fields](#article:kA00H000000kJ5fSAE@Success-Center).  
Administrators can use these metrics to monitor the workload of specific teams or users, allowing for timely intervention when necessary.
