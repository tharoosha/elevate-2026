Matcher Undo Matches
====================

Undo Matched Transactions
-------------------------

1.  From the Matcher home page, navigate to **Administration**, click the drop-down, and select **Import History**.
2.  Using the drop-down menu, select the **Legal Entity** that includes the transactions to unmatch.
3.  Select **Undo matched transactions**.

  
![2024-02-23_12-31-57.png](https://static.adra.com/adra-assistant/images/ed5fa053e4f6671a088856d3c91050e3.jpg)   
  

 **HELPFUL HINT**: Undo matched transactions if imports or matching rules need to be modified.

Import Details
--------------

Clicking on the **Import Name** will generate a breakdown of the results which you can analyze if its decided matches need to be undone. This allows users to validate that the correct transactions are being unmatched.   
  
![image](https://static.adra.com/adra-assistant/images/2a7f0e5ee56b9629d0711874922f68f9.png)

 **BEST PRACTICE**: Always review the Undo Import Details before unmatching to ensure items being unmatched are correct.
