Overview
--------

Matcher’s reporting options allow administrators and users to pull data about transactions and balances. Users can run reports only for reconciliation groups to which they have access.  
Seven standard reports can be run, and each report has its own settings and options. Once reports are run, they will populate under **Finished** on the **Reports** screen. Reports are available for download for 15 days, after which the system will delete the report. 

  
**Standard Reports:**

*   Balances
*   Corrected Transactions
*   Journals
*   Matched Transactions
*   Matching Rules Efficiency
*   Open Transactions
*   Open Transactions Bank
*   Daily Reconciliations

Create a Report
---------------

Follow the steps below to generate a report:  
 ![image.png](https://static.adra.com/adra-assistant/images/1b85a6cd7b38a2f041ec7d0e045bbe19.jpg)

1.  Navigate to **Matcher>>Reports**.
2.  Click **New Report**. 

The Generate **New Report** page opens. 

![image.png](https://static.adra.com/adra-assistant/images/8750d9d05a3b31e5ef488ff5e87b23b0.jpg)

3.  Select the report type. After selecting a report, the report generation options that match the selected report display.
    

![image.png](https://static.adra.com/adra-assistant/images/473174c27f13bfda132d2066f2d00956.jpg)

4.  Select Legal entities or Reconciliation groups to include.
    

The following sections explain each report type and their individual settings.   
  
  
 

### Balances Report

A Balances report shows summaries for the selected legal entities and the accounts within those entities. It includes information on the unmatched transactions and how many open transactions remain per account. This report helps summarize the remaining exceptions.   
 ![image.png](https://static.adra.com/adra-assistant/images/bd0b517a7d60b0ea0e4449810f95083b.jpg)

*   **Historical report** – Toggle Historical report to On, then select the type of historical report: 
    *   **Per Date** - Transactions that were open on or before the specified date.  
        **Vdate/Bdate** - Currently open transactions that have a Vdate/Bdate on or before the selected date.   
        **Period** - Transactions that were open in the selected period.
*   **Report format** – Select PDF, XLSX, or DOCX.

  
The figure below shows an example of a Balances report run for multiple legal entities and reconciliation groups.   
   
![Balances Report: Generates a report of account balances](https://static.adra.com/adra-assistant/images/a95b76a85d50d1c9add86db35a76f770.png)

  
  
 

### Corrected Transactions Report  

The Corrected Transactions report shows a summary of data for transactions that have been corrected. Unlike the other standard reports, the Corrected Transactions report shows information by variance type.

![image.png](https://static.adra.com/adra-assistant/images/9696837868c9a3d19b7679244bf1391e.jpg)

*   **Variance Type**
    *   **Diff** – The matched transactions had minor variations but were reconciled completely with no lingering open items.
    *   **Split** – The matched transactions had minor variations, and the variance was separated, resulting in an outstanding open item that requires further attention.
*   **Sort Data** – Enable to Sort data by Amount, ABS(amount), BDate, VDate, Comment, Reference or Text. Check **Enable secondary sort** to add additional sorting.
*   **Report format** – Select PDF, XLSX, or DOCX.

The **Corrected Transactions** report shows a summary of data for transactions that have been corrected through a split and/or diff.

![Corrected Transactions](https://static.adra.com/adra-assistant/images/cf16ef95345c077ae2707ef7bc9323d5.png)  
 

### Journals Report

This option is only available if the Journal Entry application is enabled for the engagement.

The **Journals Report** includes journal entries with the status **Ready to Post** from Matcher, Balancer, and Journal Entry.  
To create a journal entry report select **Journals** as the report type.

  ![image.png](https://static.adra.com/adra-assistant/images/daa881f6ba6d8a284e6c76324fa922ba.jpg)

*   **Mark journals as exported** - Toggle to on (blue) to mark the journals as exported. Once marked as exported, these journals cannot be exported again from the **Exceptions** page or the **Reports** page. Turn the toggle to off to allow the journals to be exported again later.
*   **Report format** - Select PDF, XLSX or DOXC as the file type. The report can be downloaded directly from the **Reports** page, unlike the export option on the **Exceptions** page.

The figure below shows an example of the Journals report as exported from the Reports page.

![image.png](https://static.adra.com/adra-assistant/images/5ced1985425f62a4b3da064392d5090e.jpg)

 **HELPFUL HINT**: Journal entries can also be exported from the **Journals** tab on the **Exceptions** page. The advantage of the Journals report is that administrators can create recurring report templates. Additionally, the report allows entries to remain in the ready-for-export status, so they can be included in reports multiple times.

### Matched Transactions Report

The **Matched Transactions** report shows detailed information regarding transactions that have been matched together for a specific reconciliation group.

![image.png](https://static.adra.com/adra-assistant/images/8ac0b78f749368c9b82d7f8b4e9b0cbd.jpg)

*   **Matched data** – Select the date range for including matched transactions in the report. Transaction data can include matches made up to 90 days prior to the date the report is run.
*   **Sort data** – Enable to sort data by Amount, BDate, Matched ID (desc), ABS(Amount), BDate, VDate, Comment, Reference, and Text. Check **Enable secondary sort** to add additional sorting. Matched ID groups matched transactions in the report.
*   **Report format** – Select PDF, XLSX, or DOCX.

  
The figure below shows an example of a Matched Transactions report.

 ![image.png](https://static.adra.com/adra-assistant/images/af4548d5906a33f71e74a67b30fbeb5f.jpg)

### Matching Rules Efficiency

The **Matching Rules Efficiency** report shows how effective the matching rules were for a selected legal entity or reconciliation group during a specific time period. 

The report is used to evaluate the health and effectiveness of all matching rules within the last 90 days. It helps identify underperforming rules, offering insights to refine or deactivate them, ultimately improving overall match rates and reconciliation efficiency.

![image](https://static.adra.com/adra-assistant/images/5ff7a9f2fda22e366c288df2ba74c813.jpg)

*   **Matched date** - Select the time period or the specific day to create the report for.
*   **Export only rules with matches** - Toggle to on to only include rules that had successful matches.

The figure below shows an example of the Matching Rule Efficiency report run for one reconciliation group.  
The report shows the number of transactions processed by each rule, the number of matches, and the match percentage. 

![image](https://static.adra.com/adra-assistant/images/a77cebb6af72308a9b4e8379468e3018.jpg)   
 

### Open Transactions Reports

The **Open Transactions** and **Open Transactions Bank** reports are similar to the **Balances** report, showing the sum of unmatched transactions for a particular reconciliation group. However, the Open Transactions and Open Transactions Bank reports also include detailed information about the unmatched transactions. This information can be sorted by Amount, Date, Reference, etc. If needed, a secondary sort can be enabled.

![image.png](https://static.adra.com/adra-assistant/images/eb0cc6a02878690e14b578d5b9855208.jpg)

*   **Select variance type**
    *   **Diff** – The matched transactions had minor variations but were reconciled completely with no lingering open items.
    *   **Split** – The matched transactions had minor variations, and the variance was separated, resulting in an outstanding open item that requires further attention.
*   **Sort data** – Enable to Sort data by Amount, ABS(amount), BDate, VDate, Comment, Reference or Text. Check **Enable secondary sort** to add additional sorting.
*   **Report format** – Select PDF, XLSX, or DOCX

The figure below shows an example of an Open transactions report run for multiple legal entities and reconciliation groups.   
 ![image.png](https://static.adra.com/adra-assistant/images/0d7b63381a4742be4e38d10e713e5906.jpg)
