Balancer Journal Entry
======================

 **HELPFUL HINT**: Adra Journal Entry is a new module that will be generally available to customers in April 2025. If you’d like to be an early adopter, please contact your account manager.

The Adra Journal Entry application enhances financial processes by automating journal entries, and centralizing audit documentation to streamline compliance. It eliminates the need for manual work by integrating with ERP systems 

To create journal entries in Balancer, do the following:

![image](https://static.adra.com/adra-assistant/images/5e20a895c61c6ea1f02727b776d99173.jpg)

1.  Navigate to the **Accounts and status** page and select an account
    *   The account must have the status not prepared, and the current user must be a preparer

![image](https://static.adra.com/adra-assistant/images/f666b5f8984679de43508aa7d5a54d9b.jpg)

2.  Click **Journal entry>>****New Journal**
    *   The **Existing journals** functionality will be available at a later date

![image](https://static.adra.com/adra-assistant/images/33c56bcd61e194834170a4848f2b6475.jpg)

3.  Add entry **Description**
4.  Select **Journal date**
5.  Select entry **Period**
6.  Add journal entry details. All fields are edited manually.  
    *   Click **Delete** to remove an entry
7.  Click + **Add row** to add additional lines
    *   The journal entry can only be saved if the credit and debit difference is zero. 

3.  Add additional comments if applicable
4.  Click **Create**

![image](https://static.adra.com/adra-assistant/images/9441aada95830999d3749ba33f90c9cb.jpg)

10.  The entry appears as a comment in the account. Copy the link into your browser's address bar to go directly to the entry's edit page. 

To view, edit, and export the entry, go to the **Journal Entries** page in **Journal entry**. To learn more, see [Journal Entry - Journal Entries Page](#article:kA0Ua0000004XOnKAM@Success-Center).
