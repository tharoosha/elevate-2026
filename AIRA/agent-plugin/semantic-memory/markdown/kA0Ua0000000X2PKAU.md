Setup Organization Settings
===========================

The **Organization** page allows organization administrators to do the following:

*   **Organization details** \- View and manage organization settings
*   **Organization administrator** \- Add and remove internal and external organization administrators
*   **Engagements** \- View and manage engagements
*   **Security** \- Manage Organization security settings
*   **Audit trails** - View Organization audit trails.

Below is an overview of each **Organization** page tab.  
 

Organization Details
--------------------

![image-20220426-185238.png](https://static.adra.com/adra-assistant/images/0da22f57b6a18c9c9674c1310652794c.jpg)

*   **Create engagements -** Allows an organization admin to create engagements.
*   **Language and Time zone** - When language and Time zone is selected for the organization, the same settings are applied to the legal entities created within it. These settings can be overridden on the Engagement level and for individual users.
*   **Storage location** - Assigned by a Trintech technician and assigned to new engagements. Can be overridden by a Trintech technician.
*   **Customer ID -** Only relevant for BPO Organizations and Concern.
*   **Domain -** This feature is part of future plans related to auditor employee management.

  
Organization Administrator
-----------------------------

Organization administrators can manage all details at the organizational level and all associated engagements.  
The Organization Administrator tab allows administrators to add or remove both internal and external administrators as needed.

![image.png](https://static.adra.com/adra-assistant/images/0785816fb2c50e2d5a240a4b565630f7.jpg)

*   **Add administrator** - Click the field and select the users who should become organization administrators. Click **Add** to add them.
    *   Only users who have the organization listed as the employer can be added as an organization administrator.
*   **Add external administrator** - Enter the email address of the external administrator and click **Add**.
*   **Recycle icon** - Click to remove organization admin access for the user. Engagement access and roles remain unchanged.

See **Related Articles** to learn more.

  
Engagements
--------------

The engagements are organized hierarchically under an organization.  
The Engagement tab allows admins to view and filter all connected engagements.  
Additionally, when the BPO Organization's agreement with Adra includes the creation of engagements, BPO Admins can add engagements based on their customer's needs. See [Setup Create Engagement and Assign Engagement Admins](#article:kA06S000001DXalSAG@Success-Center) to learn more.  
![image.png](https://static.adra.com/adra-assistant/images/3a782992bde30972d3f6389ae61c0170.jpg)

  
Security
-----------

The **Security** tab allows organization admins to customize and manage idle timeout, security policy and user management.  
![image.png](https://static.adra.com/adra-assistant/images/87611c3699ac5e65f5990365c9e6c979.jpg)  
See [Setup Security for Engagements and Organizations](#article:kA0Ua0000000X2PKAU@Success-Center) to learn more.

  
Audit Trail
--------------

The **Audit trail** tab allows administrators to view all administrative changes made within the organization, such as when users are given the organization as their employer, and engagements created.  
![image.png](https://static.adra.com/adra-assistant/images/78ede425cde47bd9d79a588dc9b6d3a8.jpg)
