Adra Document Preview
=====================

Adra users now have the ability to preview documents in the Adra suite without leaving the software or disrupting workflows.

Multiple pages in Balancer support this capability, and this functionality will continue to grow across all Adra modules.

Several examples of using the document preview feature are shown below.

Hyperlinks and Drop-Down Menus
------------------------------

Links open in a separate web browser tab. However, files like Excel workbooks, Word documents, and .txt notes open on top of the Adra screen when clicking the NAME of the file, as shown in Figure 1. 

**Figure 1**

![image](https://static.adra.com/adra-assistant/images/994cb9cb529d240437668af6a0a7fd3a.jpg)

In order to open documents in a new tab, hover over the file ICON. The icon will change to a down arrow. Click the arrow to view the selection menu, as shown in Figure 2. Click **View in new tab** to ensure that the attachment opens in a new tab, not on top Adra.

**Figure 2**

![image](https://static.adra.com/adra-assistant/images/6ce185e20837c006b279de615a2282da.jpg)

Preview Options
---------------

Once opened, one-click icons provide quick access to download or open in a new tab, reducing missed actions and improving navigation during review.

**Figure 3**

1.  **Download**
2.  **View in new tab**

Bulk Actions
------------

When multiple attachments are listed in a grid, check the boxes to select the desired attachments and click **Bulk actions**. Click **View selected** to open each file / link in a separate tab.
