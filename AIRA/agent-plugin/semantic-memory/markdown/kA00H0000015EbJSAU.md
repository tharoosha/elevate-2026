Matcher FAQs
============

**How do I export unmatched transactions to Balancer?**

The exceptions page is used to export unmatched transactions to Balancer. [Matcher Export to Balancer](#article:kA00H000000kJAzSAM@Success-Center) can explain in detail all the steps required for this process.

**How do I view the percent matched for each matching rule?**

The automatic matching page will show users how to view match rates. [Matcher Automatic Matching Overview](#article:kA00H000000kJBTSA2@Success-Center) can walk through the process and offer some tips around rules.

**How do I set up fiscal years, periods, and legal entities in Matcher?**

Fiscal periods and legal entities are set up in the administration area of the product. [Matcher Fiscal Years & Periods](#article:kA00H000000kJAaSAM@Success-Center) and [Matcher Legal Entities](#article:kA06S0000019LtzSAE@Success-Center) will explain the process.

**How do I import files into Matcher?**

Import settings have to be configured before importing files to Matcher. [Matcher Importing Files](#article:kA00H000000kJAkSAM@Success-Center) can give more information on how to configure these settings. If import configurations have already been established, [Matcher Edit Import Configurations](#article:kA00H000000oOhDSAU@Success-Center) can show how to make edits.

**How do I undo an automated matching job?**

Matches can be undone in bulk. [Matcher Undo Matches](#article:kA00H000000kJApSAM@Success-Center) will explain step by step how to undo matches.

**How do I add an extra field in Matcher?**

Extra fields are used to show additional information about a transaction and can allow users to have more fields to match. [Matcher Extra Fields](#article:kA00H000000kJB9SAM@Success-Center) explains how to set up extra fields from the Administration area of the product.

**How do I create a user-defined source?**

User-defined sources can be added from within General Settings. [Matcher General Settings](#article:kA00H000000oOvjSAE@Success-Center) can explain more about how to add new system sources.

**How do I create a reconciliation group?**

Reconciliation groups are required to import transactions. [Matcher Reconciliation Groups](#article:kA00H000000kJB4SAM@Success-Center) will explain the process for adding, viewing, and editing new reconciliation groups.

**How do I create a matching rule?**

[Matcher Automatic Matching Rules](#article:kA00H000000kJBJSA2@Success-Center) will define all the fields found on the Match Rules page which is used to set up match rules. [Matcher Use Cases for Match Rules](#article:kA00H000000kJBESA2@Success-Center) provides 7 match rules scenarios that can help you understand match rules.

**What are Regular Expressions**

Regular Expressions can be used to set up match rules within Matcher. [Matcher Regular Expressions](#article:kA00H000000kJBYSA2@Success-Center) explains how to use this type of code and how it can apply to the product. Use [https://regex101.com/](https://regex101.com/) and AI to build and test RegEx code. This [RegEx handout](https://success.adra.com/s/mediaplaylist?vtui__mediaId=a7UUa00000061XhMAI) explains the RegEx code in detail.
