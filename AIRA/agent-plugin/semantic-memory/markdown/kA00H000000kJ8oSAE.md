Overview
--------

The **Accounts and status** page displays accounts for the selected period. 

The period is selected in the left-hand menu.

![image](https://static.adra.com/adra-assistant/images/7c06de870cd7da73720aa730db3b35f5.jpg)

On the **Accounts and status** page, users can do the following

*   Filter and sort accounts.
*   Export list of accounts.
*   View account status, balance, and other account details.
*   Click an account to open the account’s page and perform a reconciliation.
*   Temporarily reassign user roles.
*   Send reminders.

Navigate to **Balancer>>****Accounts and status**.    
 ![image](https://static.adra.com/adra-assistant/images/ec386ae3639ed27d11f04af97e40c585.jpg)

1.  **Period documents** \- Click to view and upload documentation for the current period. See [Balancer Period Documents](#article:kA06S00000117t8SAA@Success-Center) for more information.
2.  **Update settings and roles** \- Click to apply account settings changes to a period. This feature is only available to administrators.
3.  **Filter accounts**
    *   **Legal entity** - Select a legal entity to only view accounts in that entity.
        *   **Padlock** \- Represents whether the period is open, closed, or archived.

![image](https://static.adra.com/adra-assistant/images/e1d77a372fafbc81d5022a1deec405ad.jpg)

3.  *   **Account number** - Enter a partial account number to filter the list, or the entire account number to click go and be taken directly to the account.
    *   **Show sub accounts** \- Toggle to display any sub-accounts included in a group account.
    *   **Show accounts where I have roles** - Toggle to show only accounts where users have completed work or need to take action.
4.  **Views** \- Click to save the current column order as a view for future reference, or switch to one of the previously saved list views.
5.  **List options** - Configure, export or reset the account list.

![image](https://static.adra.com/adra-assistant/images/54e59955289b92ad6d09d0ad6f59405c.jpg)

*   **Clear all filters** - Remove any active account filters applied on the headers.
*   **Reset table** \- Restore the default column order, size, and which columns are active.
*   **Export to Excel** \- Generate an Excel file containing the account list with currently displayed columns.
*   **Columns** - Toggle any column name to show or hide them.

6.  **Account list** - View account status, balance, and additional details.
7.  **Bulk actions** \- Click to bulk approve, export, reassign roles or send reminders for selected accounts. See the Bulk Actions section in this article for more information.

Account List
------------

![image](https://static.adra.com/adra-assistant/images/ee95a5dfebda7664cc8d23e95107ab3a.jpg)

1.  **Group accounts** - Drag one or more column headers to the field above to group accounts.   
    As shown below, multiple filters create a cascading group.
    *   Click the arrow on the right side of the group to sort the content in ascending or descending order.
    *   Click the X to remove the grouping.

![image](https://static.adra.com/adra-assistant/images/73325e89634a8d6ddbf885fe399591c6.jpg)

2.  **Reorder and filter columns**
    *   Drag the headers horizontally to reorder the columns.
    *   Click a column header to sort the list in ascending or descending order.
    *   Click the **filter** icon next to the column name to select or clear a filter.

![image](https://static.adra.com/adra-assistant/images/6fcb38251dd0f00a5657253e0a6700f1.jpg)

3.  **Group accounts** \- The hierarchy icons in the account type column signify that an account is a group account or sub account. **Show sub accounts** at the top of the page must be checked to display the sub accounts.
4.  **Account status icons** - Indicate the stage of the account’s reconciliation. Hover over an icon to view more details.

![image](https://static.adra.com/adra-assistant/images/94c1491c0cd101845ec1349c8aeb88d8.jpg)

Period Documents
----------------

The period documents feature allows users to attach documents to a specific period. These documents can provide additional context for internal review or allow for efficient handover to auditors. 

Click the name of a document to preview it in a new browser tab.

![image](https://static.adra.com/adra-assistant/images/4ab4fb88720a6f8de6f8748bd9298aa9.jpg)

1.  **Drag and drop** - Drag up to five files to the upload field to import them.
2.  **Document list** - Drag a column header to the blank field above the column headers to group the documents. Click the filter icon in any of the headers to filter and sort the documents. 
3.  **Add documentation**:
    *   **Upload document(s)** - Click to open a local computer folder. Locate and select up to five files to upload.
    *   **Add link** - Click to attach a URL. Both options prompt a pop-up. 
4.  **Document list settings** - Add or remove columns in the document list view.
5.  **Action icons**:
    *   Click the **delete** icon to delete a document. 
    *   Click the **edit** icon to edit document details to edit selections made while uploading documents or adding links.
6.  **Bulk actions** - Check any period document, then click **Bulk actions** to:

*   *   **View selected** \- View selected documents in a new browser tab.
    *   **Delete selected**
    *   **Download selected**

### Upload Period Documents

The figure below shows the upload document pop-up on the left, and the add link pop-up on the right.

![image](https://static.adra.com/adra-assistant/images/3ab5fe2ec95924dde988d38f74bb80a9.jpg)

1.  **Legal entity** - Select a legal entity to attach the document(s) to.
2.  **Expansion arrow** \- Click the **expansion** arrow next to a document to add a description and modify user access.
3.  **Description** \- Enter a document description.
4.  **Specific users** - To restrict viewing privileges, click **Specific users** and click the empty field. Check the box for users who should have viewing privileges.
5.  **Upload documents(s)** - Click to finalize upload.
6.  **Add link pop-up** - Add a document link instead of a document file.

Bulk Action
-----------

The **Bulk action** feature, located at the bottom left of the **Accounts and status** page, allows users to select multiple accounts from the account list and perform one of the following actions. 

![image](https://static.adra.com/adra-assistant/images/4b6ff7a9e7a3b030e679528176a04bcb.jpg)

*   **Approve Selected** - Click to approve the selected accounts
    *   Only prepared accounts where the active user has a role can be approved using **Bulk action**. 
*   **Export selected** - Click to send an email with a zip file containing account reconciliation details and documentation.
*   **Reassign account roles** - Click to reassign account roles for the currently selected period temporarily.
*   **Send reminders** - Click to send a reminder to users that action is required on the accounts they are assigned.

### Bulk Approve Selected Accounts

Only accounts that have been prepared, and you have the approver role for, can be approved using this feature.

To bulk-approve accounts, follow the steps below:

1.  Select specific accounts to be approved, or all accounts in the list.

![image](https://static.adra.com/adra-assistant/images/2f440f2523ffc09be65558d915c436ce.jpg)

*   *   It can be helpful to filter the accounts on for example role and status.

2.  Click **Bulk action>>Approve** **selected**
3.  Ensure appropriate accounts are selected, and click **Certify**

****![image](https://static.adra.com/adra-assistant/images/94fb315db6dc23704b9cdaa89f1ccbe0.jpg)****

### Export Selected Accounts

The zip file with the selected accounts is sent to the active user's email. The folder must be unzipped to open the files within. 

The zip folder contains:

*   **Excel File**: An overview of the exported accounts.
*   **Folders**: Each folder contains:
    *   Documentation for each account.
    *   An Excel file with
        *   Transactions
        *   Historical and current balances
        *   Comments
        *   Account history (who prepared, approved, and reviewed the account)
        *   Account procedures and descriptions

 **HELPFUL HINT**: All accounts from multiple legal entities can be exported as a zip file on the **Jobs** page as well. This file does **not** include documentation for each account.

To learn more see [Balancer Job Export a Period](#article:INTERNAL-Adra-Balancer---Job-Export-a-Period@Success-Center).

### Temporarily Reassign Account Roles

Administrators can temporarily reassign roles per period on the **Accounts and status** page. These changes do not affect the following periods, making it ideal for managing temporary staff. To learn more, see [Balancer Transfer or Remove User Roles](#article:kA00H000000oP13SAE@Success-Center).

### Send Reminder

The send reminder functionality in Balancer allows users and administrators to send reminders to the users who are assigned the accounts selected in the account grid.  
Only the primary assignee of non-finalized accounts receives the notification by email.

![image](https://static.adra.com/adra-assistant/images/5707404c39e32693d5cccea014de83d1.jpg)

The sender can include a custom message in the Send reminder pop-up.
