Matcher Journal Entry Settings
==============================

 **HELPFUL HINT**: Adra Journal Entry is a new module that will be generally available to customers in April 2025. If you’d like to be an early adopter, please contact your account manager.

In Matcher, users can create, manage, and export journal entries.

Journal entries created in Matcher can be viewed and edited in both the Matcher and the Journal Entry applications. To learn more about the Journal entry application, see [Journal Entry - Journal Entries Page](https://trintech.lightning.force.com/articles/Knowledge_Article/Journal-Entry-Journal-Entries-Page).   
 

Dimensions for journal entries can be created in the Journal Entry application and then linked to the extra fields in Matcher. 

To learn more about Matchers extra fields, see [Matcher Extra Fields](#article:kA00H000000kJB9SAM@Success-Center).

To link the dimensions to extra fields, follow the steps below.

1.  Navigate to **Administration>>Journal Entry Settings**

![image](https://static.adra.com/adra-assistant/images/b79696fd1b346974f8c906ee6c956001.jpg)

2.  Click a dimension

![image](https://static.adra.com/adra-assistant/images/f19ca487305b2235d58808e37b83f325.jpg)

3.  Select the extra field in the drop-down
4.  Click **Save**
