Setup Users Page
================

The **Users** page in **Setup** allows Administrators to manage users tied to their engagement or organization.  
  
![image.png](https://static.adra.com/adra-assistant/images/edf70ac20eb2d5a1314553e91cca8dbe.jpg)

1.  **The Tabs**
    *   **Access** \- Displays all employees with access to 
    *   **Employees** \- 
2.  **Add users**
    *   **Create user** \- Click to create a new user. See [Setup Create New Users In Adra](#article:kA00H000000kJ5LSAU@Success-Center) to learn more.
    *   **Connect external user** - Click to add an external user already registered on the Adra platform under a different employer, such as technicians and auditors. See [Setup Connect External User](#article:kA06S000001DXbFSAW@Success-Center) to learn more.
3.  **Grid settings**
    *   **Show inactive engagements** - Toggle to display any users connected to inactive engagements (on the **Access** tab) or organizations (on the **Employees** tab)
    *   **Views** \- Click to save the current column organization or to select a previously saved view.
    *   **Settings icon** \- Click to 
        *   Clear grid view filters
        *   Reset Table
        *   Export displayed user list
        *   Activate or deactivated columns.
4.  **User grid**
    *   **Drag and drop here** \- Drag and drop a column header to group the users by the column content.
    *   **Column headers** **​​​**
        *   Click and drag column headers to reorganize the column order.
        *   Click the funnel icon to apply a column filter.
        *   Click a funnel header to sort the content in ascending or descending order.
