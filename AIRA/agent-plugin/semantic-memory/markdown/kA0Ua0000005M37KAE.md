Task Manager Ad-hoc Task
========================

In addition to creating task lists and recurring tasks from the task templates in the **Library**, users can create Ad-hoc tasks. This feature allows users to create one-off tasks outside of an existing process.

To enable Ad-hoc tasks for all users, including Standard User, navigate to **General Settings** and enable the **Enable Ad-hoc task creation for all users** setting. Otherwise, only Business Administrators can create Ad-hoc tasks.

Create Ad-hoc Task
------------------

To create an Ad-hoc task, click + Create Ad-hoc Task in the left-hand menu.

![image](https://static.adra.com/adra-assistant/images/53d01a2d193f07b318149010fd52d675.jpg)

The **Create Ad-hoc Task** popup window opens.

![image](https://static.adra.com/adra-assistant/images/89df5465c3b8b47f41749403f2235365.jpg)

1.  **Task name** - Enter a descriptive name.
2.  **Team and assignee** - Select which team the task is assigned to. The assignee can be the entire team or a specific user.
    *   Any team member, regardless of role permissions within the team, can be assigned the task.
3.  **Due date** - Select a due date if applicable.
4.  **Task list -** If applicable, choose a task list to add the task to. Ad-hoc tasks can be added to any open task list.
5.  **Description** - Enter a description of the task. This field can be edited by the task creator after the task has been created. 
6.  **Procedure** - Enter the process of how the task should be completed. This field can be edited by the task creator after the task has been created. 
7.  **Attachments** - Expand and attach supporting documents if applicable.
8.  **Checklist** - Expand to add checklist items. These items will appear as a checklist on the task, allowing them to be marked off as they are completed. 

![image](https://static.adra.com/adra-assistant/images/c297b4e122baac196c2a12489b5293e6.jpg)

1.  1.  Click **AI Generate checklist** to generate suggestions. [See this video](https://success.adra.com/s/share-playlist?vtui__p=1YrNXuhzxBh%2BvHTnwTBPt3ld697aqT3mgmSVa%2FXlTQg%2BoE%2FWCNasdSp1%2BwI%2BeF29HchQT3oYP2vGFSyqaz%2FXJOX4WXN0y3nfA626byp1mBHdD6n9SQ%2FK9gwuNOlTQWbs7UQi5fWVc%2B0%2BWjqNIUimxjdp6Hv3M9T8%2B319eTDoOYoZueMXxS6Xq1iPYTCjkOQh&iospref=web) for more information on the AI-generated checklists.
    2.  Manually enter the description of the item and click **Add to checklist** to add items.
    3.  Toggle **Checklist must be completed before the task can be prepared** to ensure that the assigned user must check off all checklist items before the task is finalized. 

9.  **Additional information** - Expand to select the **Company** and **Department** for the task if applicable.
10.  **Extra fields** - Expand to enter details in the available extra fields if applicable.
11.  **Create Ad-hoc Task** - Click to create the Ad-hoc task.

If a task list is selected, the ad-hoc task displays on the task list. The blue flag indicates that the task is an ad-hoc task.

![image](https://static.adra.com/adra-assistant/images/4c730f50dc0c5bbae4b1eadf78b405a9.jpg)

Similarly, a blue flag on a user's Home page indicates that the task is an ad-hoc task.

![image](https://static.adra.com/adra-assistant/images/a44dc057c75e90200a423ba3d967d069.jpg)

 **HELPFUL HINT**: Ad-hoc tasks can not be included in a task sequence or have sub-tasks.

Edit Ad-hoc Tasks
-----------------

The description and procedure field can be edited by the creator of the task. 

Click the task and click **Edit Details.**

  ![image](https://static.adra.com/adra-assistant/images/f48ec1276902cbef3b40990450a34be3.jpg)

The user can then edit the fields displayed in the following fields:

*   Team
*   Preparer
*   Date
*   Company
*   Department
*   Description
*   Procedure

Delete Ad-hoc Task
------------------

If the Ad-hoc task was created by mistake, it can be deleted.

![image](https://static.adra.com/adra-assistant/images/027fac0c1c3b4fa761a7921c5a0c9f0c.jpg)

Open the Ad-hoc task and click **Delete**. 

Tasks that have been started can be restored by a Trintech technician. Reach out to Adra support for assistance.
