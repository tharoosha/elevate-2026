Matcher Shared Matching Rulesets
================================

A matching ruleset is a set of rules that can be used by more than one reconciliation group.

Create a Ruleset
----------------

To create a new Shared Ruleset:

1.  Navigate to **Matcher>>Administration>>Matching Rules**.
2.  Click the **Shared Rulesets tab**.
3.  Click **\+ New ruleset**.

![image.png](https://static.adra.com/adra-assistant/images/a5e09369e01e61f4f1e865c3db3ddaf0.jpg)

4.  Enter the ruleset name.
5.  Click **Save changes**.

![Click Save Changes](https://static.adra.com/adra-assistant/images/f45dbed954bc54c88857db1cef639999.jpg)

  
Manage Rulesets
------------------

To navigate between existing rulesets:

1.  Click the **Select a set of matching rules drop-down**.
2.  Select the **ruleset**.

![Click Drop-down](https://static.adra.com/adra-assistant/images/5b448b45c4a4cf27e142ad92887a94fb.jpg)  
 

To change the name of a ruleset:

1.  Select the **ruleset** from the drop-down. 
2.  Click **Manage ruleset**.

![Click Manage Ruleset](https://static.adra.com/adra-assistant/images/d8c4ac50597d56b48c5b43e0d2707af7.jpg)  
 

3.  Enter the ruleset name.
4.  Click **Save changes**.

![Click Save Changes](https://static.adra.com/adra-assistant/images/58dff89fe55166a435d47d685f6bb804.jpg)  
 

Add Rules to a Ruleset
----------------------

To add matching rules to a ruleset:

1.  Select the **ruleset** from the drop-down.
2.  Click **\+ New Rule**.

![Click New Rule](https://static.adra.com/adra-assistant/images/b8e3ba0b97c6d9fe08093bbcef267b5f.jpg)  
 

3.  Enter the name of the rule and select the matching details.
4.  Click **Save**.

![Enter Rule Details](https://static.adra.com/adra-assistant/images/57a49849af8f72a3d3a18cbbc143d4ef.jpg)

  
To copy matching rules from an existing ruleset:

1.  Select the **ruleset** from the drop-down.
2.  Click **\+ Copy Rules**.

![Click Copy Rules](https://static.adra.com/adra-assistant/images/6cda71170d7dacf995ed605746e38d08.jpg)  
 

3.  Select the **ruleset** from which to copy rules from the drop-down.
4.  Select the **rules** to copy.
5.  Click **Copy**.

![Click Copy](https://static.adra.com/adra-assistant/images/3f2084416520714b3867dc42b50f4190.jpg)

  
  
Add a Ruleset to a Reconciliation Group
---------------------------------------------

To add a ruleset to a reconciliation group:

1.  Navigate to **Matcher>>Administration>>Matching Rules**.
2.  Click the **Matching Rules tab**.
3.  Click the **Select reconciliation group drop-down**.
4.  Select the **reconciliation group**.

![image](https://static.adra.com/adra-assistant/images/144015eb19b37024a3b7540e538c2d7d.jpg)

5.  Click the **Select a set of matching rules drop-down**.
6.  Select a **ruleset** to be used for the reconciliation group.

![image](https://static.adra.com/adra-assistant/images/5207c2948ec5cc6015c282b66f42abd3.jpg)

  
  
For the selected reconciliation group, the rules included in the selected ruleset appear above the matching rules configured for that group. During Automatic Matching, rules in a ruleset will run prior to other matching rules.  
![image](https://static.adra.com/adra-assistant/images/95cd5e465c04c9b3ec43ffc2b7e3b17f.jpg)  
  
Note that each Reconciliation Group can only utilize one Matching Ruleset.
