Matcher Recon. Groups and Details
=================================

Recon Groups and Details
------------------------

This page will show users the activity associated to a reconciliation group including up to 3 months of data if that data has been uploaded into Matcher.

![Recon Groups and Details.jpg](https://static.adra.com/adra-assistant/images/b572b4f989fd35a0c98930ae1816fad5.jpg)

The details on this page can be customized using the filters available for each column. Two types of actions can be taken for each rec group shown in the table:

1.  **Go to Exceptions for this account -** This button will take user directly to the exceptions page for that rec group.
2.  **View Matching stats and account info -** This button will show users a pop up graph for that reconciliation groups for up to 3 months worth of data. The current period drop down allows users to change their view.
3.  **Send groups to Balancer** **\-** Allows users or administrators to send any number of groups to Balancer. 
4.  **View Send to Balancer jobs -** View a list of jobs already sent to Balancer
5.  **Gear icon -** Allows the user or administrator to toggle on and off filters
