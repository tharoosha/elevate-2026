Setup Remove User Access in Adra
================================

To prevent loss of historical data, it is not possible to delete a user within Adra. Instead, users can be deactivated, or access to applications or engagements removed.  
 

Inactivate a User
-----------------

Inactivating a user removes access to all applications.

To make a user inactive follow the steps below: 

1.  Navigate to **Setup>>Users** and click the user. 

![image.png](https://static.adra.com/adra-assistant/images/69014e6339f390497d55a5eb87ebbc36.jpg)

2.  On the **User details** tab, scroll down to **User status**.****
3.  Click **Deactivate user**. The user will no longer be able to log in to Adra.

 **HELPFUL HINT**: If the deactivation button is disabled, it is likely because the user belongs to a different employer and has been added to your engagement as an external user. To remove access, refer to option **one** in the next section.  
![image.png](https://static.adra.com/adra-assistant/images/67f044186ca4fb7a9b200725a075a310.jpg)

Application and Engagement Access
---------------------------------

If the user requires access to specific applications but not others, or needs access to other engagements, navigate to the **Access and roles** tab.   
 

**Manage engagement access:**  
This option is used to remove external users such as Auditors from an engagement.

1.  Click the **delete** icon next to a specific engagement to revoke access to it. The user will still be able to access other engagements.

**Remove application access:**

2.  Select **No access** for the applications from which the user should no longer have access. The user will still be able to access applications they have Standard user or Business admin rights assigned.

  
![image.png](https://static.adra.com/adra-assistant/images/8832770b3a57ce3f09478f1157bb5544.jpg)
