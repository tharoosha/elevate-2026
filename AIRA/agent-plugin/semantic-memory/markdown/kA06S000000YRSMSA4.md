Matcher Report Templates
========================

In Matcher, users can manually run individual reports or schedule that a report is generated automatically using a report template.

To learn more in depth about each report, see [Matcher Reports](#article:kA06S0000019Ly1SAE@Success-Center)

Create Report Template
----------------------

For reports that are run regularly, using report templates decreases the time spent manually running reports.   
To create a report template:

1.  Navigate to **Matcher>>Reports>>Report Templates**.
2.  Click **New report template**.

![new template](https://static.adra.com/adra-assistant/images/51b8cd4111aba65c14546daeaf50254d.jpg)  
 

3.  Enter the **Template Name**.
4.  Select the **report** type from the drop-down menu. Some of the following options vary based on the selected report.
5.  To use the report template, ensure that the Status is **Enabled**.

### ![image](https://static.adra.com/adra-assistant/images/d6c319f03f8b1213cc7906db63e06d6c.jpg)

###   
  
Legal Entities (For all reports):

6.  Select the **Legal Entities and Reconciliation Groups** to include in the report. Uncheck a rec group or legal entity to exclude it from the report.

![select entities](https://static.adra.com/adra-assistant/images/f9c5b64b489341a0157df5e2250717ff.jpg)

  
7\. Report Configurations
----------------------------

### Historical Reports (Reports: Balances, Open transactions, and Open transactions bank) 

To run a historical report, toggle **Historical report** to On.

*   Select the date **type** or **period**.
    *   **Per Date** - Transactions that were open on or before the specified date.
    *   **Vdate/Bdate** - Currently open transactions that have a Vdate/Bdate on or before the selected date. 
    *   **Period** \- Transactions that were open in the selected period.
*   Select the **number of days** or the **period**.

![select days](https://static.adra.com/adra-assistant/images/88659c2561a6121d287667619dd0ee85.jpg)

###   
  
Variance Type (Reports: Corrected Transactions)

Select the variance type. Note that these are mainly labels.

![select variance type](https://static.adra.com/adra-assistant/images/7145baa0fdf96375d9b575edba766fdb.jpg)'

*   **Diff** – The matched transactions had minor variations but were reconciled completely with no lingering open items.
*   **Split** – The matched transactions had minor variations, and the variance was separated, resulting in an outstanding open item that requires further attention.

  
  
 

### Matched Date (Reports: Matched Transactions and Matching Rules Efficiency)

Select the time frame for included matches.

![select match](https://static.adra.com/adra-assistant/images/e95fa09912d15726da4929bf322788db.jpg)

The Matching Rules Efficiency Report additionally has the **Export only rules with matches** toggle. 

### ![image](https://static.adra.com/adra-assistant/images/30e90f7b1914a05613310ef1f2772702.jpg)

###   
  
Sort Data (Reports: Corrected transactions, Matched transactions, Open transactions, and Open transactions bank)

To customize the order in which data is listed, toggle **Sort data** to On.

*   Select the **Primary sort** type. For example, items in the report can be sorted by **Amount** or by **Booking Date (BDate)**.

![select sort](https://static.adra.com/adra-assistant/images/3df0c20edbc7147e095a873274ab7b72.jpg)

*   To further sort the report information, check **Enable secondary sort** and select the **secondary sort** type. Note that the primary sort selection is automatically removed from the drop-down menu for the secondary sort type.

Report Format (For all reports)
----------------------------------

8.  Select the **Report format**. Reports can be run as PDF, Word, or Excel files.

![select format](https://static.adra.com/adra-assistant/images/75c3e5f07ff26e04045691bb2523fefe.jpg)  
 

9.  Under **How should the report be run?**, select when to run the report.

*   **Run manually** - All selections will be saved in the template, but the report will not run automatically.

![run manually](https://static.adra.com/adra-assistant/images/cfd68f3e85422f2f2d195cf9726fe5c0.jpg)

*   **Run daily** - Reports are run automatically on a specific day or days every week. Select the **day(s)** of the week to run the report, then select the **time or times** of the day for the report to run.

![run daily](https://static.adra.com/adra-assistant/images/d11bacf83935b78e3641bd7218e7276a.jpg)

*   **Run monthly** - Reports are run automatically on a specific date each month. Select the **day and time(s)** for the report to run. If the selected date does not occur within a given month, the report will run on the last day of the month. For example, the report runs on September 30 if the selected day is 31. 

![run monthly](https://static.adra.com/adra-assistant/images/d14ca03124e983d1d384fa24f0968850.jpg)

10.  Under **How should the report be distributed?**, determine how users can access the report.

*   **Download manually (No notification)** - Users will not receive notification when the report runs, but can access it from the **Reports** tab.

![no notification](https://static.adra.com/adra-assistant/images/73790eb11d22b6334b1e991a265cc0a4.jpg)

*   **Notify by email (Distribution list)** - When the report runs, an email is automatically sent to selected users. 

![select users](https://static.adra.com/adra-assistant/images/ffd6bce78babb8f701c185a0f4030883.jpg)

11.  Click **Save Template**.
