Setup SAML Using OKTA
=====================

**Note**: This article is under approval. Until further notice, [find the current article here](#article:old-Setup-Okta-Configuration@Success-Center). 

Okta is an application used for signing in to different applications. Administrators can configure SAML 2.0 Single Sign-On (SSO) for Adra. 

Supported features
------------------

The OKTA/Adra SAML integration supports: 

*   IdP-initiated SSO
*   SP-initiated SSO

SP-initiated SSO
----------------

1.  Navigate to [https://login.adra.com.](https://login.adra.com) The URL will depend on your configured domain. _E.g. for adratest.com the URL would be [https://login.adratest.com](https://login.adratest.com)._ 
2.  Enter your email, then click **Continue**. 

Prerequisites 
--------------

Before configuring, ensure the following steps are completed: [Prerequisites for SAML Configuration](#article:kA0VW000000BP6L0AW@Success-Center) and/or [Prerequisites for SCIM Configuration](#article:kA0VW000000BQgj0AG@Success-Center).  
  

1.  Note down the **Environment domain** configuration.
2.  Create a **Personal Access Token** for Identity API and save it.
3.  Obtain the **Adra Signing Certificate**.  

  
 

Configuration in Okta
---------------------

1.  Log in to your **Okta Organization**
2.  Navigate to **Applications**
3.  Click **Browse App Catalog** **![image](https://static.adra.com/adra-assistant/images/862b160cbae4811762ab7f3b5f4a9bdb.jpg)**
4.  **To finish the configuration, follow the steps in [Post-requisites for SAML Configuration](#article:kA0VW000000BQiL0AW@Success-Center).** 

**Frequently Asked Questions
--------------------------

**What are the supported login flows?**  
The OKTA Gallery App supports Service Provider (SP) initiated login where the user needs to start at the Adra application (e.g. Adra Balancer, Adra Task Manager) in order to log in. Using an Identity Provider (IdP) initiated login (starting from Okta and clicking on the Adra by Trintech application) takes the user to Adra Setup. From there, users can navigate to other applications to which they have access.  
  
**How can Multi-Factor Authentication (MFA) be configured in OKTA?**  
OKTA provides the capability to configure different methods of performing Multi-Factor Authentication. Okta also provides very detailed guidelines on how to configure MFA. Read [Multi-Factor Authentication](https://help.okta.com/en/prod/Content/Topics/Security/MFA.htm?cshid=ext_MFA) and/or [Setting up MFA](https://support.okta.com/help/s/setting-up-mfa-for-end-users?language=en_US) from the OKTA documentation site to learn more.
