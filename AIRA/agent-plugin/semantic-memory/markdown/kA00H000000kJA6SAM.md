Setup Password Management
=========================

Password Management
-------------------

There are multiple ways to access the **Setup** area of the product.

1.  Click **Profile** on the left-hand menu displayed under the user's name. The Setup page will display.

_Below are examples of where to find the Profile area in Task Manager, Balancer, and Matcher._

![User-added image](https://static.adra.com/adra-assistant/images/cae487f837f374577912ab1de2fe0a98.png)

2.  Click **Change Password** at the bottom of the **Profile** screen. 

  
![User-added image](https://static.adra.com/adra-assistant/images/723912f5a82cc17b0c598ab856287c02.png)  
 

3.  Enter the requested information.
4.  After information is entered, click **Change Password**.

![User-added image](https://static.adra.com/adra-assistant/images/b5d9fbaff0a5a26405b2133fe72ff021.png)

How to Reset a Password 
------------------------

 In order to reset a password:

1.  Click the **Forgot Password** link from the login page.

 ![User-added image](https://static.adra.com/adra-assistant/images/a03d07175a3ada6262c492f890719cb6.png)  
                                                                                 

2.  Enter the correct username, and select **Continue**.

 

  ![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/60a06309-a186-40a3-9b01-c17cfca555f2/whcheckmarkv1.png)  **Tips:**  If a user is locked out of a product, the account will be locked for 15 minutes. Adra has no ability to unlock an account.  
If you don’t want the program to lock its users, you can set your own password policy for the company. This is set by the system administrator in the program.   
  
After 15 minutes, the user will receive an email titled "**Set a new password"** to unlock the account.  
If the user doesn't receive this email, he/she can select **Forgot password**.

  
![User-added image](https://static.adra.com/adra-assistant/images/540c2ceeb5f178e79f4c7dc021a3bc14.png)  
 

3.  Enter the appropriate email address, the new password, and the password again to confirm. 

   
![User-added image](https://static.adra.com/adra-assistant/images/4394ab2b108cf7e99973f0997207ac45.png)  
 

4.  Click **Save**.    

 

![User-added image](https://content.screencast.com/users/TrintechTraining/folders/Adra/media/60a06309-a186-40a3-9b01-c17cfca555f2/whcheckmarkv1.png)  **Tips:**  **System Administrators have the ability to lock its users or not based on the needs of the organization. Password policies can be set for each individual organization.**
