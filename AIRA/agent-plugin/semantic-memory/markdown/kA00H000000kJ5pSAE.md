Library Overview
----------------

The Library stores all of the task templates within Task Manager, and they can be organized in several ways, which allows for customization by the organization. In the figure below, tasks are sorted by section, created in several ways addressed under the section Organizing the Library in this article.

![image.png](https://static.adra.com/adra-assistant/images/4164207a9ab732385f1659bedaae52c3.jpg)

1.  Select **Task List** or **Recurring tasks** to filter the Library and show only relevant tasks.
2.  Click **Create section** to add a new **Library** section.
3.  Use the search bar to find a specific task and several keywords to locate the item.
    *   **Example** \- If the Admin searches for "Fixed Asset," the search will return every task in the keywords versus searching "Fixed Asset Depreciation." The search bar can be particular because it searches for items in word order versus a keyword. If the task has a "-" in it like "fixed assets – close" and does not include the dash in the search, it will not return the item.
        
4.  Shows the customized list of sections. Clicking the down arrow will show the folders and sub-folders. Similarly to the above in #2, clicking the **ellipsis** will open a menu providing the option to **Copy section**, **Create a Folder**, **Create Task Templates**, **Import/Export Task Templates**, or **Import/Export Extra Fields**.
5.  Click the **edit** icon to edit the name of a section, folder, or subfolder. Click the **ellipsis** to export and import task templates and extra fields.

Use Folders and Sub-Folders to help organize the tasks. Create them using the three dots for the specified section. This will help Admins stay organized and can be customized to the organization.

  
A badge displays in the Library when an Admin

*   Copies a task template.
*   Copies or deletes a section, folder, or subfolder.

![image.png](https://static.adra.com/adra-assistant/images/25ae51cff3ed66f0b126da6c795a53de.jpg)

While the badge is displayed, other users cannot make changes to the same template, section, folder, or subfolder.  
  
A notification appears in the top left corner of the screen when an Admin:

*   Copies a task template
*   Copies or deletes a section, folder, or subfolder
*   Exports task templates or extra fields

![image.png](https://static.adra.com/adra-assistant/images/c6ab1103aeb00ad56c36262bd734a884.jpg)  
The notification indicates whether the action failed or was completed successfully.

Organizing the Library
----------------------

There are many options for organizing the Library. Each organization has varying needs based on the type and amount of tasks to manage. Because of this, the Library is meant to be configurable.  
There are many ways to organize the Library. Listed below are some recommended options for grouping tasks:

*   **Frequency**: Group tasks are due daily, weekly, monthly, quarterly, etc. Then create sub-folders to organize by category. If an organization has many tasks or companies, this is a good option that will help keep them on time.
*   **Company**: Use if there are fewer separate companies. Sub-folders might include departments or frequency.
*   **Departmenta**l: Groups tasks by department.
*   **Task Type**: Groups tasks by type, including month-end close, journal entries, Cash Recs, and Tax Checklist.

The **Library** will likely encompass a combination of these organization types. The figure below shows an example of a department combined with a frequency subfolder. There is no "right" or "wrong" way to organize the Library.  
 

![image.png](https://static.adra.com/adra-assistant/images/e6fa9358fc89aa3f71e4afb6aca5fa54.jpg)

  
To learn more about granting access to sections for individual users, see [Task Manager User Page Overview](#article:kA0Ua00000002WTKAY@Success-Center)[](#article:kA00H000000kJ5pSAE@Success-Center). This is benefitial to reduce the workload on the Business Administrators.

 **BEST PRACTICE**: To group tasks the following is considered best practice:

*   Frequency folders
    
    *   Use case: Selecting tasks across departments/legal entities, based on frequency; only one Administrator can be responsible for starting the list.
    
*    Legal entity folders
    
    *   Use case: Typically used if Administrators have many separate legal entities; they can be enriched with departments/areas etc., and frequencies.
    
*   Departmental folders
    *   Use case: Typically in use if Administrators have many and separate departments.

### Add a Subfolder

1.  Select a parent folder to create a subfolder beneath and click the three vertical dots button on the right side of the folder's listing.
2.  Select **Create subfolder.** 

![image.png](https://static.adra.com/adra-assistant/images/91aa885b315bd28ddded3080c9af8529.jpg)

3.  Name the folder in the new window that loads, and click **Add**.
