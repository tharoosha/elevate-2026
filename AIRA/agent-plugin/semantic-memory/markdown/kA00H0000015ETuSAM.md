Task Manager How to Use ZERO-day
================================

What is a ZERO-day?
-------------------

A ZERO-day is sometimes mistaken for a due date. However, ZERO-day is a reference point around which tasks are oriented. For example, the most common use of the ZERO-day is the last day of the month, as that is when bookings are closed for the period. This functionality allows users to focus on day-to-day tasks during the month, in preparation for their close. The ZERO-day for a given list could also be a quarter-end, year-end, etc. Throughout the period, admins and users know how to prioritize task completion based on the ZERO-day and the subsequent dates for each task. Scheduling ZERO-days around important dates makes it easier to copy task lists and maintain important information. Instead of having to change the date on every single task individually, users can select a new ZERO-day for the new task list, which determines which days the other tasks are due. ZERO-day should be carefully selected as all other tasks’ due dates are determined using that date.

How to orient tasks around a ZERO-day
----------------------------------------

When tasks are created in the **Library**, the **Offset ZERO-day** function is used to set how many days before or after the ZERO-day that specific task is due. Tasks with an orange negative (-) offset will be due before the set ZERO-day. Tasks with a green positive (+) offset will be due after the set ZERO-day. If the ZERO-day of a task is changed, that change is reflected in the next task list that is copied or created, even if task settings are copied from an existing task list.   
Use the **ZERO-day options** shown in the figure above when the ZERO-day falls on a non-working day. Select Push forward to move the ZERO-day to the next working day. Select Pull backwards to move the ZERO-day to the previous working day.
