Balancer Amortizations and Accrual Items
========================================

Overview
--------

Within a reconciliation, users have the ability to add schedule items. Scheduled items refer to amortizations and accruals.  
  
**Amortization** – an amount that trends toward zero  
**Accrual** – an amount that trends away from zero  
  
For example, a company may want to amortize its prepaid insurance bill over multiple periods or add an accrual for bonuses to be paid out at the end of the year. With Balancer, users can configure the line item one time, and then have it copied from period to period, automatically adjusting the amount according to how they set the schedule.  
  
To add an amortization or accrual, navigate to **Accounts and status** or **Home** and click a desired account.

 **HELPFUL HINT**: When **Accrual** and **Amortization** items have been created, they must be transferred to the next period. Users can click **Import items>>Import from prior period** on the **Account and status** page. Business Admins and Local Business Admins can navigate to **Jobs>>Other jobs>>Carry forward**.

Learn more about **Import from prior period****:** [Balancer Account Reconciliation Page Overview](#article:Balancer-TroWorking-With-An-Account@Success-Center).  
Learn more about **Carry forward**: [Balancer Carry Forward](#article:kA06S000000YQgdSAG@Success-Center).

Add Scheduled Items
-------------------

1.  Click **\+ New scheduled item** and select **Amortization** or **Accrual**.

![image](https://static.adra.com/adra-assistant/images/0a9373aeef15fbf1a8197a12d700ef6e.jpg)

2.  Add details for the scheduled item. Amortization is shown as an example below.

![image](https://static.adra.com/adra-assistant/images/644d8d0d347d434c3df8130fb25e149a.jpg)

1.  **Details** – Add date, reference number, and text if necessary. 
2.  **Amortization/Accrual** **amount** – Enter the amount to be divided.
3.  **Number of periods** – Enter the number of periods to divide the amount over.
4.  **Start in period** – Select the period in which the amortization/accrual should begin.
5.  **Amount amortized/Scheduled amount** – These fields are automatically populated. Enter the correct amount if necessary.
6.  **Add** – Click to add amortization/accrual item.

The item appears on the account reconciliation page.  
  
 

Edit Scheduled Items
--------------------

Users can edit the schedule for current and future periods by clicking the information symbol.  
![image](https://static.adra.com/adra-assistant/images/db8474b36415543c35208389b6005a95.jpg)

Export Scheduled Items
----------------------

Administrators can export scheduled items to an Excel file.   
Only scheduled accruals/amortizations that are ongoing in the selected period **OR** upcoming within the selected fiscal year are included in the file. Scheduled items that have concluded in a previous period are not included.  
To export scheduled items, follow the steps below:  
![image.png](https://static.adra.com/adra-assistant/images/38e205f50756b92c56167fc8020da4eb.jpg)

1.  Navigate to **Jobs>>Other jobs>>Export scheduled items**.

![image.png](https://static.adra.com/adra-assistant/images/d2e45552704e41f3efb367058baa4412.jpg)

2.  Select which period to export from. Only periods with  the status Open or Closed are available in the drop-down.
3.  Select whether to export **Accruals** or **Amortizations**.
4.  Check which legal entities to export from.
5.  Click **Export accruals**. The **Jobs** page loads.

 ![image.png](https://static.adra.com/adra-assistant/images/35c7a0be123c9e071af695a519343513.jpg)

6.  Click **Download** for the export job. A zip folder containing the Excel file is downloaded.

The Excel file contains details of all accruals/amortizations within the active scheduled items. The exported period is highlighted in green.
